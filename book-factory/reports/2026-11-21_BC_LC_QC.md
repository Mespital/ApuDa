## 4. 시리즈 표준으로 확정할 것 (총괄작업지시서 v1.1에 반영)

1. **조판 표준 = LC v22 구조**: 앞부분(응급·차례·바로시작) → PART별 본문 + 해당 장 바로 옆 EP → FAQ 100 → 워크북 → 근거·용어.
2. **만화 표준 = BC v29 / LC v22 양식**: EP 1편 = 2쪽(왼쪽 4컷 + 오른쪽 핵심 설명). 4컷 전부 일러스트.
3. **EP 수 = 권당 20편** (기본 10 + 심화 10). **전부 본문 해당 장 옆에.** 뒤쪽 부록에 만화 몰아넣기 금지.
4. 매 판본은 **원본 소스에서 전체 재출력.** 기존 PDF에 덧붙이기·합본 금지.
5. 판본 표기 1종, 내부 작업 메모(“근거: v12.0 본책 3쪽”) 독자용 지면에 노출 금지.
6. 출력 직전 자동 검사: HTML 태그 노출, 쪽번호, 판본 표기, 중복 쪽.
