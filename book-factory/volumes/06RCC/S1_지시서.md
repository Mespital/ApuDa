## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 우연히 찾은 혹, 어디쯤일까
1. 건강검진센터, 태수가 결과지를 받고 어리둥절 / 태수 "신장에 혹이요?" / 검진 중 우연 발견이 흔함.
2. 콩팥 의학삽화에 작은 혹 하나 / (대사 없음) / 크기·위치·모양을 먼저 봄.
3. 갈림길 그림 3갈래(작은/국소/전이, 색만) / 주치의 "어디쯤인지 정리해요" / 상황별로 선택지가 다름.
4. 지은이 태블릿에 질문 정리 / 지은 "신장 기능도 물어보자" / 신장 기능 보존이 중요한 기준.

### EP02 진단 뒤 72시간, 세 가지만
1. 태수 혼자 사는 집, 밤에 판독지를 보다 한숨 / 태수 "혼자 어쩌나" / 첫 사흘은 세 가지만.
2. 지은이 영상통화로 일정을 같이 잡음 / 지은 "아빠, 내가 예약할게" / 비뇨의학과(비뇨기종양) 예약.
3. 원무과, 지은이 판독지·영상 CD 사본 요청 / 지은 "CD도 두 장이요" / 서류는 처음부터 두 부씩.
4. 태수가 약 봉투를 늘어놓고 목록 작성 / 태수 "진통제도 적자" / 소염진통제는 신장에 부담 가능.

### EP03 판독지의 '고형'과 '낭성'
1. 진료실, 태수가 판독지 영어에 밑줄 / 태수 "솔리드가 뭐예요?" / 단어 몇 개만 알면 됨.
2. 꽉 찬 혹 단면 의학삽화 / (대사 없음) / 고형 + 조영 증강은 암 가능성.
3. 물주머니 같은 낭성 혹 의학삽화(벽 두께 다르게) / (대사 없음) / 낭성은 Bosniak 등급으로 분류.
4. 지은이 추적 영상 기록표 첫 칸을 채움 / 지은 "크기 적어 두자" / 추세가 판단에 쓰임.

### EP04 콩팥 기능도 치료의 기준
1. 채혈실, 태수가 팔을 내밈 / 간호사 "신장 기능 볼게요" / 혈액검사로 신장 기능 확인.
2. 콩팥 두 개 중 하나에 혹, 다른 하나는 건강한 의학삽화 / (대사 없음) / 남는 신장의 기능도 봄.
3. 진료실, 주치의가 혈압·당뇨 기록을 함께 봄 / 주치의 "지병도 같이 봐요" / 동반질환이 선택에 영향.
4. 태수가 혈압계로 측정 / 태수 "매일 재 볼게요" / 혈압·혈당 관리가 신장 보호.

### EP05 작은 혹, 세 가지 길
1. 진료실, 주치의가 세 갈래 그림 카드 / 주치의 "지켜보기, 태우기, 떼기" / 감시·소작·부분절제.
2. 영상검사실, 태수가 정기 CT / (대사 없음) / 감시는 정기 영상으로 크기 변화 확인.
3. 바늘로 혹을 얼리거나 태우는 개념 의학삽화(피 없음) / (대사 없음) / 소작은 작은 혹 일부에서.
4. 태수가 비교표 '내 불안' 칸에 점수 / 태수 "불안도 이유가 되죠?" / 불안도 선택에 반영할 수 있음.

### EP06 신장을 지키는 수술
1. 진료실, 콩팥 삽화에서 혹 부분만 연한 색 / 주치의 "혹만 떼는 방법" / 부분신절제는 신장 보존에 유리.
2. 같은 삽화, 콩팥 전체 연한 색 / (대사 없음) / 크거나 위치가 어려우면 근치적 신절제.
3. 병실, 간호사가 소변량 기록을 확인 / 간호사 "소변 잘 나와요" / 수술 후 소변량 확인.
4. 복도 걷기, 지은이 링거대를 밀어 줌 / 지은 "한 바퀴만 더" / 조기 보행이 회복을 도움.

### EP07 전이성 신장암의 1차 치료
1. 진료실, 종양내과 의사와 부녀, 무거운 공기 / 의사 "치료 선택지는 있습니다" / 전이가 있어도 치료는 계속.
2. 세 칸 저울 그림(위험군, 색만) / (대사 없음) / IMDC 위험군과 조직형으로 결정.
3. 항암주사실, 태수가 수액 맞으며 신문 / (대사 없음) / 면역 병용 등 범주(허가·급여 확인).
4. 지은이 원무과 비용 상담 메모 / 지은 "급여 조합도 묻자" / 처방 전 비용 확인.

### EP08 퇴원 첫 주, 소변과 열
1. 집, 지은이 며칠 같이 지내며 짐 정리 / 지은 "일주일은 내가 있을게" / 퇴원 첫 주 돌봄 계획.
2. 태수가 소변 색·양을 기록 / 태수 "색이 좀 붉네" / 육안 혈뇨·핏덩이는 연락.
3. 밤, 체온계를 보고 지은이 병원 전화 / 지은 "38.0도에 배가 부어요" / 38.0°C 이상·복부 팽만은 바로 연락.
4. 태수가 무거운 쌀포대 앞에서 멈춤 / 지은 "그건 내가 들게" / 무거운 물건은 의료진 상의 후.

### EP09 콩팥 하나로 잘 사는 법
1. 약국, 태수가 약사에게 진통제 문의 / 태수 "신장 하나예요" / 새 약은 신장 기능을 말하고 처방.
2. 식탁, 물병과 싱거운 반찬 / (대사 없음) / 충분한 수분(제한 없을 때)·균형 식사.
3. 공원 산책, 태수가 담배 대신 사탕 / 태수 "담배는 이제 끝" / 금연은 신장·재발 위험에 중요.
