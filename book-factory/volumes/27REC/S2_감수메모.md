# v0.2 (2026-11-24) — 1·2·3장 1순위 보강 + 새 장 4·5·6·7·9·10

## 1·2·3장 보강 재점검
- 중대(반영, 근거·병리): 3장 v0.1 「확인 필요」 2건(종양표지자·재조직 성질 검사)을 국가암정보센터 진단방법·NCCN 유방 전이 환자판으로 확인 → "암 없이도 오를 수 있어 단독 확정 안 함", "암은 시간이 지나며 성질이 달라질 수 있어" 한 문장씩 보강.
- 경미(반영, 정신건강의학과): 1장 "재발 소식 = 고통이 커지는 시기, 먼저 말해도 됨" 추가(NCCN Distress 환자판). 점수 기준 미기재.
- 경미(반영, 설명간호사): 2장 결과지 사본은 2차 소견에도 쓰임 + 결과 대기 불안은 흔함.

## 4장 어디로 돌아왔나
- 중대(반영, 병리·영상): "다른 장기 이차암이 드물지 않게" 빈도 표현 삭제(근거 없음), EP04 오해 문장의 "대개는 처음 암" → "처음 암일 수 있음, 검사로 구분".
- 중대(반영, 종양내과): 국소·영역 재발의 완치 목표는 "암종에 따라" 한정, 원격 재발에서 국소치료는 10장으로 연결.
- 중대(반영, 설명간호사): 자리별 응급 신호 상자 — 공통 카드 범위 안에서만, 38.0°C 포함.
- 경미(반영, 환자 P4·국문): 국소/영역/원격 표에 "먼저 물어볼 것" 칸, "전이"와 같은 말임을 표에 병기.

## 5장 다시 하는 검사
- 심각(예방 반영, 병리): 바이오마커 검사(암세포)와 유전성 검사(태어날 때부터)를 혼동하지 않게 표·문단 분리, "바이오마커 결과에서 유전성 의심 시 별도 확인 검사".
- 중대(반영, 종양내과): "모든 재발에서 다시 검사하는 것은 아님", 검사 종류는 암종·자리·이전 결과에 따라.
- 중대(반영, 근거): 국내 급여 기준 미확인 → "다르고 바뀔 수 있음 + 의료진·원무과 확인"만(근거표 확인 필요).
- 경미(반영, 환자 P2·심리): "결과가 달라짐 = 나빠짐만은 아님" 문장.
- 경미(반영, 보호자 G1): 유전상담에서 "알고 싶지 않은 가족의 마음"까지.

## 6장 첫 치료 뒤 지낸 시간도 정보다
- 심각(반영, 근거·방사선종양학): "같은 자리 방사선은 따로 상의하는 경우가 많다" 출처 미확인 → 삭제.
- 중대(반영, 종양내과): 무치료 기간 기준 수치 0, "암종·치료 종류마다 달라 담당의에게". "진행"과의 구분은 1장과 용어 통일.
- 중대(반영, 환자 P1·설명간호사): 후유증을 숨기지 않도록 "후유증이 있다 = 치료 불가 아님", 표현법(언제·어디·무엇을 할 때).
- 경미(반영, 국문): "내성" 괄호 풀이.

## 7장 영상은 괜찮은데 혈액 수치만 오를 때
- 심각(반영, 근거): "생화학적 재발" 용어 정의 출처 미열람 → 본문에서 삭제, 근거표 확인 필요.
- 중대(반영, 종양내과): 전립선 PSA 쪽 근거를 공통 원칙으로 쓸 때 "암종과 상황에 따라서는"으로 한정, 수치·배가시간·검사 이름 0.
- 중대(반영, 설명간호사): 지켜보는 동안 새 증상(새 통증·기침·체중 감소)은 바로 알리기.
- 경미(반영, 심리·환자 P3): "지켜보기 = 아무것도 안 하는 것 아님", 결과 확인하는 날 정하기.

## 9장 내 치료 이력서 만들기
- 중대(반영, 근거): "병원에서 받는 치료 요약지"가 국내에서 일반적인 것처럼 읽힘 → "병원에 따라 주기도, 없으면 직접".
- 중대(반영, 설명간호사): 약 이름·용량은 기억 대신 약 봉투·처방전 사진으로(본문에 약 이름·용량 없음).
- 경미(반영, 편집): 이력서 칸 표 + W2 연결, 모르는 칸 = 다음 질문.
- 경미(반영, 보호자 G1): 개인 건강 정보 공유 범위는 환자가 정함.

## 10장 몇 군데만 돌아왔을 때
- 심각(반영, 외과종양학): "떼어 내면 끝" 오해 정정 — 목표는 완치 시도일 수도 조절일 수도, 합병증·회복 기간 명시.

- 중대(반영, 방사선종양학·영상의학): 국소치료 종류는 출처 확인된 3가지만(냉동 삭제), "같은 자리 방사선 이력"은 고려 항목으로만 + 확인 필요.
