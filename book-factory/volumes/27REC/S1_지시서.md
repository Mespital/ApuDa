- 톤: 재발은 **"처음으로 돌아간 것"이 아니라 "이미 아는 것을 들고 다시 시작하는 30일"**이다. 책 전체의 축은 세 가지: ① **재발을 확인하는 데도 순서가 있다**(영상의 그림자 하나로 단정하지 않고, 필요하면 조직을 다시 본다 · 새 유전자 검사), ② **이번 치료의 목표를 먼저 묻는다**(완치를 다시 노리는 재발 · 오래 함께 관리하는 재발 · 편안함을 가장 앞에 두는 선택 — 모두 정당한 길), ③ **첫 치료의 경험은 자산이다**(내 치료 이력서 · 어떤 부작용이 힘들었는지 · 무엇이 나를 지탱했는지). "내가 뭘 잘못해서"라는 자책, "이제 끝"이라는 단정을 걷어 낸다. 완화의료는 마지막이 아니라 처음부터 같이 가는 팀이라는 문장을 반복한다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **응급 기준은 시리즈 공통으로.** 항암 중 발열 **38.0°C** = 해열제보다 먼저 병원 연락. 재발 부위와 관련된 공통 응급만(등·허리 통증과 함께 다리 힘 빠짐·대소변 장애 = 척수 압박 의심, 갑작스러운 심한 두통·한쪽 마비·경련, 숨참·피 섞인 가래, 배가 불러 오고 토하며 가스·변이 안 나옴, 심한 혼동·졸림 — 고칼슘혈증 등 가능, 멈추지 않는 출혈, 한쪽 다리 붓기·갑작스러운 숨참). 암종 특이 신호는 "해당 권 응급 카드"로.
2. **수치 쓰지 않기.** 재발률·생존율·"몇 년 안에 재발하면" 같은 기준 시간, 종양표지자 "몇 배 상승", 치료 반응률, 임상시험 참여 조건의 숫자, 산정특례 비율·기간은 본문에 넣지 않는다. 필요하면 "병원 일정표·결과지·공단 기준". "치료 없이 지낸 기간(무치료 기간)"은 개념으로만 — "암종마다 기준이 달라 담당의에게".
3. **약·처방 단정 금지.** 이 권은 약 이름을 쓰지 않는 것이 원칙(암종 공통). 범주(항암·표적·면역·호르몬·방사선·수술·국소치료·임상시험)까지만. 용량 미기재. 국내 허가·급여는 "변경 가능 + 의료진 확인".
4. **"완치 불가" 단정 금지.** 재발 유형(국소·영역·원격)과 암종에 따라 다시 완치를 목표로 하는 경우도 있음을 명시하되, "재발도 낫는다" 같은 효능 약속도 금지. 목표는 "담당의와 함께 정하는 것".
5. **원인 단정·탓 금지.** "스트레스·음식·운동 부족 때문에 재발" 금지. 첫 치료가 "실패"였다는 표현 금지 — "첫 치료는 그때 가장 맞는 선택이었다" 쪽으로. 대체요법으로 표준치료 대체 금지("함께 쓰려면 의료진과 상의").
6. **심리 문장은 진단 단정 금지.** "우울증입니다" 대신 "이런 날이 두 주 넘게 이어지면 전문가와 이야기해 보세요" 수준. 디스트레스 온도계는 개념만, 기준 점수 숫자는 "병원 안내 기준".
7. **사전 돌봄 계획 문장.** 사전연명의료의향서·연명의료계획서는 "개념 + 어디에 묻는지"까지, 재발 = 임종 준비라는 연결 금지. "건강할 때 미리 생각해 두는 것"으로. 법률 조언 아님.
8. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시, 종양내과·완화의료·임상심리 관점 감수 필요 표기. 참고(NCCN Distress Management · Palliative Care · Survivorship, ASCO 환자 안내, 국가암정보센터 등)는 실재·최신 판 S4 확인 후 판 번호 따로.
9. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~14·26권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(공통 카드: 항암 중 38.0°C 발열·오한 = 해열제보다 먼저 연락, 등·허리 통증 + 다리 힘 빠짐·대소변 장애 = 응급실, 갑작스러운 심한 두통·한쪽 마비·말이 어눌함·경련 = 119, 숨이 차서 말을 잇기 어려움·피 섞인 가래, 심한 혼동·졸림·심한 갈증, 배가 불러 오고 토하며 가스·변이 안 나옴, 한쪽 다리가 갑자기 붓고 아픔, 스스로를 해치고 싶은 생각 → 109·119 / 암종별 신호는 해당 권 응급 카드) · 0-2 오늘 확인할 세 가지(재발이 "확정"인지 "의심"인지 / 다음 검사·진료 날짜 / 첫 치료 기록 한 장 모으기) · 0-3 책 사용법(내 길 찾기: 아직 의심 단계 → PART 1, 확정·치료 결정 → PART 2, 오래 관리하는 재발 → 13장, 편안함을 먼저 → 14·16장) · 0-4 온라인 연결

### PART 1. 소식을 들은 첫 주 — 다시, 정확히 알기
1. "재발입니다" 앞에서 — 첫 진단 때와 다른 감정, 모두 정상 · 재발·진행·새 암(이차암)의 차이 → **EP01**
2. 소식 뒤 72시간(확정인지 의심인지 · 다음 일정 · 첫 치료 기록 모으기 · 누구에게 먼저 알릴지) → **EP02**
3. 재발을 확인하는 순서: 증상·진찰 · 영상(CT·MRI·PET-CT) · 필요하면 조직검사 다시 · 영상의 그림자만으로 단정하지 않는 이유 → **EP03**
4. 어디로 돌아왔나: 국소 재발 · 영역(림프절) 재발 · 원격 재발 — 같은 "재발"도 다른 길 → **EP04**
5. 다시 하는 검사: 조직의 성질이 바뀌었는지(호르몬 수용체·표적 유전자·NGS 등은 암종별) · 유전상담 → 심화 **EP11**
6. 첫 치료 뒤 지낸 시간도 정보다: 치료 없이 지낸 기간 · 첫 치료에 대한 반응 · 남은 부작용 → 심화 **EP12**
7. 영상은 괜찮은데 혈액 수치만 오를 때(종양표지자·생화학적 재발) — 바로 치료하지 않을 수도 있는 이유 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 이번 치료의 목표부터: 다시 완치를 노리는 재발 · 오래 함께 관리하는 재발 · 편안함을 먼저 두는 선택 → **EP05**
9. 내 치료 이력서 만들기: 진단일·병기·받은 치료·힘들었던 부작용·남은 후유증·복용 약 → **EP06**
10. 몇 군데만 돌아왔을 때: 수술·방사선·고주파 등 국소치료를 함께 상의하는 경우(소수 전이 개념) → 심화 **EP14**
11. 한 번 더 듣는 의견: 2차 소견 · 다학제 진료 · 준비할 서류(슬라이드·영상 CD·이력서) → **EP07**
12. 임상시험 문 두드리기: 찾는 곳·묻는 질문·표준치료와의 관계 · 참여는 언제든 철회 가능 → 심화 **EP15**
13. 오래 함께 가는 재발: 치료–휴식–검사가 반복되는 생활 · 치료를 바꾸는 이유 · "만성질환처럼"이라는 말의 뜻과 한계 → 심화 **EP16**
14. 덜 힘든 쪽을 고를 권리: 치료 강도 · 나이·체력·삶의 우선순위 · 치료를 쉬거나 멈추는 결정도 상의할 수 있음 → 심화 **EP17**
15. 치료 결정 대화법: 공유 의사결정 · "가장 좋은 경우·흔한 경우·나쁜 경우"를 묻기 · 결정 미루고 싶을 때
16. 완화의료는 처음부터 같이 가는 팀: 통증·숨참·잠·마음 · 외래 완화의료·가정형 호스피스의 차이(→ ㉚ PAL권) → 심화 **EP18**

### PART 3. 30일 실행 로드맵
17. Day 0–7 확인하고 모으기(확정 검사 · 첫 치료 기록 · 응급 연락처 갱신 · 가족 한 명과 공유)

2. 혈액 속 백혈구가 줄어든 개념 삽화(색만) / (대사 없음) / 두 번째 치료는 골수가 더 지쳐 있어 감염에 주의.
3. 인숙이 해열제 서랍을 닫고 휴대폰을 듦 / 인숙 "약보다 병원 전화 먼저" / 해열제가 감염 신호를 가릴 수 있음.
4. 응급실 접수대, 인숙이 치료 이력서와 항암 카드(글자 없음)를 내밂 / 인숙 "재발로 항암 중이에요" / 응급실에서 항암 중임과 이력서를 먼저 보여 주기.

### EP09 결과 기다리는 밤
1. 새벽, 형석이 잠 못 들고 거실 창가에 서 있음(창밖 가로등) / 형석 "내일 결과가 나와" / 결과를 기다리는 불안(검사 불안)은 매우 흔함.
2. 마음속 파도가 크게 일었다가 작아지는 그림(색만) / (대사 없음) / 불안은 파도처럼 오르내림 — 이름을 붙이면 조금 작아짐.
3. 상담실, 심리상담사가 마음 온도계 그림(숫자 없음)을 함께 봄 / 상담사 "잠이 계속 안 오면 알려요" / 잠·식사·일상이 두 주 넘게 흔들리면 전문가와 상의.
4. 아침, 인숙이 형석에게 따뜻한 보리차를 건네고 둘이 웃음 / 인숙 "같이 듣고 같이 정하자" / 결과는 혼자 듣지 않기 — 함께 갈 사람 정하기.

### EP10 가족에게 다시 말하기
1. 주말 거실, 형석이 손주 사진 액자를 만지작(사진 속 얼굴 흐림) / 형석 "애들한테 또 말해야 하나" / 다시 알리는 일은 처음보다 더 어렵게 느껴질 수 있음.
2. 식탁에 둘러앉은 가족 실루엣, 가운데 촛불 하나(색만) / (대사 없음) / 누구에게·어디까지·언제 알릴지는 환자가 정함.
3. 시우가 아버지 어깨에 손을 얹음 / 시우 "저한테는 다 말해 줘요" / 가족이 원하는 정보의 양도 사람마다 다름 — 물어보기.
4. 관리사무소, 형석이 동료(측면)에게 일정표를 건넴 / 형석 "치료 날은 부탁해요" / 직장에는 일정 조정에 필요한 만큼만 알려도 됨.

### EP11 (심화) 암도 성질이 바뀔 수 있어요
1. 외래 대기실, 경란이 조율 공구 가방을 무릎에 두고 형석 옆에 앉음 / 경란 "저는 조직검사를 다시 했어요" / 재발한 암은 처음과 성질이 다를 수 있음.
2. 같은 모양의 열쇠가 조금 다른 자물쇠에 맞춰지는 개념 그림(색만) / (대사 없음) / 호르몬 수용체·표적 유전자 등을 다시 보면 맞는 약이 달라질 수 있음.
3. 진료실, 주치의가 검사 종류 그림 카드(글자 없음)를 넘김 / 주치의 "어떤 검사가 필요한지 볼게요" / 다시 할 검사는 암종·부위·이전 결과에 따라 다름.
4. 형석이 이력서의 "검사" 칸에 새 줄을 그음 / 형석 "결과 나오면 여기 적자" / 새 검사 결과는 이력서에 날짜와 함께 추가.

### EP12 (심화) 치료 없이 지낸 시간도 정보
1. 진료실, 주치의가 형석의 이력서 달력 칸을 손가락으로 따라감(숫자 없음) / 주치의 "그동안 잘 지내셨네요" / 첫 치료 뒤 치료 없이 지낸 기간은 다음 치료 선택의 단서.
2. 긴 다리 위 쉼표 같은 쉼터들이 놓인 그림(색만) / (대사 없음) / 첫 치료에 대한 반응·지낸 시간·남은 부작용이 함께 쓰임.
3. 형석이 놀란 얼굴로 묻는 장면 / 형석 "같은 약을 또 쓸 수도 있어요?" / 암종과 지낸 시간에 따라 이전 약을 다시 쓰기도, 바꾸기도 함.
4. 인숙이 수첩에 질문을 적음 / 인숙 "기준은 우리 병마다 다르대" / 기간 기준은 암종마다 달라 담당의에게 직접 묻기.

### EP13 (심화) 수치만 올랐을 때
1. 외래, 형석이 혈액검사 결과지를 보고 불안한 얼굴(숫자 흐림) / 형석 "영상은 괜찮은데 수치가…" / 종양표지자만 오르는 경우가 있음.
2. 저울 한쪽에 피검사 병, 다른 쪽에 영상·증상 그림(글자 없음) — 저울이 기울지 않음 / (대사 없음) / 수치 하나로 재발을 확정하거나 바로 치료하지 않을 수도 있음.
3. 주치의가 달력에 다시 보는 날 칸을 표시(숫자 없음) / 주치의 "간격을 두고 다시 봐요" / 추이·영상·증상을 함께 보고 결정.
4. 형석과 인숙이 동네 공원을 걷는 뒷모습 / 인숙 "숫자에 하루 다 쓰지 말자" / 기다리는 동안 일상 지키기, 새 증상은 바로 알리기.

### EP14 (심화) 몇 군데만 돌아왔다면
1. 다학제 설명실, 형석이 외과·방사선종양학과 의사 그림(측면, 글자 없음)이 붙은 안내판을 봄 / 형석 "수술로 뗄 수도 있대요?" / 몇 군데만 돌아온 경우 국소치료를 함께 상의하기도 함.
2. 폐에 작은 점 두 개를 정밀한 빛줄기(방사선)·작은 가위(수술) 아이콘 대신 부드러운 개념 삽화로(색만) / (대사 없음) / 수술·방사선·고주파 등 방법은 자리·개수·몸 상태로 고름.
3. 주치의가 전신 치료 약병 그림과 국소치료 그림을 나란히 둠 / 주치의 "전신 치료와 같이 봐요" / 국소치료만 할지, 전신 치료와 함께할지는 다학제 결정.
4. 형석이 이력서에 질문 세 개를 적음(글자 흐림) / 형석 "장점과 부담, 둘 다 묻자" / 국소치료의 기대와 부담, 회복 기간을 함께 묻기.

### EP15 (심화) 임상시험 문 두드리기
1. 임상시험 상담실, 코디네이터가 도윤 부부에게 안내 그림 카드(글자 없음)를 건넴 / 도윤 "실험 대상이 되는 거예요?" / 임상시험은 정해진 기준과 보호 장치 아래 진행.
2. 문 여러 개가 있는 복도, 몇 문에 열쇠 구멍 빛(색만) / (대사 없음) / 참여 조건은 시험마다 달라 맞는 시험이 없을 수도 있음.
3. 코디네이터가 동의서(글자 흐림)를 가리킴 / 코디네이터 "언제든 그만둘 수 있어요" / 참여 중에도 언제든 철회할 수 있음.
4. 집, 도윤이 아들(측면)을 안고 노트북 질문 목록을 봄 / 도윤 "비용과 일정도 물어볼게" / 표준치료와의 차이·비용·방문 일정을 미리 묻기.

### EP16 (심화) 오래 함께 가는 재발
1. 경란의 작업실, 경란이 피아노 조율을 하고 있음(약 봉투가 선반에 놓임, 상표 없음) / 경란 "치료하면서 일도 해요" / 일부 재발은 치료를 바꿔 가며 오래 관리함.
2. 긴 강변길에 쉼터·다리·갈림길이 이어진 그림(색만) / (대사 없음) / 치료–휴식–검사가 반복되며 약이 바뀌는 것은 실패가 아님.
3. 외래, 경란이 형석에게 일정 수첩을 보여 줌 / 경란 "치료 바뀌는 날도 있어요" / 약을 바꾸는 이유는 효과·부작용·생활을 함께 본 결정.
4. 경란이 공구 가방을 들고 외출, 현관 창가 화분 / 경란 "오늘 할 일부터 해요" / "만성질환처럼"이라는 말은 사람마다 뜻이 달라 담당의에게 확인.

### EP17 (심화) 덜 힘든 쪽을 고를 권리
1. 진료실, 순례가 지팡이를 짚고 딸(측면)과 앉음 / 순례 "힘든 치료는 이제 싫어요" / 치료 강도는 나이·체력·삶의 우선순위로 함께 정함.
2. 저울 한쪽에 약병, 다른 쪽에 손뜨개·찬송가 악보(글자 없음)·손녀 그림 / (대사 없음) / 치료의 이득과 부담을 내 삶의 무게와 함께 재기.
3. 주치의가 순례의 손을 잡고 고개를 끄덕임 / 주치의 "그 선택도 함께 지켜요" / 치료를 줄이거나 쉬는 결정도 의료진과 상의할 수 있음.
4. 시골집 마루, 순례가 딸과 숄을 함께 덮고 햇볕을 쬠 / 딸 "엄마 뜻대로 하자" / 결정은 바꿀 수 있음 — 마음이 바뀌면 다시 말하기.

### EP18 (심화) 완화의료는 같이 가는 팀
1. 외래 완화의료 상담실, 간호사가 순례와 딸에게 의자를 내줌 / 딸 "아직 그럴 때는 아니잖아요" / 완화의료는 마지막 단계만이 아니라 처음부터 함께할 수 있음.
2. 둥근 탁자에 의사·간호사·상담사·사회복지사 실루엣이 둘러앉은 그림(색만) / (대사 없음) / 통증·숨참·잠·마음·돌봄 계획을 함께 돕는 팀.
3. 간호사가 통증 표정 그림 카드(얼굴 그림, 숫자 없음)를 순례에게 보여 줌 / 간호사 "아픈 건 참지 마세요" / 통증은 참지 말고 표현 — 조절 방법은 여러 가지.
4. 집, 순례가 딸이 끓인 국을 맛보며 미소 / 순례 "오늘은 잘 잤어" / 항암과 완화의료는 함께 받을 수 있음(→ ㉚ PAL권).

### EP19 (심화) 왜 나에게 두 번
1. 저녁 공원 벤치, 형석이 노을을 보며 혼잣말 / 형석 "왜 하필 또 나야" / "왜 나에게"라는 질문은 답이 없어도 함께 나눌 수 있음.
2. 비 온 뒤 땅에서 새싹이 다시 올라오는 그림(색만) / (대사 없음) / 재발은 내 잘못이 아님 — 첫 치료도 그때 가장 맞는 선택.
3. 상담실, 심리상담사가 형석과 인숙을 함께 마주함 / 상담사 "두 분 마음도 같이 봐요" / 부부·가족 상담, 환자 모임, 신앙 공동체도 도움이 될 수 있음.
4. 집, 형석이 인숙의 손을 잡고 소파에 나란히 앉음 / 인숙 "오늘 하루 잘 지냈다" / 하루 단위로 작은 계획 세우기.

### EP20 (심화) 산정특례, 다시 확인
1. 원무과 창구, 인숙이 서류 파일을 내밂 / 인숙 "예전 산정특례 그대로예요?" / 적용 기간이 끝났거나 끝나 가면 재등록 여부를 확인.
2. 달력 위에 끝나 가는 리본과 새 리본(색만, 숫자 없음) / (대사 없음) / 재발·전이로 계속 치료가 필요하면 재등록 요건을 공단·병원에 문의.
3. 사회복지팀 상담실, 사회복지사가 지원 안내 그림 카드(글자 없음)를 펼침 / 사회복지사 "다른 지원도 같이 봐요" / 의료비 지원·간병·돌봄 제도는 사회복지팀에서 한 번에 상담.
4. 집, 시우가 보험 약관을 휴대폰으로 확인(글자 흐림) / 시우 "재진단 조항 있는지 볼게" / 보험의 재진단·전이 관련 조항은 약관마다 다름.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **3장(재발을 확인하는 순서) · 8장(이번 치료의 목표부터) · 16장(완화의료는 처음부터 같이 가는 팀)**.
- 기존 원고 v0.2.2가 나오면 문장 우선 재사용, 없으면 공식 환자 안내(NCI·ASCO·국가암정보센터 등 — S4에서 실재·최신 판 확인)와 각 권 재발 문장을 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~9를 골든샘플부터 적용.
- 이 권은 약 이름을 쓰지 않는다. 암종별 세부가 필요한 곳마다 "→ 해당 권 ○장" 연결 상자를 둔다(①~㉕ 권 번호표를 부록에 1쪽).
- 생존율·재발률 수치는 본문에 넣지 않는다. 예후를 묻고 싶은 독자를 위해 "예후를 묻는 말" 예시 상자를 15장에 1개.
- 주인공 형석은 암종 미표시·몇 군데만 돌아온 재발 경로. 오래 관리는 경란, 2차 소견·임상시험은 도윤, 편안함 먼저는 순례 — 본문 사례도 같은 분담.
- 26장(미리 생각해 두기)은 첫 문단을 "재발은 마지막이 아니다"로 열고, 제도 설명은 개념 + 문의처까지만.
- 보호자 문장은 ㉖ CG권과 중복되지 않게 24장에 "가족에게 다시 말하기"만, 보호자 자신의 돌봄은 CG권으로 연결.
