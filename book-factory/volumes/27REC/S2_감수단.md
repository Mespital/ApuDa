# ㉗ REC — 감수단 구성 (가상 사전 감수 · 고정)

> ⚠ 이 감수단은 AI가 각 관점을 맡아 수행하는 **가상 사전 감수**다. 아래 인물은 모두 **가상 인물**이며, 실제 전문의·간호사·환자의 감수가 아니고 대신하지도 않는다. 독자 지면·보고서 어디에도 "전문의 감수 완료"처럼 쓰지 않으며, 독자 지면에 인원·이름을 노출하지 않는다(standards/04 머리말·01 원칙). 판권 표기는 그대로 "실제 전문의 서면감수 전".

- 구성 기준: `standards/04_근거확인_감수기준.md` §2 (전문의 다학제 4+ · 설명간호사 2+ · 환자 4+ · 보호자 1 · 편집·언어 2 · 심리 1). 공통편이므로 종양내과·완화의료·정신건강 관점을 핵심으로 둠.
- 고정일: 2026-11-24 · 이 권이 끝날 때까지 같은 구성 사용
- 가상 환자는 본문 캐릭터(형석·인숙·시우·경란·도윤·순례)와 겹치지 않게 기호(P1~P5, G1)로만 부른다.

| 팀 | 역할(가상) | 관점 |
|---|---|---|
| 전문의 다학제 | 종양내과(고형암 전신치료) | 재발 치료 목표(완치 재시도·조절·편안함) 단정 여부, 약 이름 0·범주만, 임상시험 문장 |
| 〃 | 외과종양학(국소 재발·소수 전이 수술) | 국소치료 문장이 약속처럼 읽히지 않는가, "일부 경우" 한정 |
| 〃 | 방사선종양학과 | 재치료·정위방사선 등 국소치료 범주 표현, 증상 완화 방사선 |
| 〃 | 영상의학과 | 영상 소견만으로 재발 단정 금지, 검사 종류 설명의 정확성 |
| 〃 | 병리과 | 재조직검사·재발 vs 이차암 구분 문장 |
| 〃 | 완화의료(호스피스·완화의료 전문의) | 완화의료 = 처음부터 함께, 호스피스와의 차이, 국내 제도(입원형·가정형·자문형) 문장 |
| 〃 | 정신건강의학과(정신종양학) | 재발 뒤 불안·우울 문장이 진단 단정이 되지 않는가, 연결 경로 |
| 설명간호사 | 종양 전문간호사(외래 설명·재발 상담) | 집에서 따라 해도 안전한가, 확정/의심 구분, 응급 공통 카드 |
| 〃 | 항암 주사실 간호사(부작용·응급 전화 상담) | 38.0°C·두 번째 치료의 누적 부작용 |
| 〃 | 완화의료 전문간호사 | 통증·숨참 표현법, 완화의료 의뢰 요청 문장 |
| 환자 | P1 50대 후반 남성, 대장암 수술·항암 뒤 간 일부 재발 → 국소치료 상의, 수도권, 디지털 보통 | "실패" 자책, 치료 목표 질문의 실용성 |
| 〃 | P2 60대 여성, 유방암 오랜 뒤 뼈 재발 → 오래 관리 중, 영남, 디지털 낯섦 | "만성질환처럼"의 뜻과 한계, 공포 문장 |
| 〃 | P3 40대 남성, 림프종 재발 → 2차 소견·임상시험 상의, 수도권, 디지털 익숙 | 정보 과잉·검색 불안, 임상시험 문장 |
| 〃 | P4 80대 초반 여성, 재발 뒤 치료 강도 낮추고 편안함 먼저, 호남 군 지역, 디지털 낯섦 | "포기"로 읽히지 않는가, 글자·용어 |
| 〃 | P5 30대 여성, 갑상선암 수술 뒤 림프절 재발 → 다시 완치 목표 치료, 충청, 디지털 익숙 | 재발 = 끝이라는 공포를 덜어 주는가, 단정 금지 |
| 〃 | 보호자 G1 50대 아내(남편 재발, 직장 병행) | 보호자 몫·가족에게 다시 말하기 |
| 편집·언어 | 책 편집디자이너 | 장 구조(30초 요약·표·질문·기록칸) 일관성, 연결 상자("해당 권") 위치 |
| 〃 | 국문학 교수 | 용어 통일(재발/진행/이차암, 완화의료/호스피스, 국소/영역/원격) |
| 심리 | 임상심리학자 | 공포·탓·희망 단정, "왜 나에게 두 번" 문장 톤 |
