- 상태: **G1 대기** — 결재함에 `G1 승인 HNC` 또는 `G1 수정 HNC: …`

- 범위: **성인 두경부 편평세포암 첫 진단** — 구강암(혀·잇몸·입바닥 등)·구인두암(HPV 관련 포함)·후두암·하인두암을 한 권의 공통 줄기로 묶고, 부위별 차이는 장 안 "내 부위" 상자로 나눈다. 주인공 줄기는 **구강암(혀) 수술 → 재건 → 수술 뒤 항암방사선**. 후두암(후두 보존 치료 · 후두전절제)과 HPV 양성 구인두암(항암방사선 중심)은 보조 인물로 같은 무게로 보여 준다. 비인두암(EBV·방사선 중심)·침샘암·비강·부비동암은 15장 안내 상자. 갑상선암은 ⑤ TC, 식도암은 ⑰ EC, 뇌종양은 ⑲ BT, 피부 흑색종은 ⑳ MEL, 처음부터 원격 전이는 15장 + ㉕ MET, 재발은 24장 끝 + ㉗ REC.
- 톤: 두경부암은 **"먹고 말하고 숨 쉬는 자리의 병"**이다 — 치료 계획이 얼굴·목소리·삼킴·침과 바로 이어지고, 치과·영양·재활이 치료 전부터 한 팀이다. 책 전체의 축은 두 가지: ① **"치료 전 준비가 치료의 절반"**(치과·영양·삼킴·말하기 기록을 치료 전에 남기면 회복 계획이 선다), ② **"잃는 기능보다 다시 배우는 기능"**(삼킴 재활·발성·입 벌리기·목 어깨 운동은 연습으로 되찾는 과정). 흡연·음주·HPV와의 관련은 탓하는 문장이 아니라 정보와 "지금 끊으면 치료·회복에 도움" 방향으로만. 얼굴·목소리 변화에 대한 마음은 숨기지 않고 다룬다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 항암 중 발열·수술 뒤 상처 발열·영양관·기관절개 부위 발열 모두 38.0°C. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리. 웹 FAQ의 "38℃"·"38°C" 표기는 책에서 38.0°C로 통일.
2. **수치 쓰지 않기.** 생존율·재발률·국소제어율, 방사선 선량(Gy)·횟수·"주 몇 회 몇 주", 항암 횟수·주기, 절제연 "몇 mm", 침윤 깊이 기준 mm, 입원·금식 일수, 체중 감소 "몇 %", 입 벌림 "손가락 몇 개", 발치 뒤 방사선까지 "며칠", 추적 "몇 개월마다" 같은 수·기간은 본문에 넣지 않는다. 필요하면 "병원 안내문·일정표 기준"으로. 병기(TNM)는 부위마다 달라 개념만 출처 달고, 지침 표 복제 금지.
3. **약은 "범주 + 대표 예"로만.** 방사선과 함께 쓰는 백금계 항암제(시스플라틴 대표 예), 시스플라틴을 쓰기 어려울 때의 다른 선택(범주), EGFR 항체(세툭시맙 대표 예), 면역항암제(PD-1 억제제 — 범주명 위주), 침 분비 돕는 약·불소 → 용량·주기 미기재, 모두 "국내 허가·급여 변경 가능 + 의료진 확인". PD-L1 CPS 기준값 미기재 — "결과지의 PD-L1 결과가 약 선택에 쓰일 수 있음"까지. 시스플라틴 전 청력·신장 확인은 개념만.
4. **HPV 문장은 낙인 없이.** HPV 양성 구인두암은 "바이러스 관련 유형이며 치료 반응·계획에 쓰이는 정보". 성생활·배우자 탓 금지, "옮는 암" 금지. 배우자 검사·백신 질문은 "의료진과 상담" 방향으로만. HPV 정보를 구강암·후두암에 그대로 적용하지 않는다는 문장 고정.
5. **원인 단정·탓 금지.** 흡연·음주·씹는 담배·구강위생과의 관련을 "당신 때문"처럼 쓰지 않는다. 위험요인은 FAQ·5장에서 출처 달고 개념만, 금연·금주는 "치료 효과·상처 회복·두 번째 암 예방에 도움" 방향. 금연상담전화 번호는 S4에서 재확인.
6. **기능 문장은 약속하지 않기.** "말하기·삼킴이 원래대로 돌아온다" 단정 금지 → "재활로 나아지는 경우가 많고, 정도는 수술 범위·치료에 따라 다름 — 내 목표를 재활팀과 정함". 후두 보존 치료도 "목소리가 그대로"라고 쓰지 않음.
7. **응급 문장 고정.** 입·목·기공에서 피가 많이 나거나 멈추지 않음 → 119(목에 큰 출혈 전 조금씩 피가 묻어나는 것도 바로 연락), 숨이 막히거나 쌕쌕거림·기관절개관·기공이 막힘 → 119, 재건 부위 색이 갑자기 검붉거나 창백해짐(수술 직후 입원 중 — 바로 간호사), 항암 중 38.0°C 발열, 물·침도 삼키지 못하고 소변이 크게 줄어듦(탈수), 먹을 때마다 기침·고열(흡인성 폐렴 가능), 얼굴·목이 갑자기 붓고 숨참, 갑자기 한쪽 힘 빠짐·말이 어눌함 → 119 — 0-1·10장·20장·22장 같은 문장.
8. **후두전절제 응급 안내.** 후두전절제 환자는 "숨을 목의 기공으로 쉰다 — 응급 시 입·코가 아닌 기공에 산소·인공호흡" 카드를 지니도록 안내(전절제 환자에게만 해당한다고 명시). 물놀이·샤워 주의는 개념만.
9. **방사선 뒤 치아 문장.** "방사선 뒤 발치·임플란트는 턱뼈 골괴사 위험 때문에 방사선종양학과·치과와 먼저 상의" 고정. "방사선 전 모든 이를 뺀다" 금지 → "치과 평가로 필요한 치료만".
10. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN Head and Neck Cancers, ESMO, ASCO, 대한두경부종양학회·대한이비인후과학회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
11. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~17·26·27권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(입·목·기공에서 피가 많이 나거나 멈추지 않음 → 119 · 숨이 막히거나 쌕쌕거림, 기관절개관·기공이 막힘 → 119 · 항암 중 38.0°C 이상 발열·오한 = 해열제보다 먼저 연락 · 물·침도 삼키지 못하고 소변이 크게 줄고 어지러움(탈수) · 먹을 때마다 기침·사레에 열이 남(흡인성 폐렴 가능) · 얼굴·목이 갑자기 붓고 숨참 · 수술 상처가 벌어지거나 고름·심한 붓기 · 갑자기 한쪽 힘 빠짐·말이 어눌함 → 119 · 스스로를 해치고 싶은 생각 → 109·119) · 0-2 오늘 확인할 세 가지(내 암의 정확한 부위 — 구강·구인두·후두·하인두·비인두 중 어디인지 / 조직형과 HPV(p16) 결과가 필요한 부위인지 / 치료 길 — 수술 중심인지 방사선·항암방사선 중심인지, 치과·영양 진료 날짜) · 0-3 책 사용법(내 길 찾기: 구강암 수술 → PART 2 앞쪽(9·10·13장), 후두암 → 12장, HPV 양성 구인두암 → 6·11장, 비인두·침샘·비강 → 15장, 처음부터 전이·재발 → 15장 + ㉕·㉗) · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 두경부암은 한 곳이 아니에요: 입안·인두(코 뒤·목구멍·아래 목구멍)·후두 · 대부분 편평세포암 · 부위마다 치료가 다른 이유 → **EP01**
2. 진단 뒤 72시간: 결과지 두 부 · 체중·먹는 양·목소리 상태 기록 · 다학제 진료 일정 · 가족 한 명 → **EP02**
3. 검사가 여러 개인 이유: 조직검사 · 후두·인두 내시경 · CT·MRI(부위마다 보는 것) · PET-CT · 필요하면 식도·폐 확인 → **EP03**
4. 치료 전에 치과·영양·삼킴부터: 치과 평가와 필요한 치료 · 불소 관리 · 영양 상담 · 삼킴 평가 · 금연·금주 상담 → **EP04**
5. 병리 읽기: 편평세포암·분화도 · 침윤 깊이 · 절제연 · 신경주위침범(PNI) · 림프절 피막외침범(ENE) — 뜻만, 기준 수치 없이 → 심화 **EP11**
6. HPV(p16)와 구인두암: 바이러스 관련 유형의 뜻 · 탓이 아닌 정보 · 구강암·후두암에 그대로 적용하지 않기 · 배우자 질문은 상담으로 → 심화 **EP12**
7. 치료 전의 나를 기록하기: 얼굴 사진·목소리 녹음·입 벌림·체중·삼킴 상태 · PD-L1 등 표지자 검사는 필요한 경우에 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 수술 중심(± 수술 뒤 방사선·항암방사선) / 방사선·항암방사선 중심(기능 보존) / 처음부터 전이 — 전신치료 · 부위·병기·기능·환자 선택 · 다학제가 함께 정하는 이유 → **EP05**
9. 수술과 재건: 절제 범위 · 목 림프절 절제(경부곽청술) · 유리피판 재건(팔·다리 등에서 조직을 옮김) · 재건 부위 혈류 확인 · 수술 뒤 말하기·삼킴 → **EP06**
10. 목에 낸 숨구멍: 일시적 기관절개관 · 가래 관리 · 말하기 방법 · 막힘·출혈 응급 · 영구 기공(후두전절제)과의 차이 → 심화 **EP14**
11. 방사선·항암방사선: 얼굴 고정 마스크 · 세기조절방사선(IMRT) 개념 · 함께 쓰는 항암제(범주) · 치료 중 피부·입안·삼킴 변화 → **EP07**
12. 후두를 지키는 길, 후두를 떼는 길: 아주 초기 후두암(레이저·방사선 상의) · 후두 보존 항암방사선 · 후두전절제와 새 목소리(발성보철·전기후두·식도발성) · 전절제 응급 카드 → 심화 **EP17**
13. 수술 뒤 보조치료: 병리 결과(절제연·ENE 등)에 따라 방사선 또는 항암방사선을 상의하는 경우 · 시작 시기는 회복 상태와 병원 판단 → 심화 **EP15**

1. 밤 거실, 태석이 휴대폰 검색 화면을 끄고 소파에 기댐 / 태석 "검색은 그만, 기록부터" / 진단 직후엔 검색보다 내 결과지와 몸 상태 기록이 먼저.
2. 욕실, 연화가 체중계 옆에서 태석의 발을 가리킴(숫자 없음) / 연화 "매일 아침 같은 시간에" / 체중·먹은 양을 기록하면 영양 계획을 세우기 쉬움.
3. 원무과, 민혁이 결과지·영상 CD 봉투 두 개를 받음 / 민혁 "두 부씩 부탁드려요" / 결과지·영상은 처음부터 두 부씩.
4. 식탁, 민혁이 손가락 세 개를 펴 보이고 태석이 고개를 끄덕임 / 민혁 "다학제 진료, 같이 가요" / 부위·조직형·치료 길, 세 가지를 먼저 확인.

### EP03 목 안을 보는 검사들
1. 이비인후과 진료 의자, 태석이 앉아 있고 주치의가 옆에서 화면을 가리킴(멀리서 본 구도, 관 근접 없음) / 주치의 "목 안쪽까지 봐요" / 내시경으로 입안 너머 인두·후두까지 살핌.
2. 같은 목을 세 방향(안쪽 카메라·단면 사진·몸 전체 빛)으로 보는 세 칸 개념 그림(색만, 글자 없음) / (대사 없음) / 내시경은 안쪽, CT·MRI는 깊이·림프절, PET-CT는 몸 전체를 봄.
3. MRI 검사실 대기 의자, 태석이 검사복 차림으로 기다림(기계는 멀리) / 태석 "CT 찍었는데 MRI도요?" / 부위에 따라 CT와 MRI가 보는 것이 달라 함께 찍기도 함.
4. 진료실, 주치의가 폐·식도 그림 카드(글자 없음)를 함께 놓음 / 주치의 "다른 곳도 같이 봐요" / 두경부암은 폐·식도 등 다른 곳도 함께 확인하는 경우가 있음.

### EP04 치료 전에 치과부터
1. 치과, 태석이 진료 의자에 앉아 고개를 끄덕임(입 안 근접 없음), 치과 의사가 마스크를 내리고 설명 / 치과 의사 "치료 전에 이부터 봐요" / 방사선 전 치과 평가로 나중의 턱뼈·충치 문제를 줄임.
2. 치아 그림 카드 몇 장 중 일부에만 색이 칠해진 그림(색만, 글자 없음) / (대사 없음) / 모든 이를 빼는 것이 아니라 필요한 치료만 치료 전에 마침.
3. 화장실, 태석이 거울 앞에서 부드러운 칫솔과 불소 용기(상표 없음)를 듦 / 태석 "불소도 매일 하래" / 치료 중·후 불소 관리와 부드러운 칫솔질이 치아를 지킴.
4. 영양 상담실, 영양사가 태석·연화에게 단백질 음식·영양음료 그림 카드(상표 없음)를 보여 줌 / 영양사 "치료 전에 영양부터요" / 체중이 빠지기 전에 영양 상담과 삼킴 평가를 받음.

### EP05 길은 여럿, 지키고 싶은 것
1. 다학제 면담실, 주치의·방사선종양학과 의사·언어재활사가 태석·연화·민혁과 둥근 탁자에 앉음 / 민혁 "선생님이 이렇게 많아요?" / 두경부암은 여러 진료과가 함께 치료 길을 정하는 경우가 많음.
2. 갈래 길이 같은 산꼭대기로 이어지고, 꼭대기에 숟가락·말풍선·숨결 모양 깃발(글자 없음) / (대사 없음) / 수술 중심·방사선 중심 길은 부위·병기와 지키고 싶은 기능으로 정함.
3. 주치의가 첫 번째 길을 짚음 / 주치의 "먼저 떼고, 다시 만들어요" / 수술로 암을 떼고 재건한 뒤 병리 결과로 다음 치료를 정하는 길.
4. 태석이 휴대폰 메모의 "지키고 싶은 것" 칸에 숟가락 기호를 넣음 / 태석 "나는 맛을 지키고 싶어" / 내가 중요하게 여기는 기능을 의료진에게 말하기.

### EP06 팔에서 옮겨 온 조직
1. 수술 설명실, 주치의가 혀와 팔 그림 카드(글자 없음)를 나란히 펼침 / 연화 "팔에서 떼어 온다고요?" / 뗀 자리를 메우려 팔·다리 등의 조직을 옮겨 오는 재건을 하기도 함.
2. 팔의 작은 조직이 혈관과 함께 입안으로 옮겨져 연결되는 개념 삽화(색만) / (대사 없음) / 옮긴 조직은 혈관을 이어 붙여 살아 있게 함(유리피판).
3. 병실, 간호사가 태석의 얼굴을 살피며 메모, 태석은 목에 머플러·왼팔에 붕대(노출 없음) / 간호사 "자주 확인할게요" / 수술 직후 재건 부위 혈류를 자주 확인하는 것이 중요.
4. 병실, 태석이 글씨판(글자 없음)에 손가락으로 가리키고 연화가 고개를 끄덕임 / 연화 "말 대신 이걸로 해요" / 수술 직후엔 말하기·먹기를 단계적으로 다시 시작.

### EP07 내 얼굴에 맞춘 마스크
1. 방사선 계획실 대기실, 방사선종양학과 의사가 그물 무늬 흰 마스크를 손에 들고 보여 줌 / 방사선종양학과 의사 "매일 같은 자리에 맞춰요" / 두경부 방사선은 얼굴 고정 마스크로 매번 같은 위치에 맞춤.
2. 목을 따라 가는 빛줄기가 침샘 등 주변을 피해 휘어 가는 개념 삽화(색만) / (대사 없음) / 세기조절방사선(IMRT)은 주변 조직을 최대한 피하도록 설계함.
3. 집, 태석이 거울 앞에서 머플러 가장자리로 붉어진 목을 살짝 봄 / 태석 "목이 좀 붉어졌네" / 방사선 부위 피부 변화는 병원 안내대로 관리하고 심하면 알림.
4. 주사실, 태석이 팔에 작은 반창고를 붙이고 나오며 귀를 만짐 / 태석 "귀가 좀 먹먹해" / 함께 쓰는 항암제로 청력 변화·귀울림이 생기면 바로 알리기.

### EP08 38.0도면 연락부터
1. 밤, 태석이 담요를 두르고 오한, 연화가 체온계를 봄(숫자 없음) / 연화 "38.0도 넘었어요" / 항암 중 38.0°C 이상 발열은 응급.
2. 혈액 속 백혈구가 줄어든 개념 삽화(색만) / (대사 없음) / 백혈구가 낮은 시기엔 감염이 빠르게 진행할 수 있음.
3. 연화가 해열제 서랍을 닫고 휴대폰으로 병원에 전화 / 연화 "약보다 병원 전화 먼저" / 해열제가 감염 신호를 가릴 수 있음.
4. 응급실 접수대, 연화가 치료 중 카드(글자 없음)를 내밂 / 연화 "두경부암 항암방사선 중이에요" / 응급실에서 항암·방사선 중임을 먼저 알리기.

### EP09 입안이 헐 때
1. 식탁, 태석이 미음을 한 숟갈 뜨다 멈추고 볼을 감쌈(입 다문 얼굴) / 태석 "입안이 다 헐었어" / 방사선·항암으로 입안 점막염이 생길 수 있음.
2. 순한 물로 입을 헹구는 컵과 부드러운 칫솔이 놓인 세면대 그림(색만, 상표 없음) / (대사 없음) / 순한 헹굼과 부드러운 칫솔질, 자극적인 세척액은 상의 후.
3. 진료실, 태석이 통증 기록(기호만)을 내밀고 주치의가 메모 / 주치의 "아프면 진통제 써요" / 통증을 참으면 먹는 양이 줄어 — 진통제를 상의해 충분히 조절.
4. 밤, 연화가 물병과 가습기를 머리맡에 둠 / 연화 "입이 마르면 조금씩 자주" / 입마름·끈적한 침·하얀 막·맛 변화는 기록하고 알리기.

### EP10 삼킴도 연습이에요
1. 삼킴 재활실, 언어재활사가 태석에게 턱을 당기고 삼키는 자세를 보여 줌 / 언어재활사 "치료 중에도 운동해요" / 삼킴 운동은 치료 중에도 이어 가면 기능을 지키는 데 도움.
2. 컵 세 개에 묽은 것·걸쭉한 것·부드러운 것이 차례로 담긴 그림(색만, 글자 없음) / (대사 없음) / 음식 농도와 자세는 삼킴 평가 결과에 맞춤.
3. 식탁, 태석이 국을 먹다 연달아 기침, 연화가 등을 두드림 / 연화 "또 사레예요" / 먹을 때마다 기침이 나면 음식이 기도로 넘어가는 신호일 수 있음.
4. 밤, 태석이 기침하며 이마를 짚고 연화가 체온계를 꺼냄 / 연화 "열까지 나면 바로 가요" / 기침이 없어도 흡인이 있을 수 있고, 발열·숨참이 겹치면 바로 진료.

### EP11 (심화) 결과지의 '절제연'
1. 외래, 민혁이 수술 병리보고서 한 줄을 손가락으로 짚음(글자 흐림) / 민혁 "절제연이 뭐예요?" / 절제연은 떼어 낸 조직의 가장자리에 암세포가 있는지 보는 항목.
2. 떼어 낸 조직 덩어리 바깥 테두리에 색 띠가 둘러진 개념 그림(색만, 숫자 없음) / (대사 없음) / 가장자리가 깨끗한지, 가까운지, 닿아 있는지에 따라 다음 치료가 달라질 수 있음.
3. 주치의가 결과지 아래 칸 두 줄을 가리킴 / 주치의 "신경·림프절 소견도 봐요" / 신경주위침범·림프절 피막외침범 등도 보조치료 결정에 쓰임.
4. 태석이 메모의 병기 칸을 비워 두고 질문 표시 / 태석 "숫자 말고 내 경우로 묻자" / 결과지 항목이 내 치료에 어떤 의미인지 "내 경우"로 묻기.

### EP12 (심화) HPV라는 말
1. 진료실, 재형이 목을 만지며 아내(측면)와 앉아 있음 / 재형 "목에 멍울만 있었는데요" / 구인두암은 목 멍울로 먼저 발견되기도 함.
2. 세포 안에 작은 바이러스 표시가 있는 개념 삽화(색만, 글자 없음) / (대사 없음) / HPV(p16) 양성은 바이러스 관련 유형이라는 뜻이며 치료 계획에 쓰이는 정보.
3. 재형의 아내가 걱정스러운 얼굴, 주치의가 손을 들어 차분히 설명 / 주치의 "누구 탓이 아니에요" / HPV 관련 암은 탓할 일이 아니며, 배우자 걱정은 상담으로 물어볼 수 있음.
4. 음악실, 재형이 피아노 앞에 앉아 달력(칸만)에 치료 칸 표시 / 재형 "항암방사선으로 간대" / HPV 정보는 구인두암에 해당하며 구강암·후두암에 그대로 적용하지 않음.

### EP13 (심화) 치료 전의 나를 기록해요
1. 거실, 민혁이 휴대폰으로 태석의 얼굴 사진을 찍음 / 민혁 "치료 전 사진 남겨요" / 치료 전 얼굴·목 상태를 기록해 두면 회복을 비교하기 쉬움.
2. 휴대폰 녹음 화면 아이콘(글자 없음) 앞에서 태석이 책을 소리 내어 읽음 / 태석 "목소리도 녹음해 두자" / 말하기·목소리 기록은 재활 목표를 세우는 데 도움.
3. 태석이 입을 크게 벌리는 연습을 거울 앞에서 함(입 안 근접 없음, 얼굴만) / 연화 "얼마나 벌어지나 봐 둬요" / 입 벌림 정도를 기록하면 나중의 굳음을 빨리 알아챔.
4. 진료실, 주치의가 결과지의 검사 칸(글자 흐림)을 가리킴 / 주치의 "필요한 검사만 해요" / PD-L1 등 표지자 검사는 필요한 경우에 하며 약 선택에 쓰일 수 있음.

### EP14 (심화) 목에 낸 숨구멍
1. 병실, 태석이 목의 머플러 아래 윤곽(관 근접 없음)을 손으로 짚음 / 태석 "목으로 숨 쉬는 거야?" / 수술 뒤 붓기 동안 숨길을 지키려고 일시적 기관절개관을 두기도 함.
2. 입·코로 가는 숨길과 목 아래로 바로 가는 숨길이 나란히 그려진 개념 그림(색만) / (대사 없음) / 붓기가 가라앉으면 관을 빼고 원래 숨길로 돌아가는 경우가 많음(병원 판단).
3. 간호사가 연화에게 가래 흡인 기구(실루엣)와 생리식염수병을 보여 줌 / 간호사 "가래는 이렇게 빼요" / 관 관리·가습·가래 제거는 병원 교육대로.
4. 밤, 연화가 비상 연락 카드(글자 없음)를 침대 옆에 붙임 / 연화 "막히거나 피 나면 119" / 관이 막혀 숨이 차거나 출혈이 많으면 바로 119.

### EP15 (심화) 수술 뒤, 한 걸음 더
1. 외래, 태석이 수술 병리 결과지 봉투를 들고 긴장 / 태석 "다 뗐는데 또 치료해요?" / 떼어 낸 조직 결과에 따라 수술 뒤 방사선·항암방사선을 상의할 수 있음.
2. 계단 끝에 작은 계단 하나가 더 이어진 그림(색만) / (대사 없음) / 절제연·림프절 소견 등 재발 위험 신호가 있으면 보조치료를 권하는 경우가 있음.
3. 방사선종양학과 의사가 태석의 회복 상태를 살피며 달력 카드(칸만)를 건넴 / 방사선종양학과 의사 "상처가 아물면 시작해요" / 시작 시기는 상처 회복과 병원 판단으로 정함.
4. 태석이 메모의 "물어볼 것" 칸에 질문 기호 두 개 / 태석 "왜 필요한지 묻자" / 보조치료의 목적과 예상되는 변화를 "내 경우"로 묻기.

### EP16 (심화) 코로 지나가는 가는 관
1. 병실, 태석이 볼에 작은 테이프와 코 옆 가는 관(근접 없음)을 단 채 거울을 봄 / 태석 "이제 입으로는 못 먹나?" / 영양관은 입으로 못 먹는다는 뜻이 아니라 치료를 버티는 다리.
2. 관으로 영양이 들어가는 길과 입으로 먹는 길이 나란히 이어진 그림(색만) / (대사 없음) / 영양관으로 채우면서 입으로 먹는 연습·삼킴 운동은 계속함.
3. 간호사가 연화에게 관 씻는 주사기와 물컵을 보여 줌(관 연결부 근접 없음) / 간호사 "막히지 않게 물로 씻어요" / 코위관·위루관(PEG) 관리는 병원 교육대로.
4. 집, 연화가 관 관리표(칸만)에 체크, 태석이 걸쭉한 음료를 한 모금 / 연화 "빠지거나 열나면 바로 전화" / 관이 빠지거나 주변이 붉고 고름·발열이 있으면 연락.

### EP17 (심화) 새 목소리를 배우는 길
1. 진료실, 춘식이 천 스카프로 목을 감싸고 글씨판(글자 없음)을 듦, 주치의가 마주 앉음 / 주치의 "말하는 길이 몇 가지 있어요" / 후두전절제 뒤에도 말하는 방법을 다시 배울 수 있음.
2. 목 기공으로 숨 쉬고, 발성보철·전기후두·식도발성 세 갈래로 소리가 나는 개념 그림(색만, 글자 없음) / (대사 없음) / 발성보철·전기후두·식도발성 중 맞는 방법을 재활팀과 정함.
3. 재활실, 언어재활사가 춘식에게 전기후두(무늬 없음)를 턱 밑에 대는 법을 보여 줌 / 언어재활사 "천천히, 또박또박" / 새 목소리는 연습으로 익숙해짐 — 정도는 사람마다 다름.
4. 목공방, 춘식이 지갑에서 응급 카드(글자 없음)를 꺼내 보여 줌 / (춘식, 전기후두로) "숨은 목으로 쉬어요" / 후두전절제자는 응급 시 기공으로 숨 쉰다는 카드를 지니기(전절제 환자에게만 해당).

### EP18 (심화) 굳는 목과 어깨 풀기
1. 거실, 태석이 셔츠를 입다 팔을 다 못 올리고 얼굴을 찡그림 / 태석 "어깨가 잘 안 올라가" / 목 림프절 수술 뒤 어깨가 내려가거나 아플 수 있음.
2. 목·어깨·턱 근육이 부드럽게 늘어나는 운동 순서 그림(색만, 숫자 없음) / (대사 없음) / 목·어깨·입 벌리기 운동은 재활팀이 정한 방법으로 꾸준히.
3. 재활실, 물리치료사가 태석의 어깨를 받치며 팔 들기 운동 / 물리치료사 "아프지 않은 데까지만" / 운동 강도는 상처·방사선 상태에 맞춰 상의.
4. 거울 앞, 태석이 턱 아래 붓기를 손등으로 살짝 만짐(머플러 가장자리) / 연화 "붓기도 적어 둬요" / 목 림프부종·턱이 안 벌어짐은 기록하고 재활 진료에 알리기.

### EP19 (심화) 다시 생긴 혓바늘
1. 식탁, 태석이 혀를 입 안에서 굴리며 불안한 얼굴(입 다문 얼굴) / 태석 "또 따끔한 데가 생겼어" / 치료 뒤 새 상처·통증은 혼자 판단하지 말고 확인.
2. 입안·목 멍울·목소리·삼킴 네 칸 신호 그림(색만, 글자 없음) / (대사 없음) / 새 입안 상처·목 멍울·쉰 목소리·삼킴 악화는 예약을 기다리지 말고 알리기.
3. 진료실, 주치의가 진찰 일정 카드(칸만)와 혈액검사 카드(글자 없음)를 함께 건넴 / 주치의 "갑상선 피검사도 해요" / 목 방사선 뒤 갑상선 기능을 확인하고, 재발이 의심되면 검사로 확인(→ ㉗).
4. 치과, 태석이 치과 의사에게 방사선 치료 카드(글자 없음)를 보여 줌 / 태석 "방사선 받았어요, 이 뽑기 전에" / 방사선 뒤 발치·임플란트는 턱뼈 골괴사 위험 때문에 먼저 상의.

### EP20 (심화) 다시 웍을 잡는 날
1. 중식당 주방, 태석이 천천히 웍을 들고 민혁이 옆에서 거듦 / 민혁 "아빠, 오늘은 반나절만" / 복귀는 체력·식사 횟수·말하기 상태에 맞춰 단계적으로.
2. 주방 한쪽, 태석 몫의 부드러운 음식과 물컵이 따로 놓인 그림(색만) / (대사 없음) / 내 속도와 내 음식으로 일하면서 먹는 시간을 지킴.
3. 홀 계산대, 태석이 손님에게 휴대폰 메모(글자 흐림)를 보여 주며 웃음, 연화가 옆에서 거듦 / 연화 "천천히 말해도 다 알아들어요" / 말하기가 느려도 메모·몸짓을 함께 쓰면 대화가 편해짐.
4. 저녁 가족 식탁, 태석이 술잔을 엎어 두고 물컵으로 건배 / 태석 "나는 물로 건배" / 술·담배 권유를 거절하는 말을 미리 정해 두면 편함 — 금연·금주는 회복에 도움.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 길은 여럿, 지키고 싶은 것) · 4장(치료 전에 치과·영양·삼킴부터) · 21장(입안 지키기)**.
- `oral.json`·`laryngeal.json`·`nasopharyngeal.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~11을 골든샘플부터 적용.
- 병기(TNM)·치료 알고리즘 표는 지침 표 복제 금지 — 부위마다 ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. 생존율·국소제어율은 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 장마다 "내 부위" 상자(구강·구인두·후두·하인두)를 두되 상자 안 문장은 짧게, 비인두·침샘·비강은 15장으로 모음.
- 영양·삼킴·입안 장(4·14·21·22장)은 응급 신호 상자를 맨 위에(출혈·숨막힘·물도 못 삼킴·사레+발열), 생활 팁은 그 아래(순서 고정). 삼킴 단계 이름은 W3 기록지와 같은 말로, ⑰ EC 원고의 삼킴·흡인·영양관 문장과 대조해 통일.
- 주인공 태석은 혀 구강암·목 림프절 전이·수술+재건+일시 기관절개→수술 뒤 항암방사선·코위관 경로. HPV 양성 구인두암 항암방사선은 재형, 후두전절제는 춘식 — 본문 사례도 같은 분담. 12장(후두)은 9장과 같은 무게로.
- 25장 "마음" 상자 첫 줄은 "달라진 얼굴과 목소리도 여전히 나예요", 26장 "가족 식탁" 상자 첫 줄은 "억지로 먹이지 않아도 돼요"(보호자 대상).
