**기존 원고에서 고칠 것(S2·S4)**
1. **발열 표기 38.0°C 통일.** 완전판 응급 상자 "38°C 이상 발열·오한 + 황달·복통(담관염)", "항암 중 38°C 이상 발열", 증상표 끝 "항암 중 38°C 이상(병원 기준에 따라 37.8°C 이상 1시간 지속 등)" → 모두 **38.0°C**. 37.8°C 병기는 삭제하고 "병원 안내 기준이 다르면 병원 기준을 따르세요"로 대체. PTBD·스텐트 관련 발열, 담관염도 같은 기준. FAQ 데이터 80번 "38도 이상 발열"도 책에 옮길 때 38.0°C로.
2. **출처 없는 수치·효능 문장 → 처리 방침.**
   - 8장 "보조항암(먹는 항암제 약 6개월 범주)", 질문 모음 8번 "보조항암은 얼마 동안 하나요?" → 기간은 "담당 의료진이 정하는 일정"으로, 수치 삭제 또는 "일반적 예시"로 표시하고 근거 쪽 출처 연결.
   - 추적 "수술 후 3년까지 3~6개월마다, 5년까지 6개월마다, 그 뒤 해마다" → "국내 자료 예시"로 출처 표기, 간격은 "병원 추적 일정표"가 우선.
   - 6장 "담도암은 표적치료로 이어질 수 있는 유전자 변화가 비교적 많은 암" + 표의 "주로 많은 곳(간내 담관암 등)" → 지침·리뷰 출처 연결. 비율 수치는 새로 넣지 않음.
   - 우연 발견 담낭암 표 T1a/T1b/절제면/담즙 유출별 "흔한 다음 단계" → 지침 내용이므로 출처(NCCN 등) 표기, 표 구조는 ApuDa 언어로 새로 짬(지침 표 복제 금지). "대개 추적" 같은 단정 → "추적을 권하는 경우가 많음 · 내 경우는 의료진 확인".
   - FAQ Q9 "간은 수주~수개월에 걸쳐 커집니다", Q2 "보통 수개월 간격" → 출처 연결 또는 "개인차가 크다"로 수치 삭제.
   - 증상표 "하루 4~6회 이상 설사", "한 달 5% 이상 체중 감소", 검사 준비 카드 "PET 4~6시간 금식", 움직이기 "주 150분" → 출처 연결 또는 "일반적 예시"(병원 기준 우선).
   - 가상 사례 수경 씨(FGFR2 융합) "다음 치료 선택지가 생겼다" → 표적 효능 암시. "국내 사용 가능 여부와 비용을 함께 확인했다"를 덧붙여 기대 과장 방지. 경자 씨 "서류를 챙겨 간 덕분에 일정이 빨랐어요"는 유지 가능.
   - 사례 머리말 "감수단 환자 페르소나를 바탕으로 재구성" → "ApuDa가 만든 가상의 이야기"로(내부 작업 용어 노출 금지).
3. **급여·허가 문장 S4에서 재확인(2026.10 기준 → 발행 시점 기준).** 1차 "젬시타빈 + 시스플라틴 + 면역치료(더발루맙·펨브롤리주맙)" 국내 허가·급여("센터 2023년 자료에서는 병용 시 전체 비급여" → 2023 자료 인용은 낡음, 최신 확인 후 문장 교체), 보조항암 "카페시타빈 비급여 / 5-FU·류코보린 급여(2023년 자료)", FGFR2·IDH1·HER2·BRAF 표적약 국내 허가·급여, 산정특례(본인부담 5%·30일 이내·5년), 상병수당 시범사업, 가족돌봄휴직(90일)·가족돌봄휴가(10일). 모두 "변경 가능 + 의료진·공단 확인" 꼬리 유지.
4. **약은 "범주·대표 예"로만.** 약 이름은 범주 설명의 대표 예로만 남기고 용량·투여 간격·주기 미기재 → "병원 일정표"로 대체. 표적약은 "검사 후 해당 시 · 국내 허가·급여 변경 가능 + 의료진 확인" 문장으로 통일. 워크북 W4 "용량·횟수" 칸은 독자가 처방대로 적는 칸이므로 유지(책이 숫자를 제시하지 않음).
5. **판권·근거 쪽.** "감수: ApuDa 「첫 30일」 감수단(전문의 30인·환자 36인·편집자문 3인 역할 기반 AI 사전 검토단)… 출판본에는 실제 감수자 명단이 별도 표기" → "**실제 전문의 서면감수 전**"을 판권에 명시. AI 검토단 인원수는 독자 지면에서 삭제. 참고 지침 판 표기 "NCCN … Biliary Tract Cancers, Version 1.2026"은 실재·최신 여부 S4에서 확인.
6. **조판 결함.** "찾는 곳담당 교수에게"(줄바꿈·띄어쓰기 누락), "교체 예정\n\_배액관 하루 관리"(제목이 기록칸에 붙음), "추적수술 후 처음 2년은"(소제목 붙음), 증상표 "메스꺼 움"(단어 깨짐), 검사 준비 카드 "CT(조\n영)·PET/C\nT·조직검\n사" 셀 줄바꿈 깨짐, 장 번호가 9장 뒤로 사라짐(진행·전이·2차 소견·임상시험·PART 3 이후 무번호), FAQ 12문항뿐 → 이번 판에서 전부 재출력으로 해결.
7. **응급 상자 정리.** "스스로를 해치고 싶은 생각 → ☎ 109, 119"는 유지하되 마음 장과 문구 통일. "외부배액량이 많은데 어지럽고 소변이 줄어듦(탈수)"는 배액량 수치 없이 유지.

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(발열 38.0°C·오한 + 황달·복통 = 담관염 가능, 배액관이 빠지거나 배액이 갑자기 줄고 통증·발열, 배액에 피·토혈·검은 변, 외부배액이 많은데 어지럽고 소변 감소, 의식 흐림·심한 복통, 항암 중 발열 38.0°C, 한쪽 다리 부종·갑작스러운 숨참) · 0-2 오늘 확인할 세 가지(판독지의 위치·간담췌 전문 센터 예약·황달 시 배액 계획) · 0-3 책 사용법 · 0-4 온라인 연결

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **1장(위치 네 갈래) · 3장(황달과 담도배액) · 19장(배액관 하루 관리)**.
- 기존 완전판 문장 우선 재사용, 새 수치 추가 금지. 0절 "고칠 것" 1~7을 골든샘플부터 적용(38.0°C, 출처 없는 수치 처리, 용량·기간 삭제).
- 위치 표·우연 발견 담낭암 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에.
- 표적·면역치료는 "검사 후 해당 시 · 국내 허가·급여 변경 가능 + 의료진 확인" 문장으로만. 효과 크기·반응률 수치 금지.
- 예후·생존율 수치는 본문에 새로 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
