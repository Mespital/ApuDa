# ㉘ 고령 환자편 (GER) — S1 권별 작업지시서 v1.0

- 발행: 2026-11-22 · 책공장(Claude 총괄 PD)
- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **GER v1.0** (로스터상 "미착수" — 새로 설계)
- 상태: **G1 대기** — 결재함에 `G1 승인 GER` 또는 `G1 수정 GER: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학·제도 문장은 방향 설계이며 확정 문장이 아니다.
- 범위: **나이가 많은(흔히 '고령'이라 부르는 나이의) 성인이 처음 암 진단을 받은 뒤 30일.** 암종 공통편이다. 독자는 환자 본인(큰 글씨·짧은 문장)과 함께 사는 배우자·자녀 보호자 둘 다. "몇 세부터 고령"이라는 숫자 기준은 본문에 쓰지 않는다 — 기관·지침마다 다르고, 이 책의 첫 문장이 "나이 숫자보다 몸 상태"이기 때문이다(내부 상정 독자: 대략 일흔 이후, S4에서 지침 표현 확인). 암종별 치료 세부는 해당 권(①~㉕), 재발은 ㉗ REC, 임종기 돌봄은 ㉚ PAL, 보호자 자신의 이야기는 ㉖ CG권으로 연결하고 입구만 안내한다.
- 톤: 고령 암 환자에게 흔히 따라붙는 두 가지 말 — **"이 나이에 무슨 치료를"**(나이만으로 포기)과 **"자식들이 알아서 하겠지"**(본인 없이 결정) — 을 걷어 낸다. 책 전체의 축은 세 가지: ① **나이 숫자보다 몸의 나이**(걷기·일상동작·영양·기억·기분·복용 약·함께 사는 사람을 먼저 살피는 노인포괄평가 — 같은 나이라도 길이 다르다), ② **치료 목표는 "얼마나 오래"만이 아니다**(혼자 걷기·집에서 지내기·정신이 맑은 것·손주 보기 — 내가 지키고 싶은 것을 먼저 말한다), ③ **고령에서 먼저 오는 위험을 미리 막는다**(약이 많을 때의 상호작용, 열 없이 오는 감염, 낙상, 섬망, 체중 감소). 본인이 가장 먼저 듣고 본인이 정한다 — 가족은 돕는 자리다. 치료를 줄이거나 받지 않는 선택도, 표준 치료를 그대로 받는 선택도 모두 정당하다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **응급 기준은 시리즈 공통 + 고령 신호 한 줄.** 항암 중 발열 **38.0°C** = 해열제보다 먼저 병원 연락. 여기에 고령 고정 문장: "나이가 많으면 감염이 있어도 열이 높게 오르지 않을 수 있다고 설명됩니다(S4 출처 확인). 갑자기 평소와 달리 멍하거나 엉뚱한 말을 함, 하루 종일 기운 없이 누워만 있음, 잘 먹던 사람이 거의 못 먹고 못 마심, 소변이 눈에 띄게 줄어듦, 새로 자꾸 넘어짐 — 열이 없어도 병원에 연락." 그 밖에 공통(숨참·가슴 통증, 갑작스러운 한쪽 마비·말 어눌함 → 119, 피를 토하거나 검은 변, 넘어진 뒤 머리를 부딪힘 + 혈액을 묽게 하는 약 복용 중 → 진료).
2. **수치 쓰지 않기.** 고령 환자 생존율·합병증률·"몇 세 이상은" 같은 나이 기준, 노인포괄평가 도구의 점수 기준(G8 등 점수 컷), 걸음 속도 기준, 체중 감소 "몇 kg·몇 %", 약 "몇 가지 이상이면 다약제", 낙상 위험 점수, 장기요양 등급 점수, 본인부담 비율은 본문에 넣지 않는다. 필요하면 "병원 평가지·공단 안내 기준". 도구 이름(노인포괄평가 등)은 개념으로만.
3. **약·처방 단정 금지.** 이 권은 항암제 이름을 쓰지 않는다(암종 공통). 범주(수술·항암·표적·면역·호르몬·방사선·관찰·증상 조절)까지만. 용량 미기재. "고령은 용량을 줄인다" 단정 금지 → "몸 상태에 맞춰 의료진이 용량·일정을 조정할 수 있음". 평소 약(혈압·당뇨·혈액을 묽게 하는 약·수면제 등)은 "임의로 끊거나 더하지 말고, 약 봉투를 모두 들고 가 의료진·약사와 정리". 한약·건강기능식품도 같은 원칙.
4. **"나이 때문에 치료 불가/가능" 단정 금지.** "나이만으로 치료를 정하지 않는다"가 원칙. 동시에 "고령도 다 버틸 수 있다" 같은 효능 약속도 금지. 결정은 "몸 상태·치료 목표·본인 뜻을 함께 놓고 담당의와".
5. **본인 결정권 문장.** "환자 본인에게 먼저 설명", "가족이 진단을 숨기지 않기"를 원칙으로 쓰되, 본인이 "자녀에게 맡기겠다"고 원하면 그것도 본인의 선택임을 존중. 기억력 저하가 있어도 "이해할 수 있는 만큼 본인에게 설명하고 뜻을 묻는다". 의사결정 능력 판단·법정 대리(성년후견 등)는 개념 + 문의처까지만, 법률 조언 아님.
6. **인지·기분 문장은 진단 단정 금지.** "치매입니다"·"우울증입니다" 금지. 섬망은 "갑자기 생기는 혼란 상태 — 흔히 일시적이지만 원인을 찾아야 하는 신호"로, 치매와 다르다는 점만 개념으로. 기억 검사는 "평가 결과는 의료진이 해석".
7. **낙상·영양·운동 문장.** 운동 처방(횟수·시간·강도 숫자) 금지 → "할 수 있는 만큼, 재활 의료진 안내대로". "단백질을 몇 g" 금지 → "영양 상담". 집 안 낙상 예방은 일반 생활 수칙(문턱·전선·조명·미끄럼 방지)만.
8. **제도 문장.** 산정특례·장기요양보험·노인맞춤돌봄서비스·방문간호·의료급여·차상위 지원 등은 "개념 + 신청 창구(공단·주민센터·병원 사회복지팀)"까지, 등급·요건·금액은 "기관 확인" — 모두 S4에서 현행 확인. 사전연명의료의향서는 REC 26장과 같은 원칙(개념 + 등록기관에 문의, 암 진단 = 임종 준비 연결 금지).
9. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시, 종양내과·노년내과(노인의학)·재활의학·약제·영양·임상심리 관점 감수 필요 표기. 참고(ASCO 고령 암 환자 지침, SIOG 권고, NCCN Older Adult Oncology, 국가암정보센터 등)는 실재·최신 판 S4 확인 후 판 번호 따로.
10. **독자 배려 조판 지시(S6로 전달).** 본문 글자 한 단계 크게, 장마다 "오늘의 한 가지" 상자, 표·도해는 흑백 출력에서도 읽히게, 응급 카드는 냉장고에 붙일 수 있는 1쪽.
11. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~20·26·27권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽, 큰 글씨)
- 0-1 기다리지 않는 신호(공통 카드: 항암 중 38.0°C 발열·오한 = 해열제보다 먼저 연락 / **열이 없어도**: 갑자기 멍함·엉뚱한 말, 종일 누워만 있음, 거의 못 먹고 못 마심, 소변 크게 줄어듦, 새로 자꾸 넘어짐 = 연락 / 숨이 차서 말을 잇기 어려움·가슴 통증, 갑자기 한쪽 팔다리 힘 빠짐·말 어눌함 = 119 / 피를 토함·검은 변 / 넘어져 머리를 부딪혔고 혈액을 묽게 하는 약을 먹는 중 = 진료 / 암종별 신호는 해당 권 응급 카드) · 0-2 오늘 확인할 세 가지(진단을 내가 직접 들었는가 / 다음 진료 날짜와 같이 갈 사람 / 먹는 약 봉투 모두 한 봉지에) · 0-3 책 사용법(환자 본인은 각 장 "오늘의 한 가지"만 읽어도 됨 · 보호자는 PART 3 로드맵 · 치료를 줄이거나 쉬는 선택을 생각 중이면 12·14장) · 0-4 온라인 연결(가족이 대신 열어 줄 수 있게 QR 큰 크기)

### PART 1. 진단 첫 주 — 나이보다 '나'를 알리기
1. "이 나이에 암이라니" — 놀람·체념·"자식에게 짐"이라는 마음 · 오래 살았으니 괜찮다는 말 뒤의 진짜 마음 → **EP01**
2. 소식 뒤 72시간: 진단을 본인이 직접 듣기 · 동행 한 명 정하기 · 약 봉투 모두 챙기기 · 먼저 걱정되는 것 세 가지 적기 → **EP02**
3. 진료실에서 잘 듣는 법: 보청기·안경 챙기기 · "천천히, 한 번 더" 요청 · 큰 글씨 안내문 · 녹음은 병원에 묻고 · 가족이 대신 답하지 않기 → **EP03**
4. 진단과 병기 확인 — 검사에도 부담이 있다 · "이 검사 결과가 치료를 바꾸나요?" 묻기 · 조영제·장 정결·금식이 힘들 때 미리 말하기 → **EP04**
5. 노인포괄평가 — 걷기·일상동작·영양·기억·기분·복용 약·함께 사는 사람을 한 번에 살피는 이유(점수는 의료진이 해석) → 심화 **EP11**
6. 약 봉투를 모두 꺼내기: 여러 약을 함께 먹을 때(다약제) · 혈압·당뇨·혈액을 묽게 하는 약·수면제 · 한약·건강기능식품 포함 · 약사 상담 → 심화 **EP12**
7. 기억이 깜빡할 때와 섬망 — 갑자기 생기는 혼란은 원인을 찾아야 하는 신호 · 치매와 다른 점 · 가족이 알아차리는 법 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 나이만으로 정하지 않는다: 같은 나이, 다른 몸 · 체력·동반 질환·일상동작으로 함께 보기 → **EP05**
9. 치료 목표 말하기: 얼마나 오래 · 얼마나 잘 · 어디서(집에서) — 내가 지키고 싶은 것을 먼저 → **EP06**
10. 수술 전 몸 만들기(수술 전 재활): 걷기 · 숨쉬기 운동 · 먹는 양 늘리기 · 수술 뒤 회복 계획(퇴원 후 누가 돌볼지)까지 → 심화 **EP14**
11. 나에게 맞춘 강도: 항암·방사선의 용량·일정 조정은 의료진이 정하는 것 · 부작용을 숨기지 않아야 조정할 수 있음 → 심화 **EP15**
12. 지켜보는 것도 계획이다: 적극 치료 대신 관찰·증상 조절을 고르는 선택 · 마음이 바뀌면 다시 상의 · 완화의료는 처음부터 함께 → 심화 **EP16**
13. 누가 결정하나: 본인 결정권 · 자녀가 대신 듣고 정하는 관행 바꾸기 · 본인이 맡기고 싶을 때 · 가족 의견이 갈릴 때 → **EP07**
14. 미리 말해 두기: 사전 돌봄 계획 · 사전연명의료의향서 개념 · 대신 결정할 사람 정하기(암 진단 = 마지막 준비가 아님을 먼저) → 심화 **EP17**
15. 치료 결정 대화법: 공유 의사결정 · "치료하면/안 하면 내 일상은 어떻게 달라지나요?" · 결정을 미루고 싶을 때

### PART 4. 치료 중 몸과 마음
19. 감염과 열: 38.0°C · 열 없이 오는 감염 신호 · 예방접종은 의료진과 상의 · 손 씻기·입 관리 → **EP08**
20. 넘어지지 않기: 집 안 낙상 예방(문턱·전선·조명·화장실 손잡이·미끄럼 방지) · 어지러움·밤 화장실 · 지팡이·보행기 → **EP09**

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 이 나이에도, 내 일이에요
1. 진료실, 한수가 중절모를 무릎에 올려놓고 담담한 얼굴, 옆에서 은영이 입술을 깨묾 / 한수 "살 만큼 살았는데 뭘" / "이 나이에"라는 말 뒤에도 두려움·서운함이 함께 있을 수 있음 — 모두 자연스러운 반응.
2. 오래된 나무 의자에 새 받침대를 끼워 다시 세우는 목수의 손(색만) / (대사 없음) / 나이가 많다는 것만으로 치료 길이 정해지지 않음.
3. 주치의가 한수와 눈높이를 맞춰 몸을 숙이고 앉음 / 주치의 "어르신 뜻을 먼저 듣고 싶어요" / 진단과 치료 설명은 환자 본인이 먼저 듣는 것이 원칙.
4. 집 마루, 한수가 덕희에게 따뜻한 보리차를 따라 줌 / 한수 "내 일이니 내가 들어야지" / 결정의 중심은 본인 — 가족은 곁에서 돕는 자리.

### EP02 약 봉투는 다 들고 오세요
1. 안방, 은영이 서랍·찬장에서 약 봉투·한약 파우치·영양제 통을 꺼내 식탁에 모음(색 덩어리, 글자 없음) / 은영 "아빠 약이 이렇게 많았어?" / 진단 직후 먹고 있는 약을 모두 한자리에 모으기.
2. 큰 지퍼백 하나에 약들이 차곡차곡 담기는 그림(색만) / (대사 없음) / 처방약·한약·건강기능식품·연고·안약까지 전부.
3. 한수가 달력에 다음 진료 칸을 비워 두고 은영과 동행 표시(기호만, 숫자 없음) / 한수 "다음엔 누가 같이 가냐" / 다음 진료 날짜와 함께 갈 사람을 먼저 정하기.
4. 한수가 돋보기를 쓰고 작은 수첩에 걱정 세 가지를 그림 기호로 적음(집·밥그릇·덕희 얼굴 그림) / 한수 "제일 걱정되는 건 이거" / 가장 걱정되는 것을 적어 가면 진료 대화가 쉬워짐.

### EP03 한 번 더, 천천히요
1. 진료실, 한수가 보청기 낀 귀를 기울이며 미간을 찌푸림 / 한수 "다시 한 번만 말해 주쇼" / 잘 안 들리면 다시 요청하는 것은 당연한 권리.
2. 커다란 글씨 안내문과 그림 카드가 탁자에 펼쳐지는 장면(글자 흐림) / (대사 없음) / 큰 글씨 안내문·그림 설명을 요청할 수 있음.
3. 은영이 대답하려다 멈추고 아버지 쪽으로 손바닥을 내밂 / 은영 "아빠가 직접 말씀하세요" / 가족이 대신 답하면 환자의 진짜 증상·뜻이 묻힐 수 있음.
4. 주치의가 천천히 고개를 끄덕이며 요약하는 손짓 / 주치의 "제가 한 말, 어르신 말로 해 보실래요?" / 들은 내용을 내 말로 다시 말해 보면 이해를 확인할 수 있음.

### EP04 이 검사가 무엇을 바꾸나요
1. 검사 안내 데스크, 한수가 검사 일정표(글자 흐림)를 들고 한숨 / 한수 "검사가 또 있어요?" / 진단·병기 검사는 치료를 정하는 데 필요하지만 부담도 있음.
2. 저울 한쪽에 돋보기(검사 정보), 다른 쪽에 지친 의자(몸의 부담) 그림(색만) / (대사 없음) / 검사로 얻는 정보와 몸의 부담을 함께 따져 보기.
3. 진료실, 은영이 수첩 질문을 짚음 / 은영 "결과가 치료를 바꾸나요?" / 검사 결과가 치료 선택을 바꾸는지 물어보는 것은 좋은 질문.
4. 간호사가 금식·장 준비 안내 그림 카드(글자 없음)를 보여 주고 한수가 손을 듦 / 한수 "굶는 게 제일 힘들어" / 금식·장 정결·조영제가 힘들 것 같으면 미리 말하기 — 방법을 조정할 수 있는지 상의.

### EP05 나이 숫자보다 몸의 나이
1. 외래 대기실, 주황 등산 조끼의 호철이 한수 옆에 앉아 등산 사진을 보여 줌(휴대폰 화면 흐림) / 호철 "나는 주사 그대로 맞소" / 비슷한 나이라도 몸 상태에 따라 치료 강도가 다를 수 있음.
2. 같은 크기의 두 나무 — 하나는 줄기가 단단하고 하나는 뿌리를 보살펴야 하는 그림(색만) / (대사 없음) / 나이 숫자보다 체력·일상동작·동반 질환이 치료 선택에 중요.
3. 진료실, 주치의가 한수의 걷는 모습을 지켜보는 장면(진료실 복도) / 주치의 "걸음도 같이 볼게요" / 걷기·일상생활 능력은 치료를 견딜 힘을 가늠하는 단서.
4. 한수가 호철에게 손을 흔들며 서로 다른 진료실로 들어감 / 한수 "각자 몸에 맞게 가는 거지" / 남과 비교하지 않고 내 몸에 맞는 길을 의료진과 정하기.

### EP06 내가 지키고 싶은 것
1. 집 마당 목공 작업대, 한수가 대패를 쓰다듬으며 생각에 잠김 / 한수 "손주 의자는 다 만들고 싶어" / 치료 목표에는 "오래"뿐 아니라 "무엇을 하며 살고 싶은지"가 들어감.
2. 세 개의 작은 액자: 걸어서 산책하는 노부부·손주와 의자·집 마루(색만) / (대사 없음) / 혼자 걷기·집에서 지내기·정신이 맑은 것 — 지키고 싶은 것을 말하기.
3. 진료실, 한수가 수첩 그림을 보여 주고 주치의가 메모 / 주치의 "이걸 치료 계획에 넣을게요" / 내 우선순위를 알려야 의료진이 치료의 이득과 부담을 함께 잴 수 있음.
4. 저녁 마루, 덕희가 한수 손을 잡음 / 덕희 "당신 하고 싶은 대로 해요" / 목표는 바뀔 수 있음 — 마음이 바뀌면 다시 말하기.

### EP07 아버지께 먼저 말씀해 주세요
1. 진료실 앞 복도, 경수가 휴대폰 화상통화 화면 속에서 굳은 얼굴, 은영이 휴대폰을 들고 있음 / 경수 "아버지껜 자세히 말하지 말자" / 가족이 충격을 걱정해 진단을 숨기려는 경우가 있음.
2. 닫힌 문 앞에 선 사람과 열린 창으로 햇빛이 드는 방 그림(색만) / (대사 없음) / 숨기면 본인이 자기 치료를 고를 기회를 잃음.
3. 진료실, 은영이 주치의에게 한 손을 내밀며 아버지 쪽을 가리킴 / 은영 "아버지께 먼저 말씀해 주세요" / 본인에게 먼저, 이해할 수 있는 속도로 설명하는 것이 원칙.
4. 한수가 화상통화 화면 속 경수에게 웃어 보임 / 한수 "다 들었다. 걱정 마라" / 본인이 "자녀에게 맡기겠다"고 원하면 그것도 본인의 선택 — 뜻을 먼저 묻기.

### EP08 열이 없어도 이상하면
1. 아침 안방, 한수가 이불 속에서 멍하게 천장을 봄, 덕희가 이마를 짚음 / 덕희 "열은 없는데 이상해요" / 고령에서는 감염이 있어도 열이 높지 않을 수 있음(평소와 다른 멍함·기운 없음이 신호).
2. 체온계(숫자 없음) 옆에 물컵·밥그릇이 그대로 남은 그림(색만) / (대사 없음) / 못 먹고 못 마심·소변 줄어듦·새로 넘어짐도 연락할 신호.
3. 은영이 휴대폰으로 병원 응급 연락처(냉장고 카드)를 보며 전화 / 은영 "평소랑 많이 달라요" / 열이 없어도 "평소와 다름"을 구체적으로 전하기. 항암 중 38.0°C 이상이면 해열제보다 먼저 연락.
4. 응급실 접수대, 은영이 약 목록 한 장과 치료 카드(글자 없음)를 내밂 / 은영 "항암 중이고 약은 이거예요" / 응급실에서 치료 중임과 약 목록을 먼저 보여 주기.

### EP09 문턱 하나, 전선 하나
1. 거실, 물리치료사가 방문 안내 중 바닥 전선과 미끄러운 깔개를 가리킴(밝은 낮) / 치료사 "여기가 제일 위험해요" / 치료 중에는 어지러움·기운 없음으로 넘어지기 쉬움.
2. 집 평면 그림에 문턱·전선·깔개 자리가 연한 색으로 표시되고 화장실 손잡이·야간등이 더해짐(색만) / (대사 없음) / 문턱·전선 정리, 화장실 손잡이, 밤길 조명이 낙상 예방의 기본.
3. 한수가 직접 깎은 나무 지팡이를 들고 멋쩍게 웃음 / 한수 "내 손으로 만든 거니 써야지" / 지팡이·보행기는 약해서가 아니라 넘어지지 않으려고 쓰는 도구.
4. 밤, 한수가 침대 가장자리에 잠시 앉았다가 천천히 일어남, 발밑 야간등 / 한수 "앉았다가 천천히" / 누웠다 일어날 때 잠깐 앉아 있기 — 어지러움이 자주 오면 의료진에게 알리기.

### EP10 짐이 아니에요
1. 저녁 마루, 한수가 창밖을 보며 혼잣말, 등 뒤로 은영이 퇴근 가방을 내려놓음 / 한수 "내가 애들한테 짐이지" / "짐이 된다"는 생각은 고령 환자에게 흔한 마음.
2. 오래된 나무에 새 가지가 자라 서로 기대는 그림(색만) / (대사 없음) / 돌봄은 주고받는 것 — 평생 가족을 돌봐 온 시간도 함께 있음.
3. 상담실, 심리상담사가 한수와 눈을 맞추고 손을 모음 / 상담사 "밤에 잠은 좀 주무세요?" / 잠·입맛·의욕이 두 주 넘게 떨어지면 전문가와 상의.
4. 주말, 한수가 손주와 은영 앞에서 작은 나무 의자 다리를 맞춰 보임 / 은영 "아빠가 있어서 든든해" / 할 수 있는 작은 역할 하나가 마음을 지탱함.

### EP11 (심화) 걷기·밥·기억·약 — 몸 점검
1. 평가실, 노인포괄평가 간호사가 클립보드(글자 없음)를 들고 한수와 마주 앉음 / 간호사 "몸 전체를 한 번 볼게요" / 노인포괄평가는 치료 전에 몸과 생활을 두루 살피는 평가.
2. 원 하나를 여섯 조각으로 나눈 그림: 걷는 발·밥그릇·머리(기억)·하트(기분)·약 봉투·집(함께 사는 사람) (색만) / (대사 없음) / 걷기·일상동작·영양·기억·기분·복용 약·사회적 지원을 함께 봄.
3. 복도, 한수가 표시선(글자 없음) 사이를 걷고 간호사가 지켜봄 / 간호사 "평소 걸음으로 걸으세요" / 평가 결과는 점수 자체보다 무엇을 도와야 하는지 찾는 데 쓰임 — 해석은 의료진이.
4. 진료실, 주치의가 평가 결과지(글자 흐림)를 보며 한수에게 설명 / 주치의 "약 정리랑 밥부터 챙겨요" / 평가에서 찾은 약한 부분은 치료 전에 보완할 수 있음.

### EP12 (심화) 약이 몇 가지인지 세어 봐요
1. 약제부 상담실, 약사가 지퍼백 속 약을 탁자에 펼침(색 덩어리) / 약사 "같은 성분이 두 번 있네요" / 여러 병원에서 받은 약이 겹치거나 서로 영향을 줄 수 있음.
2. 실타래가 엉켰다가 풀려 색깔별로 정리되는 그림(색만) / (대사 없음) / 항암 치료와 평소 약·한약·건강기능식품 사이의 상호작용을 확인.
3. 약사가 색 스티커로 아침·점심·저녁 칸을 나눈 약 달력을 보여 줌(글자 없음) / 은영 "이렇게 하면 헷갈리지 않겠다" / 약 달력·약통으로 복용 실수를 줄일 수 있음.
4. 한수가 수면제 봉투를 들고 머뭇거림 / 한수 "이건 그냥 끊을까?" / 평소 약을 임의로 끊거나 더하지 말고 의료진·약사와 상의.

### EP13 (심화) 밤에 갑자기 낯설어질 때
1. 수술 뒤 병실 밤, 한수가 혼란스러운 얼굴로 창문을 보며 이불을 걷으려 함(어둑한 조명, 무서운 연출 없음) / 한수 "여기가 우리 집 아니여?" / 수술·감염·약 등으로 갑자기 생기는 혼란(섬망)이 고령에서 생길 수 있음.
2. 구름이 낀 하늘 사이로 해가 다시 드는 그림(색만) / (대사 없음) / 섬망은 치매와 다르며 원인을 찾아 치료하면 좋아지는 경우가 많다고 설명됨 — 빨리 알리기.
3. 병동 간호사가 은영과 함께 침대 옆 낮은 조명을 켜고 시계·달력(숫자 없음)을 보이는 자리에 둠 / 간호사 "익숙한 물건이 도와요" / 안경·보청기, 익숙한 얼굴·물건, 낮과 밤의 구분이 도움.
4. 다음 날 아침 햇살, 한수가 맑은 얼굴로 은영과 죽을 먹음 / 한수 "어젯밤엔 내가 왜 그랬나" / 가족이 "평소와 다르다"를 먼저 알아차림 — 이상하면 바로 의료진에게.

### EP14 (심화) 수술 전에 몸부터
1. 재활실, 물리치료사가 한수에게 의자에서 앉았다 일어나기를 보여 줌 / 치료사 "할 수 있는 만큼만요" / 수술 전 걷기·근력·숨쉬기 운동(수술 전 재활)을 권하기도 함.
2. 계단 세 칸에 걷는 발·숨쉬는 풍선·밥그릇 그림이 하나씩 놓임(색만) / (대사 없음) / 움직이기·숨쉬기·잘 먹기가 회복을 돕는 세 가지 — 운동 양은 의료진 안내대로.
3. 동네 골목, 한수가 덕희와 천천히 산책, 손에는 나무 지팡이 / 덕희 "오늘은 저 전봇대까지" / 무리하지 않고 매일 조금씩 — 숨이 차거나 가슴이 아프면 멈추고 알리기.
4. 진료실, 은영이 퇴원 뒤 돌봄 계획 메모(그림)를 보여 줌 / 은영 "퇴원하면 제가 첫 주 있을게요" / 수술 뒤 누가 어디서 돌볼지도 수술 전에 미리 계획.

### EP15 (심화) 나에게 맞춘 강도
1. 주사실 의자, 호철이 주사를 맞으며 간호사에게 손 저림을 말함 / 호철 "손끝이 좀 저려요" / 부작용을 숨기지 않고 말해야 의료진이 조정할 수 있음.
2. 라디오 다이얼이 사람마다 다른 위치에 맞춰진 그림(색만, 숫자 없음) / (대사 없음) / 치료 용량·간격·방법은 몸 상태와 부작용에 맞춰 의료진이 조정할 수 있음.
3. 진료실, 주치의가 호철과 대화하며 일정표(글자 흐림)를 손짓 / 주치의 "이번엔 간격을 조정해 봐요" / 조정은 의료진이 정함 — 환자가 스스로 약을 줄이거나 건너뛰지 않기.
4. 등산로 입구 벤치, 호철이 가벼운 산책 차림으로 앉아 물을 마심 / 호철 "산은 낮은 데로 바꿨소" / 일상 활동도 치료 중 몸에 맞게 조절.

### EP16 (심화) 지켜보는 것도 계획
1. 진료실, 화자가 손수레를 옆에 두고 조카며느리(측면)와 앉음 / 화자 "힘든 치료는 안 하고 싶어" / 적극 치료 대신 관찰·증상 조절을 고르는 것도 정당한 선택.
2. 정원사가 나무를 자르지 않고 받침대를 세워 주는 그림(색만) / (대사 없음) / 관찰도 정기 진료와 증상 관리가 함께하는 하나의 계획.
3. 주치의가 화자의 손등에 손을 얹고 끄덕임 / 주치의 "불편하면 언제든 오세요" / 통증·숨참·잠·입맛은 계속 돌볼 수 있음 — 완화의료팀이 처음부터 함께할 수 있음.
4. 화자 집 앞 평상, 화자가 떡 쟁반을 이웃(측면)과 나눔 / 화자 "마음 바뀌면 또 물어볼게" / 결정은 바꿀 수 있음 — 마음이 바뀌면 다시 상의.

### EP17 (심화) 미리 말해 두기
1. 저녁 마루, 한수가 휴대폰 화상통화로 경수·은영과 함께 이야기(경수는 화면 속) / 한수 "미리 말해 둘 게 있다" / 건강할 때 원하는 돌봄을 미리 이야기해 두는 것을 사전 돌봄 계획이라 함.
2. 나무 상자에 편지 한 장과 열쇠를 넣는 그림(색만, 글자 없음) / (대사 없음) / 사전연명의료의향서는 개념과 등록 기관을 알아 두는 것부터 — 암 진단이 곧 마지막 준비라는 뜻은 아님.

### EP18 (심화) 틀니가 헐거워졌어요

### EP19 (심화) 혼자 사는 화자 씨

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **5장(노인포괄평가) · 8장(나이만으로 정하지 않는다) · 13장(누가 결정하나)**.
- 공식 환자 안내(NCI·ASCO 고령 환자 안내·국가암정보센터 등 — S4에서 실재·최신 판 확인)와 각 권 고령 관련 문장을 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~11을 골든샘플부터 적용.
- 이 권은 항암제 이름을 쓰지 않는다. 암종별 세부가 필요한 곳마다 "→ 해당 권 ○장" 연결 상자(①~㉕ 권 번호표를 부록에 1쪽).
- 문장 규칙: 한 문장 한 가지, 본인용 "오늘의 한 가지" 상자는 두 줄 이내, 존댓말(어르신을 아이처럼 대하는 말투 금지 — "잘하셨어요~" 같은 표현 금지).
- 주인공 한수는 암종 미표시·수술 전 몸 만들기 → 수술 → 섬망 회복 경로. 표준 강도 그대로는 호철, 관찰·증상 조절과 돌봄 제도는 화자 — 본문 사례도 같은 분담.
- 13장(누가 결정하나)은 첫 문단을 "진단은 본인이 먼저 듣는다"로 열고, 본인이 맡기고 싶어 하는 경우의 존중 문장을 반드시 함께 둔다.
- 14장(미리 말해 두기)은 REC 26장과 같은 원칙: 첫 문단 "암 진단은 마지막 준비가 아니다", 제도는 개념 + 문의처까지.
- 보호자 문장은 ㉖ CG권과 중복되지 않게 "환자 곁에서 할 일"만, 보호자 자신의 소진·돌봄은 CG권으로 연결.
