- 발행: 2026-11-22 · 책공장(Claude 총괄 PD)
- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **MEL v1.0** (로스터상 "미착수" — 새로 설계)
- 상태: **G1 대기** — 결재함에 `G1 승인 MEL` 또는 `G1 수정 MEL: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학 문장은 방향 설계이며 확정 문장이 아니다.
- 범위: **성인 피부 흑색종 첫 진단** — 주인공 줄기는 한국에서 상대적으로 많이 보고되는 **손발바닥·손발톱(말단) 흑색종: 발바닥 → 넓은 절제 + 피부이식 → 감시림프절생검 양성 → 수술 뒤 보조 면역치료**(빈도 표현은 S4 출처 확인 후, 확인 전엔 "한국 등 아시아에서 비교적 많이 보고됨" 수준). 등·팔 등 햇빛 노출 부위의 얇은 흑색종(넓은 절제 뒤 추적)과 처음부터 전이된 흑색종(면역치료·표적치료 · 면역 부작용)은 보조 인물로 같은 무게로 보여 준다. 점막(입안·코·생식기·항문)·안구(포도막) 흑색종은 15장 안내 상자. 다른 피부암(기저세포암·편평세포암)은 1장 비교 상자, 뇌전이는 15장 + ⑲ BT·㉕ MET, 재발은 24장 끝 + ㉗ REC, 소아는 ㉓ PED.
- 톤: 흑색종은 **"눈으로 볼 수 있는 자리에서 시작하는 암"**이다 — 내 피부를 내가 살피는 습관이 치료 뒤에도 가장 오래가는 도구다. 책 전체의 축은 두 가지: ① **"결과지의 두께 한 줄이 길을 정한다"**(두께·궤양·감시림프절·BRAF 결과가 수술 범위와 약 선택을 바꾼다 — 결과지를 읽고 묻는 법), ② **"면역치료는 몸 전체에 신호를 보낸다"**(부작용은 어느 장기에나 올 수 있고 늦게도 올 수 있다 — 새 증상은 참지 말고 바로 알린다). "점 하나 늦게 봐서" 같은 탓 문장 금지, 자외선 정보는 말단 흑색종 독자에게 그대로 적용하지 않는다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 면역치료·표적치료 중 발열, 수술 상처 발열 모두 38.0°C. 표적치료(BRAF·MEK 억제제) 중 발열은 "약 때문이라고 넘기지 말고 연락 — 약을 계속할지 의료진이 판단" 고정. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리.
2. **수치 쓰지 않기.** 생존율·재발률·반응률, Breslow 두께 기준 "몇 mm", 절제 여백 "몇 cm", 감시림프절 양성 비율, 면역치료 "몇 주마다·몇 회·몇 년", 추적 "몇 개월마다", LDH 기준값, SPF 숫자 권고, 회복 기간 같은 수·기간은 본문에 넣지 않는다. 필요하면 "병원 안내문·결과지 기준"으로. 병기(AJCC)는 개념만 출처 달고, 표 복제 금지.
3. **약은 "범주 + 대표 예"로만.** PD-1 억제제(대표 예는 S4에서 국내 허가 확인 후 하나만), CTLA-4 억제제(범주), LAG-3 병합(범주), BRAF·MEK 억제제 병합(범주 — 상품명 나열 금지), 종양 내 주사·세포치료(범주, 국내 미도입 가능성 명시) → 용량·주기 미기재, 모두 "국내 허가·급여 변경 가능 + 의료진 확인". "BRAF 음성이면 치료 없음" 금지 → "면역치료 등 다른 길".
4. **면역 부작용 문장 고정.** 설사·혈변·복통, 새 기침·숨참, 심한 피로·추위 탐·어지러움(호르몬), 눈·피부가 노래짐, 심한 두통·시야 변화, 근육 약해짐·가슴 두근거림, 소변 감소, 심한 발진·입안 물집 → "참지 말고 바로 연락, 치료 끝난 뒤에도 생길 수 있음". 면역치료 카드 지니기(다른 병원·응급실에서 보여 주기). 스테로이드 치료는 "부작용 치료로 필요할 수 있음 — 임의로 시작·중단하지 않음", 항암 효과 단정(사라진다/유지된다) 금지 → "의료진이 판단".
5. **탓·낙인 금지.** "점을 늦게 봐서"·"햇볕을 많이 쬐어서" 같은 원인 단정 금지. 말단 흑색종에 자외선 원인 문장 적용 금지 — "손발바닥·손발톱 흑색종은 자외선과의 관련이 뚜렷하지 않은 것으로 설명됨(S4 출처 확인)". 자외선 차단은 "새 피부암 예방·피부 보호" 방향으로만.
6. **자가검진 문장.** ABCDE·'미운 오리 새끼' 징후는 개념만, "모든 점을 뗄 필요는 없음 — 변하는 점·새로 생긴 점·다른 점과 다른 점은 진료". 손발톱 세로줄은 "모두 흑색종은 아님, 넓어지거나 번지면 진료". 진단은 조직검사로만 — 사진·앱으로 판정 금지.
7. **수술 문장은 약속하지 않기.** "흉터 없이·기능 그대로" 단정 금지 → "부위·범위에 따라 다르고, 재건·재활로 돕는다". "발가락·손가락 절단이 원칙" 금지 → "부위·깊이에 따라 다르며 기능 보존 수술을 우선 상의(S4 확인)". 감시림프절 양성이어도 "모든 림프절 제거가 원칙은 아님 — 지금은 추적·보조치료를 상의하는 경우가 많음(S4 지침 확인)".
8. **응급 문장 고정.** 면역치료 중 숨참·가슴 통증 → 119, 의식 저하·심한 두통과 구토·갑자기 한쪽 힘 빠짐·말 어눌함·경련 → 119, 설사가 하루 여러 번·혈변·심한 복통, 38.0°C 발열, 눈·피부 노래짐, 심한 어지러움·쓰러질 듯함, 수술 부위가 갑자기 붓고 뜨겁고 고름 — 0-1·20장·21장 같은 문장.
9. **유전·가족 문장.** "흑색종은 대부분 유전되지 않지만 가족 중 여러 명·젊은 나이·여러 개 원발 등은 유전상담 상의"(S4 출처 확인), 가족에게 피부 검진 권유는 강요 없이.
10. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN Melanoma: Cutaneous, ESMO 피부 흑색종, ASCO, AJCC 제8판 병기, 대한피부과학회·대한피부암학회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
11. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~19·26·27권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(면역치료 중 숨참·가슴 통증 → 119 · 의식 저하·심한 두통과 구토·갑자기 한쪽 힘 빠짐·경련 → 119 · 면역·표적치료 중 38.0°C 이상 발열·오한 = 해열제보다 먼저 연락 · 설사가 잦아지고 피가 섞이거나 심한 복통 · 눈·피부가 노래짐·소변이 짙어짐 · 심한 피로·어지러움·쓰러질 듯함 · 시야가 갑자기 흐려지거나 눈 통증 · 수술 부위가 붓고 뜨겁고 고름·벌어짐 · 스스로를 해치고 싶은 생각 → 109·119) · 0-2 오늘 확인할 세 가지(결과지의 흑색종 종류·두께·궤양 / 감시림프절·영상 검사 계획과 BRAF 검사 여부 / 다음 진료 날짜와 응급 연락처, 면역치료를 받으면 치료 카드) · 0-3 책 사용법(내 길 찾기: 손발바닥·손발톱 → PART 2 앞쪽(8·9·10장), 얇은 흑색종 넓은 절제 뒤 추적 → 9·24장, 감시림프절 양성 → 10·11장, 처음부터 전이 → 12·13·14장, 점막·안구 → 15장, 재발 → 24장 + ㉗) · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 흑색종은 어떤 암인가요: 멜라닌세포에서 생기는 암 · 다른 피부암과의 차이 · 종류(표재확산형·결절형·말단흑자형·악성흑자형) · 색이 없는 흑색종도 있음 → **EP01**
2. 진단 뒤 72시간: 결과지·조직 사진 사본 두 부 · 병변 사진 기록 · 피부 전체 사진 · 가족 한 명 → **EP02**
3. 검사가 여러 개인 이유: 조직검사(절제 생검·부분 생검) · 감시림프절생검 · 초음파·CT·PET-CT·뇌 MRI는 필요한 사람에게 · LDH → **EP03**
4. 손발바닥·손발톱 흑색종: 한국 독자에게 중요한 이유(S4 출처) · 자외선 탓이 아님 · 손발톱 세로줄 · 걷기·손 쓰기를 지키는 수술 → **EP04**
5. 병리 읽기: Breslow 두께 · 궤양 · 유사분열 · 절제연 · 상피내 흑색종과 침윤 흑색종 — 뜻만, 기준 수치 없이 → 심화 **EP11**
6. 유전자 검사: BRAF V600 · NRAS·KIT 등 · 결과가 약 선택에 쓰이는 방식 · BRAF 음성이어도 길은 있음 → 심화 **EP12**
7. 내 피부를 내가 살피기 첫걸음: ABCDE · 다른 점과 다른 점 · 사진으로 변화 기록 · 앱·사진으로 판정하지 않기 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 넓은 절제(± 감시림프절생검) → 추적 / 수술 뒤 보조치료 상의(병기·위험도) / 수술 전 면역치료 상의(일부) / 처음부터 전이 — 면역치료·표적치료 · 다학제가 함께 정하는 이유 → **EP05**
9. 넓은 절제와 재건: 점을 뗀 자리보다 넓게 떼는 이유 · 피부이식·피판 · 발바닥·손가락 부위의 기능 보존 · 상처 관리 → **EP06**
10. 감시림프절생검: 무엇을 알려 주는 검사인가 · 양성이면 모두 떼나요(지금은 추적·보조치료 상의가 많음 — S4) · 림프부종 → **EP07**
11. 수술 뒤 보조치료: 누구에게 상의하나 · 보조 면역치료 · BRAF 양성이면 보조 표적치료도 상의 · 치료 안 하고 추적하는 선택 → 심화 **EP15**
12. 면역치료 이해하기: PD-1·CTLA-4·LAG-3(범주) · 몸 전체에 신호를 보낸다는 뜻 · 치료 카드 · 커 보여도 곧 진행은 아님 → 심화 **EP14**
13. 표적치료 이해하기: BRAF·MEK 억제제 병합(범주) · 발열·눈·피부·심장 확인 · 먹는 약 시간 지키기 · 면역치료와의 순서는 의료진과 → 심화 **EP16**
14. 처음부터 전이된 흑색종: 전신치료 먼저 · 뇌전이도 치료 길이 있음(수술·방사선·약 — ⑲ BT·㉕) · 방사선이 쓰이는 경우 · 임상시험 → 심화 **EP17**
15. 다른 흑색종 안내: 점막 흑색종(입안·코·생식기·항문 — 부위별 진료과) · 안구(포도막) 흑색종(안과·간 추적) · 원발 부위를 모르는 흑색종 · 임신 중 진단 · 2차 소견 · 임상시험
16. 치료가 어려울 때: 통증·부기·출혈 완화 · 완화의료 병행 · 치료 목표 다시 묻기

### PART 3. 30일 실행 로드맵
17. Day 0–7 확인하고 기록하기(결과지 종류·두께·궤양 · 병변·피부 사진 · 영상 계획 · BRAF 검사 여부 · 복용 약·자가면역질환 목록)
18. Day 8–21 결정하고 준비하기(넓은 절제·감시림프절생검 · 재건 계획 · 다학제 결과 · 보조치료 상의 · 직장·가족 역할)

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 장화 속의 검은 점
1. 저녁 집, 용수가 장화를 벗고 발을 주무르다 영애가 뒤꿈치를 가리킴(발바닥은 보이지 않게, 영애의 놀란 표정) / 영애 "여기 점이 커졌어요" / 모양·색·크기가 변하는 점은 진료로 확인.
2. 피부과 진료실, 주치의가 확대경으로 발을 살피는 뒷모습(발은 가림) / 주치의 "조직검사로 확인해 볼게요" / 흑색종 진단은 조직검사로만 — 사진·앱으로 판정하지 않음.
3. 의학삽화: 피부 단면 — 표피 아래 멜라닌세포가 짙은 색으로 표시(글자 없음) / (대사 없음) / 흑색종은 피부 색을 만드는 멜라닌세포에서 생기는 암.
4. 진료실, 주치의가 서로 다른 모양의 점 그림 카드 여러 장 중 하나를 집음 / 주치의 "흑색종도 종류가 여러 가지예요" / 흑색종은 종류가 여럿이고 색이 거의 없는 경우도 있음.

### EP02 사진부터 찍어 둬요
1. 밤 거실, 용수가 휴대폰 검색 화면을 보다 영애가 화면을 덮음 / 영애 "검색은 그만, 정리부터" / 진단 직후엔 검색보다 내 결과지·일정 정리가 먼저.
2. 한결이 휴대폰으로 아버지 발의 붕대 감은 자리를 멀리서 찍음(자를 옆에 둔 시늉, 숫자 없음) / 한결 "날짜 넣어서 찍어 둘게요" / 병변·피부 사진을 날짜와 함께 남기면 변화 비교에 도움.
3. 식탁, 영애가 결과지 사본을 투명 파일 두 개에 나눠 넣음 / 영애 "한 부는 집, 한 부는 가방" / 결과지·조직 슬라이드 정보는 사본 두 부 — 다른 병원 진료에 바로 쓰기 위해.
4. 거실, 셋이 달력에 다음 진료 날짜를 표시하고 한결이 아버지 어깨를 두드림 / 용수 "가게는 잠깐 한결이가" / 가족 한 명이 진료에 동행하고 일 분담을 정함.

### EP03 파란 물감을 따라가요
1. 외과 설명실, 외과 의사가 다리의 림프관 의학삽화(가는 길이 사타구니로 모임)를 보여 줌 / 외과 의사 "첫 번째 림프절을 찾아요" / 감시림프절은 종양에서 림프액이 처음 닿는 림프절.
2. 의학삽화: 파란 점이 림프관을 따라 한 림프절에 모이는 그림(글자 없음) / (대사 없음) / 추적 물질로 감시림프절을 찾아 떼어 전이 여부를 확인.
3. 용수가 "그럼 암을 다 없애는 수술이에요?" 하는 표정 / 외과 의사 "퍼졌는지 알아보는 검사예요" / 감시림프절생검은 병기를 정하는 검사 — 치료 계획에 쓰임.
4. 영상검사실 앞, 용수가 영애와 함께 대기, 안내판(글자 없음) / 영애 "CT는 필요한 사람만이래요" / CT·PET-CT·뇌 MRI는 병기·증상에 따라 필요한 사람에게 함.

### EP04 햇볕 탓이 아니에요
1. 시장 가게, 용수가 장화를 신고 일하며 고개를 갸웃 / 용수 "햇볕도 안 닿는 발바닥인데" / 손발바닥·손발톱 흑색종은 햇볕 노출과 관련이 뚜렷하지 않은 것으로 설명됨.
2. 의학삽화: 손바닥·발바닥·손발톱을 부드러운 색으로 표시한 몸 그림(글자 없음) / (대사 없음) / 말단 흑색종은 한국 등 아시아에서 비교적 많이 보고되는 유형.
3. 진료실, 주치의가 손톱 세로줄 그림 카드 두 장(가는 줄 / 넓게 번진 줄)을 보여 줌 / 주치의 "세로줄이 다 암은 아니에요" / 손발톱 세로줄이 넓어지거나 주변으로 번지면 진료.
4. 용수가 영애를 보며 미안한 표정, 영애가 손을 잡음 / 영애 "당신 탓 아니래요" / 흑색종은 누구의 탓이 아님 — 지금 할 일은 결과지 읽기와 치료 계획.

### EP05 결과지 한 줄이 정하는 길
1. 다학제 면담실, 피부과·외과·종양내과 의사가 함께 앉고 용수 가족이 맞은편 / 주치의 "세 과가 같이 봐요" / 흑색종 치료는 피부과·외과·종양내과 등 다학제가 함께 계획.
2. 의학삽화: 갈림길 — 수술 후 지켜보기, 수술 후 약, 약 먼저(아이콘, 글자 없음) / (대사 없음) / 치료 길은 두께·궤양·림프절·전이 여부로 달라짐.
3. 종양내과 의사가 결과지의 한 줄을 손가락으로 짚음(글자 흐릿) / 종양내과 의사 "이 결과가 길을 정해요" / 결과지의 두께·궤양·감시림프절 결과를 함께 읽기.
4. 한결이 질문 목록을 내밀고 용수가 끄덕임 / 한결 "아버지 가게 일도 생각해서요" / 일·생활에서 지키고 싶은 것을 말하면 계획에 반영할 수 있음.

### EP06 허벅지에서 옮긴 피부
1. 수술 전 설명실, 외과 의사가 발바닥 의학삽화에 넓은 테두리를 그림 / 외과 의사 "점 자리보다 넓게 떼요" / 넓은 절제는 주변에 남은 암세포를 줄이기 위한 수술.
2. 의학삽화: 허벅지에서 얇은 피부를 떼어 발바닥에 덮는 화살표(글자 없음) / (대사 없음) / 넓게 뗀 자리는 피부이식이나 피판으로 덮기도 함.
3. 병실, 용수가 수술용 신발을 신은 발을 베개 위에 올리고 간호사가 설명 / 간호사 "당분간 발에 무게는 조금만" / 상처·이식 부위가 붙을 때까지 의료진 안내대로 체중을 싣지 않음.
4. 퇴원 날, 영애가 상처 관리 안내를 수첩에 받아 적음 / 영애 "붓고 뜨거우면 바로 연락" / 수술 부위가 붓고 뜨겁거나 고름·벌어짐이 있으면 바로 연락.

### EP07 첫 림프절의 소식
1. 진료실, 외과 의사가 결과지를 펼치고 용수가 숨을 고름 / 외과 의사 "첫 림프절에서 암세포가 보여요" / 감시림프절 양성은 병기와 치료 계획에 쓰이는 정보.
2. 용수가 "그럼 다 떼야죠?" 하는 표정 / 외과 의사 "다 떼는 게 원칙은 아니에요" / 감시림프절 양성이어도 모든 림프절 절제 대신 추적·보조치료를 상의하는 경우가 많음.
3. 의학삽화: 다리 림프액 흐름과 부은 다리 윤곽(글자 없음) / (대사 없음) / 림프절 수술 뒤엔 다리·팔이 붓는 림프부종이 생길 수 있음.
4. 집, 한결이 아버지 다리 옆에 줄자를 놓고 영애가 기록지를 듦(숫자 없음) / 한결 "같은 자리를 재 둘게요" / 부기가 생기면 의료진이 정한 위치의 둘레를 기록해 알림.

### EP08 설사도 알려 주세요
1. 주사실, 용수가 팔걸이 의자에서 수액을 맞고 간호사가 카드(글자 없음)를 건넴 / 간호사 "이 카드는 꼭 지니세요" / 면역치료 카드는 다른 병원·응급실에서 치료 중임을 알리는 데 쓰임.
2. 며칠 뒤 집, 용수가 배를 감싸 쥐고 화장실 쪽을 봄, 영애가 걱정 / 용수 "배탈이겠지 뭐" / 면역치료 중 설사·복통은 장염일 수 있어 참지 말고 바로 연락.
3. 영애가 전화로 병원에 알리고 수첩에 횟수 칸을 체크(숫자 없음) / 영애 "면역치료 중인데 설사가 잦아요" / 횟수·혈변·복통·열을 함께 알리면 판단이 빨라짐.
4. 진료실, 종양내과 의사가 설명하고 용수가 고개를 끄덕임 / 종양내과 의사 "부작용 치료는 저희가 정해요" / 부작용 치료에 스테로이드 등이 필요할 수 있음 — 임의로 시작·중단하지 않음.

### EP09 약 먹다 열이 나면
1. 밤 침실, 봉수(딸이 옆)가 이불을 덮고 떨며 체온계를 봄(숫자 없음) / 딸 "아빠, 38.0도 넘었어" / 표적치료 중 38.0°C 이상 발열·오한은 약 때문이라고 넘기지 말고 연락.
2. 딸이 전화하며 약 봉투를 들어 보임 / 딸 "표적약 먹는 중이에요" / 약을 계속 먹을지는 의료진이 판단 — 병원 안내 기준이 다르면 병원 기준.
3. 진료실, 종양내과 의사가 눈·심장 그림 카드를 보여 줌 / 종양내과 의사 "눈이랑 심장도 확인해요" / 표적치료 중엔 시력 변화·피부·혈압·심장 기능을 함께 확인.
4. 집, 봉수가 아침 약 상자를 열고 딸이 알림을 맞춤 / 봉수 "토했다고 더 먹진 말자" / 약을 먹고 토했을 때 다시 먹을지는 미리 의료진 안내를 받아 둠.

### EP10 부은 발목 재기
1. 아침 거실, 용수가 수술한 쪽 발목이 부어 신발이 꽉 끼는 표정 / 용수 "오른발보다 붓네" / 수술·림프절 생검 뒤 다리 부기가 생길 수 있음.
2. 상처 전문간호사가 다리 올리기·발목 운동 그림 카드를 보여 줌 / 간호사 "올리고, 발목 돌리고" / 부기는 다리 올리기·운동·압박 등으로 관리 — 방법은 의료진과 정함.
3. 의학삽화: 감염 신호 — 붉고 뜨거운 부위, 열 아이콘(글자 없음) / (대사 없음) / 붓던 다리가 갑자기 붉고 뜨겁고 열 나면 감염일 수 있어 바로 연락.
4. 영애가 기록지에 둘레를 적고 용수가 압박 스타킹(무늬 없음)을 신음 / 영애 "매주 같은 날 재요" / 둘레 기록은 의료진이 정한 위치·시간에 맞춰 함.

### EP11 (심화) 두께라는 말
1. 진료실, 용수가 결과지의 영어 단어에 손가락을 짚음(글자 흐릿) / 용수 "브레슬로가 뭐예요?" / Breslow 두께는 피부 표면에서 흑색종이 내려간 깊이.
2. 의학삽화: 피부 단면에 깊이가 다른 두 흑색종(얕은 것·깊은 것), 표면이 벗겨진 궤양 표시(글자 없음) / (대사 없음) / 두께와 궤양은 병기와 수술 범위·보조치료 상의에 쓰임.
3. 주치의가 "상피내" 카드와 "침윤" 카드(색만 다른 두 장)를 나란히 놓음 / 주치의 "피부 겉층에만 있으면 달라요" / 상피내 흑색종과 침윤 흑색종은 치료 계획이 다름.
4. 영애가 수첩에 질문을 적음 / 영애 "내 경우엔 어떤 뜻이에요?" / 결과지 용어는 "내 경우의 뜻"을 담당 의사에게 묻기 — 기준 수치는 결과지·의료진 설명 기준.

### EP12 (심화) BRAF가 음성이래요
1. 진료실, 용수가 "음성" 소리에 실망한 얼굴 / 용수 "그럼 쓸 약이 없어요?" / BRAF 검사는 표적치료가 맞는지 보는 검사.
2. 의학삽화: 열쇠와 자물쇠 — 맞는 열쇠(표적약)와 다른 문(면역치료)(글자 없음) / (대사 없음) / BRAF 음성이어도 면역치료 등 다른 길이 있음.
3. 종양내과 의사가 NRAS·KIT 카드(색 카드, 글자 없음)를 보여 줌 / 종양내과 의사 "다른 유전자도 볼 수 있어요" / 필요한 경우 다른 유전자 검사를 상의 — 결과 활용은 의료진 판단.
4. 영애가 용수의 등을 토닥이고 용수가 웃음 / 영애 "길이 하나만 있는 게 아니래" / 내 결과에 맞는 길을 의료진과 함께 고름.

### EP13 (심화) 등 뒤의 점은 누가 보나
1. 수아 집, 수아가 거울에 등을 비춰 보며 고개를 돌림 / 수아 "등은 내 눈에 안 보여" / 넓은 절제 뒤에도 정기 진료와 함께 내 피부를 살피는 습관이 중요.
2. 언니가 수아 등 뒤에서 휴대폰으로 사진을 찍음(등은 옷 위 윤곽만) / 언니 "매달 같은 자세로 찍자" / 같은 자세·같은 조명으로 찍은 사진은 변화 비교에 도움.
3. 의학삽화: 다섯 칸 점 그림 — 비대칭·경계·색·크기·변화(글자 없음) / (대사 없음) / ABCDE와 '다른 점과 다른 점'은 진료가 필요한 점을 고르는 기준 — 진단은 조직검사로.
4. 수아가 모자·긴소매로 그늘을 걷고 언니가 웃음 / 수아 "새 피부암 예방은 이렇게" / 자외선 차단은 새 피부암 예방을 위한 습관 — 검진을 대신하지 않음.

### EP14 (심화) 지갑 속의 치료 카드
1. 주사실, 종양내과 의사가 몸 그림에 여러 장기를 부드러운 색으로 표시한 카드를 보여 줌 / 종양내과 의사 "면역은 온몸에 신호를 보내요" / 면역치료 부작용은 장·폐·간·호르몬·피부 등 어디에나 올 수 있음.
2. 용수가 지갑에 치료 카드를 넣고 영애가 확인 / 영애 "다른 병원 가도 보여 줘요" / 다른 병원·응급실에서 면역치료 중임을 알리기.
3. 의학삽화: 시간 줄 위에 늦게 나타나는 작은 신호 표시(글자 없음) / (대사 없음) / 면역 부작용은 치료가 끝난 뒤에도 생길 수 있음.
4. 영애가 냉장고에 부작용 신호 그림표(장·숨·피로·피부·눈 아이콘)를 붙임 / 영애 "새 증상은 참지 말자" / 새 증상은 다음 진료까지 기다리지 않고 바로 알림.

### EP15 (심화) 수술 뒤, 한 걸음 더
1. 진료실, 종양내과 의사가 용수 결과지를 보며 설명 / 종양내과 의사 "재발 위험을 낮추는 약을 상의해요" / 수술 뒤 보조치료는 병기·위험도에 따라 상의.
2. 의학삽화: 두 길 — 약을 쓰며 추적, 약 없이 추적(아이콘, 글자 없음) / (대사 없음) / 보조 면역치료·(BRAF 양성 시) 보조 표적치료·추적만 하는 선택을 함께 따져 봄.
3. 용수가 가게 장부와 달력을 보여 줌 / 용수 "가게 일도 계속하고 싶어요" / 부작용·일정·생활을 함께 놓고 결정 — 내 바람을 말하기.
4. 영애와 용수가 진료실을 나서며 서로 손을 잡음 / 영애 "같이 정했으니 됐어요" / 보조치료 여부는 정답이 하나가 아님 — 충분히 묻고 정하기.

### EP16 (심화) 아침 저녁 알약
1. 진료실, 봉수가 딸과 함께 결과지를 들음 / 종양내과 의사 "BRAF 변이가 있어요" / BRAF V600 변이가 있으면 표적치료를 상의할 수 있음.
2. 의학삽화: 두 알약이 함께 신호 길을 막는 그림(글자 없음) / (대사 없음) / BRAF·MEK 억제제는 함께 쓰는 경우가 많음 — 면역치료와의 순서는 의료진과 정함.
3. 집, 딸이 요일 약통(글자 없음)에 약을 나눠 담음 / 딸 "아침 저녁 같은 시간에" / 먹는 약은 시간 지키기 — 다른 약·건강기능식품은 의료진·약사와 확인.
4. 봉수가 햇볕 아래 모자를 쓰고 긴소매 차림으로 산책 / 봉수 "햇빛에 피부가 예민해졌어" / 표적치료 중 피부 발진·햇빛 민감이 생기면 진료 때 알림.

### EP17 (심화) 커 보여도 기다려 봐요
1. 진료실, 봉수가 CT 화면(회색 단면, 일부 밝아진 점)을 보고 굳은 얼굴 / 봉수 "더 커진 거예요?" / 면역치료 초기엔 일시적으로 커 보이기도 함 — 판단은 의료진이.
2. 의학삽화: 면역세포가 종양 주변에 모여 부풀어 보이는 그림(글자 없음) / (대사 없음) / 영상 변화 판단은 추가 검사·시간을 두고 의료진이 함.
3. 봉수가 피곤한 얼굴로 담요를 덮고 딸이 내분비내과 진료 안내지를 봄 / 딸 "피곤하고 추운 것도 알려요" / 심한 피로·추위 탐은 호르몬(갑상선·뇌하수체 등) 부작용일 수 있어 확인.
4. 진료실, 의사가 뇌 MRI 안내를 하고 딸이 메모 / 종양내과 의사 "뇌도 함께 살펴봐요" / 전이 흑색종은 뇌 MRI를 하기도 함 — 뇌전이도 치료 길이 있음(⑲ BT·㉕).

### EP18 (심화) 다시 장화를 신는 날
1. 재활치료실, 용수가 평행봉 사이에서 수술한 발로 조심스럽게 디딤 / 물리치료사 "뒤꿈치부터 천천히" / 발바닥 수술 뒤 걷기는 재활로 단계적으로 회복.
2. 의학삽화 풍: 쿠션 깔창·넉넉한 신발·양말(글자 없음) / (대사 없음) / 이식 부위를 보호하는 신발·깔창은 의료진·재활팀과 상의.
3. 가게, 용수가 새 고무장화에 깔창을 넣고 짧은 의자를 둠 / 용수 "오래 서 있을 땐 의자 하나" / 오래 서는 일은 쉬는 시간·자세를 조정.
4. 저녁, 용수가 장화를 벗어 발을 살피고 영애가 사진 기록표를 펼침 / 영애 "오늘도 이상 없지?" / 수술 부위와 주변 피부를 살피는 습관을 이어 감.

### EP19 (심화) 흉터 옆 갈색 점
1. 거실, 영애가 용수 발을 보다 흉터 옆을 가리킴(발은 가림, 영애 표정) / 영애 "흉터 옆에 점이 생겼어요" / 흉터 근처 새 점·멍울은 다음 진료까지 기다리지 않고 확인.
2. 진료실, 주치의가 사진 기록표와 이전 사진을 비교 / 주치의 "사진 덕분에 비교가 쉬워요" / 날짜별 사진은 변화 판단에 도움 — 판정은 진찰·조직검사로.
3. 의학삽화: 몸 지도에 림프절 위치(목·겨드랑이·사타구니) 부드러운 표시(글자 없음) / (대사 없음) / 새 멍울이 모두 재발은 아님 — 진찰·영상으로 확인.
4. 용수가 다음 검진 날짜를 달력에 표시하고 영애가 어깨를 감쌈 / 용수 "확인하면 마음이 편해" / 추적 일정은 병원 기준 — 재발이 의심되면 ㉗ REC권.

### EP20 (심화) 아들의 등을 봐 주는 저녁
1. 저녁 거실, 한결이 셔츠를 걷은 등을 돌리고 용수가 확대경 대신 휴대폰 불빛으로 봐 줌(등 윤곽만) / 용수 "이번엔 내가 봐 줄게" / 가족끼리 서로 피부를 살펴 주면 등처럼 안 보이는 곳도 확인 가능.
2. 유전상담실, 영애와 한결이 설명을 들음 / 유전상담 간호사 "대부분 유전되진 않아요" / 가족력·여러 개 원발 등이 있으면 유전상담을 상의할 수 있음.
3. 시장, 용수가 가게 차양을 내리고 손님과 웃음 / 용수 "그늘은 내가 만들지" / 자외선 차단 생활은 새 피부암 예방 — 검진을 대신하지 않음.
4. 가족 식탁, 셋이 다음 피부 검진 달력을 보며 건배(물컵) / 한결 "가족 검진 날 정해요" / 가족에게 검진을 권할 땐 강요 없이 정보와 함께.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 결과지 한 줄이 정하는 길) · 4장(손발바닥·손발톱 흑색종) · 20장(면역치료 중 자기 관리)**.
- `melanoma.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~11을 골든샘플부터 적용.
- 병기(AJCC)·치료 알고리즘 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. 생존율·반응률은 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 장마다 "내 흑색종" 상자(말단 / 햇빛 노출 부위 / 전이)를 두되 상자 안 문장은 짧게, 점막·안구는 15장으로 모음.
- 면역·표적·림프부종 장(20·21·22장)은 응급 신호 상자를 맨 위에(숨참·가슴 통증, 의식 저하·마비·경련, 38.0°C, 혈변·심한 설사, 황달), 생활 팁은 그 아래(순서 고정). 면역 부작용 장기 이름은 W4 증상 일지와 같은 말로, ② LC·⑪ LYM 원고의 면역항암제 부작용 문장과 대조해 통일.
- 주인공 용수는 발바닥 말단 흑색종 넓은 절제·피부이식·감시림프절 양성 → 보조 면역치료 → 장염 부작용 조절 경로. 얇은 흑색종 추적은 수아, 처음부터 전이·표적치료·호르몬 부작용은 봉수 — 본문 사례도 같은 분담. 4장(말단)은 1장과 같은 무게로.
- 25장 "마음" 상자 첫 줄은 "달라진 발도 나를 걷게 해요", 26장 "가족" 상자 첫 줄은 "검진은 권하되 다그치지 않아요"(보호자 대상).
- 말단 흑색종 빈도·국내 약제 허가·급여·상피내암 보험 분류 문장은 S4에서 출처 확인 후 기재, 확인 전엔 "병원·관계 기관 확인" 꼬리.
