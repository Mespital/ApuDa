# ㉙ AYA(청년)편 (AYA) — S1 권별 작업지시서 v1.0

- 발행: 2026-11-22 · 책공장(Claude 총괄 PD)
- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **AYA v1.0** (로스터상 "미착수" — 새로 설계)
- 상태: **G1 대기** — 결재함에 `G1 승인 AYA` 또는 `G1 수정 AYA: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학·제도 문장은 방향 설계이며 확정 문장이 아니다.
- 범위: **청년기(AYA, Adolescents and Young Adults)에 처음 암 진단을 받은 성인의 첫 30일.** 암종 공통편이다. AYA 나이 구간은 기관·지침마다 정의가 달라(S4에서 지침 표현 확인) 본문에 숫자 기준을 내세우지 않는다. 이 권의 독자는 **성인(만 18세 이상) 본인**으로 잡고, 미성년 청소년과 그 보호자는 ㉓ PED권으로 연결한다. 암종별 치료 세부(약 이름·수술 조건)는 해당 권(① BC·⑪ LYM·⑮ LEU·⑤ TC 등, 고환암은 웹 FAQ `testicular` + 해당 권 상자), 재발은 ㉗ REC, 보호자 자신의 이야기는 ㉖ CG권으로 연결하고 입구만 안내한다.
- 톤: 청년 암 환자는 **"또래와 다른 시계"**를 산다 — 친구들이 취업·연애·독립을 할 때 혼자 진료실에 앉는다. 책 전체의 축은 세 가지: ① **치료 시작 전에 미래를 지키는 상담이 있다**(가임력 보존은 첫 치료 전에 물어야 하는 질문 — 시간 창이 짧고, 하지 않는 선택도 정당하다), ② **내 삶의 일정표를 같이 들고 간다**(학업·첫 직장·프리랜서 일·연애·자취·돈 — 의료진에게 "내 생활"을 먼저 알리면 치료 일정과 지원 연결이 달라진다), ③ **치료의 끝이 끝은 아니다**(오래 사는 만큼 오래 챙기는 몸 — 치료 요약지와 장기 추적 계획을 첫 30일부터 묻는다). 성인으로서 본인이 듣고 본인이 정한다 — 부모는 든든한 지원군이지만 대신 결정하는 사람이 아니다. "젊으니까 금방 이겨 낸다" 같은 낙관 단정도, "인생이 끝났다"는 체념도 걷어 낸다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **응급 기준은 시리즈 공통 + 혼자 사는 청년 한 줄.** 항암 중 발열 **38.0°C** = 해열제보다 먼저 병원 연락. 숨참·가슴 통증, 갑작스러운 심한 두통·한쪽 마비·경련 → 119, 피를 토함·검은 변·멈추지 않는 출혈, 한쪽 다리가 붓고 아픔, 스스로를 해치고 싶은 생각 → 109·119. 고정 문장: "혼자 산다면 '열이 나면 누구에게 먼저 연락하고, 누가 병원에 데려다줄지'를 치료 시작 전에 정해 두세요."
2. **수치 쓰지 않기.** 가임력 보존 성공률·임신율, 난자 채취까지 "며칠·몇 주", 난소 기능 회복 가능성, 정자 수 기준, 치료 뒤 임신 시도 "몇 년 뒤", 이차암·심장 후기 효과 위험률, 생존율, 상병수당·지원금 금액·기간, 병역 판정 기준은 본문에 넣지 않는다. 필요하면 "생식의학과·병원·기관 안내 기준".
3. **약·처방 단정 금지.** 이 권은 항암제 이름을 쓰지 않는다(암종 공통). 범주까지만. 용량 미기재. 난소 보호 목적 호르몬 주사는 "일부에서 쓰기도 하나 효과와 대상에 대한 의견이 갈려 의료진과 상의" 수준(S4 지침 확인), "이 주사를 맞으면 난소가 지켜진다" 금지. 치료 중 피임은 "임신을 피해야 하는 기간과 맞는 피임법은 암종·치료에 따라 달라 의료진과 상의" — 특정 피임법 권고·금지 단정 금지.
4. **가임력 문장 고정.** ① "가임력 보존 상담은 첫 치료 전에 묻는 질문"(치료를 시작한 뒤에는 선택지가 줄 수 있음), ② "상담이 치료를 크게 늦추지 않도록 일정은 종양 담당의와 생식의학과가 함께 정함", ③ "보존해도 나중 임신을 약속하지 않으며, 보존하지 않아도 나중에 임신이 가능한 경우가 있음 — 내 경우는 의료진에게", ④ "하지 않는 선택도 정당하다". 여성(난자 동결·배아 동결·난소 조직 동결 개념), 남성(정자 동결, 사정이 어려울 때 다른 방법 개념). 성소수자·비혼·파트너 유무에 따른 차별 문장 금지 — "파트너 유무와 관계없이 상담 가능".
5. **임신 중 진단.** 7장은 짧은 장: "임신 중에도 치료 계획을 세울 수 있는 경우가 있으며 산과·종양과·신생아과가 함께 결정"(S4 확인), 임신 유지·중단에 대한 권고·판단 금지 — "본인의 선택과 의료진 상담".
6. **유전 문장.** "젊은 나이 진단·가족력이 있으면 유전상담을 권하기도 함" — 유전자 결과를 보험·취업 차별과 연결하는 법률 문장은 "관련 법·제도는 S4 확인" 표기 후 개념만.
7. **심리 문장은 진단 단정 금지.** "우울증입니다" 대신 "두 주 넘게 이어지면 전문가와". 술·전자담배·대마 등 물질 사용은 "치료 중에는 의료진에게 솔직히 말하기 — 상호작용·감염 위험"으로, 훈계 톤 금지. 성·친밀감은 정보 제공 톤, 노출 묘사 금지.
8. **제도 문장.** 산정특례·실손보험·청년 대상 의료비·생활비 지원·학자금 상환 유예·휴학·병가·상병수당·병역(연기·판정)·가임력 보존 비용 지원은 "개념 + 신청 창구(공단·학교·회사 인사팀·병무청·지자체·병원 사회복지팀)"까지, 요건·금액·기간은 "기관 확인" — 모두 S4에서 현행 확인. 회사에 알리는 범위는 "본인이 정함", 법률 조언 아님.
9. **SNS·온라인 문장.** "투병 공유는 본인의 선택", 병원·의료진 사진 게시는 동의 필요, 온라인 "완치 후기"·광고성 정보 걸러 듣기. 크라우드펀딩 등 모금 권유 금지(중립 안내도 생략).
10. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시, 종양내과·혈액종양내과·생식의학(산부인과·비뇨의학과)·임상심리·사회복지 관점 감수 필요 표기. 참고(NCCN Adolescent and Young Adult Oncology, ASCO 가임력 보존 지침, ESMO AYA·가임력 권고, NCI AYA 환자 안내, 국가암정보센터 등)는 실재·최신 판 S4 확인 후 판 번호 따로.
11. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~20·26·27·28권 인물 명단과 대조 완료).

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 친구들은 이직 얘기를 하는데
1. 카페, 친구 셋이 웃으며 이야기하고 채원만 텀블러를 쥔 채 웃는 척(휴대폰 화면 흐림) / 채원 (속마음) "나만 다른 시계에 있네" / 청년기에 진단받으면 또래와 다른 시간을 사는 외로움이 클 수 있음.
2. 같은 길을 걷던 사람들 사이에서 한 사람만 다른 갈림길에 선 그림(색만) / (대사 없음) / 놀람·분노·억울함은 모두 자연스러운 반응.
3. 진료실, 주치의가 마주 앉아 천천히 설명 / 주치의 "궁금한 건 다 물어봐요" / 젊은 나이의 암도 치료 계획은 암종·병기·몸 상태로 정함.
4. 밤 자취방, 채원이 스케치북에 오늘 하루를 짧게 그림, 창가 화분 / 채원 "오늘은 여기까지만" / 한 번에 다 알려고 하지 않아도 됨 — 하루 한 가지씩.

### EP02 사흘 동안 세 가지만
1. 밤, 채원이 침대에서 휴대폰 검색 화면(흐림)을 보다 멈춤 / 채원 "검색은 그만하자" / 인터넷 정보는 암종·병기가 달라 오해를 키울 수 있음.
2. 메모지 세 장이 냉장고에 붙음: 달력·작은 씨앗·전화기 그림(글자 없음) / (대사 없음) / 다음 일정 · 가임력 상담 질문 · 같이 갈 사람.
3. 외래, AYA 간호사가 채원에게 질문 카드(글자 없음)를 건넴 / 간호사 "치료 전에 물을 걸 적어 와요" / 첫 치료 전에 꼭 물어야 할 질문이 있음(가임력·일정·학업·일).
4. 채원이 엄마 혜옥에게 영상통화, 혜옥이 미용실 의자에 앉아 받음 / 혜옥 "엄마가 내일 올라갈게" / 다음 진료에 같이 들을 사람 한 명 정하기 — 부모·연인·친구 누구든.

### EP03 치료 전에 꼭 물어볼 것
1. 진료실, 채원이 수첩을 펴고 손을 듦 / 채원 "아이 가질 수 있는지도 묻고 싶어요" / 일부 항암·방사선 치료는 가임력에 영향을 줄 수 있음.
2. 모래시계 옆에 작은 씨앗 바구니 그림(색만, 숫자 없음) / (대사 없음) / 가임력 보존 상담은 첫 치료 전에 — 치료를 시작한 뒤에는 선택지가 줄 수 있음.
3. 생식의학과 상담실, 의사가 채원에게 그림 카드(글자 없음)를 보여 줌 / 의사 "치료 일정에 맞춰 같이 볼게요" / 상담이 치료를 크게 늦추지 않도록 종양과와 생식의학과가 함께 일정을 정함.
4. 주치의와 생식의학과 의사가 같은 달력(숫자 없음)을 보며 고개를 끄덕이는 장면(측면) / 주치의 "두 과가 일정 맞출게요" / 보존해도 나중 임신을 약속하지는 않음 — 내 경우를 의료진에게 묻기.

### EP04 엄마, 이건 내가 정할게
1. 자취방, 혜옥이 반찬통을 정리하며 빠르게 말함, 채원이 소파에서 듣고 있음 / 혜옥 "엄마 집으로 내려와, 당장" / 부모의 걱정은 크지만 성인 환자의 결정권은 본인에게 있음.

1. 자취방, 채원이 월세 고지서와 병원 영수증(흐림)을 나란히 놓고 머리를 짚음 / 채원 "월세는 어떡하지" / 청년 환자는 생활비 부담이 치료 걱정과 겹치기 쉬움.
2. 지갑 옆에 작은 우산 세 개(공단·보험·사회복지) 그림(색만) / (대사 없음) / 산정특례·실손보험·의료비 지원을 하나씩 확인.
3. 병원 사회복지팀, 사회복지사가 채원에게 지원 안내 그림 카드(글자 없음)를 펼침 / 사회복지사 "청년 지원도 같이 봐요" / 의료비·생활비 지원 제도는 요건이 있어 사회복지팀·기관에 문의.
4. 채원이 엄마와 영상통화하며 정리표(칸만)를 보여 줌 / 채원 "엄마, 같이 정리해 보자" / 돈 이야기를 가족과 미리 나누면 결정이 쉬워짐.

### EP20 (심화) 치료 요약지 한 장 (플래시포워드)
1. 몇 달 뒤 외래(짧게 자란 머리의 채원), 주치의가 서류 한 장(글자 흐림)을 건넴 / 주치의 "치료 요약지예요" / 치료가 끝나면 받은 치료·날짜·주의할 후기 효과를 정리한 요약지를 요청.
2. 요약지가 긴 길의 지도로 펼쳐지는 그림(색만) / (대사 없음) / 장기 추적·생존자 진료 계획을 담당의와 정함.
3. 생식의학과 상담실, 의사가 채원에게 웃으며 설명 / 의사 "나중에 다시 상담해요" / 보관한 난자·배아의 이후 계획은 원할 때 다시 상담.
4. 사무실 책상, 채원이 스케치북에 새 프로젝트를 그림, 창가 화분 / 채원 "다시, 내 속도로" / 복귀 속도는 사람마다 다름 — 몸 상태에 맞춰.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **4장(치료 전에 꼭 묻기: 가임력 보존 상담) · 8장(누가 보호자인가) · 24장(일)**.
- 공식 환자 안내(NCI AYA·ASCO 가임력 보존 환자 안내·국가암정보센터 등 — S4에서 실재·최신 판 확인)와 각 권 가임력 문장을 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~11을 골든샘플부터 적용.
- 이 권은 항암제 이름을 쓰지 않는다. 암종별 세부가 필요한 곳마다 "→ 해당 권 ○장" 연결 상자(①~㉕ 권 번호표를 부록에 1쪽, 고환암은 웹 FAQ 연결).
- 문장 규칙: 반말·유행어 금지(존댓말, 그러나 딱딱하지 않게), 훈계 톤 금지("~해야 합니다"보다 "~해 보세요").
- 주인공 채원은 암종 미표시·난자 동결 후 치료 시작·자취 유지 경로. 남성 가임력·휴학·병역은 규민, 청년 부모·일 조정은 소희 — 본문 사례도 같은 분담.
- 4장은 첫 문단을 "첫 치료 전에 물어야 하는 질문"으로 열고, 마지막 문단을 "하지 않는 선택도 정당하다"로 닫는다.
- 7장(임신 중 진단)은 1쪽 분량 + 문의처, 임신 유지·중단 권고 문장 금지.
- 보호자(부모·연인) 문장은 ㉖ CG권과 중복되지 않게 "환자가 부탁하는 법" 중심으로, 보호자 자신의 돌봄은 CG권으로 연결. 미성년 청소년은 ㉓ PED권 연결 상자.
