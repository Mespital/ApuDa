**기존 원고에서 고칠 것(S2·S4)**
1. **발열 표기 38.0°C 통일.** 완전판 응급 상자 "전신치료(면역치료·표적치료) 중 38°C 이상 발열", 증상표 끝 "항암 중 38°C 이상(병원 기준에 따라 37.8°C 이상 1시간 지속 등)" → 모두 **38.0°C**. 37.8°C 병기는 삭제하고 "병원 안내 기준이 다르면 병원 기준을 따르세요"로 대체. 응급 상자·신호등의 "시술 후 고열", "복수 + 열", "퇴원 후에도 고열 지속" 등 기준 없는 '고열'은 "38.0°C 이상 발열"로 명시. FAQ 데이터 80번 "38도 이상 발열"도 책에 옮길 때 38.0°C로.
2. **출처 없는 수치 문장 → 처리 방침.**
   - "C형간염 … 항바이러스 치료(대개 8~12주 먹는 약)" → 기간 삭제, "먹는 항바이러스제로 치료하며 기간은 의료진이 정함"으로.
   - "바이러스를 잘 억제하면 간암 치료 후 재발 위험이 줄어든다는 연구가 있습니다" → 근거 쪽에 출처(대한간암학회 가이드라인 등) 연결, 없으면 "간염 관리가 간을 지키는 데 중요"로 낮춤.
   - 치료 경로 표 "작은 종양(대개 3cm 이하. 3~5cm는 TACE와 함께 하는 병합치료를 검토)" → 지침 기준이므로 출처 표기, 없으면 크기 수치 삭제하고 "작은 종양에서 주로 검토".
   - "TARE … 국내는 2020년 말부터 건강보험 부분 급여" → 급여 연도·범위 S4 재확인, "변경 가능 + 원무과 확인" 꼬리.
   - FAQ Q4 "국내 지침에서는 6개월 안에 두 번 이상 TACE를 해도 반응이 없거나 … '불응'" → 국내 가이드라인 판·쪽 출처 연결, 없으면 "반응이 없거나 간기능이 떨어지면 다른 치료로 바꿀 시점을 미리 묻기"로.
   - FAQ Q5 "2024년 국내 간이식의 약 4분의 3이 생체간이식" → 출처(장기이식관리센터 통계 등) 필수. 없으면 "국내는 생체간이식 비중이 큼"만 유지.
   - 추적 "치료 뒤 첫 2년은 2~6개월, 그 뒤에도 3~6개월 간격", "절제 뒤 5년 안에 절반 안팎에서 재발" → 재발률은 **예후 수치이므로 본문 삭제**("재발이 드물지 않고 대부분 간 안에서 생김"), 간격은 "일반적 예시" + 출처, "병원 추적 일정표 우선".
   - Q8 "만 40세 이상 … 국가 간암 검진(6개월마다 간 초음파 + 혈액검사)" → 국가암검진 기준 출처(국립암센터·공단) 연결 + 발행 시점 재확인.
   - 간성뇌증 카드 "하루 2~3회 부드러운 변을 목표로 락툴로오스" → 배변 목표 횟수는 처방 지시이므로 "목표 배변은 처방한 의료진 안내대로"로 바꿈. 약 이름은 "처방약(예: 락툴로오스)"까지만.
   - 공통 증상표 "하루 4회 이상/4~6회 이상 설사", "한 달 5% 이상 체중 감소", "낮잠 30분 이내", PET "4~6시간 금식", "주 150분", 불안 대처 "검색 하루 30분" → 출처 연결 또는 "일반적 예시"(병원 기준 우선).
   - 1장 LI-RADS 표(LR-3·4·5·M·TIV 정의) → ACR LI-RADS 정의이므로 출처 표기, 표 구조는 ApuDa 언어로 새로 짬(지침 표 복제 금지). mUICC "2cm 이하" 등 정의도 출처 표기.
3. **약·전신치료는 "범주 + 대표 예"로만.** 6장 표의 아테졸리주맙+베바시주맙, 더발루맙+트레멜리무맙, 더발루맙 단독, 렌바티닙·소라페닙 → 범주명 위주, 성분명은 "대표 예"로 한 번만, 용량·투여 간격·주기 미기재 → "병원 일정표". 모두 "국내 허가·급여 변경 가능 + 의료진 확인". "TACE에 전신치료를 함께하는 전략", "수술·소작 후 보조 면역치료 이득 불확실" 문장은 S4에서 최신 근거 재확인(효능 단정 금지 유지).
4. **급여·허가·제도 S4 재확인(2026.10 기준 → 발행 시점 기준).** 면역 단독 요법 국내 허가·급여, TARE·양성자 급여, 영상 진단 간암의 산정특례 등록 기준, 산정특례(본인부담 5%·30일 이내 신청·5년), 상병수당 시범사업, 가족돌봄휴직(90일)·가족돌봄휴가(10일), 보험금 청구권 소멸시효(3년). 모두 "변경 가능 + 의료진·공단 확인" 꼬리 유지.
5. **판권·근거 쪽.** 완전판 "감수: ApuDa 「첫 30일」 감수단(전문의 30인·환자 36인·편집자문 3인 역할 기반 AI 사전 검토단)… 출판본에는 실제 감수자 명단이 별도 표기" → "**실제 전문의 서면감수 전**"을 판권에 명시, AI 검토단 인원수는 독자 지면에서 삭제. 가상 사례 머리말 "감수단 환자 페르소나를 바탕으로 재구성한" → "ApuDa가 만든 가상의 이야기"로. 참고 지침 판 표기 "NCCN … Hepatocellular Carcinoma, Version 2.2026"은 실재·최신 여부 S4에서 확인. 대한간암학회-국립암센터 가이드라인 "(최신판 확인)" → 판 연도 명기.
6. **조판 결함.** 간성뇌증 관찰 카드 표 깨짐(열 머리 "멍함·헛소리 / 손떨림 / 변(횟수)"가 다음 쪽 공통 증상표 위로 흘러감), W3 7일 증상 일지 열 머리("식사(평소의 %) 배변·배뇨 잠 기분")가 W4 아래로 밀림, 치료 경로 표 "TACE(경동\n맥화학색전\n술)"·"고주파·\n극초단파\n소작" 세로 쪼개짐, 6장 표 "·치료" 행 분리, "찾는 곳담당 교수에게" 붙음, 6장 이후 장 번호 소실, FAQ 12문항뿐 → 이번 판에서 전부 재출력으로 해결.
7. **가상 사례 정리.** 기존 사례 "58세 진우 씨 — B형간염 보유자"는 본 권 주인공(상철)과 설정이 겹침 → 30장에서 다른 배경(예: 지방간 관련·C형간염 치료 후)으로 교체. 사례 "숫자로 들으니 용기가 났다"는 유지 가능(효능 주장 아님).

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 간에 생긴 혹, 다 같은 암이 아니에요
1. 진료실, 상철이 결과지를 쥐고 혜경이 노트를 폄 / 상철 "간에 생기면 다 간암이죠?" / 간에 생기는 암은 몇 종류가 있음.

3. 다른 장기에서 화살표가 간으로 오는 개념 그림(색만) / 주치의 "다른 데서 온 건 달라요" / 다른 암의 간 전이는 원발암 기준으로 치료.

### EP02 사흘 동안 세 가지만
1. 밤, 상철이 철물점 카운터에서 휴대폰으로 검색 중 / 상철 "검색은 오늘까지만" / 첫 사흘은 세 가지만.
2. 원무과, 혜경이 판독지·영상 CD 사본을 받음 / 혜경 "두 부씩 부탁드려요" / 판독지·CD는 처음부터 두 부씩.
3. 거실, 혜경이 간암 진료팀 예약 전화 / 혜경 "다학제 되는 날로요" / 소화기내과·외과·영상의학과가 함께 보는 팀.
4. 식탁, 상철이 매일 먹던 알약 통을 손에 듦 / 상철 "이 약은 계속 먹는 거지" / B형간염 항바이러스제는 임의로 끊지 않기.

### EP03 바늘 없이 내린 진단
1. 진료실, 상철이 의아한 얼굴 / 상철 "조직검사도 안 했는데요?" / 고위험군은 영상 소견만으로 진단할 수 있음.
2. 간 의학삽화에서 종양이 먼저 밝아졌다 어두워지는 두 장면(색만) / (대사 없음) / 시기별 조영 변화가 간세포암의 특징.
3. 주치의가 다른 결절 그림을 가리킴 / 주치의 "애매하면 조직을 봐요" / 소견이 전형적이지 않으면 조직검사.
4. 혜경이 한 장 요약의 '진단 방법' 칸을 채움 / 혜경 "영상 진단, 적어 둘게" / 진단 근거는 보험·제도 서류에도 필요.

### EP04 암보다 먼저 보는 간의 체력
1. 진료실, 상철이 고개를 갸웃 / 상철 "혹은 작은데 왜 고민해요?" / 치료는 종양과 남은 간의 힘을 함께 봄.
2. 간을 배터리처럼 표현한 개념 그림(칸 색만, 숫자 없음) / (대사 없음) / Child-Pugh·ALBI는 간기능을 나누는 지표.
3. 주치의가 혈액검사 결과지를 넘김(글자 없음) / 주치의 "간의 힘이 치료를 정해요" / 간기능이 좋을수록 선택지가 넓음.
4. 혜경이 노트에 '간기능 등급' 칸을 비워 둠 / 혜경 "다음엔 이것부터 묻자" / 내 간기능 등급을 진료 때 확인.

### EP05 그 약, 끊지 마세요
1. 약국 앞, 상철이 약 봉투를 보며 망설임 / 상철 "항암하면 이건 끊어도 돼?" / 항바이러스제는 간암 치료 중에도 유지.
2. 간 의학삽화 위로 바이러스를 작은 점으로 표현, 약이 막는 개념 / (대사 없음) / 간염이 악화되면 간기능이 떨어질 수 있음.
3. 주치의가 고개를 저으며 설명 / 주치의 "그것도 치료예요" / 시술·전신치료 중 B형간염 재활성화 주의.
4. 주말, 아들 건우가 보건소 안내문을 들고 옴 / 건우 "나도 간염 검사할게" / 가족 B형간염 검사·예방접종 상의.

### EP06 세 가지 열쇠로 고르는 길
1. 진료실, 상철이 친구에게 들은 말을 꺼냄 / 상철 "친구는 수술했다던데요" / 같은 간암도 치료가 사람마다 다름.
2. 열쇠 세 개(종양·간기능·전신상태)를 색으로만 그린 개념 그림 / (대사 없음) / 세 가지를 함께 보고 치료를 고름.
3. 여러 갈래 길 그림(절제·이식·소작·색전·방사선·약, 색만) / 주치의 "다학제에서 같이 정해요" / 여러 과가 함께 상의.
4. 혜경이 선택지마다 장단점 칸을 만듦 / 혜경 "장단점 세 줄씩 듣자" / 선택지별 장단점과 회복 기간 묻기.

### EP07 바늘 하나로 태우는 치료
1. 설명실, 중재영상의학과 의사가 간 삽화를 보여 줌 / 의사 "작은 혹은 태울 수 있어요" / 작은 종양에서 소작이 선택지.
2. 바늘이 종양에 닿아 열로 치료하는 개념 의학삽화 / (대사 없음) / 고주파·극초단파로 종양을 태움.
3. 병실, 상철이 침대에 누워 시계를 봄(이불 덮음) / 상철 "입원이 생각보다 짧네" / 수술보다 입원이 짧은 편.
4. 혜경이 퇴원 안내지를 노트에 붙임 / 혜경 "열나면 바로 전화" / 시술 후 38.0°C 이상 발열이 계속되면 연락.

### EP08 시술 뒤 사흘, 신호등 보기
1. 병실, 상철이 얼굴을 찌푸리고 배를 감쌈(이불 덮음) / 상철 "열이랑 배가 좀 아파" / TACE 후 미열·통증·메스꺼움은 흔함.

3. 진료실, 상철이 마음 온도계를 가리킴(숫자 없이 색만) / 상철 "요즘 잠을 못 자요" / 고통 점수 4점 이상이면 진료 때 말하기.

### EP11 (심화) 병기 이름이 두 개인 이유

3. 주치의가 BCLC를 길 안내판처럼 설명(글자 없음) / 주치의 "이건 치료 방향 지도예요" / BCLC는 치료 방향과 연결됨.

3. 진료실, 상철이 안도한 얼굴 / 상철 "AFP 정상이면 괜찮죠?" / AFP가 오르지 않는 간암도 많음.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **4장(남은 간의 힘: 간기능) · 7장(간염과 간경변: 항바이러스제) · 19장(간경변 응급 신호 셋)**.
- 기존 완전판 문장 우선 재사용, 새 수치 추가 금지. 0절 "고칠 것" 1~7을 골든샘플부터 적용(38.0°C, 출처 없는 수치 처리, 약 용량·배변 목표 횟수 삭제).
- LI-RADS·Child-Pugh·BCLC·mUICC 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. Child-Pugh 점수 계산표는 넣지 않는다(개념·등급만).
- 예후·생존율·재발률 수치는 본문에 새로 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 간내 담관암·전이성 간암 독자는 1장에서 ⑨ BTC권·해당 원발암 권으로 안내하는 상자를 둔다.
