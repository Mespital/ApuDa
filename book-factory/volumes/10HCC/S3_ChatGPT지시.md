### EP09 간이 보내는 세 가지 경보

### EP10 누구 탓도 아니야
1. 밤 거실, 상철이 소파 끝에 앉아 고개를 숙이고 두 손을 모음. 낡은 가족사진 액자가 탁자 위에 놓임(얼굴 흐리게). / 상철 "엄마한테서 왔겠지" / 원인 찾기보다 지금부터의 간 보호가 중요합니다.

### EP11 (심화) 병기 이름이 두 개인 이유
1. 진료실, 상철이 서류 두 장을 양손에 들고 번갈아 봄(글자 보이지 않게). 혜경이 옆에서 고개를 갸웃. / 상철 "병기가 왜 두 개예요?" / BCLC와 mUICC를 함께 쓰는 경우가 많습니다.

3. 주치의가 갈래길 안내판 모양의 그림(글자 없음)을 손으로 짚으며 설명. 부부가 함께 봄. / 주치의 "이건 치료 방향 지도예요" / BCLC는 치료 방향과 연결됩니다.
4. 혜경이 한 장 요약 종이에 칸을 두 개로 나눠 적음(글자 보이지 않게). 상철이 손가락으로 두 칸을 가리킴. / 혜경 "둘 다 적어 두자" / 내 병기를 두 체계로 기록합니다.

### EP12 (심화) AFP가 정상이라도
1. 밝은 채혈실, 상철이 소매를 걷고 팔을 내밈. 연하늘 스크럽의 병동 간호사(짧은 커트)가 채혈 준비를 함(바늘·피 보이지 않게). / 간호사 "종양표지자 두 개 봐요" / AFP·PIVKA-II는 간암 혈액 표지자입니다.

3. 진료실, 상철이 안도한 얼굴로 의자에 등을 기댐. 혜경은 노트를 든 채 주치의를 바라봄. / 상철 "AFP 정상이면 괜찮죠?" / AFP가 오르지 않는 간암도 많습니다.
4. 주치의가 모니터의 간 영상 개념 그림(글자 없음)과 결과지를 번갈아 손으로 짚음. 부부가 고개를 끄덕임. / 주치의 "영상이랑 같이 봐요" / 숫자 하나보다 영상과 추세로 판단합니다.

### EP13 (심화) 떼는 것보다 남기는 것
1. 외과 진료실, 간담췌외과 의사가 간 의학삽화에서 일부만 연한 색으로 표시된 곳을 짚음. 상철과 혜경이 함께 봄. / 간담췌외과 의사 "남는 간이 충분한지 봐요" / 절제는 남는 간의 양과 기능이 관건입니다.
2. 간이 다시 자라는 전후 개념 그림(색 면적만, 글자·숫자 없음). 오른쪽 그림 테두리에 옅은 그물무늬로 간경변을 암시. / (없음) / 간은 일부 다시 자라지만, 간경변이 있으면 한계가 있습니다.
3. 간담췌외과 의사가 간으로 들어가는 혈관 삽화의 압력 표시(색 단계만)를 가리킴. / 간담췌외과 의사 "문맥압도 확인해요" / 문맥압항진이 있으면 절제를 신중히 판단합니다.
4. 병실 복도, 환자복을 입은 상철이 링거대를 밀며 걷고, 혜경이 링거대를 함께 잡음. 상철 손목에 검은 디지털시계. / 혜경 "한 바퀴만 더" / 수술 뒤 일찍 걷기가 회복을 돕습니다.

### EP14 (심화) 이식, 일찍 물어보기
1. 진료실, 혜경이 노트를 쥔 채 손을 살짝 듦. 상철이 혜경을 돌아봄. 주치의가 고개를 끄덕임. / 혜경 "이식도 가능한가요?" / 이식 가능성은 처음부터 물어보세요.
2. 옷 입은 두 사람 실루엣 사이로 간 일부가 옮겨 가는 개념 의학삽화(화살표·색만, 실제 장기·수술 장면 없음). / (없음) / 국내는 생체간이식 비중이 큽니다.
3. 주치의가 손가락을 하나씩 접으며 설명(글자·숫자 없음). 부부가 진지하게 들음. / 주치의 "기준과 공여자를 같이 봐요" / 종양 기준·간기능·공여자 조건을 함께 평가합니다.
4. 저녁 식탁, 상철·혜경·아들 건우가 조용히 이야기. 건우는 회색 후드티 차림, 상철은 건우의 어깨에 손을 얹고 고개를 저음(부담 갖지 말라는 몸짓). / 건우 "검사는 받아 볼게요" / 공여 결정은 강요 없이, 충분한 상담 뒤에 합니다.

### EP15 (심화) 칼 대신 빛으로
1. 방사선종양학과 진료실, 방사선종양학과 의사가 간 의학삽화 위 여러 방향에서 모이는 빛줄기를 손가락으로 따라감. 상철과 혜경이 봄. / 방사선종양학과 의사 "정밀하게 모아서 쏴요" / 정위체부방사선치료(SBRT)는 방사선을 종양에 모읍니다.
2. 간으로 들어가는 혈관 안에 종양을 색으로만 표시한 개념 의학삽화(글자·숫자 없음). / (없음) / 소작이 어렵거나 혈관 침범이 있을 때 방사선을 검토합니다.
3. 방사선치료 대기석, 상철이 휴대폰 메모(화면 흐리게)를 보며 걱정스러운 얼굴. 손목에 검은 디지털시계. 옆자리 혜경. / 상철 "매일 오면 가게는?" / 통원 일정과 거리를 치료 계획에 넣습니다.
4. 혜경이 스프링 노트에 새 칸을 만들고 형광펜을 긋는 모습(글자 보이지 않게). 상철이 옆에서 들여다봄. / 혜경 "비용이랑 급여도 묻자" / 양성자는 일부 센터에서 하며, 급여 기준을 확인합니다.

### EP16 (심화) 주사 전에 내시경부터
1. 진료실, 주치의가 간 의학삽화와 식도 그림이 함께 있는 설명 카드(글자 없음)를 가리키며 설명. 상철은 의아한 얼굴, 혜경은 스프링 노트를 폄. / 주치의 "약 전에 내시경 먼저요" / 일부 요법은 시작 전 정맥류 확인이 필요합니다.
2. 식도 안쪽 혈관이 부푼 모습을 색으로만 표시한 개념 의학삽화(글자·숫자 없음, 피 없음). / (없음) / 간경변의 정맥류는 출혈 위험이 있습니다.
3. 항암주사실 리클라이너, 상철이 팔에 수액 줄을 달고 창밖을 봄(바늘 부위는 거즈로 가림, 수액 봉지 글자 없음). 손목에 검은 디지털시계. / (없음) / 면역·표적치료 범주가 있고, 약 선택은 간기능에 따라 다릅니다.
