- 톤: 식도암은 **"먹는 일이 곧 치료의 일부"**인 병이다 — 진단 순간부터 체중과 삼킴이 치료 계획을 좌우한다. 책 전체의 축은 두 가지: ① **"치료 순서보다 먼저 영양"**(삼키기 어려운 몸으로도 오늘 먹을 수 있는 방법, 영양관은 "포기"가 아니라 치료를 버티는 다리), ② **"길은 여럿, 목표는 같다"**(내시경·수술 전 치료 후 수술·수술 없는 항암방사선은 우열이 아니라 병기·몸 상태·환자 선택에 따른 길). 흡연·음주와의 관련은 탓하는 문장이 아니라 "지금 끊으면 치료와 회복에 도움" 방향으로만. 수술 뒤 바뀐 식사(조금씩·자주·앉아서)를 생활 장면으로 반복한다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 항암 중 발열·수술 뒤 발열·영양관 부위 발열 모두 38.0°C. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리. 웹 FAQ의 "38°C" 표기는 책에서 38.0°C로 통일.
2. **수치 쓰지 않기.** 생존율·재발률, pCR 비율, 방사선 선량(Gy)·횟수, 항암 횟수·주기, 입원·금식 일수, 체중 감소 "몇 %면 위험", 식후 "몇 분 눕지 말 것", 침대 "몇 도" 같은 수·기간은 본문에 넣지 않는다. 필요하면 "병원 안내문·일정표 기준"으로. 병기(TNM) 정의는 개념만 출처 달고, 지침 표 복제 금지.
3. **약은 "범주 + 대표 예"로만.** 백금계 항암제(시스플라틴·카보플라틴 대표 예) + 플루오로피리미딘 계열 또는 탁산 계열(대표 예), 면역항암제(PD-1 억제제 — 범주명 위주), HER2 표적약(선암 일부, 범주), 수술 전 항암방사선 병용 → 용량·주기 미기재, 모두 "국내 허가·급여 변경 가능 + 의료진 확인". PD-L1 기준값(CPS·TPS 숫자) 미기재 — "결과지의 PD-L1 결과가 약 선택에 쓰일 수 있음"까지.
4. **영양관·스텐트 문장은 신중히.** 영양관은 "입으로 영영 못 먹는다는 뜻이 아님 — 치료를 버티는 동안의 다리"로. 스텐트는 "삼킴을 돕는 관이며 암을 치료하는 것은 아님". 어떤 방법이 맞는지는 "치료 계획·병원 판단".
5. **원인 단정·탓 금지.** 흡연·음주·뜨거운 음식·역류와의 관련을 "당신 때문"처럼 쓰지 않는다. 위험요인은 FAQ·5장에서 출처 달고 개념만, 금연·금주는 "치료 효과·수술 회복·두 번째 암 예방에 도움" 방향. 금연상담전화 안내는 번호를 S4에서 재확인.
6. **"수술 안 함" = 포기 아님.** 근치적 항암방사선은 일부 환자에서 수술과 다른 정당한 길로, 효과 비교 수치 없이. 선행치료 뒤 영상에서 안 보여도 "수술 취소"를 단정하지 않음(병원 판단).
7. **응급 문장 고정.** 피를 토함·검은 변, 침도 삼키지 못함, 수술 뒤 가슴·목 통증과 발열(문합부 누출 가능), 갑자기 숨참·가슴 통증, 식사 때마다 기침·고열(흡인성 폐렴 가능)은 0-1·11장·22장 같은 문장.
8. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN Esophageal and Esophagogastric Junction Cancers, ESMO, 대한식도학회·대한위암학회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
9. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~15·26·27권 인물 명단과 대조 완료).

### PART 1. 진단 첫 주 — 정확히 알기

3. 검사가 여러 개인 이유: 내시경 조직검사 · 초음파내시경(깊이·림프절) · CT · PET-CT · 필요하면 기관지내시경 · 심장·폐 기능 검사 → **EP03**

5. 병리·병기 읽기: 조직형·분화도 · 깊이(점막·점막하층 등 개념) · 림프절 · 병기(TNM)는 검사를 모아 정함 · 위험요인은 탓이 아닌 정보 → 심화 **EP11**

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 목에 걸리던 그 느낌
1. 집 식탁, 병구가 밥을 삼키다 가슴을 쓸어내림, 귀남이 물컵을 내밂 / 병구 "요즘 밥이 자꾸 걸려" / 음식이 걸리는 느낌은 식도가 좁아졌다는 신호일 수 있음.
2. 목에서 위까지 이어진 식도를 부드럽게 그린 의학삽화, 가슴 높이 한곳이 좁아짐(색만, 글자 없음) / (대사 없음) / 식도는 늘어나는 관이라 꽤 좁아진 뒤에야 걸리는 느낌이 오기 쉬움.
3. 진료실, 주치의가 두 종류 세포 무늬 그림 카드(글자 없음)를 가리킴 / 주치의 "편평세포암이에요" / 식도암은 편평세포암과 선암으로 나뉘고 치료 선택이 달라질 수 있음.
4. 병구가 주머니 공책에 연필로 한 줄 적음(기호만), 귀남이 어깨를 잡음 / 귀남 "이름부터 적어 둬요" / 내 조직형과 암의 위치(목·가슴·식도위접합부)를 기록.

### EP02 먹는 것부터 챙기는 사흘
1. 밤 거실, 병구가 휴대폰 검색 화면을 끄고 공책을 폄 / 병구 "검색은 그만, 기록부터" / 진단 직후엔 검색보다 내 결과지와 몸 상태 기록이 먼저.
2. 욕실, 귀남이 체중계 옆에서 병구의 발을 가리킴(숫자 없음) / 귀남 "매일 아침 같은 시간에" / 체중과 먹은 양을 기록하면 영양 계획을 세우기 쉬움.
3. 원무과, 소라가 결과지·영상 CD 봉투 두 개를 받음 / 소라 "두 부씩 부탁드려요" / 결과지·영상은 처음부터 두 부씩.
4. 식탁, 병구가 공책에 세 칸(기호만)을 그리고 소라가 영상통화로 고개를 끄덕임 / 소라 "다학제 진료, 같이 가요" / 조직형·먹는 양·치료 길, 세 가지를 먼저 확인.

### EP03 검사가 여러 개인 이유
1. 검사 대기실, 병구가 검사 안내문 여러 장(글자 흐림)을 넘기며 한숨 / 병구 "검사가 왜 이렇게 많아요?" / 검사마다 보는 것이 달라 여러 검사를 모아 병기를 정함.
2. 같은 식도를 세 방향(안쪽 카메라·바깥 단면·몸 전체 빛)으로 보는 세 칸 개념 그림(색만, 글자 없음) / (대사 없음) / 내시경은 안쪽, 초음파내시경은 깊이·림프절, CT·PET-CT는 몸 전체.
3. 회복실, 병구가 침대에서 눈을 뜨고 간호사가 물컵을 아직 치움 / 간호사 "목 감각 돌아오면 드세요" / 내시경 뒤 먹기 시작 시간은 병원 안내대로.
4. 진료실, 주치의가 폐 그림 카드와 심장 그림 카드(글자 없음)를 함께 놓음 / 주치의 "심장·폐도 같이 봐요" / 수술·치료를 견딜 수 있는지 심장·폐 기능도 확인.

### EP04 넘기기 힘들 때 먹는 법
1. 부엌, 귀남이 믹서에 죽을 갈며 병구를 돌아봄 / 귀남 "갈면 좀 넘어가요?" / 부드럽고 촉촉한 음식은 삼키기 쉬움.
2. 큰 그릇 하나 대신 작은 그릇 여러 개가 하루 시간대에 놓인 그림(색만, 숫자 없음) / (대사 없음) / 조금씩 자주, 천천히, 앉아서 먹기.
3. 식탁, 병구가 물을 마시다 사레들려 고개를 돌림(얼굴만) / 병구 "물 마셔도 사레가 들어" / 물·침에도 사레가 잦으면 삼킴 평가를 상의.
4. 영양 상담실, 영양사가 단백질 음식·영양음료 그림 카드(상표 없음)를 보여 줌 / 영양사 "치료 전에 영양부터요" / 체중이 빠지면 치료를 기다리지 말고 바로 영양 상담.

### EP05 길은 넷, 목표는 하나
1. 다학제 면담실, 주치의·흉부외과 의사·방사선종양학과 의사가 병구·귀남·소라와 둥근 탁자에 앉음 / 소라 "선생님이 세 분이에요?" / 식도암은 여러 진료과가 함께 치료 길을 정하는 경우가 많음.
2. 네 갈래 길이 같은 산꼭대기로 이어진 그림(색만, 글자 없음) / (대사 없음) / 내시경·수술 전 치료 후 수술·수술 없는 항암방사선·전신치료는 병기와 몸 상태로 정함.
3. 흉부외과 의사가 두 번째 길을 짚음 / 흉부외과 의사 "먼저 줄이고, 수술해요" / 수술 전에 항암방사선으로 암을 줄인 뒤 수술하는 길.
4. 병구가 공책의 "우리 길" 칸에 표시(기호만) / 병구 "길은 달라도 목표는 같네" / 내가 선택한 길과 이유를 기록하기.

### EP06 방사선이 지나가는 길
1. 방사선 계획 CT실 대기실, 병구가 안내를 받으며 앉아 있음(기계는 멀리) / 병구 "사진을 또 찍어요?" / 방사선이 지나갈 길을 정하려 계획용 CT를 따로 찍음.
2. 식도를 따라 가는 빛줄기가 주변 장기를 피해 가는 개념 삽화(색만) / (대사 없음) / 암이 있는 곳에 맞추고 주변 장기는 최대한 피함.
3. 집 식탁, 병구가 미음을 먹다 가슴을 짚고 얼굴을 찡그림 / 병구 "삼킬 때 따끔해" / 방사선 식도염으로 삼킬 때 통증이 생길 수 있어 진통·식사 방법을 상의.
4. 진료실, 방사선종양학과 의사가 고개를 끄덕이며 메모 / 방사선종양학과 의사 "아프면 참지 마세요" / 통증으로 먹는 양이 줄면 바로 알리기 — 치료를 버티는 데 중요.

### EP07 위가 올라와 길이 돼요
1. 수술 설명실, 흉부외과 의사가 그림 카드(식도·위, 글자 없음)를 펼침 / 귀남 "식도를 떼면 어떻게 먹어요?" / 식도를 떼고 위를 길게 만들어 끌어올려 연결하는 경우가 많음.
2. 위가 가늘게 다듬어져 가슴 쪽으로 올라가 연결된 모습을 부드럽게 그린 의학삽화(색만) / (대사 없음) / 새 길이 생기면서 한 번에 먹는 양과 먹는 방법이 바뀜.
3. 병실, 병구가 목에 회색 머플러를 두르고 쉰 목소리로 속삭임 / 병구 "목소리가 좀 쉬었어" / 수술 뒤 목소리가 쉬는 경우가 있어 회복 여부를 진료 때 확인.
4. 간호사가 병구의 체온계와 가슴 쪽을 가리키며 설명(노출 없음) / 간호사 "열나고 아프면 바로요" / 수술 뒤 목·가슴 통증과 38.0°C 발열은 연결 부위 문제 신호일 수 있음.

### EP08 38.0도면 연락부터

4. 응급실 접수대, 귀남이 항암 치료 카드(글자 없음)를 내밂 / 귀남 "식도암 항암 중이에요" / 응급실에서 항암·방사선 중임을 먼저 알리기.

### EP09 조금씩, 자주, 앉아서
1. 퇴원 뒤 집 식탁, 병구가 작은 그릇의 죽을 몇 숟갈 먹고 배를 쓰다듬음 / 병구 "조금만 먹어도 배불러" / 수술 뒤엔 한 번에 먹는 양이 줄어 조금씩 자주 먹음.
2. 하루 해와 달 사이에 작은 접시 여러 개가 놓인 그림(숫자 없음) / (대사 없음) / 끼니를 나눠 여러 번, 천천히 오래 씹기.
3. 식후 소파, 병구가 식은땀을 흘리며 어지러워함, 귀남이 등을 받침 / 귀남 "단 거 먹고 이러네" / 식후 어지러움·식은땀·설사는 덤핑 증상일 수 있어 알리기.
4. 병구가 식후 의자에 바르게 앉아 공책에 식사 기록 / 병구 "먹고 바로 안 눕기" / 식후 바로 눕지 않고 앉아 쉬기, 체중을 계속 기록.

### EP10 사레는 신호예요

2. 목 안에서 음식길과 숨길이 갈라지는 지점을 부드럽게 그린 의학삽화(색만) / (대사 없음) / 기도로 넘어간 음식은 흡인성 폐렴을 일으킬 수 있음.
3. 삼킴 재활실, 언어재활사가 병구에게 고개 숙이고 삼키는 자세를 보여 줌 / 언어재활사 "턱을 당기고 삼켜요" / 삼킴 검사 뒤 자세·음식 농도를 맞추는 재활을 받을 수 있음.
4. 밤, 병구가 기침하며 이마를 짚고, 귀남이 체온계를 꺼냄 / 귀남 "열까지 나면 바로 가요" / 기침·가래에 발열·숨참이 겹치면 바로 진료.

1. 진료실, 소라가 병리보고서 첫 줄을 손가락으로 짚음(글자 흐림) / 소라 "편평이 무슨 뜻이에요?" / 편평세포암은 식도 안쪽 벽의 납작한 세포에서 시작한 암.
2. 식도 벽을 층층이 나눈 의학삽화, 가장 안쪽 층부터 색이 스며든 깊이(색만, 글자 없음) / (대사 없음) / 암이 벽의 어느 층까지 들어갔는지가 병기와 치료에 중요.
3. 주치의가 결과지 아래 칸을 가리킴 / 주치의 "검사를 모아 병기를 정해요" / 깊이·림프절·전이를 내시경·초음파·CT·PET로 모아서 판단.
4. 병구가 공책의 병기 칸을 비워 두고 연필을 꽂음 / 병구 "확정 전엔 빈칸으로" / 확정 전 병기는 추측으로 채우지 않고 다음 진료에 묻기.

### EP12 (심화) 내시경으로 떼는 초기암
1. 진료실, 경희가 건강검진 결과 봉투를 들고 놀란 얼굴 / 경희 "증상도 없었는데요" / 아주 초기 식도암은 검진 내시경에서 발견되기도 함.
2. 식도 벽 가장 안쪽 층의 얇은 부분만 떼어 내는 개념 삽화(색만) / (대사 없음) / 점막에 머문 초기암은 내시경 절제(EMR·ESD)를 상의할 수 있음.
3. 회복실, 경희가 미음 그릇 앞에 앉고 간호사가 식사 안내 카드(글자 없음)를 줌 / 간호사 "식사는 안내 순서대로" / 시술 뒤 금식·식사 단계는 병원 안내를 따름.
4. 외래, 주치의가 떼어 낸 조직 결과지를 보여 줌(글자 흐림) / 주치의 "깊이를 보고 다음을 정해요" / 떼어 낸 조직이 깊으면 추가 치료를 상의할 수 있음.

### EP13 (심화) 낯선 검사 이름들
1. 진료실, 소라가 휴대폰 메모의 영어 약자를 보여 줌(글자 흐림) / 소라 "PD-L1은 뭐예요?" / PD-L1 결과는 면역항암제 선택에 쓰일 수 있음.
2. 열쇠 꾸러미에서 서로 다른 모양의 열쇠 몇 개만 빛나는 그림(색만) / (대사 없음) / HER2·MSI 같은 검사는 조직형·병기에 따라 필요한 사람에게 함.
3. 주치의가 손을 저으며 설명 / 주치의 "모두 같은 검사를 하진 않아요" / 검사 결과가 있다고 맞춤약을 반드시 쓰는 것은 아님(허가·급여 확인).

### EP14 (심화) 수술 전 숨쉬기 연습
1. 거실, 병구가 호흡 연습 기구(무늬·글자 없음)를 물고 천천히 숨을 들이쉼 / 병구 "숨을 길게, 천천히" / 수술 전 호흡 운동은 수술 뒤 폐 합병증 예방에 도움.

### EP15 (심화) 수술 뒤, 한 걸음 더
1. 외래, 병구가 수술 병리 결과지 봉투를 들고 긴장 / 병구 "다 뗐는데 또 치료해요?" / 떼어 낸 조직 결과에 따라 보조치료를 상의할 수 있음.
2. 계단 끝에 작은 계단 하나가 더 이어진 그림(색만) / (대사 없음) / 수술 전 치료 뒤 암이 남아 있었다면 면역항암제 보조치료를 상의하는 경우가 있음.
3. 주치의가 두 갈래 화살표 그림 카드(글자 없음)를 보여 줌 / 주치의 "관찰도 선택지예요" / 보조치료 여부는 병리 결과·몸 상태로 함께 정함.

### EP16 (심화) 배에 단 작은 관
1. 병실, 병구가 옷 위로 살짝 보이는 가는 관과 거즈를 내려다봄(피부 안 보임) / 병구 "이제 입으로는 못 먹는 거야?" / 영양관은 입으로 못 먹는다는 뜻이 아니라 회복을 돕는 다리.

3. 간호사가 귀남에게 관 씻는 주사기와 물컵을 보여 줌(관 연결부 근접 없음) / 간호사 "막히지 않게 물로 씻어요" / 관 관리·영양액 속도는 병원 교육대로.

2. 같은 산꼭대기로 가는 두 길 중 다른 쪽 길을 걷는 사람 그림(색만) / (대사 없음) / 근치적 항암방사선은 수술과 다른 정당한 치료 길.

### EP18 (심화) 베개를 높이는 밤
1. 밤 침실, 병구가 누웠다가 기침하며 일어나 앉음 / 병구 "누우면 신물이 올라와" / 수술 뒤 위가 가슴으로 올라와 역류가 생기기 쉬움.

3. 진료실, 주치의가 내시경 일정 카드(칸만)를 건넴 / 주치의 "내시경으로 확인해요" / 협착인지 재발인지는 내시경·영상으로 확인(재발 → ㉗).

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 길은 넷) · 4장(삼키기 어려울 때 오늘 먹는 법) · 21장(수술 뒤 식사)**.
- 기존 골든샘플·목차가 나오면 문장 우선 재사용, 없으면 `esophageal.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~9를 골든샘플부터 적용.
- 병기(TNM)·치료 알고리즘 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. 생존율·pCR 비율은 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 영양·삼킴 장(4·14·21·22장)은 응급 신호 상자를 맨 위에(침도 못 삼킴·사레+발열·피 토함), 식사 팁은 그 아래(순서 고정). 삼킴 단계(묽은 것·부드러운 것·보통 밥)는 W3 기록지와 같은 말로.
- 주인공 병구는 국소진행 편평세포암·수술 전 항암방사선·식도절제술·공장루 경로. 수술 없는 항암방사선은 재근, 초기 내시경 절제는 경희 — 본문 사례도 같은 분담.
- 식도위접합부·선암 부분(15장)은 ③ GC 원고 문장과 대조해 용어 통일(덤핑·B12·철분 문장 포함).
- 26장 "가족 식탁" 상자 첫 줄은 "억지로 먹이지 않아도 돼요"(보호자 대상).
