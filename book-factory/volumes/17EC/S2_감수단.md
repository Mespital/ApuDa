# ⑰ EC — 감수단 구성 (가상 사전 감수 · 고정)

> ⚠ 이 감수단은 AI가 각 관점을 맡아 수행하는 **가상 사전 감수**다. 아래 인물은 모두 **가상 인물**이며, 실제 전문의·간호사·환자의 감수가 아니고 대신하지도 않는다. 독자 지면·보고서 어디에도 "전문의 감수 완료"처럼 쓰지 않으며, 독자 지면에 인원·이름을 노출하지 않는다(standards/04 머리말·01 원칙). 판권 표기는 그대로 "실제 전문의 서면감수 전".

- 구성 기준: `standards/04_근거확인_감수기준.md` §2 (전문의 다학제 4+ · 설명간호사 2+ · 환자 4+ · 보호자 1 · 편집·언어 2 · 심리 1)
- 고정일: 2026-11-26 · 이 권이 끝날 때까지 같은 구성 사용
- 가상 환자 이름은 본문 캐릭터(병구·귀남·소라·재근·경희)와 겹치지 않게 기호(P1~P5, G1)로만 부른다.

| 팀 | 역할(가상) | 관점 |
|---|---|---|
| 전문의 다학제 | 종양내과(식도암 전신치료·면역항암) | 치료 길 넷의 순서와 무게, 약은 범주 + 대표 예·용량 0, PD-L1·HER2 기준값 미기재 |
| 〃 | 흉부외과(식도절제술) | 수술 단정·"수술 안 함 = 포기" 오해, 수술 뒤 식사·누출 신호 문장 |
| 〃 | 방사선종양학과(수술 전·근치적 항암방사선) | 근치적 항암방사선을 정당한 길로 썼는가, 선량·횟수 0, 방사선 식도염 문장 |
| 〃 | 소화기내과(내시경 절제·확장술·스텐트) | 초기암 내시경 절제, 스텐트 = 삼킴 돕기(암 치료 아님), 확장술 표현 |
| 〃 | 병리과·영상의학과 | 편평세포암/선암 구분, 병기는 검사를 모아 정함, 지침 표 복제 금지 |
| 〃 | 재활의학과(삼킴 재활) | 사레 신호·삼킴 평가 의뢰 문장, 집에서 따라 해도 안전한가 |
| 설명간호사 | 식도암 전문간호사(외래 설명·전화 상담) | 연락 기준(38.0°C·피 토함·침도 못 삼킴·사레+열)이 분명한가, 진료실 질문의 실용성 |
| 〃 | 영양 전담 간호사·임상영양사 관점 | 부드럽게·조금씩·자주·앉아서 먹기, 체중 기록, 영양관 = 다리 문장 |
| 〃 | 흉부외과 병동 간호사 | 수술 뒤 영양관·연결 부위 누출 신호·퇴원 교육 |
| 환자 | P1 60대 남성, 편평세포암, 수술 전 항암방사선 → 식도절제술, 수도권, 디지털 보통 | 처음 듣는 사람 이해도, 먹는 문제의 현실성, 공포 문장 |
| 〃 | P2 70대 남성, 심장병으로 수술 대신 근치적 항암방사선, 충북 군 지역, 디지털 낯섦 | "수술 못 함 = 포기"로 읽히지 않는가, 글자·용어 부담 |
| 〃 | P3 50대 여성, 검진에서 아주 초기 식도암 → 내시경 절제, 대구, 디지털 익숙 | 초기암 독자의 과잉 공포, 추가 치료 설명 |
| 〃 | P4 50대 후반 남성, 식도위접합부 선암, 처음부터 전이, 전신치료, 부산, 디지털 보통 | 소외감, 15장 연결, 표지자 검사 이해 |
| 〃 | P5 60대 남성, 술·담배를 오래 함, 영양관 경험, 전남 | 원인 탓 문장, 금연·금주 문장 톤 |
| 〃 | 보호자 G1 60대 여성(배우자 식도암, 음식 준비 담당) | 집에서 음식 만들기·사레 대처·응급 판단 |

| 〃 | 국문학 교수 | 용어 통일(식도절제술, 근치적 항암방사선, 수술 전 치료/선행치료, 영양관), 문장 길이 |
