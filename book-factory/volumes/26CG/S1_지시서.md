- 발행: 2026-11-22 · 책공장(Claude 총괄 PD)
- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **CG v1.0** (로스터상 "원고 v0.2.2"였으나 저장소·Drive에서 원고를 찾지 못해 S1부터 새로 설계 — 원고가 나오면 S2에서 문장 대조·재사용)
- 상태: **G1 대기** — 결재함에 `G1 승인 CG` 또는 `G1 수정 CG: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학·제도 문장은 방향 설계이며 확정 문장이 아니다.
- 범위: **가족이 암 진단을 받은 뒤 첫 30일의 보호자**(배우자·성인 자녀·부모·형제·청년 보호자). 암종과 무관한 공통편이다. 암종별 치료 내용은 다루지 않고 "해당 권(①~㉕)으로" 연결한다. 소아암 부모는 ㉓ PED권, 임종기 돌봄 상세는 ㉚ PAL권, 재발 소식 직후는 ㉗ REC권으로 연결하고 이 권에서는 입구만 안내한다.
- 톤: 보호자는 **"두 번째 환자"가 아니라 "팀의 주장"**이다 — 그러나 주장도 교대가 필요하다. 책 전체의 축은 두 가지: ① **환자 곁에서 할 일은 생각보다 적고 구체적이다**(기록·연락·응급 판단·서류), ② **보호자 자신의 몸·잠·일·마음을 지키는 것도 돌봄의 일부다.** 죄책감·"내가 더 했어야" 서사를 걷어 내고, 도움 요청을 기술로 가르친다. 환자의 결정권(병명 공개·치료 선택)을 존중하는 대화법을 반복한다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **응급 기준은 시리즈 공통으로.** 항암 중 발열 **38.0°C** = 해열제보다 먼저 병원 연락. 그 밖의 응급 신호는 암종 공통 항목만(숨참·의식 변화·출혈·소변 안 나옴·심한 통증·자해 생각) — 암종 특이 신호는 "해당 권 응급 카드"로.
2. **제도 수치 쓰지 않기.** 가족돌봄휴가·휴직 일수, 간병비·요양 등급 기준, 산정특례 비율·기간, 장기요양 신청 조건, 상병수당, 간호·간병통합서비스 본인부담 등 숫자는 넣지 않고 "고용노동부·국민건강보험공단·주민센터·병원 사회복지팀 확인" 꼬리. 제도 이름도 발행 시점 실재 여부 S4 재확인(예: 가족돌봄청년 지원사업 지역별 차이).
3. **약·처방 단정 금지.** 보호자가 약을 "조절"하는 문장 금지 — "처방대로 챙기고, 바꾸고 싶으면 의료진에게". 진통제·수면제·한약·건강기능식품은 "의료진에게 목록 보여 주기"로만. 용량 미기재.
4. **심리 문장은 진단 단정 금지.** "우울증입니다" 대신 "이런 날이 두 주 넘게 이어지면 전문가와 이야기해 보세요" 수준. 보호자 고통 점수(디스트레스 온도계)는 개념만, 기준 점수 숫자는 "병원 안내 기준".
5. **환자 탓·보호자 탓 금지.** "보호자가 잘 먹이면 낫는다", "긍정적이어야 낫는다" 같은 효능 주장 금지. 음식·마음가짐과 생존을 잇는 문장 금지.
6. **법·재정 문장.** 위임장·대리 처방·사전연명의료의향서·연명의료계획서·후견은 "개념 + 어디에 묻는지"까지. 법률 조언 아님 표기. 보험금 대리청구는 "약관·보험사 확인".
7. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시, 임상심리·사회복지 관점 감수 필요 표기. 참고(NCCN Distress Management, 국가암정보센터 보호자 안내 등)는 실재·최신 판 S4 확인.
8. **가상 사례 이름은 다른 권과 겹치지 않게**(1~12권·⑬ BLC 인물 명단과 대조 완료).

### EP14 (심화) 약 봉투에 날짜 쓰기
1. 식탁 위에 약 봉투 여러 개(글자 없음), 옥분이 헷갈려함 / 옥분 "이건 아침이었나?" / 약이 늘면 복용 실수가 생기기 쉬움.
2. 선영이 요일별 약통에 처방대로 나눠 담는 손 / (대사 없음) / 처방대로 요일·시간별로 정리.
3. 선영이 영양제·한약 병을 모아 사진을 찍음(상표 없음) / 선영 "이것도 다 보여 드리자" / 보충제·한약도 의료진에게 목록으로 알리기.
4. 휴대폰 알람 그림(숫자 없음), 종구가 약을 먹고 엄지척 / 종구 "알람 울리면 먹는다" / 알람·체크표로 빠뜨림을 줄이기, 임의 조절 금지.

### EP15 (심화) 한 숟갈이면 충분해요
1. 저녁 식탁, 옥분이 밥을 크게 떠서 내밂, 종구가 고개를 돌림 / 옥분 "한 그릇은 먹어야지" / 입맛 없는 날 억지로 먹이면 서로 힘들어짐.
2. 작은 그릇 여러 개에 조금씩 담긴 음식 그림 / (대사 없음) / 조금씩 자주, 먹고 싶은 것부터.
3. 종구가 죽 한 숟갈을 먹고 웃음 / 종구 "이 정도는 들어가네" / 먹은 양보다 수분·체중 변화를 기록해 진료 때 알리기.
4. 선영이 옥분 어깨를 감쌈 / 선영 "엄마 탓 아니야" / 음식이 암을 낫게 하거나 나쁘게 한다는 말에 휘둘리지 않기.

### EP16 (심화) 아프다는 말을 숫자로
1. 거실, 종구가 허리를 짚으며 참음 / 종구 "괜찮다, 참을 만해" / 환자는 통증을 참고 말하지 않는 경우가 많음.
2. 0~10 표정 그림 척도 개념 컷(숫자 대신 얼굴 표정만) / (대사 없음) / 통증 정도를 표정 척도로 표현하게 돕기.
3. 선영이 증상 일지에 표정 스티커를 붙임 / 선영 "어제보다 어때요?" / 통증·피로·메스꺼움·잠을 매일 같은 방식으로 기록.
4. 진료실, 선영이 일지를 보여 줌 / 주치의 "이걸 보니 약을 바꿔 봐요" / 기록이 있으면 의료진이 조절하기 쉬움(조절은 의료진).

### EP17 (심화) 화를 낸 밤
1. 밤 부엌, 경태가 싱크대를 짚고 고개를 숙임(배경에 깨진 것 없음) / 경태 "아내한테 소리를 질렀어" / 지친 보호자가 화를 내는 일은 흔함.
2. 경태 마음속 무거운 돌 개념 그림(색만) / (대사 없음) / 죄책감이 쌓이면 더 지치게 됨.
3. 상담실, 임상심리 상담사와 마주 앉음 / 상담사 "화가 난 건 지쳤다는 신호예요" / 감정을 말하는 것만으로도 부담이 줄 수 있음.
4. 다음 날 아침, 경태가 아내에게 따뜻한 차를 건넴(아내는 측면) / 경태 "어제는 미안했어" / 사과하고 다시 시작하면 됨, 두 주 넘게 힘들면 상담.

### EP18 (심화) 스물셋, 엄마의 보호자
1. 대학 강의실 대신 병원 대기실, 나래가 노트북과 약 봉투를 함께 듦 / 나래 "휴학계 내고 왔어" / 젊은 나이에 혼자 가족을 돌보는 청년 보호자가 있음.

4. 카페, 나래가 친구와 웃으며 커피를 마심 / 나래 "오늘은 두 시간만 나야" / 내 시간과 미래 계획도 지켜도 됨.

### EP19 (심화) 회사에 뭐라고 말하지
1. 사무실 복도, 선영이 팀장 방 앞에서 망설임 / 선영 "어디까지 말해야 하지" / 회사에 알릴 범위는 내가 정함.

3. 팀장이 고개를 끄덕임 / 팀장 "제도 있나 인사팀에 물어봐요" / 가족돌봄휴가·휴직 등은 회사·고용노동부 확인.
4. 퇴근길, 선영이 지하철에서 잠깐 눈을 감음 / 선영 "일도 내 삶이니까" / 일을 이어 가는 것도 보호자의 회복에 도움.

### EP20 (심화) 아직 안 정해도 되는 이야기
1. 저녁 마루, 종구가 TV 뉴스를 보다 툭 말함 / 종구 "나중에 기계는 달지 마라" / 환자가 먼저 미래 이야기를 꺼내기도 함.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **2장(첫 72시간) · 9장(응급 판단) · 18장(보호자 소진 신호)**.
- 기존 원고 v0.2.2가 나오면 문장 우선 재사용, 없으면 01~12권 보호자 장과 공통 응급 기준을 토대로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~8을 골든샘플부터 적용.
- 각 장 끝에 "암종별로 더 보기" 상자 1개(해당 권 번호만 안내, 다른 권 내용 복제 금지).
- 관계별 상자(배우자·자녀·부모·청년)는 장마다 반복하지 말고 7장·23장·24장에 모음.
- 심리 장(18~21장)은 임상심리 관점으로 쓰고 진단명 단정 금지. "두 주 넘게 이어지면" 같은 기준은 출처를 달거나 "일반적 예시"로.
- 제도 장(25~28장)은 이름과 "어디에 묻는지"까지만, 금액·일수·비율은 쓰지 않는다.
- 주인공 선영(맏딸), 배우자 보호자 경태, 청년 보호자 나래, 멀리 사는 형제 선우 — 본문 사례(30장)도 같은 분담.
