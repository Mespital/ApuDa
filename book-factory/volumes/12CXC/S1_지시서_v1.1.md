## 0. 합본 원칙
1. **한 권, 두 갈래.** 두 암은 원인(HPV vs 호르몬·대사·유전), 병기(경부 FIGO vs 내막 FIGO), 주 치료(항암방사선 vs 수술 + 보조치료)가 다르다. 독자가 길을 잃지 않게 **공통 장**(검사·72시간·로드맵·몸과 마음·돈·도구)과 **갈래 장**(경부 전용·내막 전용)을 나누고, 갈래 장 머리에 색 띠 표지를 단다: 🟪 경부 / 🟧 내막 (조판 S6에서 색으로만, 이모지는 원고 표시용).
2. 공통 장 안에서 두 암이 다른 대목은 **"경부암이라면 / 내막암이라면" 2단 상자**로 나눈다(섞어 쓰지 않음).
3. 1장 첫 쪽에 **"내 병은 어느 쪽?" 분기표**: 병리보고서의 진단명(자궁경부 / 자궁내막·자궁체부) → 이 책에서 읽을 장 목록.
4. **자궁육종**(자궁근육·간질에서 생기는 드문 암)은 치료가 달라 1장 안내 상자 + 14장 짧은 상자로만("경험 많은 센터 상담"). 상세 미수록.
5. 내막암 근거: NCCN Guidelines for Patients: Uterine Cancer **2021**(Uterine Neoplasms v3.2021 기반, 이번 실행 원문 전체 열람) — **오래된 판**이라 FIGO 2023 병기 개정·분자 분류(POLE·p53·MMR·NSMP)·최근 면역치료 1차 병용은 수록되지 않음 → 2·3순위(ESGO-ESTRO-ESP 지침, FIGO 2023 원문, 국내 부인종양학회)로 확인 전에는 **"최근 분류가 바뀌는 중 + 담당의 확인"** 수준으로만 쓴다. 국가암정보센터 자궁내막암 쪽은 다음 실행에서 열람 시도.

### 4컷 칸 장면 (새·보강)
**EP05 두 갈래 지도, 겹치지 않게** — 1. 외래 대기실, 윤희와 미옥이 나란히 앉음 / 미옥 "저도 자궁암이래요" / 같은 '자궁암'이라도 경부와 내막은 다른 병. 2. 자궁 그림에서 아래(경부)와 안쪽(내막)을 다른 색으로(글자 없음) / (대사 없음) / 시작한 자리가 다르면 원인·병기·치료가 다름. 3. 주치의가 두 길을 가리킴 / 주치의 "경부는 병기, 내막은 수술 뒤 병리가 길을 정해요" / 경부 국소진행은 항암방사선, 내막은 수술 뒤 위험도로 보조치료. 4. 태호와 미옥이 각자 수첩에 다른 칸을 체크 / 미옥 "내 길은 내 병리로" / 내 경로와 이유를 받아 적기.

**EP07 자궁과 함께 난관·난소도, 그리고 감시림프절** — 1. 진료실, 미옥이 수술 그림(의학삽화)을 봄 / 미옥 "자궁만 떼는 게 아니에요?" / 내막암 표준 수술은 자궁과 양쪽 난관·난소 절제. 2. 림프절 몇 개만 색으로 빛나는 개념 삽화(글자 없음) / (대사 없음) / 감시림프절 검사로 림프절 전이를 확인하기도. 3. 주치의가 작은 구멍 수술 그림을 가리킴 / 주치의 "자궁에 머물러 있으면 작은 구멍으로도 해요" / 최소침습 수술이 흔히 선택됨(경부암 근치 수술과 다름). 4. 미옥이 수첩에 '수술 뒤 열감·잠' 칸 / 미옥 "폐경 증상도 물어볼게요" / 난소 절제 뒤 수술 폐경 증상 상담.

**EP11 MMR 한 줄이 여는 두 갈래** — 1. 진료실, 미옥이 병리보고서의 한 줄을 짚음 / 미옥 "MMR 결핍이 뭐예요?" / 내막암은 모두 MMR(또는 MSI) 검사를 권함. 2. 두 갈래 화살표 개념(한쪽 가계도 실루엣, 한쪽 세포 표지 깃발, 글자 없음) / (대사 없음) / 결과가 유전 확인(린치)과 치료 선택 두 쪽에 쓰임. 3. 유전상담실, 상담 간호사가 가계도 종이(글자 없음)를 펼침 / 간호사 "가족 이야기도 같이 봐요" / 린치 증후군 의심 시 유전상담·검사. 4. 미옥이 휴대폰으로 조카에게 문자를 쓰는 모습(화면 글자 없음) / 미옥 "결과 나오면 알려 줄게" / 가족에게 알릴지·언제는 상담 후 함께 정함.

**EP12 관찰도 결정입니다** — 1. 수술 뒤 외래, 미옥이 최종 병리 결과를 듣고 / 미옥 "방사선 안 해도 돼요?" / 위험도가 낮으면 관찰이 표준 선택일 수 있음. 2. 저울 위에 병기·등급·침윤 깊이·나이 같은 작은 추(그림만) / (대사 없음) / 여러 위험 요소를 함께 보고 보조치료를 정함. 3. 방사선종양학과 의사가 질 근접치료 개념 삽화를 보여 줌 / 의사 "필요하면 질 위쪽만 좁게 해요" / 보조치료: 질 근접치료·골반 방사선·전신치료 범주. 4. 미옥이 달력에 추적 진료 날짜를 표시(숫자 없음) / 미옥 "대신 증상은 바로 말하기" / 관찰 중 출혈 등 새 증상은 다음 진료까지 기다리지 않음.
