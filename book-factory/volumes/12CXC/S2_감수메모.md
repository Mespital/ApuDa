# ⑫ CXC — S2 장 단위 감수 메모 (standards/04 §3-1 · 가상 사전 감수)

## 6장 (2026-11-23)
- 심각(반영, 심리): "파트너가 바람을 피웠다는 증거" 오해 칸 — "검사로 알 수 없으므로 근거가 없다"는 논리 순서로(S1 §0-7).
- 중대(반영): 국가검진 "만 20세 이상 2년마다"·백신 대상 연령 수치 삭제 → 질병관리청·공단 확인 안내.
- 경미(유지): "많은 감염이 1~2년 안에 저절로 사라짐" — NCI 확인, 수치이지만 예후·효능 수치가 아님. S4에서 유지 여부 재판단.
- 환자(P1·보호자): 파트너 대화 예시 실용적. 원인 따지는 가족에게 할 말 추가(반영).
- 다학제(부인종양): "진단 뒤 치료는 병리·병기가 정한다" 정확.

## 11장 (2026-11-23)
- 중대(반영): 회차·주 수·투여 간격·수분량 삭제, 7~8주는 NCCN 환자판·BC Cancer로 출처 확보 후 유지.
- 중대(반영, 방사선종양학과): "쉬면 효과가 떨어진다" 단정 대신 "정해진 기간 안에 마치도록 권한다 + 치료팀과 먼저 상의"로.
- 간호사(방사선치료실): 빠질 일 생기면 치료실에 먼저 알리기, 쉬지 않고 증상 줄이는 방법 — 실제 교육 흐름과 맞음.
- 환자(P3, 지방): 근접치료 연계 병원 날짜 먼저 확보 문장 중요 — 30초 요약 아래 본문 첫 목록에 배치(반영).
- 경미: 면역치료·유도항암 약 이름 삭제(범주만), 허가·급여 꼬리 유지.

## 12장 (2026-11-23)
- 중대(반영, 심리·편집): 기구 삽입 묘사(탠덤·링·바늘) 완화 → "가는 관 모양 기구", 용어는 용어집으로.
- 중대(반영): "조사 10분 안팎"·"1~2일 입원"·"질 확장기 2~4주 뒤" 삭제 → 병원 계획·교육.
- 경미(확인 필요): "치료 중 화면·마이크로 지켜봄", "고선량률 후 방사선 남지 않음", "마취·진정" — 국내 방사선종양학과 안내문 S4 대조.
- 간호사(부인암): 질 확장기를 "성생활 여부와 관계없이" 설명 — 반영. 끝난 뒤 연락 기준 38.0°C 명시.
- 환자(P2): 이른 폐경 언급이 갑작스럽지 않게 "치료할 수 있는 문제"로 마무리(반영).

## 1장 (2026-11-23 · v0.2)
- 중대(반영, 병리): 완전판 표의 "이 책에서 볼 곳"이 새 목차와 어긋남(5·8·9장) → 3·5·9장으로 재배치.
- 중대(반영, 다학제): 조직형 빈도 서열("가장 흔함/두 번째")은 이번 실행 1순위 미대조 → "흔한 조직형"으로 낮춤. S4에서 국가암정보센터 대조 후 복원 여부 결정.
- 간호사(외래): 첫 30일 지도의 Day 구간이 "늦으면 큰일" 압박으로 읽힘 → 순서만 남기고 일정은 PART 3로(반영).
- 환자(P2 가임력): "임신을 원하면 먼저 말하기"가 30초 요약에 있어 좋음. 환자(P4): 결과지 표가 어려울 수 있어 첫 질문 한 문장 안내 추가(반영).
- 편집: 자궁내막암 독자 안내 상자 — 단권안 전제 문구, G1 결정에 따라 교체 대상(경미, 표시만).
- 심리: "HPV 양성은 암이 아닙니다"를 맨 앞에 — 공포 완화 적절.

## 2장 (2026-11-23 · v0.2)
- 중대(반영): 산정특례 "30일 이내" 수치 삭제 → 시점 영향만 + 원무과·공단 확인.
- 중대(반영, 다학제): HIV "국제 지침이 권장" 출처 미대조 → "의료진이 권하면"으로 낮춤.
- 중대(반영, 심리): 마음 점수 "4점 이상" 기준은 근거 연결 전 → "높거나 며칠째 내려가지 않으면".
- 간호사(외래): 기다리지 않는 신호 상자를 2장에도 짧게 배치, 38.0°C 명시(반영).
- 환자(P1·보호자): "검색은 오늘까지만"·보호자 몫이 실제로 쓸모 있음. 병리보고서 두 부 권장 유지.

## 3장 (2026-11-23 · v0.2)
- **심각(반영, 병리):** 완전판 FIGO 정의 오기 — IA1 "3mm 미만"·IA2 "3mm 이상 5mm 미만" → FIGO 원문대로 "3mm 이하"·"3mm 초과 5mm 이하".
- **심각(반영, 병리·부인종양):** 가상 보고서가 "절제면에 침윤암 있음"인데 "IA2 범위"로 해석 — FIGO는 절제면 침윤암이면 IA로 두지 않음 → 예시 절제면을 음성으로, 절제면 침윤암 시 설명 별도 추가.
- 중대(반영, 편집): 코드블록(```) 노출 → 인용 상자 + "예시, 실제 환자 아님".
- 중대(반영): 고위험·중간위험 인자 목록은 1순위 미대조 → 10장으로 넘기고 3장에는 "최종 병리로 추가치료 결정"만.
- 환자(P2·P4): 숫자 해석은 의료진에게, 독자는 "적혀 있는 것만 옮겨 적기" 안내가 부담을 줄임. 재판독 안내 유용.
- 심리: "오진이 아니라 정보가 늘어난 결과" 문장 유지.
