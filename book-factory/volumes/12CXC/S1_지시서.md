- 발행: 2026-11-22 · 책공장(Claude 총괄 PD)
- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **CXC v2.0** (기존 「12_자궁경부암_진단첫30일_완전판」 2026.10 개정 2판 57쪽 → LC 구조 재편 + EP 20편 + FAQ 100)
- 상태: **G1 대기** — 결재함에 `G1 승인 CXC` 또는 `G1 수정 CXC: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학 문장은 방향 설계이며 확정 문장이 아니다.
- **G1에서 함께 정할 것 — 자궁내막암 처리.** 공장 로스터의 권 이름은 「자궁경부암·자궁내막암」이지만 저장소·Drive에 있는 기존 원고는 **자궁경부암 완전판뿐**이다(Drive 제목 '내막암' 검색: 사진 폴더만, 원고 없음). 두 암은 원인(HPV vs 호르몬·대사)·병기(FIGO 경부 vs 내막)·주 치료(항암방사선 vs 수술 + 분자분류)가 달라 한 권 30장에 섞으면 두 독자 모두 길을 잃는다. 이 지시서는 **(가) 자궁경부암 단권**으로 설계했다. 결재 선택지:
  - (가) `G1 승인 CXC` → 자궁경부암 단권으로 진행. 자궁내막암은 별권(예: ⑫-2 EMC) 또는 ⑭ 난소암(OVC)과 「부인암」 묶음으로 나중에 S1부터. 1장에 자궁내막암 독자 안내 상자만 둠.
  - (나) `G1 수정 CXC: 내막암 합본` → PART 2를 경부암·내막암 두 갈래로 나누고 EP 일부(최대 6편)를 내막암으로 교체한 v1.1 지시서를 다음 실행에서 재발행.
- 범위: 침윤성 자궁경부암 첫 진단(편평상피암·선암·선편평상피암). 전암병변(CIN·AIS)은 1장 안내 상자로만, 신경내분비암(소세포암)·임신 중 진단은 14장 "드문 상황" 장에서 방향만.
- 톤: 자궁경부암은 **"탓할 일이 아닌 병"** 과 **"날짜를 지키는 치료"** 두 축으로 쓴다. HPV를 둘러싼 죄책감·의심을 처음부터 걷어 내고, 국소진행 환자의 7~8주 항암방사선 + 근접치료 일정을 끝까지 지키도록 생활 동선까지 돕는다. 몸의 변화(폐경 증상·질 협착·성 건강·배뇨)는 부끄러운 일이 아니라 치료할 수 있는 문제라는 태도를 유지하되, 장면 연출은 절제한다.

**기존 원고에서 고칠 것(S2·S4)**
1. **발열 표기 38.0°C 통일.** 응급 상자 "38°C 이상 발열(특히 항암치료 중)", 수술 후 "퇴원 후 38°C 이상 발열", 11장 "38°C 이상 발열이 있으면 바로 연락", 증상표 끝 "항암 중 38°C 이상(병원 기준에 따라 37.8°C 이상 1시간 지속 등)" → 모두 **38.0°C**. 37.8°C 병기는 삭제하고 "병원 안내 기준이 다르면 병원 기준을 따르세요"로 대체. FAQ 데이터 80번 "38도 이상 발열"도 책에 옮길 때 38.0°C로.
2. **출처 없는 수치 문장 → 처리 방침.**
   - 추적 장 "국내 자료로는 근치 수술을 받은 초기 환자의 5~20%가 재발하며, 그중 절반은 1년 안, 대부분은 3년 안" → **예후 수치이므로 본문 삭제**("재발은 치료 뒤 처음 몇 년 사이에 많아 이 시기 추적이 특히 중요"). 진찰 간격 "1~2년 3~6개월·3~5년 6~12개월·5년 이후 1년" → "일반적 예시" + 출처, "병원 추적 일정표 우선". "가임력 보존 수술 후 골반 MRI 6개월 뒤, 이후 2~3년간 매년" → 간격 삭제, "보존 수술 뒤 영상 추적 일정을 담당의와 정함".
   - 11장 "외부방사선 주 5회 × 5~6주", "근접치료 3~5회(약 2주)", "전체 7~8주 안에" → 7~8주 원칙은 지침 핵심이므로 **출처(NCCN·국내 부인종양 지침) 표기 후 유지**, 횟수·주 수 세부는 "일반적 예시 · 병원 계획표 우선". 주차별 캘린더의 "항암 1~5회" 회차 표기 → 회차 삭제, "주 1회 항암하는 날(병원 일정표)"로.
   - 11장 "주로 시스플라틴 주 1회 … 신장 기능이 나쁘면 카보플라틴" → 약 이름은 "대표 예"로 한 번만, 투여 간격 삭제("병원 일정표"). 유도항암 "카보플라틴 + 파클리탁셀", 면역치료 "펨브롤리주맙", 재발 2차 "티소투맙 베도틴", 베바시주맙 → 범주명 위주 + 대표 예 1회, 모두 "국내 허가·급여 변경 가능 + 의료진 확인".
   - 응급 상자 "하루 6회 이상 설사", "패드가 1시간 안에 흠뻑 젖을 정도" → 출처 연결 또는 "일반적 예시"(병원 안내 우선). 출혈 기준은 독자 행동에 꼭 필요하므로 S4에서 국내 부인과 안내문 기준 확인 후 유지 여부 결정.
   - 캘린더 "수분 하루 1.5~2L(제한 없을 때)", 증상표 "하루 4~6회 이상 설사"·"한 달 5% 이상 체중 감소"·"낮잠 30분 이내", 검사 준비 카드 "PET 4~6시간 금식", 수술 준비 "하루 20~30분 걷기", 움직이기 "주 150분", 불안 대처 "검색 하루 30분", "치료 끝난 뒤 2~4주 동안 증상", 질 확장기 "방사선 종료 2~4주 뒤부터", 난자 동결 "보통 2주 안팎", 입원 "수일~1주 안팎" → 출처 연결 또는 "일반적 예시"(병원 기준 우선).
   - FIGO 병기 정의(IA1 3mm 미만·IA2 3~5mm·IB1 2cm 미만·IB2 2~4cm·IB3 4cm 이상 등)와 가임력 보존 조건(2cm 미만 등) → **병기·지침 정의이므로 유지**, FIGO 2018·NCCN 출처 표기. 표 구조는 ApuDa 언어로 새로 짬(지침 표 복제 금지).
   - 수술 장 "최소침습 근치 자궁절제는 연구에서 재발 위험 증가가 보고" → 출처(무작위 연구) 근거 쪽 연결. "저위험 IA2·IB1은 단순 자궁절제 가능이 최근 권고" → 출처 연결, 발행 시점 재확인.
   - Q8 "성인 여성 가족은 만 20세 이상 2년마다 국가 자궁경부암 검진" → 국가암검진 기준 출처(국립암센터·공단) 연결 + 발행 시점 재확인. HPV 백신 "국가예방접종 대상 연령" → 연령 수치 없이 "대상 연령은 질병관리청·소아청소년과 확인".
   - 산정특례 "30일 이내·본인부담 5%·5년", 가족돌봄휴직 "90일"·휴가 "10일", "보험금 청구권 소멸시효 3년", 직장 "현금 흐름 3개월"·"한 번에 100%" → 앞 권들과 같은 방식으로 수치 삭제, "원무과·공단·고용노동부 확인" 꼬리.
3. **급여·허가·제도 S4 재확인(2026.10 기준 → 발행 시점 기준).** 국소진행 항암방사선 + 면역치료 병용, 유도항암, 재발·전이 1차 면역치료 병용(PD-L1 기준), 2차 ADC, PET/CT 급여 기준, 근접치료 시행 병원, 난자 동결 비용 지원(지자체), 상피내암(제자리암) 산정특례 비율, 상병수당 시범사업. 모두 "변경 가능 + 의료진·공단 확인" 꼬리 유지.
4. **판권·근거 쪽.** 완전판 "감수: ApuDa 「첫 30일」 감수단(전문의 30인·환자 36인·편집자문 3인 역할 기반 AI 사전 검토단)… 출판본에는 실제 감수자 명단이 별도 표기" → "**실제 전문의 서면감수 전**"을 판권에 명시, AI 검토단 인원수는 독자 지면에서 삭제. 가상 사례 머리말 "감수단 환자 페르소나를 바탕으로 재구성한" → "ApuDa가 만든 가상의 이야기"로. 참고 지침 판 표기 "NCCN … Cervical Cancer, Version 2.2026"은 실재·최신 여부 S4에서 확인. "국제 지침이 진단 시 권장"(HIV·마음 점검) 문장은 출처 쪽에 지침명 연결.
5. **조판 결함.** 전암/침윤암 표의 "이 책에서 볼 곳" 열이 다음 쪽으로 분리(6장·5·8·9장·14장이 행과 어긋남), 첫 30일 지도 "대략 시기" 열이 질문 뒤로 밀림, 병리 표 "LVSI(림 프혈관 침범)" 단어 분리, 가상 보고서 블록에 마크다운 ``` 기호가 그대로 노출, 병리보고서 기록칸 체크박스 뒤섞임, FIGO 표가 IIIA부터 다음 쪽으로 넘어가며 열 머리 누락, 치료 경로 표 "항암방 사선"·"전신치 료" 쪼개짐, 항암방사선 캘린더 "보호자 동행" 열이 다음 쪽으로 밀려 주차와 어긋남, 10장 "있습니다." 중복, 증상표 "메스꺼 움" 분리, 검사 준비 카드 "PET/C T"·"조직검 사" 분리, 6장 이후 일부 장 번호 소실 → 이번 판에서 전부 재출력으로 해결.
6. **가상 사례 정리.** 기존 사례 "31세 지은 씨"는 ⑤ TC권 보호자 이름(지은)과 겹침 → 이름 교체(예: '다인 씨'). "46세 미선 씨(IIB 항암방사선)"는 본 권 주인공(윤희, IIB)과 설정이 겹침 → 30장에서 **수술 후 최종 병리로 추가 방사선을 받은 IB2** 사례로 바꿈. 사례 나이 표기 삭제하고 생활 설정으로. "정숙 씨(IVB)" 유지(이름 겹침 없음 — S2에서 재확인).
7. **독자 지면 정리.** 병리보고서 가상 예시는 "예시, 실제 환자 아님" 표시 유지 + 코드 블록 대신 회색 상자. HPV 장의 "파트너가 바람을 피웠다는 증거다 — 사실이 아닙니다" 문장은 유지하되 단정 대신 "HPV 검사로는 언제·누구에게서 왔는지 알 수 없습니다"를 앞에 둠.

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(패드가 빠르게 흠뻑 젖는 질 출혈 + 어지럼·실신 → 119, 발열 38.0°C·오한·악취 분비물·심한 골반통, 한쪽 다리가 갑자기 붓고 아픔·갑작스러운 흉통·숨참, 소변이 거의 안 나옴·심한 옆구리 통증, 설사·구토로 물을 못 마심, 새 다리 힘 빠짐·대소변 조절 이상, 스스로를 해치고 싶은 생각 → 109·119) · 0-2 오늘 확인할 세 가지(병리보고서 / 부인종양 전문의 예약 / 임신 희망 여부 정리) · 0-3 책 사용법 · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 먼저 구분하세요: HPV 양성·전암병변·침윤암 (+ 자궁내막암·전암병변 독자 안내 상자) → **EP01**
2. 진단 뒤 72시간 → **EP02**
3. 병리보고서 읽기: 침윤 여부·조직형·침윤 깊이·LVSI·절제면 → 심화 **EP11**
4. 병기 검사: 골반 MRI와 PET/CT, 영상 단어장 → **EP03**
5. FIGO 병기: 숫자보다 "어디까지", 수술 뒤 병기가 바뀌는 이유 → 심화 **EP12**
6. HPV 바로 알기: 원인이지만 탓할 일은 아닙니다 · 파트너에게 말하기 → **EP04**
7. 임신을 원한다면: 치료 전에 말하세요(보존 수술·난자/배아 동결·난소전위) → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 수술 · 항암방사선 · 전신치료, "겹치지 않게" 설계 → **EP05**
9. 초기 수술: 원추절제~근치 자궁절제, 개복 vs 최소침습, 난소 보존 → 심화 **EP14**
10. 수술 후 최종 병리와 추가치료(고위험·중간위험 인자)
11. 국소진행: 항암방사선 7~8주 원칙 → **EP06**
12. 근접치료: 빼면 안 되는 이유와 하루 안내 → **EP07**
13. 재발·전이: 바이오마커(PD-L1 등)와 전신치료 범주 → 심화 **EP15**
14. 드문 상황: 신경내분비암(소세포암)·임신 중 진단·근종 수술 뒤 발견
15. 진행·재발이라면: 치료 목표·완화의료·증상별 대처·2차 소견·임상시험 → 심화 **EP16**

### PART 3. 30일 실행 로드맵
16. Day 0–7 확인하고 검사받기(MRI·PET/CT·신장 기능·생식의학과 의뢰)
17. Day 8–21 결정하고 준비하기(경로 확정 · 근접치료 병원 확보 · 통원 교통 · 직장 일정)
18. Day 22–30 시작하기 · 7~8주 항암방사선 달력(W6) · 수술 경로라면 입원 준비

### PART 4. 치료 중·후의 몸과 마음
19. 항암방사선 중 몸 관리: 설사·빈뇨·피부·피로·혈구 감소와 발열 38.0°C → **EP08**
20. 수술 뒤 배뇨·배변: 잔뇨·자가도뇨·골반저 재활 → 심화 **EP17**
21. 성 건강·질 확장기·폐경 증상(치료할 수 있는 문제) → 심화 **EP18**
22. 림프부종·뼈 건강·봉와직염 신호 → **EP09**
23. 추적: 재발 확인 + 후유증 관리(골반 진찰 중심, 세포검사의 한계)
24. 마음 돌보기 · HPV 죄책감 · 파트너와의 대화 · 예후 이야기를 듣는 법 → **EP10**
25. 보호자에게 · 아이에게 알리기 · 딸의 HPV 백신·여성 가족 검진 · 먹는 것과 움직이는 것 · 금연 → 심화 **EP19**

### PART 5. 돈 · 서류 · 제도
26. 산정특례·의료비 지원(상피내암·전암병변과의 차이 확인)
27. 보험 청구: 제자리암(상피내암)과 침윤암 진단비 분류 · 회사 서류 → 심화 **EP20**
28. 직장과 일상: 7~8주 매일 통원 근무 조정, 복귀

### PART 6. 진료실 도구
29. 진료실 질문 모음 · 대화법 · 내 자궁경부암 한 장 요약 · 응급 카드
30. 같은 진단, 다른 30일(가상 사례 3: 가임력 보존·수술 후 추가 방사선·원격전이)

### 뒤쪽
- FAQ 100(기본 40 · 추가 40 · 생활·몸 20) · 워크북 W1~W7(비상 연락처·진료 기록지·7일 증상 일지·복용 약·보충제 목록·30일 달력·7~8주 항암방사선 달력·배뇨/림프부종 기록) · 근거·검토 상태 · 용어 100±10 · 영문약어 색인 · 판권 · 뒤표지

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 양성이라는 말, 암이라는 말
1. 마트 사무실, 윤희가 휴대폰 문자(글자 없음)를 보고 굳음 / 윤희 "HPV 양성이면 암이야?" / HPV 양성은 "더 확인이 필요하다"는 뜻.
2. 계단 세 칸 개념 그림: 바이러스 점 → 세포 변화 → 침윤(색만) / (대사 없음) / HPV 감염·전암병변·침윤암은 서로 다른 단계.
3. 진료실, 주치의가 조직검사 결과지를 함께 봄 / 주치의 "조직검사로 확인됐어요" / 침윤암은 조직검사로 확진.
4. 태호가 수첩에 '침윤암·편평상피암'을 받아 적음 / 태호 "정확한 이름부터 적자" / 진단명과 조직형을 정확히 확인.

### EP02 사흘 동안 세 가지만
1. 밤, 윤희가 식탁에서 휴대폰 검색, 태호가 휴대폰을 살짝 덮음 / 태호 "검색은 오늘까지만" / 첫 사흘은 세 가지만.
2. 원무과, 윤희가 병리보고서 사본을 받음 / 윤희 "두 부씩 부탁드려요" / 병리보고서는 처음부터 두 부씩.
3. 거실, 태호가 부인종양 전문의 예약 전화 / 태호 "부인암 보시는 선생님으로요" / 부인종양 전문의에게 진료.
4. 침대 머리맡, 윤희가 서아 사진 액자를 봄 / 윤희 "둘째, 정말 끝일까" / 임신 희망 여부를 첫 진료에서 말하기.

### EP03 사진 두 장으로 그리는 지도
1. MRI 대기실, 윤희가 금속 귀걸이를 빼서 태호에게 건넴 / 윤희 "금속은 다 빼래" / 골반 MRI는 국소 범위를 봄.
2. 골반 단면 개념 삽화에 종양 범위를 색으로, 옆에 몸 전체 실루엣(점 몇 개) / (대사 없음) / MRI는 골반 안, PET/CT는 몸 전체.
3. 진료실, 주치의가 림프절 그림을 가리킴 / 주치의 "커 보여도 다 전이는 아녜요" / 영상의 림프절 크기와 실제 전이는 다를 수 있음.
4. 태호가 검사 체크 칸에 기호만 표시 / 태호 "다음엔 신장 수치도" / 요관 막힘이 있으면 신장 기능도 확인.

### EP04 누구 탓도 아닌 바이러스
1. 밤 부엌, 윤희가 등을 돌리고 서 있음 / 윤희 "내가 뭘 잘못했나 봐" / 암 진단은 잘못이나 행실의 결과가 아님.
2. 많은 사람 실루엣 위에 작은 점이 스쳐 지나가는 개념 그림(색만) / (대사 없음) / HPV는 대부분이 한 번쯤 노출되는 흔한 바이러스.
3. 진료실, 태호가 조심스럽게 묻고 주치의가 고개를 저음 / 주치의 "언제 누구한테선지 몰라요" / 검사로 감염 시기·경로를 알 수 없음.
4. 거실, 태호가 윤희 손을 잡음 / 태호 "따지지 말고 같이 준비하자" / 원인보다 치료 준비에 마음을 모으기.

### EP05 세 갈래 길, 겹치지 않게
1. 진료실, 윤희가 친구 이야기를 꺼냄 / 윤희 "친구는 수술로 끝났대요" / 같은 자궁경부암도 병기마다 경로가 다름.
2. 세 갈래 길 그림(수술·항암방사선·전신치료, 색만) / (대사 없음) / 초기는 수술, 국소진행은 항암방사선 + 근접치료.
3. 주치의가 두 길이 겹치는 부분을 손으로 가림 / 주치의 "수술 뒤 방사선까지면 힘들어요" / 치료가 겹치지 않게 처음부터 설계.
4. 태호가 수첩에 "항암방사선 + 근접치료" 칸에 체크 / 태호 "우리는 이 길" / 내 경로와 그 이유를 받아 적기.

### EP06 7주의 달력
1. 집 벽, 윤희가 큰 달력에 스티커를 붙임(숫자 없음) / 윤희 "매일 가는 거네" / 외부방사선은 평일 매일 통원.
2. 달력 위 칸 색이 이어지다 끝에 다른 색 칸(근접치료) 개념 그림 / (대사 없음) / 외부방사선 + 동시 항암 뒤 근접치료까지 정해진 기간 안에.
3. 마트 사무실, 윤희가 점장에게 근무 조정안을 건넴 / 윤희 "두 달만 오전 반차로요" / 근무 조정안은 내가 먼저 제안.
4. 차 안, 태호가 운전하며 윤희가 창밖을 봄 / 태호 "쉬고 싶으면 먼저 상의" / 임의로 쉬지 말고 치료팀과 먼저 상의.

### EP07 빼면 안 되는 마지막 치료
1. 설명실, 방사선종양학과 의사가 골반 삽화를 보여 줌 / 의사 "가까이서 한 번 더 쏴요" / 근접치료는 종양 바로 옆에서 높은 선량.
2. 골반 단면 삽화에 종양 가까이 작은 빛이 모이는 개념(기구 묘사 없이 빛만) / (대사 없음) / 외부방사선만으로는 대체할 수 없음.
3. 회복실, 윤희가 담요를 덮고 쉬며 간호사가 곁에 있음 / 간호사 "불편하면 바로 말해요" / 마취·진정과 진통제로 조절.
4. 귀가하는 차 안, 윤희가 태호에게 미소 / 윤희 "몸에 방사선 안 남는대" / 고선량률 근접치료 뒤 가족과 평소처럼 지내도 됨.

### EP08 3주차의 고비
1. 화장실 앞, 윤희가 배를 감싸고 지친 표정 / 윤희 "오늘만 몇 번째야" / 항암방사선 중 설사·복통은 흔함.
2. 식탁, 태호가 미음과 물컵을 내려놓음 / 태호 "물부터 조금씩" / 수분 섭취, 지사제 사용법은 미리 배워 두기.
3. 거실, 윤희가 증상 일지에 체크(숫자 없음) / 윤희 "소변도 자꾸 마려워" / 빈뇨·배뇨통·피부 자극도 기록해 알리기.
4. 밤, 태호가 체온계를 보고 전화 / 태호 "38.0도에 물도 못 마셔요" / 발열 38.0°C 이상·탈수면 바로 연락.

### EP09 다리가 묵직한 날
1. 퇴근길 버스 정류장, 윤희가 한쪽 종아리를 문지름 / 윤희 "다리가 왜 이렇게 무겁지" / 골반 림프절 치료 후 림프부종이 생길 수 있음.
2. 다리 림프관에 물이 고이는 개념 삽화(색만) / (대사 없음) / 묵직함·붓기를 일찍 기록하면 관리가 쉬움.
3. 림프부종 클리닉, 간호사가 압박 스타킹 상자를 보여 줌 / 간호사 "피부 보호가 먼저예요" / 피부 관리·운동·압박 요법.
4. 밤, 태호가 붉어진 다리를 보고 놀라 전화 / 태호 "열나고 빨개졌어요" / 붓는 다리에 열감·발적·발열이면 빨리 진료.

### EP10 미안해하지 않아도 돼
1. 거실, 서아가 윤희 무릎에 기대어 / 서아 "엄마 왜 맨날 병원 가?" / 아이에게는 나이에 맞게 짧고 사실대로.
2. 윤희가 서아를 안고 손으로 작은 혹을 그려 보임(글자 없음) / 윤희 "병원에서 혹을 줄이는 중" / 아이의 세 가지 걱정에 먼저 답함.
3. 밤, 윤희가 혼자 마음 온도계 그림(색만)을 봄 / 윤희 "식구들한테 미안해" / 고통 점수가 높은 날이 이어지면 진료 때 말하기.
4. 태호가 따뜻한 차를 건네며 옆에 앉음 / 태호 "미안해하지 않아도 돼" / 상담·심리지지 연결 경로가 있음.

### EP11 (심화) 4밀리미터가 말해 주는 것
1. 진료실, 다인이 원추절제 결과지를 들고 / 다인 "4mm면 큰 거예요?" / 침윤 깊이는 초기 병기를 나누는 기준.
2. 자궁경부 단면 삽화에서 겉면부터 안쪽으로 얕은 화살표(숫자 없음) / (대사 없음) / IA1·IA2는 침윤 깊이로 구분(FIGO 2018).
3. 주치의가 두 번째 줄을 짚음 / 주치의 "혈관 침범도 봐야 해요" / LVSI가 있으면 림프절 평가가 필요할 수 있음.
4. 다인이 절제면 칸에 ❔ 기호를 그림 / 다인 "절제면 양성이면 다음은?" / 절제면 양성이면 추가 절제·수술 검토.

### EP12 (심화) 수술 뒤 바뀐 병기
1. 진료실, 수술을 마친 경미가 놀란 얼굴 / 경미 "1기라더니 3기요?" / 수술로 더 많은 정보가 생기면 병기가 바뀔 수 있음.
2. 영상 그림과 현미경 그림을 나란히 둔 개념 비교(색만) / (대사 없음) / 영상으로 안 보이던 림프절 전이가 병리에서 확인되기도.
3. 주치의가 차분히 설명 / 주치의 "오진이 아니라 새 정보예요" / 바뀐 병기에 맞춰 추가치료를 정함.
4. 경미가 최종 병리 기록칸을 채움 / 경미 "추가치료 여부부터 묻자" / 고위험 인자가 있으면 수술 후 항암방사선.

### EP13 (심화) 둘째 이야기, 오늘 꺼내기
1. 진료실, 윤희가 망설이다 손을 듦 / 윤희 "둘째 계획이 있었어요" / 가임력 희망은 치료를 정하기 전에 말하기.
2. 주치의가 골반 삽화에서 난소를 옆으로 옮기는 화살표 개념 / 주치의 "난소를 비켜 둘 수 있어요" / 난소전위술은 난소 기능을 지키는 방법(자궁 영향은 못 막음).
3. 생식의학과 상담실, 의사가 일정표(숫자 없음)를 보여 줌 / 의사 "치료 일정 안에서 해 봐요" / 난자·배아 동결은 치료 일정과 함께 조율.
4. 윤희와 태호가 손을 잡고 복도를 걸음 / 태호 "선택은 같이 하자" / 배아 동결은 배우자 동의 필요, 비용 지원은 확인.

### EP14 (심화) 수술 방법도 물어보세요
1. 외래 대기실, 다인이 윤희 옆에 앉아 수첩을 봄 / 다인 "저는 수술이래요" / 초기(IA~IB2 등)는 수술 중심.
2. 원추절제·자궁경부절제·자궁절제 범위를 색 농도로 나눈 개념 삽화 / (대사 없음) / 수술 범위는 병기·위험도·가임력에 따라.
3. 진료실, 다인이 질문 / 다인 "배를 여는 수술이에요?" / 근치 자궁절제는 개복이 표준으로 권고되는 경우가 많음.
4. 다인이 수첩에 '난소 보존' 칸 / 다인 "난소는 남길 수 있나요?" / 폐경 전이면 난소 보존 가능 여부를 상의.

### EP15 (심화) 다시 생겼다면 검사부터
1. 진료실, 경미가 굳은 얼굴 / 주치의 "폐에서 보여요" / 재발·전이도 치료 선택지가 있음.
2. 세포 표면에 작은 표지 깃발이 꽂힌 개념 삽화(글자 없음) / (대사 없음) / PD-L1 등 바이오마커가 1차 치료 선택의 출발점.
3. 주치의가 여러 갈래 길 그림(색만)을 가리킴 / 주치의 "결과 보고 약을 정해요" / 백금 항암 바탕에 면역치료 등 범주(국내 허가·급여 확인).
4. 경미가 바이오마커 기록칸에 기호만 표시 / 경미 "임상시험도 물어볼게요" / 검사 종류·결과·임상시험을 함께 묻기.

### EP16 (심화) 목표를 다시 묻는 날
1. 진료실, 경미와 딸 가람이 손을 잡음 / 경미 "이 치료 목표가 뭔가요?" / 목표: 줄이기·늦추기·증상 줄이기.
2. 상담실, 완화의료팀 간호사가 함께 앉음 / 간호사 "통증·잠도 같이 봐요" / 완화의료는 항암과 함께, 포기가 아님.
3. 가람이 2차 소견 서류철(슬라이드 상자 그림)을 챙김 / 가람 "슬라이드 대여부터" / 2차 소견 준비물은 병리 슬라이드·영상 CD.
4. 거실, 경미가 서류를 덮고 창밖을 봄 / 경미 "의향서는 아직은 아니야" / 사전연명의료의향서는 원할 때, 결정은 천천히.

### EP17 (심화) 소변 감각이 돌아올 때까지
1. 병실, 다인이 소변줄을 뺀 뒤 화장실 앞에서 갸웃(이불·환자복) / 다인 "마려운 느낌이 없어요" / 근치 수술 후 배뇨 감각이 둔해질 수 있음.
2. 간호사가 잔뇨 측정 기계(글자 없음) 옆에서 설명 / 간호사 "남은 소변을 재 볼게요" / 잔뇨 측정·자가도뇨 교육을 받을 수 있음.
3. 재활실, 물리치료사가 골반저 운동 그림(의학삽화)을 보여 줌 / 치료사 "힘 주고 천천히 풀어요" / 골반저 재활이 배뇨·배변 회복을 도움.
4. 집, 다인이 배뇨 기록표에 기호 체크 / 다인 "열나면 바로 연락" / 발열 38.0°C·배뇨통·소변을 전혀 못 보면 연락.

### EP18 (심화) 말하기 어려운 변화
1. 진료실, 윤희가 시선을 피하며 / 윤희 "이런 것도 물어봐도 돼요?" / 질 건조·협착·성교통은 치료할 수 있는 문제.
2. 간호사가 파우치(질 확장기·보습제 암시, 내용물 안 보임)를 건넴 / 간호사 "시작 시기는 안내대로" / 질 확장기는 추적 진찰을 위해서도 중요.
3. 밤, 윤희가 이불 속에서 땀을 닦으며 깸 / 윤희 "갑자기 확 더워" / 방사선·난소 제거 뒤 조기폐경 증상, 호르몬요법은 개인별 상담.
4. 거실, 부부가 손을 잡고 대화 / 윤희 "천천히 다시 시작하자" / 성 재활 상담을 이용할 수 있음, 아프면 멈추기.

### EP19 (심화) 딸과 동생에게 남기는 약속
1. 주말 거실, 동생 윤정이 과일을 들고 방문 / 윤정 "나도 검사 받아야 해?" / 여성 가족은 국가 자궁경부암 검진 대상 여부 확인.
2. 보건소 안내 게시판 앞(글자 없음), 윤희가 서아 손을 잡음 / 윤희 "너도 크면 주사 맞자" / HPV 백신은 대상 연령이 정해져 있음, 소아청소년과 상의.
3. 윤정이 휴대폰으로 검진 예약 화면(글자 없음) / 윤정 "언니 덕분에 예약했어" / 백신을 맞아도 검진은 계속 필요.
4. 식탁, 세 사람이 웃으며 식사 / 윤희 "우리 집 약속이다" / 가족 예방은 원인 탓이 아니라 서로를 지키는 일.

### EP20 (심화) 제자리암이라고 적혀 있다면
1. 보험 창구, 다인이 진단서를 내밂 / 다인 "진단비가 왜 다르죠?" / 약관마다 제자리암(상피내암)·침윤암 분류가 다름.
2. 다인이 약관을 손가락으로 짚음(글자 흐림) / (대사 없음) / 유사암·소액암 분류와 병리 확정 조건 확인.
3. 진료실, 다인이 질문 / 다인 "최종 병리는 침윤암이었죠?" / 원추절제 뒤 침윤이 확인되면 진단서·병리 결과지로 보완.
4. 원무과, 윤희가 산정특례 상담 / 원무과 직원 "등록 여부 확인해 드릴게요" / 침윤암과 상피내암은 산정특례 적용이 다를 수 있음.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **6장(HPV 바로 알기) · 11장(항암방사선 7~8주 원칙) · 12장(근접치료)**.
- 기존 완전판 문장 우선 재사용, 새 수치 추가 금지. 0절 "고칠 것" 1~7을 골든샘플부터 적용(38.0°C, 예후 수치 삭제, 항암 회차·투여 간격 삭제).
- FIGO 표·가임력 보존 표·바이오마커 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에.
- 예후·생존율·재발률 수치는 본문에 새로 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 1장에 자궁내막암·전암병변(CIN3·AIS) 독자 안내 상자를 둔다(결재 (가) 기준).
- 주인공 윤희는 IIB 항암방사선 + 근접치료 경로. 수술·가임력 보존 경로는 보조 인물 다인(EP11·14·17·20), 수술 뒤 병기 변화·재발·완화는 보조 인물 경미와 딸 가람(EP12·15·16)로 보여 준다 — 본문 사례도 같은 분담.
