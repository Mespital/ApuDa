- 톤: 급성백혈병은 **"생각할 시간이 짧은 병"**이다 — 진단 며칠 안에 입원·치료가 시작될 수 있다. 책 전체의 축은 두 가지: ① **"관해는 결승선이 아니라 첫 구간"**(관해유도 → 공고 → 이식 또는 유지, 지도를 먼저 손에 쥐기), ② **"피가 모자란 시기를 함께 버티는 법"**(발열 38.0°C·출혈·입안 관리는 환자와 보호자가 같이 하는 치료). 급하게 시작하더라도 생식력·두 번째 의견·가족 역할은 "짧게라도 한 번 묻기"로 놓치지 않게 한다. 결과지의 유전자 이름에 겁먹지 않도록 "내 치료 지도에 쓰이는 표지"로 반복 설명한다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 호중구 감소기 발열·중심정맥관 부위 발열·이식 뒤 발열 모두 38.0°C. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리. 웹 FAQ의 "38°C" 표기는 책에서 38.0°C로 통일.
2. **수치 쓰지 않기.** 골수 아세포 기준 %, 관해율·생존율·재발률, 백혈구·혈소판·호중구 "몇 이하면", 입원 기간 "몇 주", 항암 "몇 일 + 몇 일", 공고 "몇 차례", TKI 반응 목표 % 같은 수·기간은 본문에 넣지 않는다. 필요하면 "결과지·병원 일정표 기준"으로. 위험군(유리·중간·불리)은 이름과 뜻만, 해당 유전자 목록 표는 지침 표 복제 금지.
3. **약은 "범주 + 대표 예"로만.** AML: 시타라빈+안트라사이클린 계열 강한 관해유도(대표 예), 저메틸화제+베네토클락스(저강도 대표 예), FLT3·IDH 표적약(범주명 위주) / APL: 레티노산 계열(트레티노인 대표 예)·비소 화합물(범주) / ALL: 스테로이드·빈크리스틴·아스파라기나제 등 여러 약 병용, Ph 양성은 TKI 병용, 이중특이항체·항체약물접합체·CAR-T(범주) / CML: TKI(이매티닙 대표 예). 용량·주기·횟수 미기재, 모두 "국내 허가·급여 변경 가능 + 의료진 확인".
4. **관해 ≠ 완치.** "관해 = 다 나았다" 금지 → "골수와 혈액에서 백혈병 세포가 기준 아래로 줄어든 상태, 다음 구간(공고)을 시작하는 신호". MRD 음성은 "검사법으로 찾을 수 있는 수준 아래"이지 "세포 0개"가 아님.
5. **이식 단정 금지.** "백혈병은 이식해야 낫는다" 금지 → "유전 위험군·MRD·나이·기증자·몸 상태로 상의". 가족 HLA 검사는 "맞는지 확인하는 검사이지 기증 확정이 아님 — 기증 여부는 검사받는 가족 본인의 결정".
6. **원인 단정·탓 금지.** 직업·생활습관·이전 치료와의 관련을 원인처럼 쓰지 않는다(치료 관련 AML은 "이전 치료 이력이 치료 선택에 쓰임" 개념만). "가족에게 옮지 않음·자녀에게 대부분 유전되지 않음"은 출처 달고 신중히(일부 유전 소인 예외는 "상담 대상"으로만).
7. **APL은 응급 문장 고정.** 0-1과 6장에 "APL이 의심되면 확진 전에 치료를 먼저 시작하기도 함, 코피·잇몸 출혈·멍·두통·시야 변화는 즉시 알림"을 같은 문장으로. 치료 성적 수치 금지.
8. **생식력 보존은 "짧게라도 한 번 묻기".** 치료가 급해 보존이 어려울 수 있음을 숨기지 않되 "가능하다"를 약속처럼 쓰지 않음. 임신 중 진단은 "산과·혈액내과 함께 결정" 안내 상자만.
9. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN AML·ALL·CML, ELN AML·APL 권고, WHO 5판·ICC 분류, 대한혈액학회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
10. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~14·26·27권 인물 명단과 대조 완료).

### PART 1. 진단 첫 주 — 정확히 알기
1. 백혈병은 한 가지가 아니에요: 피를 만드는 골수에서 생기는 병 · 급성(AML·ALL)과 만성(CML·CLL) · 골수성과 림프구성 → **EP01**
2. 진단 뒤 72시간: 입원·치료가 빨리 시작될 수 있음 · 결과지 두 부 · 직장·가족 연락 · 보호자 한 명 정하기 → **EP02**
3. 골수검사: 골수천자·골수생검(엉덩이뼈 뒤쪽) · 무엇을 보나(아세포·면역표현형·염색체·유전자) · 검사 뒤 관리 → **EP03**
4. 피가 모자라서 생기는 일: 빈혈(숨참·피로) · 백혈구 부족(감염) · 혈소판 부족(출혈) · 수혈과 예방약도 치료의 일부 → **EP04**
5. 결과지 읽기: 면역표현형 · 핵형·FISH·NGS가 각각 보는 것 · 유전 위험군(유리·중간·불리의 뜻만) · 결과가 나눠서 나오는 이유 → 심화 **EP11**
6. APL — 하루가 급한 이유: 출혈 위험 · 의심 단계에서 먼저 시작하는 치료 · 분화증후군 신호(숨참·부종·체중 증가) → 심화 **EP12**
7. ALL에서 더 확인하는 것: B세포형·T세포형 · 필라델피아 염색체(BCR::ABL1) · 뇌척수액 검사와 중추신경계 예방치료 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 관해유도 → 공고 → (동종이식 또는 유지·관찰) · 강한 치료와 저강도 치료는 목표와 방식이 다름 → **EP05**
9. 관해유도 입원: 중심정맥관 · 병실 생활(손 위생·마스크·면회 규정은 병원 기준) · 보호자 역할 나누기 → **EP06**
10. 치료 첫 주를 지키는 검사: 종양용해증후군 · 수액·소변량·체중 · 피검사를 자주 하는 이유 → 심화 **EP14**
11. 나이·체력에 맞춘 치료: 저강도 치료(외래 가능 여부는 병원 판단) · "약하게"가 "포기"가 아님 · 치료 목표 다시 묻기 → 심화 **EP17**
12. 첫 골수 재검: 관해(CR)의 뜻 · 세포가 거의 안 보이는 회복기 · MRD 개념 맛보기 · 관해 ≠ 완치 → **EP07**
13. 공고치료와 동종이식 상의: 누구에게 이식을 상의하나(위험군·MRD·몸 상태) · HLA 검사 · 형제·비혈연·반일치 기증자 개념 · 가족 검사는 기증 확정이 아님 → 심화 **EP15**
14. 생식력 보존: 치료가 급해도 짧게 한 번 묻기 · 정자 보관·난자 동결 상담 · 생리 조절 상의 · 임신 중 진단 안내 상자 → 심화 **EP16**
15. 다른 백혈병 안내: CML(먹는 표적약 TKI · 외래 · 매일 같은 시간 · 약 상호작용) · CLL(관찰 대기도 치료 전략) · 2차 소견(슬라이드·유전자 결과 재확인) · 임상시험 → (CML 사례 길수, EP19 일부)
16. 치료가 어려울 때: 완화의료 병행 · 수혈·감염 관리로 지내는 시간 · 집에서 지내기 · 치료 목표 대화

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 피를 만드는 공장에서 생긴 일
1. 진료실, 기훈이 결과지를 쥐고 보람이 노트를 펼침 / 기훈 "백혈병이면 피에 생긴 암이죠?" / 백혈병은 피를 만드는 골수에서 시작되는 혈액암.
2. 뼈 속 골수를 작은 공장처럼 그린 의학삽화, 미숙한 세포가 줄지어 막고 있음(색만, 글자 없음) / (대사 없음) / 미숙한 세포가 늘어 정상 피를 만들 자리가 줄어듦.
3. 주치의가 네 칸으로 나뉜 그림 카드(빠른 물줄기 2·느린 물줄기 2, 글자 없음)를 가리킴 / 주치의 "급성인지, 어떤 줄기인지부터요" / 급성·만성, 골수성·림프구성에 따라 치료가 크게 다름.
4. 보람이 노트에 네 칸 중 하나에 동그라미(기호만), 기훈이 고개를 끄덕임 / 보람 "우리는 급성 골수성" / 내 백혈병의 정확한 이름(AML·ALL·APL·CML)을 기록하기.

### EP02 생각할 시간이 짧아요
1. 병원 복도, 기훈이 휴대폰으로 교감에게 전화하는 옆모습, 보람이 입원 안내문을 듦(글자 흐림) / 기훈 "내일부터 입원이래요" / 급성백혈병은 진단 며칠 안에 입원·치료가 시작될 수 있음.
2. 원무과, 보람이 결과지·골수검사 보고서 봉투 두 개를 받음 / 보람 "두 부씩 부탁드려요" / 결과지는 처음부터 두 부씩 — 두 번째 의견·보험에 쓰임.
3. 집 거실, 보람이 준서와 소파에 앉아 손을 잡음 / 준서 "아빠 오래 있어?" / 아이에게는 짧고 정직하게, 자세한 말은 차차(26장).
4. 밤 식탁, 기훈이 입원 가방 옆에 메모 세 줄(기호만)을 올려 둠 / 기훈 "오늘은 세 가지만" / 유형·치료 시작 장소·함께 들을 보호자, 세 가지 먼저 확인.

### EP03 엉덩이뼈에서 하는 검사
1. 처치실 앞 의자, 기훈이 긴장한 얼굴로 앉아 있고 간호사가 설명 카드를 보여 줌 / 기훈 "골수는 어디서 뽑아요?" / 골수검사는 대개 엉덩이뼈 뒤쪽에서 함.
2. 기훈이 옆으로 누워 담요를 덮고, 의사는 등 뒤에서 마스크를 쓰고 있음(바늘·피부 안 보임) / 의사 "누르는 느낌이 들어요" / 국소마취 후 진행, 누르거나 당기는 느낌이 있을 수 있음.
3. 현미경 둥근 시야 속 세포들, 옆에 염색체 줄무늬·이중나선 그림(색만, 글자 없음) / (대사 없음) / 세포 모양·표면 표지·염색체·유전자를 한 번에 확인함.
4. 병실, 기훈이 검사 부위를 누르고 누워 휴대폰 메모, 보람이 물병을 건넴 / 보람 "결과는 나눠서 나온대" / 결과마다 걸리는 시간이 달라 여러 번에 나뉘어 나옴.

### EP04 모자란 피는 채우면서
1. 학교 운동장 계단, 기훈이 계단 중간에서 숨이 차 손잡이를 잡음(진단 전 회상, 화면 가장자리 흐림) / 기훈 "몇 계단에도 숨이 찼어" / 적혈구가 부족하면 숨이 차고 쉽게 지침.
2. 혈액 속 적혈구·백혈구·혈소판 세 종류가 듬성듬성한 개념 삽화(색만) / (대사 없음) / 빈혈·감염·출혈이 함께 올 수 있음.
3. 병실, 수액 걸이에 멀리 수혈 주머니(색 흐리게), 간호사가 기훈 옆에서 확인표를 봄(글자 없음) / 간호사 "춥거나 숨차면 바로요" / 수혈 중·후 오한·숨참·두드러기는 즉시 알리기.
4. 약 쟁반 앞, 약사가 예방약 봉투들(글자 없음)을 가리킴 / 약사 "이 약들도 치료의 일부예요" / 수혈·감염 예방약은 백혈병 치료를 버티게 하는 지원 치료.

### EP05 지도는 세 구간
1. 진료실, 주치의가 세 칸으로 이어진 길 그림 카드(글자 없음)를 탁자에 펼침 / 주치의 "길은 세 구간이에요" / 관해유도 → 공고 → 이식 또는 유지·관찰.
2. 산길 세 구간 그림, 첫 구간 끝에 작은 깃발(색만) / (대사 없음) / 첫 목표는 관해 — 백혈병 세포를 크게 줄이는 것.
3. 기훈이 두 번째·세 번째 구간을 손가락으로 짚음 / 기훈 "깃발 꽂으면 끝 아니에요?" / 관해 뒤에도 남은 세포를 줄이는 공고치료가 이어짐.
4. 보람이 노트의 세 칸 지도에 "지금 여기" 화살표를 그림(기호만) / 보람 "지금 우리는 첫 구간" / 강한 치료·저강도 치료는 목표와 방식이 달라 내 길을 확인.

### EP06 병실이 집이 되는 동안
1. 혈액내과 병실, 기훈이 침대 옆에 가족사진 액자와 스톱워치를 놓음 / 기훈 "여기가 한동안 집이네" / 관해유도는 입원해 진행하는 경우가 많음.
2. 병실 입구, 보람이 손 소독제를 쓰고 마스크를 고쳐 씀 / 간호사 "들어올 때마다 손부터요" / 손 위생·마스크·면회 규정은 병원 기준을 따름.

### EP11 (심화) 결과지에 적힌 유전자 이름

### EP12 (심화) APL, 서두르는 이유
1. 병동 휴게실, 상우가 잇몸에 손수건을 대고 앉아 있고 기훈이 옆에서 걱정스레 봄 / 상우 "저는 오자마자 약부터래요" / APL은 출혈 위험 때문에 의심 단계에서 치료를 먼저 시작하기도 함.

3. 간호사가 상우 침대 옆에서 체중계를 가리킴 / 간호사 "숨차거나 부으면 바로요" / 치료 초기 숨참·부종·급한 체중 증가는 즉시 알리기.
4. 상우가 휴대폰에 두통·시야 기호를 적어 보임 / 상우 "머리 아프면 참지 말래요" / 심한 두통·시야 변화는 머릿속 출혈 신호일 수 있어 바로 알림.

### EP13 (심화) 척수액도 확인해요
1. 진료실, 유진이 어머니(뒷모습)와 앉아 그림 카드(등뼈 그림, 글자 없음)를 봄 / 유진 "허리에서도 검사해요?" / ALL은 뇌·척수로 퍼졌는지 뇌척수액 검사로 확인.

### EP14 (심화) 물을 많이 주는 이유

### EP15 (심화) 동생의 피 검사
1. 이식 상담실, 이식 코디네이터가 기훈·보람·기범에게 그림 카드(퍼즐 조각, 글자 없음)를 보여 줌 / 코디네이터 "맞는 짝을 찾는 검사예요" / HLA 검사는 이식 기증자가 맞는지 보는 검사.
2. 퍼즐 조각 여러 쌍 중 일부만 딱 맞는 그림(색만) / (대사 없음) / 형제·비혈연·반일치 등 기증자 경로는 여러 가지.
3. 기범이 소매를 걷으며(팔 근접 없음) 웃음 / 기범 "형, 일단 검사부터 해 볼게" / 가족 HLA 검사는 기증 확정이 아니며, 기증 여부는 본인이 정함.
4. 면담실, 주치의가 결과 카드 세 장(색 다른 표, 글자 없음)을 나란히 놓음 / 주치의 "위험군과 MRD 보고 정해요" / 이식 여부는 위험군·MRD·나이·몸 상태·기증자로 함께 결정.

### EP16 (심화) 치료 전 짧은 상담
1. 진료실, 유진이 어머니(뒷모습)와 앉아 손을 꼭 쥠 / 유진 "나중에 아기는 어떡해요?" / 일부 치료는 생식력에 영향을 줄 수 있어 시작 전에 묻기.
2. 시계 그림과 작은 씨앗 주머니 그림이 나란히(숫자 없음) / (대사 없음) / 치료가 급하면 보존이 어려울 수 있어 짧게라도 바로 상담.
3. 상담실, 생식의학 상담 간호사가 선택지 카드 세 장(그림만)을 펼침 / 간호사 "할 수 있는 것부터 볼게요" / 난자 동결·생리 조절 등은 혈액내과와 함께 가능 여부를 정함.
4. 유진이 수첩에 질문 두 줄(기호)을 적음 / 유진 "치료 중 피임은요?" / 치료 중 임신은 피하고 피임 방법은 의료진과 상의.

### EP17 (심화) 나에게 맞는 세기
1. 진료실, 점순이 며느리(측면)와 앉아 손수건을 쥠 / 점순 "늙어서 치료도 못 한대요?" / 나이가 많아도 몸 상태에 맞는 치료를 상의할 수 있음.
2. 저울 양쪽에 작은 화분(효과)과 깃털(부담)이 균형을 이룬 그림(색만) / (대사 없음) / 저강도 치료는 효과와 부담의 균형을 맞춘 선택.
3. 주치의가 점순의 손을 잡고 설명 / 주치의 "약하게가 포기는 아니에요" / 체력·동반 질환·원하는 생활을 함께 보고 세기를 정함.
4. 방앗간 앞 평상, 점순이 며느리와 달력에 외래 칸 표시(숫자 없음) / 점순 "집에서 다니면서 한대" / 외래 가능 여부·수혈·감염 관리 계획은 병원 판단대로.

### EP18 (심화) 이식 뒤, 새 면역과 지내기
1. 퇴원 뒤 거실, 기훈이 팔의 붉은 발진(옅은 색)을 보며 사진을 찍음 / 기훈 "피부가 울긋불긋해" / 이식 뒤 피부 발진·설사·황달은 이식편대숙주병 신호일 수 있음.
2. 새로 심은 나무(기증자 면역)가 낯선 정원(내 몸)에 뿌리내리는 그림(색만) / (대사 없음) / 새 면역이 자리 잡는 동안 조절 약이 필요함.
3. 약사가 기훈의 약 복용표(칸만)를 함께 봄 / 약사 "면역억제제는 시간 지켜요" / 면역억제제는 정해진 대로, 임의 중단·건강식품 추가 금지.
4. 이식 외래, 이식 코디네이터가 예방접종 일정 카드(칸만)를 건넴 / 코디네이터 "주사도 처음부터 다시" / 이식 뒤 재접종은 이식팀 일정대로.

### EP19 (심화) 보이지 않는 세포까지
1. 외래 채혈실 앞, 기훈이 팔을 누르고 앉아 결과 화면(숫자 흐림)을 기다림 / 기훈 "관해인데 왜 또 검사해요?" / 관해 뒤에도 남은 세포(MRD)와 혈구 회복을 추적함.
2. 돋보기 아래 아주 작은 점 몇 개가 희미하게 보이는 그림(색만) / (대사 없음) / MRD 음성은 검사법으로 찾을 수 있는 수준 아래라는 뜻.
3. 같은 대기실, 길수가 약 봉투를 들고 기훈에게 웃어 보임 / 길수 "저는 약 먹으며 피검사만 해요" / CML은 먹는 표적약을 매일 먹고 혈액 유전자 검사로 추적.
4. 기훈이 노트의 "다시 볼 신호" 칸에 멍·열·뼈 통증 기호 / 보람 "이상하면 다음 예약 전에" / 멍·발열·뼈 통증·피로 증가는 예약을 기다리지 말고 알리기(재발 → ㉗).

### EP20 (심화) 아빠는 왜 병원에서 자?
1. 병동 면회실 유리창 너머, 준서가 손을 흔들고 기훈이 마스크 쓰고 손바닥을 유리에 댐 / 준서 "아빠는 왜 병원에서 자?" / 아이에게는 나이에 맞는 짧고 정직한 말이 도움이 됨.
2. 몸속 지킴이 병정이 잠시 쉬는 사이 의사·간호사가 대신 지켜 주는 그림(색만) / (대사 없음) / "피를 만드는 곳이 아파서 고치는 중"처럼 쉬운 말로.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 관해유도 → 공고 → 이식·유지) · 20장(호중구 감소와 발열 38.0°C) · 3장(골수검사)**.
- 기존 골든샘플·목차가 나오면 문장 우선 재사용, 없으면 `aml.json`·`all.json`·`cml.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~10을 골든샘플부터 적용.
- 위험군·분류(WHO·ICC·ELN) 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. 관해율·생존율·재발률 수치는 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 장마다 머리에 유형 표지(공통 / AML / APL / ALL / CML)를 달아 독자가 자기 길만 읽을 수 있게 한다.
- 주인공 기훈은 AML 강한 치료·관해·이식 상의 경로. 고령 저강도는 점순, 젊은 ALL·생식력은 유진, APL은 상우, CML은 길수 — 본문 사례도 같은 분담.
- 발열·출혈 장(20·21장)은 응급 신호 상자를 맨 위에, 생활 팁은 그 아래(순서 고정). APL 응급 문장은 0-1·6장·21장 같은 문장.
- 아이에게 말하기(26장)는 "가족에게 하는 말" 예시 상자(가상) 1개 — 첫 줄은 "옮지 않는 병".
