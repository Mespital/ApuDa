## 판권 · 머리말 · 바로 시작 0-1~0-4 (2026-11-24)
- 중대(반영, 혈액암 전문간호사·진단검사의학과): S1 0-1 목록의 "쥐가 남"(종양용해증후군) — 1순위에서 증상 단어 미확인 → 본문 제외, "소변이 갑자기 줄거나 몸이 붓는 느낌 → 알림"으로만. 10장 집필 때 재확인.
- 중대(반영 확인, 감염내과): 발열 기준 38.0°C 하나, "해열제보다 먼저 연락", "병원 안내 기준이 다르면 병원 기준" 꼬리 — NCI 감염·NCCN AML p.29로 확인.
- 중대(반영 확인, 혈액종양내과 A): APL 응급 문장(출혈·두통·시야 변화 즉시 + 분화증후군 신호 숨참·붓기·체중 증가)을 0-1에 두고 6장 연결 — S1 §0-7. 6·21장에서 같은 문장 유지할 것.
- 경미(확인 필요): "머릿속 출혈일 수 있음, 119"는 2순위(NCI·ACS "바로 연락") 대비 강화 표현 → S4 확인. 109는 ⑭ OVC 확인분 재사용.
- 편집: 판권 첫 문장에 판본 "LEU v0.1", 목차 미승인 표기 줄 없음(G1 일괄 승인). 0-4 웹 FAQ 3곳 주소는 저장소 canonical과 일치.
- 환자(P2, 디지털 낯섦): 0-3 "내 길 찾기" 표 6행이 길 찾기에 유용. P5(CML): 첫 줄 표에 자기 길(15장)이 있어 소외감 덜함.

## 8장 치료 경로 지도 (2026-11-24 · 골든샘플)
- 중대(반영 확인, 혈액종양내과 A): 관해유도 뒤 회복 기간·ALL 유지 기간·관해 판정 아세포 기준 수치(NCCN 환자판 확인분) 본문 0건. 약은 범주 + 대표 예(시타라빈+안트라사이클린 / 저메틸화제+베네토클락스 / 트레티노인 / 비소 화합물 / 이매티닙), 용량·주기·일수 표기 0.
- 중대(반영, 조혈모세포이식): 이식 결정 요인 문장에서 "MRD 양성이면 이식" 식 연결 금지 — "위험군·MRD·나이·몸 상태·기증자를 함께 보고 상의"로 유지, "이식해야 낫는다/위험하니 안 한다" 둘 다 단정 불가 문장 추가.
- 중대(반영, 진단검사의학과): "MRD 음성 = 세포 0개" 오해 방지 문장("그 검사법으로 찾을 수 있는 수준 아래") 배치 — S1 §0-4.
- 경미(확인 필요): 외래 저강도 치료 가능 여부·국내 허가·급여 문장은 방향 문장 → 근거표 확인 필요.
- 환자(P2, 저강도): "약하게가 포기가 아님 + 저강도로도 관해 가능"(NCCN p.35)이 표 안에 있어 안심. P1: "깃발" 비유가 "관해 = 끝" 오해를 바로 막음.
- 심리: 2차 소견 문단의 "기다리는 시간도 치료 계획의 일부"가 겁주지 않으면서 지연 위험을 알림. 편집: 표 3개(세 구간·강도 비교·다른 유형) — 분량 다소 많으나 골든샘플 기준으로 유지.

## 20장 호중구 감소와 발열 38.0°C (2026-11-24 · 골든샘플)
- 심각(반영, 감염내과): "스테로이드 같은 약 때문에 열이 잘 나지 않을 수 있다" — 열람 출처에 없음 → 삭제. "오한은 그 자체로 감염 신호(NCI)" + "처짐·어지러움도 넘기지 말고 연락해 물어보기"로 낮춤.
- 중대(반영 확인, 편집·무균병동 간호사): 응급 신호 상자를 장 맨 위(30초 요약 앞)에 고정, 생활 팁은 그 아래 — S1 §6 순서.
- 중대(반영 확인, 혈액암 전문간호사): NCI·NCCN 화씨 표기 차이를 책에서는 38.0°C 하나로 통일. 해열제 "의료진이 먹으라고 안내했다면 그 안내" 예외 문장 있음.
- 경미(확인 필요): 체온 재는 법·면회·마스크·응급실 첫마디는 생활·시리즈 공통 방향 문장 → 근거표 확인 필요(응급실 문장은 NCCN "응급 시 할 일 미리 묻기"로 방향 교차).
- 환자(P1): 응급실 첫마디 인용 상자가 실제로 쓸모 있음. 보호자(G1): 기록칸 "밤·주말 연락처"가 가장 필요했던 칸.
- 심리: "빨리 알리면 빨리 치료할 수 있습니다"로 공포를 행동으로 바꿈.

## 3장 골수검사 (2026-11-24 · 골든샘플)
- 중대(반영, 진단검사의학과): FISH "빨리 찾아봄"·유세포분석 "비교적 빨리 나옴" — 속도 비교는 열람 출처에 없음 → 삭제, "알려진 변화를 골라 찾아봄(혈액으로도 가능)" + "길러야 하는 검사는 더 걸릴 수 있음"(NCCN pp.16-17)으로 수정. 2장 같은 문장도 함께 수정.
- 중대(반영, 병리·임상 관점): "대부분 백혈병 세포 변화이고 물려받는 유전과 다른 경우가 대부분" — 대부분 단정 근거 미열람 → "백혈병 세포 변화를 보는 검사, 유전 관련 걱정은 따로 묻기"로 낮춤(S1 §0-6).
- 중대(반영, 무균병동 간호사): 국소마취 단정 → NCCN은 "진정 제공 가능"만 → "부위 마취, 필요하면 진정 — 병원마다 다름, 미리 묻기"로.
- 경미(확인 필요): "당기거나 누르는 느낌"·검사 뒤 알릴 신호는 S4 확인. 검사 뒤 통증 기간("며칠")은 "한동안"으로 — 수치 0.
- 환자(P3, 척수액·골수 공포): 단계별 번호 목록과 "아프면 참지 말고 말하세요"가 도움. 편집: 검사 표 5행, 아세포 숫자로 스스로 판단 말기 문장 유지.

## 1장 백혈병은 한 가지가 아니에요 (2026-11-24)
- 중대(반영, 혈액종양내과 B): "백혈병은 옮지 않는다" — 이번 실행 공식 출처에서 문장 확인 실패 → 1장에서 빼고 26장 집필 때 확인(근거표 확인 필요). S1 §6 "26장 첫 줄"은 그때 반영.
- 중대(반영 확인, 병리): 아세포 기준 수치·AML 연령별 통계·ALL B/T 비율·Ph 양성 비율(국가암정보센터·NCCN 확인분) 본문 0건.
- 경미(확인 필요): "이전 항암·방사선 이력은 치료 선택 정보" — NCCN 뒤쪽 미열람 부분일 수 있음 → S4. 탓 금지 방향 문장은 유지.
- 환자(P5, CML)·(P2): 네 이름 표에 CLL "처음엔 추적만 하는 경우가 많음"(국가암정보센터)이 있어 "방치"로 읽히지 않음. P1: "유전자 이름 = 치료 지도의 표지" 문장이 공포를 덜어 줌.
- 국문: 유형 이름 첫 등장 시 한글 + 약어 병기, "급성 림프모구성백혈병"(국가암정보센터 "림프모구") 표기로 통일.

## 2장 진단 뒤 72시간 (2026-11-24)
- 중대(반영 확인, 이식 코디네이터): HLA 검사 문장을 "기증이 맞는지 알아보는 것이지 기증 약속이 아님"으로 — 출처 명시 문장은 미확인 → 근거표 확인 필요, 13장 집필 때 기증자 동의 원칙 출처 확인.
- 중대(반영 확인, 혈액종양내과 A): "며칠 안에 입원" 기간은 수치 없이 방향만, APL "결과 전 치료 먼저"는 NCCN p.47 확인.

- 환자(P3): "묻지 않으면 선택지가 있었는지도 알 수 없습니다"가 약속도 포기도 아닌 균형. 보호자(G1): "교대할 사람 한 명 더"가 실용적.

## 4장 피가 모자라서 생기는 일 (2026-11-24)
- 중대(반영 확인, 감염내과): "몇 이하면 위험" 수치 0, "결과지·의료진 설명 기준". "백혈구 전체가 높아도 감염 방어 아님"은 NCCN 기전에서 추론 → 교차확인 표시, S4 확인.
