## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면(그림) / 대사(25자 이내, 조판 텍스트) / 의학 해설 한 줄. 오른쪽 핵심 설명 쪽(한 문장·3가지·오해/안전·질문 2)은 S2 원고에서 작성.

### EP01 조기위암? 진행위암? 먼저 구분하기
1. 진료실, 정훈이 결과지를 들고 굳은 얼굴, 미숙이 손을 잡음 / 정훈 "위암이라니…" / 진단 직후 멍함은 흔한 반응.
2. 주치의가 모니터의 위벽 층 단면 삽화(점막·근육층·장막, 수채 반실사)를 가리킴 / 주치의 "깊이부터 봅니다" / 침윤 깊이가 치료 길을 나눔.
3. 위벽 단면 확대 삽화 두 개 나란히: 얕은 병변 vs 근육층까지 들어간 병변 / (대사 없음) / 점막·점막하까지 = 조기위암.
4. 미숙이 수첩에 질문을 적고 정훈이 고개를 끄덕임 / 미숙 "검사 결과 나오면 다시 물어요" / 최종 판단은 검사 후 의료진과.

### EP02 진단 뒤 72시간, 세 가지만
1. 부엌 식탁, 밤. 정훈과 미숙이 휴대폰과 서류 더미 앞에서 막막 / 미숙 "뭐부터 하지?" / 첫 사흘은 세 가지만.
2. 미숙이 병원 원무과 창구에서 결과지 사본을 받음 / 미숙 "결과지 두 부요" / 서류는 처음부터 두 부씩.
3. 정훈이 약 봉투들을 식탁에 펼쳐 목록을 적음 / 정훈 "혈압약, 아스피린…" / 혈액 묽게 하는 약은 꼭 알리기.
4. 미숙이 달력에 진료 예약일을 동그라미 / 미숙 "산정특례도 물어보자" / 확진 후 30일 안 신청(원무과 확인).

### EP03 조직검사 결과지, 무엇부터 볼까
1. 진료실, 주치의가 병리보고서를 환자 쪽으로 돌려 보여 줌 / 정훈 "영어가 너무 많아요" / 단어 몇 개만 알면 됨.
2. 현미경 시야풍 수채 삽화: 정돈된 샘 구조 세포 / (대사 없음) / 분화형: 정상 구조를 닮은 세포.
3. 같은 시야풍, 흩어진 세포와 반지 모양 세포 / (대사 없음) / 미분화형·반지세포: 내시경 기준이 엄격.
4. 미숙이 결과지 위에 형광펜으로 표시 / 미숙 "분화도, 깊이, 크기" / 모르면 "쉽게 다시"라고 묻기.

### EP04 병기 검사는 왜 여러 개일까
1. CT실 앞 대기석, 정훈이 검사 안내문을 읽음 / 정훈 "또 검사야?" / 검사마다 보는 곳이 다름.
2. CT 장비 안으로 누워 들어가는 정훈(옷 입은 채, 가운) / (대사 없음) / CT: 림프절·간·복막 확인.
3. 내시경 초음파 검사 후 회복실, 간호사가 상태 확인 / 간호사 "깊이를 더 자세히 봤어요" / 내시경 초음파: 침윤 깊이.
4. 진료실, 주치의가 검사 일정표를 건넴 / 주치의 "결과 설명 날도 잡아요" / 결과 듣는 날을 미리 예약.

### EP05 헬리코박터, 내 탓이 아니에요
1. 거실, 정훈이 자책하는 표정, 미숙이 어깨에 손 / 정훈 "내가 술을 많이 먹어서…" / 암은 한 가지 원인으로 생기지 않음.
2. 진료실, 주치의가 위 점막에 사는 세균을 표현한 부드러운 의학삽화 태블릿 / 주치의 "흔한 감염이에요" / 헬리코박터는 위암 위험 요인 중 하나.
3. 식탁, 정훈이 처방 약 봉투를 요일별 약통에 정리 / 미숙 "빠뜨리지 말자" / 제균 약은 정해진 기간 빠짐없이.
4. 성인 자녀 두 명과 영상통화하는 부부 / 미숙 "너희도 검진 상의해 봐" / 가족 검사·검진은 의료진과 상의.

### EP06 내시경으로 떼는 치료(ESD)
1. 진료실, 주치의가 위벽 단면 삽화에서 얕은 병변을 가리킴 / 주치의 "위를 지키는 방법이 있어요" / 기준 안 조기위암은 ESD 가능.
2. 내시경실 모니터 클로즈업(추상적 분홍 점막, 피 없음) / (대사 없음) / 병변을 점막 아래층에서 통째로 박리.
3. 병실 침대, 정훈이 금식 안내 카드를 보며 물 한 컵을 바라봄 / 간호사 "내일부터 물이요" / 시술 후 금식→물→미음 순서.
4. 퇴원 날, 미숙이 응급 연락처 카드를 지갑에 넣음 / 미숙 "검은 변이면 바로 전화" / 지연 출혈은 2주 안에도 가능.

### EP07 위를 얼마나 떼나요?
1. 진료실, 정훈이 주치의에게 위 그림을 보여 달라고 손짓 / 정훈 "위가 없어지면요?" / 수술 범위는 위치·병기로 결정.
2. 위 모형 의학삽화: 아래쪽 2/3 절제 부위 연한 색 표시 / (대사 없음) / 원위부(아전) 위절제.
3. 위 전체 절제 후 식도-소장 연결 의학삽화 / (대사 없음) / 위 전절제: 식도와 소장을 이어 줌.
