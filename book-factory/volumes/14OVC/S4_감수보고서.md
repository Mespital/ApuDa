## 팀별 의견 요약
### 전문의 다학제
- **중대(반영)** 책 앞에 응급 신호가 없음 — S1 §1 「바로 시작」 0-1~0-4가 원고에 없고, 1장 응급 상자는 존재하지 않는 "책 앞 「기다리지 않는 신호」 쪽"을 가리킴 → 0-1~0-4 신설(S1 0-1 문구 기반, 38.0°C, 30장 응급 카드와 같은 항목), 1장 참조를 0-1로 연결.
- **중대(반영)** 7장 린치증후군 "난소암·자궁내막암·대장암" — 근거표 부분 「확인 필요」(자궁내막암 명시)가 단정으로 남음 → NCCN 환자판 p.15 확인 범위("대장암으로 잘 알려져 있지만 난소암을 비롯한 다른 여러 암")로 줄임.
- **중대(반영)** 확인 필요가 단정으로 남은 문장 묶음: 1장 투명세포 이름 풀이("세포 안이 맑게") → 삭제 · 9장 "일찍 걷기는 회복과 혈전 예방에 도움" → ACS 확인 범위("오래 누워만 있으면 혈전 위험")로 · 10장 "수술 전 걷기 연습이 도움" → 효능 주장 삭제 · 23장 30초 요약·EP18 "조직형에 따라 달라" → "달라질 수 있어".
- 경미(유지) 15장 HIPEC·13장 유지치료 범주 표현은 출처와 일치. NCCN 환자판 **2026판**이 발간됐다는 소식(OCRA 2026-10-27)이 있으나 이번에 내려온 PDF는 2022판 → S4 만화 반영 재감수 때 2026판으로 유지치료·검사 세부 재대조.
- 경미(유지) 6장 FIGO 표·1장 조직형 표는 지침 표 복제 아님(자기 문장) 재확인. 방사선치료 언급 최소 — 이 권 범위(첫 진단·상피성)에 맞음.
- 경미(유지) 28장 C48·D39.1 코드는 본문에 숫자 없이 "다른 코드로 적힐 수 있음"만 — 국내 KCD 대조 전까지 그대로.

### 설명간호사
- **중대(반영)** 27장 "산정특례는 **등록한 날부터** 적용" — 이번에 연 국내 공식 서식(의료급여 (암) 산정특례 등록 신청서, 2025-07-01 개정)에는 진단확진일 기준 소급 규정이 있어 v0.5 문장과 어긋남. 이 문장을 그대로 두면 독자가 신청을 늦춰도 된다고 읽거나, 반대로 이미 늦었다고 오해할 수 있음 → "신청 시기에 따라 적용 시작일이 달라질 수 있으니 진단 뒤 미루지 말고 등록 + 원무과 확인"으로 고치고 질문 칸에 "진단일부터인가요, 신청일부터인가요?" 추가. 건강보험 원문 대조는 「확인 필요」.
- 경미(반영) 0-1에 "응급실에서는 항암 치료 중이라고 먼저 말하기"를 20·22장과 같은 문구로 넣음(행동 안내, 근거표 확인 필요 유지).
- 경미(유지) 0-1 주사 중 반응 신호는 12장 확인 목록(가려움·두드러기·숨참·기침·가슴 답답함)만 — S1의 "얼굴 붓기"는 출처 미확인이라 뺌(EP07 대사 수정 제안으로 이월).
- 경미(유지) 22장 장폐색 응급 상자 맨 위·식사 팁 아래 순서, 장루 막힘 신호 — 그대로 따라 해도 안전.

### 환자 감수단
- P1: 0-2 "세 가지" 표가 2장·EP02와 같아 첫날 펼치기 좋음. 24장 CA-125 문단으로 숫자 불안 덜어짐. 문제 없음.
- P2: 11장·EP17 "항암 먼저 = 포기 아님"이 반복돼 안심. 경미(반영) 0-3 내 길 찾기에 "항암을 먼저 할게요" 줄이 있어 찾기 쉬움.
- P3: 7·26장 "알릴지는 내가 정함"이 상자 첫 줄에 있음. 경미(반영) 7장 "자녀가 성인이 된 뒤"와 26장 "성숙한 뒤"가 달라 헷갈림 → 7장을 "성인이 되어 스스로 결정할 수 있을 때"로 맞춤.
- P4: 첫 진단 권이라 재발 독자가 소외될 수 있음 → 경미(반영) 0-3에 "치료를 마친 뒤 다시 의심된다는 말 → 24장 · ㉗ 재발편" 줄 추가.
- P5: 14장·EP16 "약속이 아니라 상의의 출발점" 좋음. 문제 없음.
- G1: 18장 역할 나누기·20장 응급 전화 장면 실용적. 문제 없음.
