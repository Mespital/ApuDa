- 범위: **성인 상피성 난소암 첫 진단**(난관암·원발성 복막암 포함 — 같은 방식으로 치료하는 경우가 많아 한 권에서 다룸). 경계성 난소종양·생식세포종양·성삭기질종양은 15장 안내 상자에서 "치료 경로가 달라 별도 상담"으로만. 재발 난소암은 24장 끝 안내 + ㉗ REC권으로 연결.
- 톤: 난소암은 **"한 이름, 여러 얼굴"**의 병이다 — 조직형·병기·유전자 결과(BRCA·HRD)에 따라 순서와 약이 달라진다. 책 전체의 축은 두 가지: ① **"수술 먼저냐, 항암 먼저냐"는 우열이 아니라 순서의 선택**(어느 쪽이든 목표는 눈에 보이는 암을 남기지 않는 것), ② **유전자 검사는 나의 치료와 가족의 건강을 함께 여는 문**(그러나 가족에게 알릴지·언제 알릴지는 환자가 정한다). 배가 불러오고 먹지 못하는 몸의 불편을 생활 장면으로 덜어 준다. CA-125 숫자 하나에 하루가 흔들리지 않게 반복한다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 항암 중 발열·수술 뒤 발열·포트 부위 발열 모두 38.0°C. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리.
2. **수치 쓰지 않기.** 생존율·재발률, BRCA 보유자의 평생 위험 %, CA-125 정상 범위·"몇 배 상승", 항암 "6회"·"3주마다", 유지치료 "2~3년", 수술 시간·입원 일수 같은 수·기간은 본문에 넣지 않는다. 필요하면 "병원 일정표·결과지 기준"으로. FIGO 병기 Ⅰ~Ⅳ의 정의(퍼진 범위)만 출처 달고 유지.
3. **약은 "범주 + 대표 예"로만.** 백금계 항암제(카보플라틴 대표 예)+탁산 계열(파클리탁셀 대표 예), 혈관생성억제제(베바시주맙 대표 예), PARP 억제제(범주명 위주), 항체약물접합체(ADC, 엽산수용체 표적 등은 범주만) → 용량·주기 미기재, 모두 "국내 허가·급여 변경 가능 + 의료진 확인". BRCA·HRD별 유지치료 급여 조건은 S4 재확인.
4. **유전 문장은 신중히.** "BRCA 변이가 있으면 반드시 가족도 암에 걸린다" 금지 → "위험이 높아질 수 있어 유전상담에서 가족 검사 여부를 함께 정함". VUS(의미 불명 변이)는 "변이가 있다는 뜻이 아님, 결정에 쓰지 않음"으로. 자녀 검사 시기는 "성인이 된 뒤 본인 결정이 원칙 — 유전상담 확인". 예방적 수술 권고는 이 책에서 하지 않음(유전상담으로 연결).
5. **원인 단정·탓 금지.** 출산·수유·피임약·체중과의 관련을 원인처럼 쓰지 않는다. "왜 늦게 발견했나" 자책을 덜어 주는 문장(초기 증상이 흔한 소화 불편과 비슷함)은 넣되 "검진으로 조기 발견된다"는 효능 주장은 금지(일반인 CA-125·초음파 선별검사의 한계는 출처 달고 개념만).
6. **생식력 보존은 "일부 경우" 명시.** 조직형·병기·나이에 따라 가능 여부가 갈림 — "가능하다"를 약속처럼 쓰지 않음. 난자·배아 동결은 "치료 시작 전 생식의학 상담" 수준.
7. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN Ovarian Cancer, ESMO-ESGO, 대한부인종양학회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
8. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~13·26권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(배가 심하게 불러오고 토하며 방귀·변이 안 나옴 = 장폐색 의심 → 응급실, 숨이 차서 눕기 어려움(복수·흉수), 항암 중 38.0°C 발열·오한 = 해열제보다 먼저 연락, 한쪽 다리가 갑자기 붓고 아픔·갑자기 숨참·가슴 통증 = 혈전 가능, 수술 뒤 상처가 벌어지거나 고름·38.0°C 발열, 항암제 맞는 중 가려움·숨참·얼굴 붓기 = 바로 간호사 호출, 스스로를 해치고 싶은 생각 → 109·119) · 0-2 오늘 확인할 세 가지(조직 확인이 됐는지·조직형 / 수술 먼저인지 항암 먼저인지 / 유전상담·BRCA 검사 일정) · 0-3 책 사용법(내 길 찾기: 수술 먼저 → PART 2 앞쪽, 항암 먼저 → 11장, 젊은 환자·임신 계획 → 14장, 드문 조직형 → 15장) · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 난소암은 한 가지가 아니에요: 상피성(고등급 장액성이 가장 흔함 · 저등급 장액성 · 투명세포 · 자궁내막양 · 점액성) · 난관암·원발성 복막암 → **EP01**
2. 진단 뒤 72시간(조직 확인 · 다음 일정 · 유전상담 예약 · 가족에게 알리기) → **EP02**
3. 진단까지의 검사: CA-125(혼자서는 결정하지 않음) · 초음파 · CT · 필요할 때 MRI·PET-CT · 조직 확인(수술 또는 바늘 조직검사·복수 세포검사) → **EP03**
4. 배가 불러오는 이유: 복수·흉수, 조금만 먹어도 배부름 · 복수천자의 역할 → **EP04**
5. 병리보고서 읽기: 조직형·등급 · 면역염색(WT1·PAX8·p53 등은 "조직형 확인용") · 절제연·잔존종양 표기 → 심화 **EP11**
6. 수술로 정하는 병기(FIGO Ⅰ~Ⅳ) — 영상만으로 확정하지 않는 이유 · 복강 세척액 → 심화 **EP12**
7. 유전자 검사 두 가지: 혈액(생식세포) BRCA · 종양 BRCA·HRD · MMR·린치증후군 · VUS의 뜻 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 수술 먼저(일차 종양감축술 → 항암 → 유지) / 항암 먼저(선행항암 → 중간 종양감축술 → 항암 → 유지) / 조기·일부 조직형 → **EP05**
9. 종양감축술: 목표는 "눈에 보이는 암을 남기지 않기" · 그물막·복막·장 일부를 함께 떼기도 함 · 장루 가능성 미리 듣기 → **EP06**
10. 수술 전 준비: 영양·근력·혈전 예방·장 준비(병원 지시대로) · 수술 전 재활 → 심화 **EP14**
11. 항암을 먼저 하는 경우: 복막에 넓게 퍼졌거나 몸 상태를 먼저 회복해야 할 때 · 중간 수술의 의미 · 고령 환자의 치료 강도 → 심화 **EP17**
12. 첫 항암: 백금계 + 탁산(대표 예) · 주사실 하루 · 과민반응 신호 · 일정 조정은 실패가 아님 → **EP07**
13. 유지치료: PARP 억제제·베바시주맙(범주) · BRCA·HRD 결과에 따라 · 관찰도 선택지 · 먹는 약 잊었을 때(두 배 금지, 병원 안내) → 심화 **EP15**
14. 생식력을 남기는 수술: 조기·일부 조직형·젊은 환자에서 상의 · 난자·배아 동결 상담 · 치료 전 먼저 말하기 → 심화 **EP16**
15. 드문 조직형·경계성 종양·생식세포종양 안내 · HIPEC(복강 내 온열항암)은 일부 경우 · 2차 소견(슬라이드 재판독) · 임상시험
16. 치료가 어려울 때: 완화의료 병행 · 복수·장폐색 증상 조절 · 치료 목표 다시 묻기

### PART 3. 30일 실행 로드맵
17. Day 0–7 확인하고 검사받기(조직형 · 영상 · 혈액 · 유전상담 예약 · 치과·포트 상의)
18. Day 8–21 결정하고 준비하기(수술 또는 선행항암 일정 · 영양·근력 · 생식력 상담 · 직장·가족 역할 정리)
19. Day 22–30 시작하기 · 첫 항암 또는 수술 후 회복 · 30일 체크표

### PART 4. 치료 중·후의 몸과 마음
20. 항암 중 자기 관리 · 발열 38.0°C · 백혈구·호중구 검사를 반복하는 이유 · 포트 관리 · 공통 증상표 → **EP08**
21. 탈모·손발 저림·피로 · 구역(약은 처방대로) · 빈혈 · 운동은 상의 후 가능한 만큼 → **EP09**
22. 장 증상 지키기: 배부름·변비·구토 · 장폐색 신호 · 조금씩 자주 먹기 · 장루가 생겼다면 → **EP10**
23. 수술 뒤 갑자기 찾아온 폐경: 열감·잠·질 건조·뼈 건강 · 호르몬 치료 상의(조직형에 따라 다름) → 심화 **EP18**
24. 추적: 증상이 가장 중요한 신호 · CA-125만 올랐을 때 · CT를 매번 찍지 않는 이유 · 재발이 의심될 때(→ ㉗ REC권) → 심화 **EP19**
25. 마음 돌보기 · 몸의 변화와 친밀감(성교통·질 건조 상담 가능) · 보호자에게 · 아이에게 말하기
26. 가족에게 유전 결과 알리기: 누구에게·언제·어떻게(환자가 정함) · 형제자매·자녀 검사는 유전상담에서 → 심화 **EP20**

### EP10 배가 막힌 신호

2. 장이 꼬불꼬불 이어진 길에서 한곳이 좁아진 개념 삽화(색만) / (대사 없음) / 복막의 암이나 수술 뒤 유착으로 장이 막힐 수 있음.
3. 동욱이 물컵을 내려놓고 휴대폰으로 병원에 전화 / 동욱 "기다리지 말고 가자" / 장폐색이 의심되면 먹지 말고 바로 응급실.
4. 영양 상담실, 영양사가 작은 접시 여러 개 그림 카드(글자 없음)를 보여 줌 / 영양사 "조금씩, 자주, 천천히" / 평소엔 부드러운 음식을 조금씩 자주.

### EP11 (심화) 결과지의 첫 줄, 고등급 장액성
1. 진료실, 미란이 병리보고서 첫 줄을 손가락으로 짚음(글자 흐림) / 미란 "고등급이면 더 나쁜 거예요?" / 등급은 세포 모양에 따른 분류, 치료 선택에 쓰임.
2. 현미경 시야처럼 둥근 틀 안에 두 종류 세포 무늬를 색으로만 구분한 그림 / (대사 없음) / 고등급·저등급 장액성은 성장 속도와 쓰는 약이 다를 수 있음.
3. 주치의가 보고서 아래쪽 염색 결과 칸을 가리킴 / 주치의 "조직형 확인용 표시예요" / WT1·PAX8·p53 같은 염색은 조직형을 확인하는 단서.
4. 예린이 수첩의 병리 칸을 채움 / 예린 "모르는 단어는 물음표" / 결과지 단어는 ❔ 표시 후 다음 진료에 묻기.

### EP12 (심화) 병기는 수술이 알려 줘요
1. 진료실, 동욱이 CT 사진 봉투를 들고 / 동욱 "사진 보면 병기 나오잖아요" / 난소암 병기는 수술 소견과 조직으로 최종 결정.
2. 배 안을 층층이 나눈 부드러운 의학삽화에 퍼진 범위를 색 농담으로만(글자 없음) / (대사 없음) / 골반 안·배 안·배 밖으로 퍼진 범위가 병기를 나눔.
3. 주치의가 수술 기록지 그림(글자 없음)을 덮어 둠 / 주치의 "수술 뒤에 확정해요" / 복강 세척액·떼어 낸 조직 결과가 함께 쓰임.
4. 미란이 한 장 요약의 병기 칸을 비워 둔 채 연필을 꽂음 / 미란 "빈칸으로 둘게요" / 확정 전 병기는 빈칸 — 추측으로 채우지 않기.

### EP13 (심화) 내 피 검사, 내 종양 검사
1. 유전상담실, 유전상담 간호사가 미란과 예린에게 그림 카드 두 장(피 한 방울·조직 조각, 글자 없음) / 간호사 "검사가 두 가지예요" / 혈액 BRCA는 타고난 변이, 종양 검사는 암세포의 변화.
2. 이중나선 그림 두 개 중 하나에만 작은 빛(색만) / (대사 없음) / 종양 BRCA·HRD 결과는 유지치료 선택에 쓰일 수 있음.
3. 예린이 긴장한 얼굴로 묻고 간호사가 고개를 끄덕임 / 예린 "저도 검사해야 해요?" / 가족 검사 여부는 환자 결과를 보고 유전상담에서 정함.
4. 미란이 결과 대기 칸에 시계 기호를 그림 / 미란 "결과 나오면 같이 듣자" / 결과에 "의미 불명 변이(VUS)"가 있어도 변이 확정이 아님.

### EP14 (심화) 수술 날까지, 몸 만들기
1. 아파트 복도, 미란이 동욱과 함께 천천히 걷기 연습 / 동욱 "오늘도 한 바퀴 더" / 수술 전 걷기·근력 운동은 회복 준비(강도는 상의).
2. 영양 상담실, 영양사가 단백질 음식 그림 카드(달걀·두부·생선, 글자 없음) / 영양사 "단백질을 먼저 드세요" / 수술 전 영양 상태가 회복에 영향을 줌.
3. 약사가 미란의 약 봉투들을 펼쳐 봄 / 약사 "건강식품도 다 가져오세요" / 복용 중인 약·영양제는 수술 전 모두 알리기(중단은 지시대로).
4. 거실, 미란이 입원 가방에 수면양말·책·메모장을 넣음 / 미란 "장 준비는 안내문대로" / 장 준비·금식은 병원 안내문 그대로.

### EP15 (심화) 유지치료는 맞춤옷이에요
1. 진료실, 미란이 항암 마지막 날 사진(꽃다발)을 휴대폰으로 보여 줌 / 미란 "이제 끝인가요?" / 첫 항암 뒤 재발을 늦추는 유지치료를 상의할 수 있음.
2. 옷걸이에 모양이 다른 옷 세 벌(색만, 글자 없음) / (대사 없음) / BRCA·HRD 결과, 몸 상태에 따라 유지치료 종류가 달라짐.
3. 약국 상담대, 약사가 알약 보관함 그림(글자 없음)을 짚음 / 약사 "잊은 날은 두 배 금지" / 먹는 유지치료제를 잊으면 병원 안내를 따르고 두 배로 먹지 않기.
4. 외래 채혈실 앞, 미란이 팔을 누르며 웃음 / 미란 "피검사는 계속 하는구나" / 유지치료 중엔 혈액 수치를 정기적으로 확인.

### EP16 (심화) 아기 계획, 먼저 말해요
1. 진료실, 다솜이 남자친구(뒷모습)와 앉아 손을 맞잡음 / 다솜 "아기는 못 갖는 건가요?" / 조기·일부 조직형에서는 생식력을 남기는 수술을 상의할 수 있음.
2. 자궁과 한쪽 난소를 남긴 모습을 부드럽게 그린 의학삽화(색만) / (대사 없음) / 남길 수 있는지는 조직형·병기·나이로 판단.
3. 생식의학 진료실, 생식의학 전문의가 시간표 그림(숫자 없음)을 짚음 / 의사 "치료 전에 먼저 상담해요" / 난자·배아 동결 상담은 치료 시작 전에.
4. 다솜이 수첩에 질문을 적음 / 다솜 "추적은 어떻게 해요?" / 생식력 보존 뒤 추적 계획과 이후 수술 여부를 함께 묻기.

### EP17 (심화) 항암을 먼저 하는 이유
1. 진료실, 금자가 아들(측면)과 앉아 손수건을 쥠 / 금자 "수술을 안 해 준대요?" / 항암을 먼저 하는 것은 수술을 포기한다는 뜻이 아님.
2. 배 안의 넓게 퍼진 작은 점들이 줄어드는 전후 그림(색만) / (대사 없음) / 넓게 퍼졌을 때 항암으로 먼저 줄인 뒤 중간 수술을 하기도 함.
3. 주치의가 금자의 손을 잡고 설명 / 주치의 "몸 힘부터 길러요" / 나이·체력·동반 질환에 맞춰 순서와 강도를 정함.
4. 떡집 앞 평상, 금자가 아들과 달력에 중간 평가 칸을 표시(숫자 없음) / 금자 "몇 번 하고 다시 보재" / 항암 중간에 영상으로 수술 시점을 다시 정함.

### EP18 (심화) 갑자기 찾아온 폐경
1. 밤, 미란이 이불을 걷어 내고 부채질 / 미란 "갑자기 확 더워져" / 양쪽 난소를 떼면 수술 뒤 바로 폐경 증상이 올 수 있음.
2. 몸속 호르몬 물결이 갑자기 잔잔해지는 개념 그림(색만) / (대사 없음) / 열감·잠·질 건조·뼈 건강 변화가 함께 올 수 있음.
3. 진료실, 미란이 질문 메모를 내밂 / 미란 "호르몬 약 먹어도 돼요?" / 호르몬 치료 가능 여부는 조직형에 따라 달라 담당의와 상의.
4. 저녁, 미란이 걷기 운동화를 현관에 가지런히 둠 / 동욱 "뼈 검사도 물어보자" / 조기 폐경 뒤 뼈 건강 검사·관리 상의.

### EP19 (심화) 수치보다 내 몸의 말
1. 외래 대기실, 미란이 CA-125 결과지를 보고 불안한 얼굴(숫자 흐림) / 미란 "조금 올랐대요" / CA-125만 오른 경우 바로 치료를 시작하지 않을 수도 있음.
2. 나침반 그림: 바늘이 "몸의 증상" 쪽을 가리킴(글자 없음, 기호만) / (대사 없음) / 추적에서 가장 중요한 신호는 새로 생긴 증상.
3. 주치의가 증상 일지를 넘겨 봄 / 주치의 "배·식사·변을 같이 봐요" / 복부 팽만·식사량 감소·배변 변화는 미루지 말고 알리기.
4. 미란이 다음 예약 칸에 표시하고 책을 펼침 / 미란 "오늘은 책 읽을래" / 결과 기다리는 불안은 상담·기록으로 나누기.

### EP20 (심화) 딸에게 어떻게 말할까
1. 거실, 미란이 유전 결과지 봉투를 무릎에 놓고 창밖을 봄 / 미란 "예린이한테 뭐라 하지" / 유전 결과를 가족에게 알릴지·언제 알릴지는 환자가 정함.
2. 가족 나무 그림에 몇몇 잎에만 부드러운 빛(색만, 글자 없음) / (대사 없음) / 생식세포 BRCA 변이는 가족도 가지고 있을 수 있음.
3. 카페, 미란과 예린이 마주 앉고 언니 미정(측면)이 곁에 / 예린 "같이 상담받을래" / 형제자매·자녀 검사는 유전상담에서 시기와 방법을 정함.
4. 미란이 가족 상담 메모 칸에 이름 대신 하트 기호를 그림 / 미정 "알려 줘서 고마워" / 가족에게 알리는 편지·자료는 유전상담 간호사에게 도움받기.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 수술 먼저·항암 먼저) · 7장(유전자 검사 두 가지) · 22장(장 증상 지키기)**.
- 기존 원고 v0.2.1이 나오면 문장 우선 재사용, 없으면 `ovarian.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~8을 골든샘플부터 적용.
- FIGO 병기 표·조직형 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에. 생존율·재발률 수치는 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 드문 조직형·경계성·생식세포종양 독자는 15장 안내 + 별도 상담, 재발 독자는 24장 끝 + ㉗ REC권으로 연결.
- 주인공 미란은 수술 먼저·고등급 장액성·생식세포 BRCA 확인 경로. 항암 먼저·고령은 금자, 생식력 보존은 다솜 — 본문 사례도 같은 분담.
- 유전 장(7·26장)은 유전상담 간호사 관점 문장 + "가족에게 알리는 말" 예시 상자(가상) 1개. 알릴지 말지는 환자 결정이라는 문장을 상자 첫 줄에.
- 장 증상 장(22장)은 장폐색 응급 신호를 상자 맨 위에, 식사 팁은 그 아래(순서 고정).
