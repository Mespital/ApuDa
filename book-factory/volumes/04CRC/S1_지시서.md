### PART 1. 진단 첫 주 — 정확히 알기
1. 먼저 구분하세요: 결장암과 직장암 → **EP01**

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄. 오른쪽 핵심 설명 쪽은 S2 원고에서 작성.

### EP01 결장일까, 직장일까
1. 진료실, 은정이 결과지를 들고 당황, 성호가 옆에 / 은정 "대장암이요?" / 진단 직후 멍함은 흔한 반응.
2. 주치의가 대장 전체 의학삽화(결장·직장 색 구분)를 가리킴 / 주치의 "위치가 중요해요" / 결장과 직장은 치료 순서가 다름.
3. 직장 부위 확대 삽화, 항문에서 거리를 점선으로만 표시(숫자 없음) / (대사 없음) / 직장암은 MRI로 최종 구분.
4. 성호가 휴대폰에 질문을 정리 / 성호 "MMR 검사도 물어보자" / MMR은 모든 대장암에 권고.

### EP02 진단 뒤 72시간, 세 가지만
1. 밤 식탁, 은정이 노트북 앞에서 검색하다 멈춤 / 은정 "검색은 그만" / 밤 검색은 불안을 키움.
2. 원무과 창구, 성호가 결과지와 내시경 소견 사본을 받음 / 성호 "두 부씩이요" / 서류는 처음부터 두 부씩.
3. 은정이 진료 예약 전화를 함 / 은정 "대장항문외과요" / 진료팀 예약이 첫 단추.
4. 은정이 메모지에 '아이 계획?'을 적어 냉장고에 붙임 / 은정 "첫 진료 때 말하자" / 가임력 상담은 치료 전에.

### EP03 용종 안의 암, 끝일까 시작일까
1. 진료실, 주치의가 내시경 사진(추상적 점막·용종) 모니터를 보여 줌 / 주치의 "용종 안에 암이 있었어요" / 악성 용종은 병리로 다음 결정.
2. 용종 단면 의학삽화: 얕게 머문 경우 / (대사 없음) / 기준 안이면 내시경 절제로 끝날 수 있음.
3. 용종 단면 의학삽화: 줄기 쪽으로 깊이 들어간 경우 / (대사 없음) / 깊이·절제면·림프관 침범 시 추가 수술 상의.
4. 성호가 질문지를 읽음 / 성호 "추가 수술 기준이 뭐예요?" / 내 결과의 항목별 설명 요청.

### EP04 CT·MRI·CEA, 각자 보는 것
1. 검사 대기실, 은정이 일정표 세 장을 들고 / 은정 "검사가 세 개나" / 검사마다 보는 곳이 다름.
2. CT실, 은정이 가운 입고 장비 안으로 / (대사 없음) / CT: 간·폐·림프절 확인.
3. MRI 장비 앞, 간호사가 귀마개를 건넴 / 간호사 "소리가 커요" / 직장암은 골반 MRI로 주변 경계 확인.
4. 채혈실, 은정이 팔을 내밈 / 은정 "CEA는 뭐예요?" / CEA는 진단보다 추적용 표지자.

### EP05 MMR 검사, 치료 전에 꼭
1. 진료실, 종양내과 의사가 결과 화면을 띄움 / 의사 "치료 순서가 바뀔 수 있어요" / MMR 결과는 치료 시작 전 확인.
2. 세포 핵 안 DNA 수선을 '실 꿰매기'처럼 표현한 의학삽화(글자 없음) / (대사 없음) / MMR = DNA 수선 단백질.
3. 꿰매는 실이 빠진 모습의 대비 삽화 / (대사 없음) / dMMR이면 면역치료 반응이 다를 수 있음.
4. 은정이 가족력 메모를 적음, 성호가 옆에서 / 은정 "엄마도 자궁 쪽 수술을…" / 가족력은 유전상담 판단에 쓰임.

### EP06 결장암 수술 이해하기
1. 진료실, 주치의가 결장 의학삽화에서 절제 범위를 연한 색으로 표시 / 주치의 "림프절과 함께 떼요" / 해당 결장+림프절 절제가 기본.
2. 복강경 포트 위치를 몸통 그림(옷 입은 실루엣)으로 설명 / (대사 없음) / 복강경·로봇은 병원·병기에 따라.
3. 병실, 수술 다음 날 은정이 링거대를 잡고 복도 걷기 / 간호사 "천천히 한 바퀴" / 조기 보행이 회복을 도움.
4. 진료실, 수술 후 병리 결과지를 함께 봄 / 성호 "림프절이 몇 개였죠?" / 검사한 림프절 수와 전이 수 확인.

### EP07 직장암은 수술 전 치료부터
1. 진료실, 주치의가 순서도 종이(그림만)를 보여 줌 / 주치의 "수술 전에 줄여요" / 국소진행 직장암은 수술 전 치료가 흔함.
2. 방사선 치료실 앞, 은정이 혼자 들어가며 손 흔듦(보호자는 밖에서 대기) / (대사 없음) / 방사선은 단기·장기 방식이 있음.
3. 항암주사실, 은정이 수액 맞으며 책 읽음 / (대사 없음) / TNT: 항암과 방사선을 모두 수술 전에.
4. MRI 결과 상담, 주치의가 치료 전후 비교 화면 / 은정 "줄었어요?" / 반응에 따라 다음 단계를 정함.

### EP08 퇴원 첫 주, 탈수와 발열
1. 집 거실, 은정이 물병과 이온음료를 옆에 둠 / 성호 "물 자주 마셔" / 회장루는 수분 손실이 큼.
2. 은정이 소변 횟수·배출량을 기록지에 체크 / 은정 "소변이 줄었어" / 소변 감소·어지럼은 탈수 신호.
3. 밤, 체온계를 보고 성호가 병원에 전화 / 성호 "38.0도에 배가 아파요" / 38.0°C 이상+복통은 바로 연락.
4. 은정이 다리를 보며 걱정, 성호가 메모 / 은정 "한쪽 다리가 부었어" / 한쪽 다리 부종·숨참은 혈전 신호.

### EP09 장루와 친해지기

3. 은정이 산책로를 걷고 친구와 카페 테라스에서 대화 / (대사 없음) / 외출·여행·운동이 가능함.

### EP10 가족에게 유전 결과 알리기

### EP11 (심화) MRI 판독지의 세 단어

### EP12 (심화) RAS·BRAF·HER2, 전이성의 지도

### EP14 (심화) 수술 없이 지켜보는 길
