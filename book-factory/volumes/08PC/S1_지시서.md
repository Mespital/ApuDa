**기존 원고에서 고칠 것(S2·S4)**
1. **발열 표기 38.0°C 통일.** 완전판 응급 상자 "열(38°C 이상)·오한 + 황달(담관염)", "수술 후 38°C 이상 발열", "항암 중 38°C 이상 발열", 증상표 끝 "항암 중 38°C 이상(병원 기준에 따라 37.8°C 이상 1시간 지속 등)" → 모두 **38.0°C**. 37.8°C 병기는 삭제하고 "병원 안내 기준이 다르면 병원 기준을 따르세요"로 대체. 담관염·스텐트 막힘 발열도 같은 기준. 만화 참고 원고의 "38도 이상의 발열"(체크리스트 여러 곳), FAQ 데이터 80번 "38도 이상 발열"도 책에 옮길 때 38.0°C로.
2. **출처 없는 수치 문장 → 처리 방침.**
   - "인구의 약 5~10%인 루이스 음성 체질은 암이 있어도 잘 오르지 않음"(CA19-9) → 출처 연결, 없으면 "일부 사람은 체질상 CA19-9가 잘 오르지 않음"으로 수치 삭제.
   - "보조항암(약 6개월 범주)", "보조항암 시작(회복이 빠르면 보통 수술 후 3개월 안 목표)" → 항암 기간·시점은 "담당 의료진이 정하는 일정"으로, 수치 삭제 또는 "일반적 예시"로 표시하고 근거 쪽 출처 연결.
   - "합병증은 10명 중 4명 정도", "췌장액 누출은 … 대개 2~3주 안에 아물고", "위가 늦게 비는 증상도 보통 1~2주 안에 나아집니다" → 출처 연결 필수. 없으면 "합병증이 드물지 않으며 대부분 병원에서 관리합니다"로 수치 삭제.
   - "수술 후 2년까지는 보통 3~6개월마다, 그 뒤에는 6~12개월마다 CT… 재발이 첫 2년 안에 많아" → "일반적 예시"로 표시 + 출처, 간격은 "병원 추적 일정표"가 우선.
   - "2주 주기 다제병용 항암 달력(일반적 예시)"의 "7~10일 백혈구 최저" → 투여 간격·주기 표기 삭제, "주기 중간에 면역이 가장 떨어지는 시기가 있다(병원 안내 확인)"로.
   - "RAS를 겨냥한 먹는 신약이 2차 치료에서 생존을 늘린 결과가 나와 있어" → 근거 없는 효능 문장. 출처(학회 발표·논문)를 근거 쪽에 연결하고 "연구 결과가 보고됨 · 국내 허가 전 · 임상시험 여부 문의"로 낮추거나 삭제.
   - 판독지 단어장·절제 가능성 표의 "둘레의 절반 미만/이하/초과" → 지침 정의이므로 출처(NCCN 등) 표기, 표 구조는 ApuDa 언어로 새로 짬(지침 표 복제 금지).
   - "한 달에 5% 이상 체중 감소", "하루 4~6회 이상 설사", "PET 4~6시간 금식", "주 150분" → 출처 연결 또는 "일반적 예시"(병원 기준 우선).
   - 가상 사례 혜숙 씨 "해열제 먹고 기다리지 말라는 한 줄이 저를 살렸다" → 과장 인과. "빨리 연락할 수 있었다"로 순화.
3. **급여·허가 문장 S4에서 재확인(2026.10 기준 → 발행 시점 기준).** PARP 억제제 유지요법(배선 BRCA), S-1 보조요법("국내 보조요법 허가·급여 확인 필요"), 젬시타빈 + 알부민결합 파클리탁셀, RAS 표적 신약, 산정특례(본인부담 5%·30일 이내 신청·5년), 상병수당 시범사업, 가족돌봄휴직(90일)·가족돌봄휴가(10일). 모두 "변경 가능 + 의료진·공단 확인" 꼬리 유지.
4. **약·항암요법은 "대표 예"로만.** 다제병용 항암·젬시타빈 기반 등 범주명 위주, 용량·투여 간격·주기("2주 주기") 미기재 → "병원 일정표"로 대체. 췌장효소제도 "용량은 의료진이 조절"만, 캡슐 수 표기 금지.
5. **판권·근거 쪽.** 완전판 "감수단(전문의 30인·환자 36인… AI 사전 검토단)… 출판본에는 실제 감수자 명단이 별도 표기" → "**실제 전문의 서면감수 전**"을 판권에 명시. AI 검토단 인원수는 독자 지면에서 삭제. 참고 지침 판 표기 "NCCN … Version 4.2026"은 실재·최신 여부 S4에서 확인.
6. **조판 결함.** 응급 상자 "먼저\n연락피를 토하거나"(줄바꿈 누락), 치료 경로 표 "2차이후" 행 중복, 8장 이후 장 번호 소실, 표 안에 "추적" 문단 끼어듦, FAQ 12문항뿐 → 이번 판에서 전부 재출력으로 해결.

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(발열 38.0°C·오한 + 황달 = 담관염·스텐트 막힘 가능, 토혈·검은 변, 계속 토함, 수술 후 발열 38.0°C·배액 탁해짐, 고혈당·저혈당 증상, 한쪽 다리 부종·갑작스러운 숨참·흉통, 항암 중 발열 38.0°C) · 0-2 오늘 확인할 세 가지(결과지·췌장 전문 센터 예약·황달 시 배액 계획) · 0-3 책 사용법 · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기

3. 황달과 담도 스텐트(플라스틱·금속, 응급 카드) → **EP03**
4. 검사 지도와 판독지 단어(췌장 CT·MRI·내시경 초음파·진단 복강경) → 심화 **EP11**

## 3. 캐릭터 고정 블록

```
[화풍 고정] 따뜻한 수채 톤 반실사 일러스트, 부드러운 자연광, 파스텔 진료실·가정. 시리즈 BC v29 EP01과 같은 화풍.
애니·큰 눈 웹툰 화풍 금지. 평면 아이콘·벡터 도형 금지. 이미지 안 글자·숫자 금지(말풍선 비움).
[인물 고정 — CS 생성 후 모든 컷에 레퍼런스로 첨부]
- 환자 '봉희': 66세 한국 여성, 은퇴한 동네 꽃집 주인. 흑백이 섞인 짧은 곱슬 파마, 목에 줄 달린 갈색 반테 돋보기,
  테라코타색 니트 조끼 + 크림색 블라우스. 마른 편. 입원 중엔 환자복 + 같은 돋보기 줄.
- 보호자 '석규'(남편): 69세 한국 남성, 정수리가 벗어진 머리 + 짧은 흰 옆머리, 두툼한 체격, 갈색 골덴 재킷,
```

### EP19 (심화) 아프지 않을 권리
1. 소파에서 등을 웅크린 봉희 / 봉희 "등까지 뻐근해" / 췌장암 통증은 등으로 퍼지기도 함.

### EP20 (심화) 조직이 안 나오면 서류는?
1. 진료실, 조직검사에서 암세포가 안 보였다는 설명 / 봉희 "그럼 암이 아니에요?" / 비진단적 결과가 암이 없다는 뜻은 아닐 수 있음.
2. 원무과, 석규가 산정특례 상담 / 석규 "등록은 어떻게 되나요?" / 확진 시점·제도 적용은 원무과 확인.
3. 석규가 보험 약관의 병리 확정 조항을 돋보기로 봄 / (대사 없음) / 진단비는 병리 확정 요구 여부를 약관에서 확인.
4. 부부가 서류철을 정리 / 봉희 "두 부씩, 날짜순으로" / 기준은 공단·보험사에 확인.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **1장(절제 가능성 4단계) · 3장(황달과 담도 스텐트) · 19장(췌장효소·체중·근육)**.
- 기존 완전판 문장 우선 재사용, 새 수치 추가 금지. 0절 "고칠 것" 1~6을 골든샘플부터 적용(38.0°C, 출처 없는 수치 처리, 투여 간격·용량 삭제).
- 절제 가능성 표는 지침 표 복제 금지 — ApuDa 문장으로 새로 짜고 출처만 근거 쪽에.
- 예후·생존율 수치는 본문에 새로 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
