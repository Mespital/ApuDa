**기존 원고에서 고칠 것(S2·S4)**
1. 발열 표기: 응급 상자 "조직검사 후 38°C 이상 발열·오한", "항암 중 38°C 이상 발열", 증상표 "항암 중 38°C 이상(병원 기준에 따라 37.8°C 이상 1시간 지속 등)" → 모두 **38.0°C**로 통일. 37.8°C 병기 문장은 삭제하고 "병원 안내가 다르면 병원 기준을 따릅니다"로 대체.
2. 출처 없는 수치 문장 → 아래 처리 방침대로.
   - "직장을 거쳐 하는 조직검사 뒤 패혈증이 약 2%에서" → 출처를 근거 쪽에 연결하거나, 없으면 "드물지만 생길 수 있고"로 바꾸고 수치 삭제.
   - "5알파환원효소억제제 … PSA가 약 절반 정도로 낮게 측정될 수 있습니다" → 출처 연결, 없으면 "낮게 측정될 수 있어 복용 사실을 꼭 알립니다".
   - 능동감시 일정표(PSA "6개월마다", 직장수지검사 "1년마다", MRI "1~2년마다", 재조직검사 "1~2년 안") → 표 제목을 "**일반적 예시**(병원마다 다름)"로 고정하고 출처 연결. NCCN 표 형태 복제로 보이지 않게 문장형으로 재작성.
   - 방사선 횟수("일반 분할 약 8~9주", "중등도 저분할 약 4~6주", "SBRT 약 5회", 중입자 "주 4회 약 3주(12회)") → 범위는 "일반적 예시"로, 중입자 "주 4회·12회"는 투여 일정이므로 삭제하고 "병원 일정표"로 대체.
   - 호르몬 병용 기간 "약 6개월(불량 중간위험)~18~36개월(고위험)" → 개월 수 삭제, "위험군에 따라 단기~장기, 기간은 의료진이 정함". 비교표에서 **'호르몬 병용' 행이 두 번 중복**된 것도 하나로.
   - Q4 "국내 자료로는 6개월 안에 약 80~90%, 1년 안에 95% 이상" 요실금 회복 → 출처(국내 문헌명) 연결 필수. 연결 못 하면 "대부분 수개월~1년에 걸쳐 좋아집니다(개인차 큼)"로 바꾸고 수치 삭제.
   - 골반저근 운동 "5초 조이고 5초 쉬기 × 10회, 하루 3번", "수술 뒤 6~12개월 꾸준히" → "**일반적 예시**, 병원 재활·비뇨기 간호 교육을 따름" 표기.
   - Q2 "대규모 연구에서 적절한 감시 대상자의 장기 전립선암 사망률은 즉시 치료와 큰 차이가 없었습니다" → 해당 연구를 근거 쪽에 연결(연구명·연도). 수치는 넣지 않음.
   - Q10 "검사 1~2일 전에는 피하라고" → "병원 안내에 따라" 추가.
   - "운동 주 2회 이상 근력운동", "주 150분", "체중 한 달 5%" → 일반 권고 출처 연결 또는 "일반적 예시".
   - 생존율 수치 문장은 완전판에 **없음**(확인). 새로 추가 금지.
3. 급여·허가·제도 문장 → S4에서 최신 여부 재확인: "조직검사 전 MRI와 PSMA PET/CT는 2022년부터 일부 조건에서 건강보험 급여"(연도·대상 사실 확인 필수, 불확실하면 연도 삭제), 중입자 "국내 일부 병원 시행, 급여 여부 확인", "로봇수술은 비급여 부분", PARP 억제제·방사성리간드치료 "국내 허가·급여 확인 필요", 산정특례 "5%·30일·5년", 가족돌봄휴직 "90일/10일", 상병수당 "시범사업", 실손 "소멸시효 3년" — 모두 "2026.10 기준·변경 가능·공단/원무과 확인" 꼬리표 유지.
4. 약은 "**대표 예**"로만: 피나스테리드·두타스테리드 → "(대표 예)"로 표기. ARPI·PARP 억제제·뼈 보호 주사 등은 계열명만, 상품명·용량·투여 간격 미기재. 플레어 차단약 "먼저 쓰기도" 문장에 기간·순서 수치 넣지 않음.
5. 판권: 현행 "감수단(전문의 30인·환자 36인…) AI 사전 검토단" 문장은 실제 인원으로 오해될 수 있음 → "**실제 전문의 서면감수 전** · AI 역할 기반 사전 검토만 반영"으로 명시. 실제 감수자 명단 칸은 비워 둠.
6. 구조 정리: 8장 뒤 "진행·전이로 진단받았다면"부터 장 번호 없음 → 30장 체계로 번호 부여. 공용 증상표의 탈모·손발 저림·입안 헐음 행과 검사 준비 카드의 내시경 행은 전립선암 관련 행만 남김(방사선 후 배뇨·장 증상, ADT 증상 추가). "메스꺼 움" 등 PDF 줄바꿈 깨짐 수정. 능동감시="적극적 관찰" 혼용 설명은 유지.

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(조직검사 후 38.0°C 이상 발열·오한, 소변을 전혀 못 봄·많은 혈뇨·핏덩이, 첫 호르몬 주사 후 뼈 통증 악화·다리 힘 빠짐, 등 통증 + 다리 힘 빠짐·대소변 장애) · 0-2 오늘 확인할 세 가지 · 0-3 책 사용법 · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 먼저 구분하세요: PSA 상승과 확진, 국소·국소진행·전이 → **EP01**
2. 진단 뒤 72시간 → **EP02**
3. PSA 수치 읽기(비대증·염증·복용 약) → **EP03**
4. 전립선 MRI(PI-RADS)와 조직검사 방법 → 심화 **EP11**
5. 병리보고서와 등급군(글리슨) → **EP04**
6. 위험군과 병기 검사(PSMA PET·뼈스캔) → 심화 **EP12**
7. 가족력과 배선 유전검사 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 능동감시와 대기관찰 → **EP05**
9. 수술 vs 방사선: 두 진료과 모두 만나기 → **EP06**
10. 근치적 전립선절제술(로봇·신경 보존)과 비용 → 심화 **EP14**
11. 방사선 방법(분할·SBRT·근접·입자)과 통원 → 심화 **EP15**
12. 호르몬치료(ADT)가 필요한 경우 → **EP07**
13. 전이성 전립선암의 1차 치료 → 심화 **EP16**
14. 진행·전이로 진단받았다면: 치료 목표와 완화의료 → 심화 **EP17**
15. 2차 소견·다학제·임상시험

### PART 3. 30일 실행 로드맵
16. Day 0–7 확인하고 검사받기

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 PSA가 높다고 다 암은 아니에요
1. 거실, 광수가 건강검진 결과지를 들고 갸웃 / 광수 "PSA가 높대" / PSA 상승만으로 암이라 하지 않음.
2. 옷 입은 남성 실루엣 위 방광·전립선 위치 의학삽화 / (대사 없음) / 전립선은 방광 아래 요도를 둘러쌈.
3. 진료실, 주치의가 세 갈래 길 그림(색만) / 주치의 "확진은 조직검사로 해요" / 확진 뒤 범위·위험군으로 나눔.
4. 순옥이 노트에 세 줄 정리 / 순옥 "등급, 위험군, 범위" / 이 세 가지가 치료 선택의 출발점.

### EP02 진단 뒤 72시간, 세 가지만
1. 밤 식탁, 결과지 앞에 앉은 부부 / 광수 "뭐부터 해야 하지?" / 첫 사흘은 세 가지만.
2. 광수가 약 봉투에서 비대증·탈모약을 꺼냄 / 순옥 "이 약도 적어 가요" / 일부 약은 PSA를 낮게 보이게 함.
3. 원무과, 순옥이 결과지 사본 요청 / 순옥 "두 부씩 주세요" / 서류는 처음부터 두 부씩.
4. 부부가 달력에 진료일 표시, 손을 포갬 / 광수 "같이 들어가 줘" / 배우자 동반 진료가 결정에 도움.

### EP03 숫자 하나로 정하지 않아요
1. 진료실, 광수가 지난 검진표들을 펼침 / 광수 "작년엔 낮았는데요" / 수치의 변화도 함께 봄.
2. 전립선 비대·염증·암 세 단면 의학삽화(색만) / (대사 없음) / 비대증·염증으로도 PSA가 오름.
3. 현관, 자전거 옆에서 간호사 안내문을 읽는 광수 / 광수 "검사 전엔 쉬라네" / 검사 직전 활동은 병원 안내 따르기.
4. 순옥이 PSA 기록표 첫 칸을 채움 / 순옥 "날짜랑 같이 적자" / 기록은 날짜와 검사 기관을 함께.

### EP04 병리보고서의 '등급군'
1. 진료실, 부부가 병리보고서를 봄 / 광수 "3+4가 뭐예요?" / 글리슨 점수는 등급군 1~5로 표기.
2. 색 농도가 다른 다섯 계단 그림(숫자 없음) / (대사 없음) / 등급군이 높을수록 공격성이 큼.
3. 가는 조직 막대 여러 개 중 일부만 색칠된 의학삽화 / (대사 없음) / 양성 코어 수와 비율도 기록.
4. 순옥이 한 장 요약에 기록 / 순옥 "등급군 칸 채웠어" / 등급군·PSA·병기로 위험군을 정함.

### EP05 지켜보는 것도 치료 전략
1. 진료실, 광수가 놀란 표정 / 광수 "치료를 안 한다고요?" / 능동감시는 계획된 관찰 전략.
2. 벽 달력에 색 스티커 몇 개 / (대사 없음) / 정기 PSA·MRI·재조직검사(간격은 병원 일정표).
3. 갈림길 그림(계속 걷는 길·다른 길로 꺾는 길) / 주치의 "변하면 그때 넘어가요" / 등급 상승·MRI 변화 시 근치 치료.
4. 공원 벤치, 부부가 웃음 / 광수 "이것도 내가 고른 길" / 대기관찰과는 다른 전략.

### EP06 두 진료과를 모두 만나요
1. 비뇨의학과 진료실, 주치의가 의뢰서 건넴 / 주치의 "방사선과도 만나 보세요" / 둘 다 가능하면 양쪽 상담.
2. 방사선종양학과 진료실, 여의사가 설명 / 의사 "통원 일정이 달라요" / 방법마다 통원 기간이 다름.
3. 세 칸 저울(배뇨·성기능·장, 색 블록만) / (대사 없음) / 적합한 환자에서 성적은 비슷, 부작용 양상이 다름.
4. 식탁, 부부가 결정 워크시트 점수 / 순옥 "당신한테 뭐가 중요해?" / 우열이 아니라 나에게 맞는 선택.

### EP07 호르몬치료, 왜 필요할까
1. 진료실, 주치의가 설명 / 주치의 "남성호르몬을 낮춰요" / ADT는 고위험·전이성 등에서 사용.
2. 두 손이 맞잡은 상징 그림(방사선 빛 + 약병 실루엣) / (대사 없음) / 고위험에서는 방사선과 함께 쓰기도.
3. 주사실, 간호사가 안내지를 건넴 / 간호사 "첫 주사 뒤엔 이것 보세요" / 일부 약은 초기 일시 악화(플레어) 가능.
4. 집, 광수가 부채질, 순옥이 물을 건넴 / 광수 "갑자기 확 덥네" / 안면홍조·피로는 흔함, 진료 때 말하기.

### EP08 수술 후 첫 주, 소변줄과 열
1. 병실, 이불 덮은 광수, 간호사가 침대 옆 주머니 설명 / 간호사 "주머니는 방광보다 아래" / 퇴원 전 소변줄 관리 교육.
2. 집, 광수가 헐렁한 바지와 패드 포장을 챙김 / 광수 "패드도 넉넉히" / 소변줄 제거 후 초기 요실금은 흔함.
3. 밤, 체온계를 본 순옥이 병원에 전화 / 순옥 "38.0도에 오한이 있어요" / 38.0°C 이상·오한·소변 막힘은 바로 연락.
4. 광수가 무거운 화분 앞에서 멈춤 / 순옥 "그건 내가 할게" / 무거운 물건·격한 운동은 의료진 상의 후.

### EP09 요실금, 근육으로 이겨내기
1. 거실 의자, 옷 입은 광수가 눈 감고 집중 / 광수 "조이고, 쉬고" / 골반저근 운동은 수술 전부터 배우면 좋음.
2. 옷 입은 하반신 실루엣 위 골반저근 선 의학삽화 / (대사 없음) / 소변을 멈추는 근육을 찾는 것이 시작.
3. 외출 전, 광수가 가방에 패드 포장 하나를 더 넣음 / 광수 "여분 하나 더" / 흡수량별 패드로 외출 자신감.
4. 상담실, 전문간호사에게 배뇨 일지를 보여 줌 / 간호사 "조금씩 좋아지네요" / 회복은 개인차, 오래가면 치료 선택지.

### EP10 말하지 못한 걱정
1. 밤 베란다, 광수 혼자 먼 곳을 봄 / 광수 "예전 같지 않겠지" / 남성성에 대한 걱정은 흔하고 자연스러움.
2. 순옥이 옆에 앉아 따뜻한 차를 건넴 / 순옥 "같이 방법 찾아요" / 친밀감은 성관계만이 아님.
3. 색 눈금 온도계 그림(숫자 없음) / (대사 없음) / 마음 고통 4점 이상이 이어지면 진료 때 말하기.
4. 상담실, 상담사와 부부 / 상담사 "두 분이 함께 오셔도 돼요" / 정신건강·성상담 연결을 요청할 수 있음.

### EP11 (심화) MRI 먼저, 조직검사는 어떻게
1. MRI실 앞, 광수가 시계를 바구니에 넣음 / 방사선사 "시계도 빼 주세요" / MRI로 의심 부위(PI-RADS)를 봄.
2. MRI풍 수채 삽화(밝은 점 하나, 글자 없음) / (대사 없음) / 의심 부위를 겨냥한 조직검사에 쓰임.
3. 옷 입은 실루엣 위 두 경로 개념 의학삽화(색 화살표만) / (대사 없음) / 경회음 방식은 감염 위험이 더 낮다고 알려짐(출처 연결).
4. 집, 조직검사 뒤 체온을 재는 광수 / 순옥 "열 나면 바로 전화해" / 38.0°C 이상 발열·오한은 즉시 연락.

### EP12 (심화) PET에 보인 점, 다 전이일까
1. 진료실, 주치의가 네 칸 저울 그림 / 주치의 "위험군을 먼저 정해요" / 위험군은 PSA·등급군·병기로.
2. PET 검사실, 옷 입고 누워 대기하는 광수 / (대사 없음) / 고위험 등에서 병기 검사를 더함.
3. 전신 실루엣 의학삽화에 흐릿한 점 하나 / 광수 "이게 전이인가요?" / PET 소견이 곧 확정 전이는 아님.
4. 순옥이 판독 표현을 그대로 받아 적음 / 순옥 "'의심'이라고 적자" / 판독 표현 그대로 적고 치료가 바뀌는지 묻기.

### EP13 (심화) 아들에게 말해야 할까
1. 거실, 아들 준혁이 방문, 광수가 머뭇 / 광수 "너한테 할 말 있다" / 가족력은 중요한 정보.
2. 인물 실루엣으로 그린 가계도(글자 없음) / (대사 없음) / 전립선·유방·난소·췌장암 가족력 정리.
3. 유전상담실, 상담사와 부자 / 상담사 "검사 대상인지 볼게요" / 고위험·전이·가족력은 배선 유전검사 고려.
4. 준혁이 휴대폰에 메모 / 준혁 "저도 상담 받아 볼게요" / 가족의 검진 시점은 의료진과 상의.

### EP14 (심화) 로봇 수술, 무엇을 물을까
1. 진료실, 주치의가 옷 입은 실루엣 위에 손짓 / 주치의 "작은 구멍으로 해요" / 로봇·복강경·개복 중 선택.
2. 전립선 옆 신경다발을 색 선으로 표시한 의학삽화 / (대사 없음) / 신경 보존 여부는 종양 위치에 따라.
3. 원무과, 순옥이 비용 상담 메모 / 순옥 "비급여 부분이 있나요?" / 로봇수술 비용은 병원별 확인.
4. 진료실, 광수가 질문 목록을 읽음 / 광수 "수술팀 경험은요?" / 기계보다 수술팀 경험이 중요하다는 견해가 많음.

### EP15 (심화) 방사선, 몇 번 다니나요
1. 방사선종양학과, 의사가 색 칸 달력을 보여 줌 / 의사 "방법마다 횟수가 달라요" / 분할·저분할·정위·근접치료.
2. 치료실, 옷 입은 광수가 누움, 밝은 기계 / (대사 없음) / 외부방사선은 몸에 남지 않음.
3. 복도, 화장실 방향으로 서두르는 광수(뒷모습) / 광수 "자꾸 급하네" / 빈뇨·급박뇨·직장 자극이 생길 수 있음.
4. 간호사 상담, 증상 메모를 건넴 / 간호사 "적어 오시면 돼요" / 증상은 다음 치료 전에 알리기.

### EP16 (심화) 전이가 있어도 길은 있다
1. 진료실, 무거운 공기 속 주치의와 부부 / 주치의 "치료 선택지가 있습니다" / 호르몬치료 + ARPI ± 항암 범주.
2. 골격 의학삽화에 작은 점 몇 개 / (대사 없음) / 뼈 전이는 통증·골절 관리를 함께.
3. 치과, 치과의사가 광수를 검진 / 치과의사 "뼈 주사 전에 잘 오셨어요" / 뼈 보호 주사 전 치과 검진.
4. 부부가 질문 목록을 봄 / 광수 "제 치료 목표는요?" / 허가·급여는 처방 전 확인.

### EP17 (심화) 천천히, 덜 아프게
1. 진료실, 완화의료팀 간호사가 함께 앉음 / 간호사 "통증부터 같이 봐요" / 완화의료는 진단 때부터 함께.
2. 집 계단, 손잡이를 잡고 멈춘 광수 / 광수 "다리에 힘이 없어" / 등 통증 + 다리 힘 빠짐은 즉시 응급실.
3. 식탁, 부부와 아들이 이야기 / 순옥 "당신 뜻대로 하자" / 사전연명의료의향서는 원할 때 작성.
4. 저녁 공원 산책 / 광수 "오늘 하루 잘 살자" / 결정은 한 번에 하지 않아도 됨.

### EP18 (심화) 진료실에서 말해도 되는 것
1. 진료실, 광수가 모자를 만지작거리며 망설임 / 광수 "말하기 좀 그런데요" / 성기능 변화는 흔하고 상담 대상.
2. 주치의가 그림 카드 네 장을 펼침(약병·상자 실루엣, 글자 없음) / 주치의 "방법이 여러 가지예요" / 약·주사·기구·보형물·성재활.
3. 진료실, 순옥이 의자를 당겨 옆에 앉음 / 순옥 "저도 같이 들을게요" / 파트너 동반 상담을 권함.
4. 해 질 녘 손잡고 걷는 부부 뒷모습 / (대사 없음) / 친밀감은 대화·스킨십 등 여러 모습.

### EP19 (심화) 호르몬치료 중 근육 지키기
1. 동네 체력단련실, 광수가 가벼운 아령 / 광수 "가볍게, 꾸준히" / 근력 + 유산소 운동이 부작용을 줄임.
2. 골밀도 검사실, 옷 입고 누운 광수 / (대사 없음) / 뼈 약화를 검사로 확인.
3. 저녁, 순옥이 체중계 옆에서 기록 / 순옥 "체중도 적어요" / 체중·혈당·혈압 변화를 관찰.
4. 광수가 기분·기억 일지를 씀 / 광수 "깜빡한 것도 적자" / 기분·기억 변화도 말해도 되는 부작용.

### EP20 (심화) 지켜보는 중에도 서류는
1. 원무과, 순옥이 산정특례 문의 / 순옥 "지켜봐도 신청되나요?" / 확진 시 신청 가능 여부는 원무과 확인.

3. 진료실 접수대, 진단서 발급 요청 / 광수 "몇 통 필요한지 먼저" / 필요 부수를 보험사에 먼저 확인.
4. 부부가 서류철을 정리 / 광수 "날짜별로 모아 두자" / 기준은 공단·보험사 확인.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **1장(구분) · 8장(능동감시와 대기관찰) · 19장(요실금과 골반저근 운동)**.
- 기존 완전판 문장 우선 재사용, 새 수치 추가 금지, 투여 간격·용량 표기 삭제. 0절 "고칠 것" 1~6을 골든샘플에서 먼저 적용해 보여 줄 것.
- 요실금·성기능 문장은 의학 용어 + 존중하는 말투(희화화·과장 금지), "흔하다 · 말해도 된다 · 방법이 있다" 3단 구조.
