- 기준: `standards/01_총괄작업지시서.md` v1.1 (LC v22 구조 · BC v29 4컷 양식)
- 판본 목표: **MM v1.0** (로스터상 "미착수" — 새로 설계)
- 상태: **G1 대기** — 결재함에 `G1 승인 MM` 또는 `G1 수정 MM: …`
- ⚠ 실제 전문의 서면감수 전 원고. 의학 문장은 방향 설계이며 확정 문장이 아니다.
- 범위: **성인 다발골수종 첫 진단**(치료가 필요한 증상성 골수종). 이식 적합 경로(유도치료 → 자가조혈모세포 채집·자가이식 → 유지치료)를 주인공 줄기로, 이식 비적합 경로(이식 없이 여러 약 병용 → 유지)는 보조 인물과 11장으로 같은 무게로 보여 준다. MGUS·무증상(스몰더링) 골수종은 6장 + EP12(관찰도 계획), 단독 형질세포종·AL 아밀로이드증은 15장 안내 상자. 백혈병은 ⑮ LEU, 림프종은 ⑪ LYM, 다른 암의 뼈 전이는 ㉕ MET, 재발은 24장 끝 + ㉗ REC.
- 톤: 골수종은 **"뼈·신장·피를 함께 돌보는 오래가는 병"**이다 — 허리 통증·빈혈·신장 수치로 여러 진료과를 돌다 진단되는 일이 많고, 치료는 여러 해 이어지는 관리로 설명되는 경우가 많다. 책 전체의 축은 두 가지: ① **"숫자는 방향, 몸은 신호"**(M단백·유리경쇄 등 검사값은 흐름으로 보고, 하루 수치에 일희일비하지 않되 몸의 응급 신호는 바로 알림), ② **"뼈를 지키며 치료하기"**(압박골절·척수 압박 신호, 뼈 보호주사 전 치과, 넘어지지 않는 집, 무리하지 않는 걷기). "완치" "평생 약" 같은 단정 대신 "반응·유지·추적"의 말로 쓴다.

**설계 시 지킬 것(S2·S4에서 확인)**
1. **발열 38.0°C 통일.** 항암 중 발열·자가이식 뒤 발열·중심정맥관 부위 발열·CAR-T·이중특이항체 뒤 발열 모두 38.0°C. "병원 안내 기준이 다르면 병원 기준을 따르세요" 꼬리. 웹 FAQ의 "38°C"류 표기는 책에서 38.0°C로 통일.
2. **수치 쓰지 않기.** 형질세포 % 기준, M단백·유리경쇄 비율 기준값, 칼슘·크레아티닌·헤모글로빈 "몇 이상/이하", CRAB·SLiM 기준 숫자, R-ISS 병기별 생존, 반응률·생존율·재발률, 이식 입원 "며칠", 채집 "며칠", 유지치료 "몇 년", 하루 물 "몇 L", 주사 간격 같은 수·기간은 본문에 넣지 않는다. 필요하면 "결과지·병원 일정표 기준"으로. CRAB·SLiM은 **글자 뜻(고칼슘·신장·빈혈·뼈 등)만**, 숫자 기준 표 복제 금지.
3. **약은 "범주 + 대표 예"로만.** 프로테아좀 억제제(보르테조밉 대표 예), 면역조절제(레날리도마이드 대표 예), 항CD38 항체(다라투무맙 대표 예), 스테로이드(덱사메타손), 고용량 항암제 + 자가이식, 뼈 보호제(비스포스포네이트 계열·데노수맙), CAR-T·이중특이항체(범주명 위주, 재발 맥락) → **용량·주기·횟수 미기재**, 모두 "국내 허가·급여 변경 가능 + 의료진 확인". 조합 약어(VRd·Dara 등)는 용어 쪽에 "예시 이름"으로만, 표준 요법을 단정하지 않음.
4. **"완치"·"평생" 단정 금지.** 반응(부분·매우 좋은 부분·완전반응)과 MRD는 뜻만. "MRD 음성 = 완치" 금지 → "검사법으로 찾을 수 있는 수준 아래, 추적은 계속". 유지치료 기간은 "반응·부작용·병원 판단으로 정함".
5. **이식 단정 금지.** "젊으면 무조건 이식"·"나이 많으면 이식 불가" 금지 → "나이 숫자보다 몸 상태·심장·폐·신장 기능·환자 선택으로 상의". 이식 비적합 경로를 "덜 좋은 치료"로 쓰지 않음.
6. **뼈·신장 응급 문장 고정.** 허리·등 통증 + 다리 힘 빠짐·저림·대소변 이상(척수 압박 가능) = 바로 응급실, 심한 갈증·혼동·구토·변비(고칼슘 가능), 소변이 크게 줄거나 붓기(신장), 갑자기 숨참·한쪽 다리 붓기(혈전) — 0-1·4장·20장 같은 문장.
7. **진통제·조영제·물 문장은 "상의"로.** NSAIDs(소염진통제)는 "신장에 부담이 될 수 있어 스스로 계속 먹지 말고 상의", 조영 CT는 "신장 기능을 알리고 병원 판단", 물은 "양은 의료진이 정함(심장·신장 상태에 따라 다름)". 마사지·도수치료는 "뼈 상태 확인 전 강한 압박·꺾기 금지 — 상의".
8. **면역조절제 임신 주의는 개념만.** "태아에 해가 될 수 있어 임신 예방 프로그램을 따름(병원·약국 안내)" 정도, 세부 규정·기간 수치 미기재. 생식력·임신 계획은 "치료 전 상담".
9. **유전 오해 방지.** FISH의 del(17p)·t(4;14) 등은 "골수종 세포의 변화이지 가족에게 물려주는 유전자 검사가 아님" 문장 고정. 위험군은 이름과 뜻만, 생존 수치 금지.
10. **판권·근거 쪽.** "실제 전문의 서면감수 전" 명시. AI 검토단 인원수 독자 지면 삭제. 참고 지침(NCCN Multiple Myeloma, IMWG 진단·반응 기준, ESMO/EHA, 대한혈액학회 골수종연구회 등)은 실재·최신 판을 S4에서 확인 후 지침마다 판 번호를 따로 적음.
11. **가상 사례 이름은 다른 권과 겹치지 않게**(아래 3절, 3~15·17·26·27권 인물 명단과 대조 완료).

## 1. 목차 — 6부 30장 (+ 바로 시작 · 부록)

### 바로 시작 (4쪽)
- 0-1 기다리지 않는 신호(허리·등 통증에 다리 힘 빠짐·저림·소변·대변 조절 이상 = 척수 압박 가능, 바로 응급실 / 38.0°C 이상 발열·오한 = 해열제보다 먼저 연락 / 심한 갈증·구토·변비에 정신이 흐려짐 = 고칼슘 가능 / 소변이 크게 줄거나 온몸이 붓고 숨참 / 갑자기 숨참·가슴 통증·한쪽 다리 붓기 = 혈전 가능 / 넘어진 뒤 뼈 통증이 심해짐 / 멍·코피·잇몸 출혈이 멈추지 않음 / 말이 어눌함·한쪽 힘 빠짐 → 119 / 스스로를 해치고 싶은 생각 → 109·119) · 0-2 오늘 확인할 세 가지(치료가 필요한 골수종인지 — 관찰 단계인지 / 뼈·신장·피 중 어디가 영향을 받았는지 / 이식을 상의하는 길인지, 이식 없이 가는 길인지) · 0-3 책 사용법(내 길 찾기: 이식 상의 → PART 2 앞쪽 + 13장, 이식 없이 치료 → 11장, 관찰 단계(MGUS·무증상) → 6장, 신장이 많이 나빠짐 → 10장, 척추 골절·통증 → 9장·22장) · 0-4 온라인 연결

### PART 1. 진단 첫 주 — 정확히 알기
1. 다발골수종은 어떤 병인가요: 골수의 형질세포 · 항체 조각(M단백)을 만드는 혈액암 · 뼈 전이암과 다른 점 · "다발"이라는 이름 → **EP01**
2. 진단 뒤 72시간: 결과지 두 부 · 통증·소변·체온 기록 시작 · 혈액내과 첫 진료 질문 · 가족 한 명 → **EP02**
3. 검사가 한꺼번에 많은 이유: 피검사(단백전기영동·면역고정·유리경쇄) · 소변 검사 · 골수검사 · 뼈 영상(저선량 전신 CT·MRI·PET-CT) → **EP03**
4. 뼈·신장·피에 생기는 일: 뼈가 약해짐·압박골절 · 칼슘 · 신장 · 빈혈·감염 · 증상의 이름(CRAB은 글자 뜻만) → **EP04**
5. 결과지 읽기: M단백·유리경쇄는 "흐름" · 골수 형질세포 · FISH 등 세포 변화(유전 위험군의 뜻만, 가족 유전 아님) · 병기(R-ISS 등)는 예후를 묻는 말이지 1~4기와 다름 → 심화 **EP11**
6. 치료가 아직 필요 없는 단계: MGUS·무증상(스몰더링) 골수종 · 관찰도 계획 · 바로 알릴 증상 · 임상시험 문의 → 심화 **EP12**
7. 치료 전 확인 검사: B형간염 등 감염 검사 · 심장·신장 · 치과 · 예방접종 기록 · 혈전 위험 → 심화 **EP13**

### PART 2. 치료 결정 — 2~3주차
8. 치료 경로 지도: 유도치료(여러 약 병용) → 이식 상의(자가조혈모세포 채집·자가이식) 또는 이식 없이 계속 → 유지치료 → 추적 · 나이 숫자보다 몸 상태 → **EP05**
9. 뼈를 지키는 치료: 뼈 보호주사(비스포스포네이트 계열·데노수맙) · 치과 먼저 · 국소 방사선 · 척추 성형술 상의 · 보조기 → **EP06**
10. 신장을 지키는 치료: 신장이 나빠진 이유 확인 · 물·진통제·조영제 상의 · 약 선택이 달라질 수 있음 · 투석이 필요해도 골수종 치료는 상의 → 심화 **EP14**
11. 이식 없이 가는 길: 몸 상태·동반 질환·환자 선택 · 여러 약 병용과 유지 · "약하게 = 포기" 아님 · 치료 목표 다시 묻기 → 심화 **EP17**
12. 유도치료 시작: 외래 주사·먹는 약·스테로이드 날 · 약 달력 · 혈전 예방·대상포진 예방약 상의 · 손발 저림 신호 → **EP07**
13. 자가조혈모세포 채집과 자가이식: 채집 주사·채집 기계 · 고용량 항암 뒤 내 줄기세포 되돌려 넣기 · 무균실 생활 · 이식 뒤 예방접종 다시 → 심화 **EP15**
14. 면역조절제와 생활: 임신 예방 프로그램(개념) · 혈전 신호 · 피부 발진 · 생식력·임신 계획 상담 → 심화 **EP16**
15. 다른 형질세포 질환 안내: 단독 형질세포종 · AL 아밀로이드증(붓기·거품뇨·숨참) · 형질세포백혈병(드묾, 병원 판단) · 2차 소견(슬라이드·FISH 결과 재확인) · 임상시험
16. 통증과 치료가 어려울 때: 통증은 참지 않기(진통제 단계·방사선) · 완화의료 병행 · 치료 목표 다시 묻기

### PART 3. 30일 실행 로드맵
17. Day 0–7 확인하고 기록하기(결과지 · 뼈 영상 · 신장 · 통증·소변·체온 기록 · 치과 · 감염 검사 · 넘어지지 않는 집)
18. Day 8–21 결정하고 준비하기(유도치료 일정 · 이식 상의 여부 · 뼈 보호주사 · 예방약 · 직장·가족 역할)
19. Day 22–30 시작하기 · 유도치료 첫 주기 · 약 달력 · 30일 체크표

### PART 4. 치료 중·후의 몸과 마음
20. 치료 중 자기 관리 · 발열 38.0°C · 감염에 약한 이유 · 혈전 신호 · 스테로이드 날의 잠·기분·혈당 → **EP08**

## 4. EP별 4컷 칸 장면 설명

> 형식: 컷 = 장면 / 대사(25자 이내) / 의학 해설 한 줄.

### EP01 허리가 아팠던 이유
1. 버스 차고지 휴게실, 창호가 허리를 짚고 천천히 의자에 앉음, 동료(뒷모습)가 파스를 내밂 / 창호 "허리가 몇 달째 이래" / 쉬어도 나아지지 않는 뼈 통증은 진료로 원인을 확인.
2. 골수 속에서 한 종류의 세포가 늘어나 뼈 안쪽을 약하게 하는 의학삽화(색만, 글자 없음) / (대사 없음) / 골수종은 골수의 형질세포가 늘어나는 혈액암, 뼈를 약하게 할 수 있음.
3. 진료실, 주치의가 다른 장기의 암이 뼈로 간 그림과 골수에서 생긴 그림 카드 두 장(글자 없음)을 나란히 놓음 / 주치의 "뼈 전이와는 달라요" / 여러 뼈에 병변이 있어도 다른 암의 뼈 전이와는 다른 병.
4. 창호가 휴대폰 메모에 병 이름을 적고 정순이 등을 쓸어 줌 / 정순 "이름부터 제대로 알자" / 내 병 이름과 영향을 받은 곳(뼈·신장·피)을 기록.

### EP02 기록부터 시작한 사흘
1. 밤 거실, 창호가 휴대폰 검색 화면을 끄고 소파에 기댐 / 창호 "검색하니 더 무서워" / 진단 직후엔 검색보다 내 결과지와 몸 상태 기록이 먼저.
2. 식탁, 정순이 수첩에 통증·소변·체온 세 칸(기호만)을 그림 / 정순 "아픈 데랑 소변부터 적자" / 통증 위치·세기, 소변량, 체온을 기록하면 진료에 도움.
3. 원무과, 은비가 결과지·영상 CD 봉투 두 개를 받음 / 은비 "두 부씩 부탁드려요" / 결과지·영상은 처음부터 두 부씩.
4. 식탁, 은비가 영상통화로 손가락 세 개를 펴 보이고 창호가 고개를 끄덕임 / 은비 "첫 진료, 같이 가요" / 치료 필요 여부·영향 받은 곳·치료 길, 세 가지를 먼저 확인.

### EP03 피 한 번, 소변 한 번, 뼈 사진
1. 채혈실 앞, 창호가 검사 안내문 여러 장(글자 흐림)과 소변 용기 봉투를 들고 한숨 / 창호 "검사가 왜 이렇게 많아?" / 피·소변·골수·뼈 영상은 각각 다른 것을 봄.
2. 피·소변·골수·뼈 네 칸이 한 사람 실루엣으로 모이는 개념 그림(색만, 글자 없음) / (대사 없음) / 피·소변은 M단백·유리경쇄, 골수는 형질세포, 영상은 뼈 병변을 확인.
3. 처치실, 창호가 엎드려 담요를 덮고 눈을 감음, 정순이 손을 잡음(검사 부위 안 보임) / 정순 "금방 끝난대요" / 골수검사는 엉덩이뼈 뒤쪽에서 하며, 검사 뒤 관리는 병원 안내대로.
4. 영상검사실 대기 의자, 창호가 검사복 차림으로 기다림(기계는 멀리) / 창호 "뼈 사진은 전신으로 찍네" / 뼈 상태는 저선량 전신 CT·MRI·PET-CT 중 필요한 검사로 확인.

### EP04 뼈·신장·피, 세 군데
1. 진료실, 주치의가 뼈·신장·피 세 그림 카드(글자 없음)를 차례로 놓음 / 주치의 "세 군데를 같이 봐요" / 골수종은 뼈·신장·혈액에 영향을 줄 수 있어 함께 살핌.
2. 척추 하나가 살짝 내려앉은 모습을 부드럽게 그린 의학삽화(색만) / (대사 없음) / 약해진 척추뼈가 눌려 내려앉는 압박골절이 생길 수 있음.
3. 거실, 창호가 물컵을 들고 얼굴을 찡그리며 배를 짚음, 옆에 변비약 상자(상표 없음) / 창호 "목마르고 속이 더부룩해" / 심한 갈증·변비·구토·혼동은 칼슘이 높은 신호일 수 있어 바로 연락.
4. 창호가 계단 앞에서 숨을 고르고 정순이 팔을 잡음 / 정순 "숨찬 것도 적어 둬요" / 빈혈로 숨참·피로가 생길 수 있고, 감염에도 약해질 수 있음.

### EP05 내 몸에 맞는 길

2. 출발점에서 두 갈래 길이 나뉘었다가 같은 방향으로 이어지는 그림(색만, 글자 없음) / (대사 없음) / 유도치료 뒤 자가이식을 하는 길과 이식 없이 이어 가는 길이 있음.

4. 창호가 휴대폰 메모의 "알릴 신호" 칸에 뼈·열·소변 기호 / 정순 "아프면 예약 기다리지 말고" / 새 뼈 통증·발열·소변 변화는 바로 알리기.

### EP20 (심화) 손주와 보내는 오후
1. 은비 집 거실, 손주(뒷모습)가 창호에게 달려오고 창호가 쪼그려 앉으며 두 팔을 벌림 / 은비 "아빠, 안아 올리진 마요" / 뼈가 약할 땐 아이를 들어 올리기보다 앉아서 안아 주기.
2. 창호가 소파에 앉고 손주가 옆에서 그림책을 펼친 장면(색만) / (대사 없음) / 무거운 동작 대신 앉아서 함께하는 놀이로.
3. 은비가 손주 손을 씻기며 창호를 돌아봄 / 은비 "감기 기운 있으면 다음에 와요" / 감염에 약한 시기엔 아픈 가족과의 접촉을 조절.
4. 저녁 식탁, 가족이 둘러앉아 창호의 버스 운행 옛 사진첩을 넘김 / 창호 "다시 핸들 잡을 날 물어봐야지" / 운전·복직은 통증·뼈·약 상태를 보고 의료진과 상의.

## 6. S2 원고 지시 (G1 승인 후)
- 골든샘플 3장 먼저: **8장(치료 경로 지도: 내 몸에 맞는 길) · 4장(뼈·신장·피에 생기는 일) · 22장(뼈와 함께 사는 법)**.
- `myeloma.json` 답변과 출처(`sources`)를 근거로 새로 씀. 새 수치 추가 금지, 0절 "지킬 것" 1~11을 골든샘플부터 적용.
- CRAB·SLiM·R-ISS·반응 기준은 지침 표 복제 금지 — 글자 뜻과 ApuDa 문장으로만, 출처는 근거 쪽에. 생존율·반응률은 본문에 넣지 않는다. 필요하면 "담당 의사에게 내 경우를 묻는 질문"으로 바꾼다.
- 뼈·신장 장(4·9·10·22장)은 응급 신호 상자를 맨 위에(다리 힘 빠짐·대소변 이상 / 고칼슘 신호 / 소변 감소), 생활 팁은 그 아래(순서 고정). 통증 기록 기호는 W2와 같은 말로.
- 주인공 창호는 압박골절·빈혈로 발견, 이식 적합, 유도치료 → 자가이식 → 유지 경로. 이식 없이 가는 길은 복례, 관찰 단계는 선희 — 본문 사례도 같은 분담. 11장(이식 없이)은 8장과 같은 분량·같은 무게로.
- 골수검사·중심정맥관·수혈·감염 문장은 ⑮ LEU 원고와 대조해 통일. 다른 암의 뼈 전이와 구별 문장은 ㉕ MET와 맞춤.
- 26장 "가족" 상자 첫 줄은 "들어 올리지 말고, 앉아서 안아 주세요"(보호자·손주 돌봄 대상).
