# ⑬ BLC — S2 장 단위 감수 메모 (standards/04 §3-1 · 가상 사전 감수)

> ⚠ AI가 각 관점을 맡아 수행한 가상 사전 감수. 실제 전문의·간호사·환자 감수가 아님. 감수단 구성은 `S2_감수단.md`.

## 4장 TURBT (2026-11-23 · 골든샘플)
- 심각(반영, 비뇨 A): 초안의 "방광을 씻어 내기도 함"(지속 방광세척)·"변비로 힘주면 출혈" — 열람한 출처에 없음 → 삭제. 확인 못 한 내용 쓰지 않기(04 §1-2-6).
- 중대(반영, 비뇨 A): 응급 목록의 "한쪽 다리 붓기·숨참(혈전)"은 TURBT 특이 근거 미열람 → 4장에서 빼고 바로 시작 0-1 공통 신호로만 유지.
- 중대(반영, 간호사-외래): "소변이 붉고 따가운 것은 대개 옅어진다" → 경과 단정 회피, "흔한 편, 점점 심해지면 연락"으로.
- 중대(반영): 소변줄 거치는 ACS에 없음 → "두기도 함"으로 낮추고 근거표 확인 필요.
- 경미(유지): 재절제 시기(주 수)는 NCCN 환자판에서 확인했으나 S1 §0-2대로 본문 미기재.
- 환자(P1): "재절제는 실패가 아니다" 문장이 안심됨. 심리: 공포 연출 없음. 편집: 날짜 없는 흐름 표 유지.

## 10장 방광 안에 넣는 치료 (2026-11-23 · 골든샘플)
- 심각(반영): 표의 "1~2일 정도의 몸살"·"하루 이틀" → 기간 수치 삭제("짧게 지나가는"). 유도·유지 주·년 수치 0건 확인. 약 이름(성분·상표) 0건, 범주만.
- 중대(반영, 주입실 간호사): "소변에 피가 많으면 그날 주입을 미룬다" → 열람 출처(UCLH)는 "몸이 안 좋거나 요로감염 의심 시 연기"만 → 그 취지로 수정, 항생제 복용 알리기 추가.
- 중대(반영, 다학제): BCG 전신 감염 신호(관절통·기침·발진)와 "치료 후 시간이 지나도 생길 수 있음 → 다른 병원·치과에 BCG 이력 알리기" 추가.
- 중대(미완→확인 필요): "해열제 먼저 먹지 말고 연락" — 이번 실행 1순위 대조 못 함. 시리즈 공통 안전 문장이라 유지하고 근거표 확인 필요(24장에서 대조).
- 간호사: 38.0°C + "하루 넘게 또는 점점 심해짐" 기준이 S1 0-1과 일치. 연락처 기록칸 있음.
- 환자(G1 보호자): 가족 위생은 11장으로 넘긴다는 연결이 분명함. 심리: "참는 것이 능사가 아닙니다" 적절.

## 22장 요루와 함께 사는 법 (2026-11-23 · 골든샘플)
- 심각(반영, 비뇨 B): "요루는 배 오른쪽 아래" 위치 단정(미확인) → "대개 수술 전 표시한 자리".
- 심각(반영): 요루 주변 탈장 행·점액 문장 — 열람 출처에 없음 → 삭제, 근거표 확인 필요(23장에서 재조사).
- 중대(반영, WOC 간호사): 교체 간격·비우는 양·하루 수분량·식초 세척 비율(ACS 수치) 본문 미기재, "전문간호사가 정한 간격·가득 차기 전".
- 중대(반영): 연락 신호를 ACS 목록(발열·복부/등 통증·출혈 지속·심한 피부 자극·색 변화)과 국가암정보센터 부작용(수신증)에 맞춤. 벨트 조임 자극 행 추가.
- 경미(유지): 대중목욕탕·수영장은 "전문간호사 상담" — 근거 미열람 부분은 단정 없이 상담 권유.
- 환자(P2, 요루): 체험 상자(현주)·여분 한 벌·허리선 바지가 현실적. "생각보다 남들이 모른다"는 사람마다 다르다는 단서 있음(반영 유지).
- 편집: 실존 상표 0건. 제도는 27장 + "변경 가능, 공단·주민센터 확인".

## 1장 요로상피암과 근육층 (2026-11-23)
- 중대(반영, 병리): 비근육침윤성 범위에 상피내암 포함, Ta/Tis/T1 vs T2 이상 기호 연결 — NCCN 환자판은 0a/0is 표기라 5장에서 대응 설명하기로 메모.
- 중대(반영): "처음 진단받는 분들 가운데 많은 편" — 국가암정보센터 비율 확인, 수치는 미기재.
- 경미(확인 필요): 다학제 의견 문장은 방향 문장, S4 대조.
- 환자(P4, 전이성): 표에 전이성 행이 있고 16·17장 연결 — 소외감 없음. 환자(P3): 방광보존이 "같은 무게"로 소개됨(반영 확인).
- 심리: "자주 들여다보는 병" 표현이 재발 공포를 계획으로 바꿔 줌.

## 2장 진단 뒤 72시간 (2026-11-23)
- 심각(반영, 심리): 흡연 탓 문장 금지(S1 §0-5) — "자신을 탓할 필요는 없다"와 여러 요인 관련 문장 배치, 원인 단정 0건.
- 중대(반영): 금연 효과는 NCCN 환자판 취지로 "도움이 되는 것으로 알려져" 수준. 공공 금연 지원 세부 기간·횟수(2022 정책브리핑) 미기재, "변경 가능 + 기관 확인".
- 중대(확인 필요): 재절제 사유 중 "고등급·T1"은 전문가판 미열람 → S4 확인. 전자담배 문장은 26장에서 대조.
- 환자(P1): 세 가지만 하라는 구성이 부담을 줄임. 보호자(G1): 원거리 영상통화 동행 문장 유용.
- 편집: 서류 표는 28장과 중복 최소화.

## 3장 혈뇨에서 진단까지 (2026-11-23)
- 중대(반영, 영상): 조영제 주의에서 특정 당뇨약 언급(미확인) → "복용 중인 약"으로 일반화.
- 중대(반영, 비뇨 A): 방광경 뒤 증상 서술(미확인) → "검사 전 안내문으로 받아 두기" + 연락 신호만.
- 중대(반영): 세포검사 음성 ≠ 배제, 피의 양 ≠ 병기 — 국가암정보센터 취지로 유지.
- 경미(확인 필요): 여성 혈뇨 오인 문장 — 환자(P2) 요청으로 유지, 생활 조언 수준·근거표 확인 필요.

# 2차 실행 (2026-11-23 · 원고 v0.2 · 5·6·7·8·9·11장)

## 5장 병리보고서 읽기
- 중대(반영, 병리): 0a/0is/1기 ↔ Ta/Tis/T1 대응 — 1기는 "림프절·먼 곳 퍼짐이 없는 T1"로 한정해 TNM 오대응 방지.
- 중대(반영, 병리): 변이 조직형 목록(NCCN p.25) 나열은 공포·복제 우려 → 범주만.
- 경미(확인 필요): 유두상·다발성·절제연 용어 설명은 일반 설명, S4 병리 대조.
- 환자(P1): "고등급 T1 = 놓치지 않기 위한 순서" 문장이 안심됨. 심리: 판정·공포 표현 없음.
- 편집: 결과지 표 7행 → 기록칸과 항목 일치.

## 6장 위험군
- 심각(반영, 다학제·편집): 재발·진행 확률·계산표 0건 확인(S1 §6). 지침 표 복제 아닌 ApuDa 문장 표, "지침마다 이름·기준 다름" 명시(NCCN 환자판은 medium).
- 중대(반영, 비뇨 A): 최고위험에 "방광절제를 적극 상의"로 — "우선/반드시" 단정 피함, 12장 연결.
- 환자(G1 보호자): 밤에 위험군 표 검색하는 장면과 "그래서 무엇이 달라지나" 질문이 실제 걱정에 맞음.
- 심리: "위험군은 수명이 아님"은 방향 문장(근거표 표시). 희망 단정 없음.

## 7장 상부요로
- 심각(반영, 다학제): "상부요로상피암은 방광암보다 드묾" — 열람 출처에 없음 → 삭제. 국가암정보센터 동반 비율 수치 미기재.
- 중대(반영, 비뇨 B): 내시경 소작·레이저를 NCI 취지대로 "조건이 맞을 때, 연구 단계로 쓰이기도" 로 낮춤. 신장 보존 가능 여부 단정 없음.
- 중대(반영): "치료 뒤 방광경 추적이 많다" 미확인 → 추적 범위를 담당의에게 묻는 문장으로.
- 중대(남음): UTUC 치료 범주는 2순위(NCI)만 — 1순위(NCCN UTUC 환자판) S4 확인.
- 영상: 조영제·콩팥 기능 주의 3장 연결 유지. 환자(P3): 요관경 "마취를 하고 받음" 문장으로 두려움 감소.

## 8장 치료 경로 지도
- 중대(반영, 종양내과): 전이성 약은 범주만, 상표·성분 0건(NCCN 환자판 상표명 미사용). "몸 전체를 다루는 길" 목표 문장 = NCCN p.63 취지 자기 말.
- 중대(반영, 비뇨 B): 동반 절제 범위 단정 없음, "병기·성별·나이 등 담당의 상의"(S1 §6).
- 중대(반영, 방사선): 방광보존 "맞는 조건이 있어 누구에게나 가능하지 않음" — 15장 연결.
- 경미(유지): 혈전 신호는 S1 0-1 공통 신호로 유지(NCCN p.38 위험 언급).
- 환자(P3·P4): 방광보존·전이성이 같은 표 안에서 같은 무게로 소개 — 소외감 없음. 2차 소견 = 불신 아님 문장 유용.

## 9장 재절제
- 중대(반영, 비뇨 A): "길이 바뀌는 것은 드물지 않다"(빈도 주장, 미확인) → "바뀌기도 합니다".
- 중대(반영): "재절제 후 BCG 시작이 많다" → "결과를 보고 시기 정하기도"; BCG는 치유 시간 뒤 시작(NCCN p.31). 시기 주 수 0건.
- 간호사: 준비·회복은 4장 참조로 중복 줄임, 응급 신호 상자 있음.
- 환자(P1): 체험 상자 "재절제 = 확인"이 자책·불신을 줄임.

## 11장 BCG 주입 날과 그 뒤
- 심각(반영, 주입실 간호사): 소변 처리 시간·소독제 종류와 양·수분량·참는 시간·성관계 금지 기간(CRUK 수치) 본문 0건, 모두 "병원 안내문 우선". S1 장 제목의 "이틀"도 기간 수치라 제목에서 뺌("그 뒤").
- 중대(반영): "화장실 하나여도 함께 쓸 수 있는 경우가 많다"·"속옷 따로 빨기" 미확인 → 삭제/주입실 확인으로. EP14 오해 문장도 교체.
- 중대(반영): 주입 연기 = "열·심한 배뇨통·항생제 복용 알리기 + 감염 검사 결과로 연기"(CRUK·NCCN 취지)로, 혈뇨 단독 연기 문장 없음.
- 중대(남음): 해열제보다 연락 먼저 — 1순위 미대조(24장에서).
- 환자(G1 보호자): 보호자 몫 단락이 짧고 실용적. 심리: "참지 말고 알리기" 톤 유지. 간호사: 38.0°C 기준 S1 0-1과 일치, 연락처·체온 기록칸 있음.

# 3차 실행 (2026-11-23 · 원고 v0.3 · 12·13·14·15·16·17장)

## 12장 BCG가 듣지 않거나 맞지 않을 때
- 중대(반영, 비뇨 A): 초안 "다시 생긴 것이 작고 저등급이면 내시경 후 방광 내 치료 재시도" — 국가암정보센터는 등급 조건 없이 "완전 절제 후 재사용·변경, 완전 절제 불가·반복 재발·무반응이면 방광적출 적극 고려" → 그 취지로 수정.
- 경미(반영, 심리): "몰래 주입을 건너뛰지 말고" → 탓하는 어감 → "스스로 주입을 미루지 말고 먼저 알리세요".
- 경미(반영, 환자 P1·편집): 체험 상자 "영식 BCG 유지 중"은 30일 시간축과 어긋남 → "첫 BCG 일정 중".
- 경미(유지·확인 필요, 종양내과): BCG 불응성 판정 기준·새 방광 내 약 국내 허가·급여는 미확인 → 본문은 "지침 기준·담당의 판단", "변경 가능 + 의료진 확인". 상표·성분명 0건 확인.
- 환자(P1): "미리 묻는 것은 불길한 일이 아니라 준비" 문장이 재발 공포를 줄임. 비교 표(지킬까/뗄까)가 진료실 질문으로 바로 쓰임.

## 13장 근육침윤성: 수술 전 항암 → 근치적 방광절제
- 중대(반영, 종양내과): 30초 요약 "많은 병원에서 수술 전 항암" = 빈도 주장(근거 없음) → "몸 상태가 허락하면 … 지침에서 흔히 권하는 순서"(NCCN 환자판 pp.48-49·ESMO).
- 중대(반영, 간호사-주사실): "항암 중에는 감염이 빠르게 진행" 설명은 이번 실행 1순위 미대조 → 삭제, 38.0°C·해열제보다 연락 먼저 행동 문장만 유지(근거표 확인 필요 이월).
- 중대(반영, 종양내과): 이명·손발 저림 "약을 조정할 수 있습니다"(처방 단정 소지) → "계속할지·바꿀지는 의료진이 판단".
- 경미(유지, 비뇨 B): 동반 절제 장기는 "대상이 될 수 있지만 범위는 병기·성별·나이에 따라 담당의 상의"로 S1 §6 충족. 주기·기간·회복 기간 수치 0건.
- 환자(P2): 여성 장기 언급이 담담하고 단정 없음. 현주 체험 상자(일 미리 나누기)가 현실적. 간호사: 혈전·소변 감소 연락 신호 포함 확인.

## 14장 소변길 만들기(요로전환)
- 중대(반영, 비뇨 B·WOC): 선택 기준(콩팥 기능·손 사용)은 열람 출처에 없음 → 사실 문장이 아닌 진료실 질문 형태로만, 근거표 확인 필요. "요도 절제 → 방법 달라짐"은 "달라질 수 있습니다"로 낮춤.
- 경미(반영, WOC): 요루 위치 표시는 AUA·WOCN 안내 취지(네 자세·주름·벨트선·본인이 볼 수 있음·최종은 외과의)로 정리, 평소 바지 입고 가기 팁 추가.
- 경미(반영, 비뇨 B): 22장에서 삭제했던 점액 문장을 ACS 교차확인 후 14장 표 아래 "대개 정상, 열·통증 동반 시 알림"으로 수록.
- 환자(P2): "어느 쪽이 더 나은 선택이라고 정해진 것은 없다" + 현주·정민 대비 상자가 선택 압박을 줄임. 국문: "저장낭형" 용어를 표·질문·기록칸에서 통일.

## 15장 방광보존 삼중요법
- 중대(반영, 방사선): "조건이 안 맞아도 방사선·항암방사선을 다른 목적으로" — 모호하고 근거 부족 → "큰 수술이 어려운 분은 방사선을 포함한 다른 치료를 상의할 수 있음"(ACS·ESMO 취지).
- 경미(반영, 영상·방사선): 반응 확인 단계의 "방광경·조직검사·영상"은 구성 단정 → "방광경 등 검사로".
- 경미(유지): 적합 조건의 종양 크기 수치(NCCN Guide 7) 미기재 확인, 반응 확인 시기·방사선 횟수 0건.
- 환자(P3): 큰 수술 대신 고른 길이 "차선책 아님"(EP16 오해 문장)으로 존중됨. 통원 거리 질문 유용. 간호사: 방사선 중 빈뇨를 재발로 혼자 판단하지 말라는 문장이 전화 상담 현실과 맞음.

## 16장 전이성 요로상피암
- 심각(반영, 종양내과): 표 제목 "1차 치료의 범주" 안에 주로 이후 단계인 FGFR 표적치료가 들어 있어 사실 오류 소지 → "치료의 범주 — 1차와 그 이후"로 바꾸고 행 안에 "주로 다른 치료 뒤" 명시. 1차 우선순위는 출처마다 다름(NCCN 2023·NCI 2024·ESMO 2022) → 단정 없이 "지침·시점·국내 허가·급여에 따라 다름".
- 중대(반영, 종양내과): 면역치료 부작용 목록의 "피부가 심하게 벗겨짐"(ACS는 다른 약에만 언급)·"치료 끝난 뒤에도"(NCI 쪽 미열람) → 삭제, "폐·장·간·호르몬샘 반응, 숨참·심한 설사 바로 알림"(ACS)으로.
- 중대(반영, 다학제): 응급 신호 "다리 힘 빠짐·대소변 조절 안 됨(척추 쪽 문제)" 원인 설명은 미확인 → 원인 괄호 삭제, 신호만 유지(근거표 확인 필요).
- 경미(반영): 유전자 검사 조직·기간 서술(미확인) → 진료실 질문으로.
- 중대(남음 — S3 결정 사항, 원고 아님): S1 EP17 장면이 현주를 전이성으로 읽히게 함 → 편집 메모에 대표 결정 요청. 본문·EP17 오른쪽 쪽은 인물 미사용.
- 환자(P4): "할 수 있는 것이 없다는 뜻은 아님", "목표를 묻는 것은 겁나는 질문이 아님" 문장으로 소외감·공포 줄어듦. 심리: "오래 조절하는 것을 목표로 하는 경우가 많다"는 정직하되 희망 단정 없음.

## 17장 치료가 어려울 때
- 심각(반영, 심리·편집): 체험 상자 "완화의료 몇 주 만에 손주와 산책" = 가상 사례로 효능을 암시(하드룰: 근거 없는 효능 주장) → "이런 것까지 물어봐도 되는 줄 몰랐다"는 경험 진술로 교체.
- 경미(반영, 다학제): 2차 소견 준비물 "조직 슬라이드"(미확인) 삭제, NCCN p.76 취지(기록 전달·전문가·시간 확인)로.

- 간호사: 응급 신호에 통증 조절 실패·자해 생각 포함, 연락 경로(119·109) 분명. 임상시험 표(동의·그만둘 권리·가짜 약·조건·비용)는 NCCN pp.35-36 자기 말로, 미국 보험 문장 미반영.
