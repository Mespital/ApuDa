# ChatGPT에 지금 붙여넣을 다음 지시 (BC·LC)

> 각 블록을 해당 권 ChatGPT 채팅에 그대로 붙여넣기. 끝까지 '계속'만 보내면 되도록 작업 큐와 멈춤 지점을 넣어 뒀다.

---

## ① 유방암 → BC v2.0 통합 출판본

```
[작업] 유방암 BC v2.0 통합 출판본 제작
기준: 본책 v1.6(241쪽) 원고 + 4컷 만화 v29(EP01~20, 80컷). 참고 조판 양식: 폐암 v22(본문 장 옆에 EP 배치).

[절대 규칙]
- 기존 PDF에 덧붙이거나 합본하지 말 것. 원본 소스(HTML/DOCX)에서 전체를 새로 출력.
- 판본 표기는 'BC v2.0' 하나만. 꼬리말 1종: "ApuDa | 암 진단 후 첫 30일 · 01 유방암 | BC v2.0  {쪽}"
- 쪽번호 자동, 차례·"○쪽 참조"를 최종 쪽번호로 다시 맞출 것.
- 의학 문장 내용은 바꾸지 말 것(구조·배치·표기만 정리). 바꿔야 할 곳은 목록으로만 보고.

[작업 큐] 한 응답에 한 단계씩 처리하고, 끝마다
"✅ 완료: 단계n / ▶ 다음: 단계n+1 — 설명 → '계속'" 형식으로 끝낼 것.
1. EP 배치표: 신 EP01~20 각각을 어느 PART·장 바로 뒤에 넣을지 표로 제시 (EP번호·제목·삽입 위치·이유)
2. 옛 EP(v1.2) 20쪽 삭제 목록 + 보강부록 v2.0 「보강 02~33」을 흡수할 장 목록 + 중복 쪽(59·61쪽 질문 블록) 처리
3. 차례 재작성 (최종 쪽번호 포함)
4. PART 01~03 조판 출력
5. PART 04~06 조판 출력
6. PART 07~09 조판 출력
7. FAQ 100 · 용어 107 · 부록 A~D · 근거 · 판권 출력
8. 자동 점검 결과 보고: 총 쪽수, 판본 표기 종류 수(=1이어야 함), 쪽번호 불일치 수(=0), HTML 태그 노출(=0), 4컷 중 아이콘 대체 컷(=0)
9. 최종 PDF 1개 출력 → 파일명 2026-11-21_아프다_첫30일_01BC_통합본_v2.0.pdf
⛔ 9번 후 멈추고 "Claude 검수 대기"라고만 쓸 것.
```

## ② 폐암 → LC v23

```
[작업] 폐암 LC v23 정리판 제작 (v22 기준)
[절대 규칙] v22 원본 소스에서 전체 재출력. 의학 문장 내용은 바꾸지 말 것(필요 시 목록으로만 보고).
판본 표기는 'LC v23' 하나만.

[수정 목록]
L1. 219쪽 「출판 전 필수 확인」에 <b> </b> 태그가 글자로 인쇄됨 → 태그 제거, 해당 구절만 굵게.
L2. 뒤쪽 「만화로 이해하는 폐암 치료의 결정」 심화 12편(170~218쪽)을 본문 해당 장 바로 옆으로 이동.
    본문 EP01~10과 주제가 겹치는 편은 하나로 병합. 이동 후 뒤쪽 블록과 별도 쪽번호(170/220 등) 삭제.
L3. 판권의 분량 표기를 최종 실제 쪽수로 수정.
L4. 쪽 하단의 내부 메모("근거: v12.0 본책 3쪽…" 등 v12.0·v14.0 표기) 전부 삭제.
L5. 4쪽 하단에 남은 숫자 '169'와 "확장 부록…" 잔존 문구 삭제.
L6. FAQ를 "FAQ 100문항" 한 블록으로 묶고, 하위에 기본·추가·영양 구분만 소제목으로 유지.

[작업 큐] 한 응답에 한 단계씩, 끝마다 "✅ 완료 / ▶ 다음 → '계속'" 형식.
1. 심화 12편 ↔ 본문 장 배치표 + 병합 대상 표
2. 차례 재작성(최종 쪽번호)
3. 본문 전반부 출력  4. 본문 후반부 출력  5. FAQ·워크북·부록·근거 출력
6. 자동 점검 보고(총 쪽수 / 판본 표기 종류=1 / HTML 태그 노출=0 / 중복 EP=0)
7. 최종 PDF → 2026-11-21_아프다_첫30일_02LC_v23.pdf
⛔ 7번 후 멈추고 "Claude 검수 대기"라고만 쓸 것.
```

## 다음 권 착수 (③ 위암부터 같은 방식)

```
[작업] {권번호} {암종} 첫 30일 — 폐암 LC v23과 같은 구조로 제작
구조: 앞부분(응급·차례·바로시작) → PART별 본문 + 해당 장 바로 옆 4컷 EP(기본 10 + 심화 10 = 20편) → FAQ 100 → 워크북 → 근거·용어 107±
만화 양식: EP 1편 = 2쪽(왼쪽 4컷 전부 일러스트 + 오른쪽 핵심 설명). 이미지 안에 글자 넣지 말 것.
규칙: 판본 표기 1종, 원본 소스에서 전체 출력, 진단·처방 단정 금지, 발열 기준 38.0°C, 약 용량 미기재.
작업 큐: 1 목차·EP 20편 주제표 ⛔(Claude 검수 대기) → 2~11 EP01~20 만화(2편씩) → 12~16 본문 PART별 → 17 FAQ 100 → 18 워크북·부록 → 19 자동 점검 → 20 최종 PDF ⛔
매 응답 끝: "✅ 완료 / ▶ 다음 → '계속'"
```
