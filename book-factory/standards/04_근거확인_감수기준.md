# 04 근거 확인 · 다관점 감수 기준 (초고 완성도 표준) v1.0

- 제정: 2026-11-22 · 대표 지시 "NCCN 가이드라인·국가암정보센터 등을 정확히 확인하고, 암종별 전문의 다학제팀·설명간호사팀·환자 4명 이상 감수로 초고 완성도를 높여라"
- 적용: S2 원고를 쓰는 모든 실행 + 초고 완성 판정(S4 확장 감수). 01 총괄작업지시서·각 권 S1 §0과 충돌하면 **더 엄격한 쪽**을 따른다.
- ⚠ 이 문서의 감수단은 **AI가 각 관점을 맡아 수행하는 가상 사전 감수**다. 실제 전문의·간호사·환자의 감수가 아니며 대신하지도 않는다. 독자 지면·보고서 어디에도 "전문의 감수 완료"처럼 쓰지 않는다. 판권 표기는 그대로 "실제 전문의 서면감수 전".

## 1. 근거 확인 (장을 쓸 때마다)

### 1-1. 우선순위 출처
| 순위 | 출처 | 쓰는 곳 |
|---|---|---|
| 1 | **NCCN Guidelines**(해당 암종 전문가판·환자판 NCCN Guidelines for Patients), 판 번호(예: Version x.20yy)까지 | 치료 흐름·병기 개념·검사 순서의 방향 |
| 1 | **국가암정보센터**(cancer.go.kr) 암종별 정보·생활 안내, 보건복지부·국민건강보험공단·건강보험심사평가원 | 국내 진료 흐름·제도·급여·용어 |
| 2 | 국내 학회 진료권고안(대한위암학회·대한암학회·대한종양내과학회 등 해당 학회), ESMO·ASCO 지침·환자 안내, NCI(PDQ 환자판) | NCCN과 국내 관행이 다를 때 병기, 보완 |
| 3 | PubMed 체계적 문헌고찰·주요 임상시험(PubMed·ClinicalTrials 커넥터) | 1·2순위로 확인이 안 되는 세부, 근거 수준 표시용 |
| 금지 | 블로그·카페·병원 홍보글·제약사 광고·AI 요약 | 근거로 쓰지 않음 |

### 1-2. 확인 절차
1. 장마다 **의학적 사실 문장**(진단·검사·치료·부작용·응급·제도)을 뽑아 출처와 대조한다. WebSearch/WebFetch로 출처 페이지를 **실제로 열어** 확인한 경우만 "확인"으로 친다. 검색 결과 요약만 본 것은 "미확인".
2. NCCN 본문은 로그인 뒤에만 열리는 경우가 많다 → 열리면 판 번호·해당 쪽, 안 열리면 NCCN 환자판·NCCN 공개 요약·국가암정보센터·ESMO·NCI로 교차 확인하고 "NCCN 본문 미열람" 표시. 열리지 않은 출처를 열어 본 것처럼 쓰지 않는다.
3. **NCCN·국가암정보센터 표·문장·그림 복제 금지.** 자기 말로 다시 쓰고 출처만 단다.
4. 국내 허가·급여·제도(산정특례·장기요양·상병수당·병역 등)는 1순위 국내 공식 페이지로만 확인, 확인일을 남기고 본문은 "변경 가능 + 의료진·기관 확인".
5. NCCN과 국내 권고·관행이 다르면 둘 다 근거표에 적고, 본문은 단정하지 않고 "병원·나라마다 다를 수 있음"으로 쓴다.
6. **확인 못 한 내용은 쓰지 않는다.** 꼭 필요한 문장이면 방향만 쓰고 근거표 「확인 필요」에 올린다. 수치·효능·약 용량 금지(01 §2-4) 규칙은 확인됐어도 그대로 유지한다.

### 1-3. 근거표 — `volumes/{NN}{코드}/S2_근거표.md`
장마다 표 하나를 쌓는다. 독자 지면에는 넣지 않는다(내부 문서). 책 뒤의 「근거·검토 상태」 쪽은 이 표를 바탕으로 S5에서 만든다.

| 장 | 문장(요약) | 출처(기관·문서명·판/갱신일) | URL | 확인일 | 상태(확인/교차확인/NCCN 본문 미열람/확인 필요) |
|---|---|---|---|---|---|

- 장마다 최소 1개 이상 1순위 출처(NCCN 또는 국가암정보센터)를 확인해야 그 장을 "완료"로 친다. 둘 다 해당이 없는 장(제도·마음 장)은 해당 공식 기관 출처.
- 실행 보고서 ③에 "이번 실행 근거 확인 N문장 / 확인 필요 M건"을 적는다.

## 2. 다관점 감수단 (권마다 고정 구성)

권의 S1을 발행하거나 S2를 처음 시작할 때 `volumes/{NN}{코드}/S2_감수단.md`에 그 권의 감수단 명단(가상 인물, 역할·관점 한 줄)을 정해 두고 끝까지 같은 구성을 쓴다. `apuda-review-team` 스킬이 있으면 그 스킬의 절차를 쓰되 **아래 최소 구성을 채운다**(스킬 기본 구성보다 많으면 이 문서 기준).

| 팀 | 최소 인원 | 구성 예 (암종에 맞게) |
|---|---|---|
| **전문의 다학제팀** | 4명 이상 | 종양내과(또는 혈액종양내과) · 해당 장기 외과(또는 비뇨의학과·산부인과·신경외과 등) · 방사선종양학과 · 영상의학과 또는 병리과 — 필요 시 소화기·호흡기·내분비·소아청소년·재활의학·완화의료·정신건강의학과 추가. 공통편(GER·AYA·CG·REC·CUP·MET·PAL)은 노년내과·생식의학·완화의료 등 그 권의 핵심 과를 포함 |
| **설명간호사팀** | 2명 이상 | 해당 암종 전문간호사(외래 설명·교육) · 항암 주사실/병동 간호사(부작용·응급 전화 상담) — 필요 시 장루·림프부종·영양 담당 |
| **환자 감수단** | **4명 이상** | 그 암종을 겪은 가상 환자 4명 이상: 나이·성별·병기·치료 경로(수술/항암/방사선/관찰 등)·지역·디지털 친숙도를 서로 다르게. + 보호자 1명 |
| 편집·언어 | 2명 | 책 편집디자이너 · 국문학 교수(문장·용어 일관성) |
| 심리 | 1명 | 임상심리학자(공포 유발·탓 문장·희망 단정 점검) |

인원은 매 감수 보고서 머리에 표로 적는다(실행 보고서·독자 지면에는 인원수 노출 금지 — 01 원칙).

## 3. 감수를 언제 하나

### 3-1. 장 단위 빠른 감수 (S2를 쓰는 매 실행)
새로 쓴 장마다 감수단이 아래 체크를 돌리고, **심각·중대는 그 실행 안에서 고친 뒤** 커밋한다.
- 다학제팀: 사실 오류 · 지침과 다른 단정 · 빠진 응급 신호 · 위험한 생략
- 설명간호사팀: 환자가 집에서 그대로 따라 해도 안전한가 · 연락 기준(38.0°C 등)이 분명한가 · 진료실 질문이 실제로 쓸모 있는가
- 환자 4명+: 처음 듣는 사람이 이해되는가 · 무섭거나 탓하는 문장 · "내 경우는?"에 답할 곳(진료실 질문)이 있는가
- 편집·언어·심리: 문장 길이·용어 통일·톤
- 결과는 `S2_감수메모.md`에 장마다 3~8줄(심각/중대/경미 + 반영 여부).

### 3-2. 권 단위 확장 감수 (30장이 다 찼을 때 = 초고 완성 판정)
1. 30장 전체 + FAQ 질문 목록 + EP 장면을 감수단 전원이 읽는 **확장 감수 1회** → `S4_감수보고서.md`(팀별 의견, 심각·중대·경미 분류, 근거표 「확인 필요」 처리 결과).
2. 심각·중대를 모두 반영해 원고 판본을 +0.1 올린다(예: v0.6 → v0.7).
3. 아래 「초고 완성 체크」가 모두 통과하면 그 권의 `draft_complete: true`(state.json 권 항목) — 이것이 대표가 말한 "초고 완성"이다.

### 3-3. 초고 완성 체크 (권마다)
- [ ] 30장 모두 작성, 각 장 근거표 1순위 출처 확인
- [ ] 근거표 「확인 필요」 중 본문에 단정으로 남은 문장 0건
- [ ] 확장 감수 심각·중대 0건 남음
- [ ] 하드룰: 38.0°C 통일 · 약 용량 0 · 근거 없는 수치·효능 0 · 진단·처방 단정 0 · NCCN/국가암정보센터 문장 복제 0 · 실존 병원·상표 0
- [ ] 판권 "실제 전문의 서면감수 전" + "대표 목차 승인 전 초고"(G1 전이면)

## 4. 이미 원고가 있는 권 (③~⑩, 원고 v0.6)
S3(ChatGPT 만화)을 기다리는 동안에도 글 검토는 할 수 있다. 새 원고를 쓸 권이 2권이 안 되는 실행에서는 남는 슬롯으로 이 권들에 **근거표 작성 + 확장 감수(3-2)**를 소급 적용한다(order 순). 감수 반영본은 새 판본 파일로 저장(기존 파일 덮어쓰기 대신 v+0.1 새 파일)하고, 이미 ChatGPT에 보낸 S3 지시와 대사가 달라지면 「확인 필요」에 적어 대표에게 알린다.
① BC·② LC는 기존 출판본 흐름(S7_fix)을 따르고 이 목표 집계에서는 별도 표시한다.

## 5. 속도보다 품질
한 실행에서 근거 확인·장 단위 감수까지 끝낼 수 있는 만큼만 쓴다. (2026-11-23 대표 지시로 권당 6장/실행을 **기본 목표**로 상향 — FACTORY §3. 단 근거 확인·장 단위 감수를 못 한 장은 목표 수와 관계없이 쓰지 않거나 unverified로 남긴다.) 근거 확인을 못 한 장은 커밋하되 state의 `s2_progress`에 `"unverified": [장 번호]`로 남기고 다음 실행에서 먼저 처리한다.
