# 만화 어색한 컷 수정 지시 (BC v29 · LC v22)

- 점검: 2026-11-21 · 유방 80컷 + 폐 329개 배치(고유 101개) 전수 확인
- 같이 보낸 `01BC_수정컷.jpg` · `02LC_수정컷.jpg`에 문제 컷이 빨간 라벨로 표시돼 있음

## 1. 문제 유형 5가지

| 유형 | 증상 | 해당 컷 |
|---|---|---|
| A. 미완성 | 반실사 수채 컷 사이에 평면 도형·아이콘이 섞임 | BC EP02-2·3, EP03-2·3·4, EP09-3·4 |
| B. 화풍 이탈 | 애니·웹툰풍 얼굴 → 같은 주인공이 다른 사람처럼 보임 | BC EP03-1, EP06-1·3, EP09-1·2, EP14-1·4, EP15-1·4 / LC EP03 전체 |
| C. 인물 불일치 | 주인공·주치의가 다른 사람으로 바뀜 | LC EP05 전체(여성 환자 등장), LC 본문 61~66쪽(다른 부부) |
| D. 재사용·복제 | 다른 편의 그림을 그대로 씀 → 대사와 그림이 안 맞음 | LC EP02 = EP01 복제(4컷), LC 심화 171~218쪽 그림 210개 중 180개가 본문 그림 확대 재사용(흐림·얼굴 잘림) / BC EP07-2, EP15-3·4, EP16-3 |
| E. 장면 오류 | 의학적으로 틀리거나 불편한 장면 | BC EP04-4(환자 앞 책상에 절제 조직), EP06-2(진료실에 세포가 떠다님), EP06-4·EP16-3(다학제회의에 환자 착석), EP12-3(환자가 병리실험실 안), EP18-3(얼굴 잘림), EP19-3(옷 입은 채 유방초음파) / LC EP05-3(잘린 폐 조각 진열), EP08-3(방사선 조사 중 보호자 동석), EP03-2·4(이미지 속 한글 잘림 "PET-C", "조직검") |

**재생성 수량**: BC 23컷 · LC 13컷 + 심화 만화(본문 이동 시 신규 또는 그림 없이 Q&A 카드로 전환)

## 2. ChatGPT 사용법

1. 각 권 ChatGPT 채팅에 **[캐릭터 고정 블록]**을 먼저 붙여넣고, 기준 이미지를 첨부

## 3. ① 유방암 (BC)

### [캐릭터 고정 블록]
```
[화풍 고정] EP01과 같은 화풍: 따뜻한 수채 톤 반실사 일러스트, 부드러운 자연광, 파스텔 진료실.
애니·웹툰 큰 눈 화풍 금지. 평면 아이콘·벡터 도형 금지. 이미지 안 글자·숫자 금지.
[인물 고정 — 첨부한 EP01 컷과 같은 얼굴]
- 환자: 50대 초반 한국 여성, 갈색 웨이브 단발, 장밋빛 꽈배기 카디건 + 베이지 티
- 주치의: 40대 한국 여성, 갈색 낮은 올림머리, 흰 가운 + 네이비 스크럽
- 남편: 50대, 안경, 회색 니트 또는 하늘색 셔츠
[공통] 가로 4:3, 얼굴·손 잘림 금지, 손가락 5개 확인, 실존 상표·병원명 금지.
의학 장면은 실제 진료 현실과 맞게(환자는 병리실·다학제회의에 들어가지 않음).
```

### [수정 큐]
```
아래 순서로 한 응답에 한 컷씩 다시 그려. 끝마다 "✅ 완료: {컷ID} / ▶ 다음: {컷ID} → '계속'".
모두 끝나면 컷ID·파일명 목록표를 출력하고 "Claude 검수 대기"로 멈춰.

[A·미완성]
EP02-2 유관 단면 의학삽화(수채 반실사): 유관 안에 암세포가 차 있고 기저막(유관 벽 바깥 얇은 막)이 온전함
EP02-3 같은 유관 단면, 기저막 한 곳이 끊기고 암세포가 바깥 지방조직으로 퍼져 나감 — EP02-2와 확실히 다르게
EP03-1 진료실: 환자가 병리보고서를 펼쳐 들고 당황, 주치의가 옆에서 설명 (EP01 인물)
EP03-2 세포 단면 의학삽화: 핵 속 호르몬 수용체(ER·PR)에 호르몬이 결합하는 모습, 수채 반실사
EP03-3 세포막 표면에 HER2 수용체가 많이 솟아 있는 확대 삽화 + 하단 작은 원에 정상 세포 비교
EP03-4 현미경 조직 사진풍: 일부 세포핵만 갈색으로 염색된 면역염색(Ki-67) 화면을 주치의가 태블릿으로 보여줌
EP09-1 밤 거실: 환자가 담요를 덮고 체온계를 보며 걱정, 벽시계는 밤 (EP01 인물·화풍)
EP09-2 같은 거실: 환자가 오한으로 떨고, 남편이 병원에 전화하며 메모
EP09-3 응급실 입구: 구급대원이 숨찬 환자를 들것으로 옮기고 남편이 따라감
EP09-4 식탁: 환자와 남편이 냉장고에 병원 주간·야간 연락처 메모를 붙임

[B·화풍 이탈 → EP01 화풍으로 같은 구도 재생성]
EP06-1 진료실 상담(수술 전 약물치료 설명), EP06-3 진료실에서 수술 병리 결과지 설명
EP14-1 진료실 상담(HER2 설명), EP14-4 심장초음파 화면 앞 상담
EP15-1 진료실 상담(삼중음성 결과 설명), EP15-4 진료실에서 수술 병리 결과 상담

[D·재사용 → 새 장면]
EP07-2 겨드랑이 감시림프절 위치를 보여주는 측면 의학삽화(EP04-2와 다른 각도·색 표지 강조)
EP15-3 항암주사실: 환자가 수액을 맞으며 간호사와 대화, 창가 자연광 (세포 합성 장면 금지)
EP16-3 진료실: 주치의가 이전 치료 기록과 새 검사 결과를 나란히 놓고 설명

[E·장면 오류]
EP04-4 진료실: 주치의가 c·p·yp 단계별 병리보고서 3장을 책상에 나란히 놓고 설명 (조직 샘플 금지)
EP06-2 진료실: 주치의가 환자 가슴 부위를 옷 위로 진찰하고, 모니터엔 치료 전후 초음파 비교
EP06-4 진료실: 주치의가 환자에게 다음 치료 계획표를 보여줌 (다학제회의 장면 금지)
EP12-3 진료실: 주치의가 모니터의 유전자 검사 결과 그래프를 환자에게 설명 (실험실 금지)
EP18-3 진료실: 환자가 체중계 기록지를 들고 영양사와 상담, 얼굴 전체 보이게
EP19-3 초음파실: 환자가 검사용 가운을 입고 누워 있고 의사가 유방초음파 시행, 가슴 노출 없이 가운으로 가림
```

## 4. ② 폐암 (LC)

### [캐릭터 고정 블록]
```
[화풍 고정] EP01과 같은 화풍: 수채 톤 반실사, 밝은 진료실. 웹툰·만화체 금지, 이미지 안 글자 금지.
[인물 고정 — 첨부한 EP01 컷과 같은 얼굴]
- 환자: 70대 한국 남성, 회색 곱슬머리, 네이비 니트 + 체크 셔츠
- 보호자(아내): 70대, 갈색 파마머리, 베이지 꽈배기 스웨터
- 주치의: 50대 한국 남성, 안경, 흰 가운 + 남색 넥타이
[공통] 가로 4:3, 얼굴·손 잘림 금지, 실존 상표 금지, 실제 진료 현실과 맞게.
```

### [수정 큐]
```
한 응답에 한 컷씩. 끝마다 "✅ 완료 / ▶ 다음 → '계속'". 끝나면 목록표 출력 후 "Claude 검수 대기".

[D·EP02 = EP01 복제 → 4컷 신규]
EP02-1 진료실: 주치의가 두 종류 폐암 세포 사진(선암·소세포)을 나란히 띄워 보여주고 노부부가 의아해함
EP02-2 병리과: 병리의사가 현미경으로 조직 슬라이드 판독 (환자 없음, EP01-2와 다른 구도·인물)
EP02-3 진료실: 주치의가 검사 결과지(병기·분자검사 항목)를 가리키며 설명
EP02-4 진료실: 주치의가 치료 일정 달력을 보여주고 아내가 메모

[B·EP03 화풍·인물 이탈 → 4컷 재생성]
EP03-1 진료실: CT 화면 앞에서 환자가 "몇 기인가요" 묻는 표정
EP03-2 진료실: 모니터에 PET/CT와 뇌 MRI 영상을 나란히 띄워 설명 (글자 없이)
EP03-3 폐·림프절·간을 표시한 반실사 인체 도해를 주치의가 펜으로 가리킴 (T·N·M 글자 넣지 않음 — 조판에서 라벨)
EP03-4 진료실: 주치의·흉부외과의가 함께 노부부와 상담

[C·EP05 주인공 교체 → 4컷 재생성]
EP05-1 흉부외과 진료실: 외과의가 폐 모형으로 절제 범위 설명, 노부부 경청
EP05-2 폐기능검사실: 환자가 노즈클립을 끼고 폐활량계 검사, 간호사가 지도
EP05-3 폐 모형 위에 엽절제·구역절제·쐐기절제 범위를 세 가지 색 점선으로 표시한 반실사 도해 (잘린 장기 진열 금지)
EP05-4 병실: 환자가 호흡운동기구(인센티브 스파이로미터)를 쓰고 아내가 곁에서 응원

[E·장면 오류]
EP08-3 방사선치료 조정실: 아내와 간호사가 유리창 너머 모니터로 치료받는 환자를 지켜봄 (보호자는 치료실 밖)

[C·본문 61~66쪽 삽화] 위 인물 고정으로 같은 장면 재생성: 진료 일정 기록 / 약 정리 / 산책 / 전화 상담 / 간호사 상담
```

### 심화 만화 171~218쪽 처리 (택1)
- **A안(권장)**: 그림 빼고 "환자 질문 → 의료진 설명" Q&A 카드로 전환 → 본문 장 옆에 배치. 그림 재사용 문제 즉시 해결, 쪽수도 줄어듦
- B안: 12편 × 4컷 = 48컷 신규 생성 → `계속` 48번 추가
