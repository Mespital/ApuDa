# 공부관리 방: 오늘 요약·빠른 입력·반복 일정

## 사용자에게 달라지는 점

1. **오늘 한눈에:** 진행 중이거나 다음에 시작하는 일정 1개, 가까운 미완료 마감, 오늘 완료 개수를 표시한다. 기존 오늘 할 일은 우선순위에 따라 최대 3개를 먼저 보여준다.
2. **빠른 입력:** 과목·할 일·마감일 3개만 입력한다. 오늘 할 일에 등록하고, 별도의 중복 과제 없이 같은 할 일의 마감을 기억한다. 완료하면 해당 마감도 요약에서 사라진다.
3. **학원 일정 변경:** 이번 한 번의 날짜·시간 변경/휴강 또는 선택한 날부터 이후 반복 요일·시간 변경을 선택한다. 이전 일정과 다른 한 번의 변경은 유지한다. 학원 이름·주소·교재·숙제 등 공통 정보는 전체 학원의 정보임을 입력 화면에 명시한다.
4. **부모 요약:** 학생이 선택한 공부 흐름·시험/과제 공개 범위를 따른다. 학생 기록 요약은 읽기 전용이며, 기존 부모의 지원·응원·설정 기능은 계속 제공한다. 프로필을 바꾸면 화면도 즉시 바뀐다.

날짜와 반복 요일은 한국 날짜를 기준으로 계산한다. 저장 공간 부족 시 입력 중간 상태를 남기지 않도록 복원한다. 학원 변경은 주간/시간표, 오늘 한눈에, 이동 동선, 기존 수업 전 알림에도 같은 규칙을 적용한다.

## 기존 기록과의 호환

- 오늘 할 일은 기존 `compass-study-v1.tasks`에 저장한다. 명시한 마감은 기존 `fc_planner_v1.pri[taskId].due`에 저장하므로 기존 데이터 복원기가 추가 필드를 버리는 문제와 중복 완료 문제를 피한다.
- 학원 원본 `fc_academy_v1`은 유지한다. 날짜별 변경은 별도 `fc_academy_occurrences_v1`에 저장하고 가족 공유·백업에 포함한다. 최대 600개 변경 기록을 지원한다.
- 동일 날짜 변경의 기기 충돌은 `updatedAt`이 최신인 기록을 선택하며, 같은 시각은 동일한 결정 규칙으로 병합한다. 서로 다른 수업 변경은 함께 보존한다.
- 공개 범위는 기존 UI의 표시 설정이다. 가족 PIN으로 공유하는 전체 데이터의 서버 접근 권한을 분리한 기능은 아니다.
- 부모 화면이 만료된 학생 타이머를 자동 완료하거나 학생의 우선순위·집중 기록을 생성하지 않는다. 학생 화면에서는 만료된 타이머를 처음 열 때도 한 번 기록한다.

## 참고와 분석 범위

- [MyStudyLife 공식 기능 안내](https://mystudylife.com/tour/): 오늘 대시보드, 시간표·과제·시험, 반복 과제 구조.
- [TickTick 공식 기능 안내](https://ticktick.com/features): 간단한 작업 등록과 완료 흐름. 이번 구현은 명시적인 3개 입력 항목을 사용하며 자연어 날짜 해석은 추가하지 않았다.
- [TimeTree 공식 반복 일정 안내](https://support.timetreeapp.com/hc/en-us/articles/204010389-How-to-add-recurring-events): 반복 일정 변경 범위를 나누는 방식.

화면과 코드는 ApuDa의 기존 앱에 맞춰 작성했다. 위 서비스의 비공개 서버 구조나 로그인 이후의 실제 동작을 재현했다고 주장하지 않는다.

REA 6.4.0 CLI로 MyStudyLife의 공개 `flutter_bootstrap.js`, `main.dart.js`, `app.js`를 확보했다. 로컬 상세 분석은 환경의 `ps` 프로세스 소유권 확인 기능이 지원되지 않아 중단됐다. `Future Compass REA reference analysis` 워크플로는 Ubuntu/Node 24 환경에서 같은 공개 파일의 정적 분석을 다시 실행하고, 파일 URL·SHA-256·분석 상태·근거 ID·제한을 담은 `rea-mystudylife-summary`만 보관한다. 로그인, 앱 실행, 외부 변경과 제3자 스크립트 수집은 수행하지 않는다. 최신 분석 상태는 해당 워크플로 결과를 확인한다.

## 검증

`node future-compass/scripts/check.mjs`에 새 검사를 연결했다. 기존 배포와 함께 다음을 검사한다.

- 실제 3개 항목 제출, 마감 저장·복원·완료, 최대 3개 요약, 제목 이스케이프, 저장 실패 복원.
- 다음 일정, 휴업일, 날짜 전환, 한국 날짜 및 UTC/서울/LA/오클랜드에서의 반복 일정 일치.
- 1회/이후 일정 변경, 이동, 휴강, 적용 경계, 중복 방지, 백업 왕복·이전 백업·되돌리기.
- 부모 공개 범위·프로필 전환·자동 쓰기 방지와 학생 타이머의 1회 완료.
- 기기 간 오프라인 변경 병합, 최신 변경과 동일 시각 충돌의 수렴.

브라우저의 실제 화면·모바일 기기에서의 시각 검증은 이 환경에서 수행하지 않았다. 공개 주소의 파일 반영과 자동 배포 상태는 별도로 확인한다.
