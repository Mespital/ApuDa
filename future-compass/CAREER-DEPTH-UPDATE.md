# 진로탐색기 v2 업데이트
날짜: 2026-10-04 KST

## 반영된 개선
- 세부 관심 14개: 휴대폰 디자인·성능 비교·작동 원리·설명·수리·앱 제작 + 언어·콘텐츠·돌봄·환경·실험·안전·공간·장비.
- 좋아하는 과목 / 자신 있는 과목 / 더 배울 과목 분리. 성적 입력 없음. 자신 있음은 학습 시작점, 배우고 싶음은 목표로 표시.
- 10개 분야 결과 중 3개 먼저 표시, 나머지 7개 확장. 선택 없는 상태는 개인화 아닌 기본 순서라고 명시.
- 분야별 3개 역할 총 30개: 실제 업무, 하루 예시, 관련 전공·과목·학습 순서, 30분 체험, 자동화 후보와 사람의 판단을 각각 제공.
- 개별 직업 2개 비교. 분야 이름만 비교하던 기존 흐름에서 실제 역할 비교로 개선.
- 체험 재미 / 다시 해볼 마음 / 어려움 / 다음 질문을 저장. 긍정 체험은 분야별 1점만 더하고 부정 체험은 배제·감점하지 않음.
- 분야별 10·20·30년 준비 질문, 확산 조건, 이동 가능한 역량. 확정 전망·수요 예측·진로 보장 아님.
- 실제 학생 사용 점검 과제와 기기 내 피드백 기록. 외부 제출·모집·실사용 평가를 수행한 것으로 표시하지 않음.
- 다중선택 후 키보드 초점 유지, 깊은 링크의 스크립트 실행 순서 정리, 캐시 v8.

## 자체 정렬 규칙
직접 주제 3 + 겹치는 활동마다 2 + 좋아하는 과목마다 1 + 연결된 세부 관심마다 2 + 긍정 체험 분야 1.
긍정 체험: 재미있음과 다시 해보고 싶음을 동시에 선택. 같은 분야에 여러 긍정 체험을 적어도 1점.
동점은 기본 분야 순서. 현재 자신 있는 과목, 배울 과목, 일하는 방식, 부정 체험으로 순위를 변경하지 않음.
가중치는 심리측정으로 검증된 수치가 아니다. 의미는 탐색 순서 정렬에 한정한다.

## 민감도 분석
주제·활동·과목 가중치를 (3,2,1), (2,3,1), (3,1,2)로 변경한다. 세부 관심과 체험은 고정.
첫 세 후보의 순서를 비교하고 일치/변동을 화면에서 알려준다. 입력 없는 상태에는 분석 신뢰도를 언급하지 않고 기본 순서임을 알린다.
세 가지 조합은 제한적인 설계 점검이며 통계적 신뢰도·적성 안정성·전체 가능한 가중치 범위를 검증한 것은 아니다.

## 검증
기존 8화면, 뉴스 URL·본문 검증, 개인화 홈·응원 회귀 검사.
10유형 입력, 선택 없음, 4단계, 30역할 상세, 처음 3개/전체 10개, 과목 분리, 세부 관심 연결, 체험 재정렬, 감점 없음, 두 직업 비교, 저장·삭제, 메모 escaping 검사.
실제 학생 10명 실험은 아직 수행하지 않았다. 실행 과제·평가 기록 형식을 제공하고 실제 모집·관찰 후 만족도·성공률을 계산한다.
