# 승준 공부방 기출 학습 · 2026-11-20

승준 공부방의 오늘·복습 카드와 전체 메뉴에서 `gichul/index.html`을 엽니다. Netlify 기존 설정의 base는 `future-compass`, publish는 `dist`, build는 `node scripts/check.mjs`입니다.

## 제공 범위

- 8개 영역, 공통을 포함한 41개 학습 항목: 국어 3, 수학 4, 영어 1, 한국사 1, 사회탐구 9, 과학탐구 8, 직업탐구 6, 제2외국어·한문 9.
- 1994~2027학년도 공식 자료 링크 771개. 2027학년도 정답은 가안으로 표시합니다. 과거 ZIP은 여러 과목 묶음이며 전부 문항 단위로 전사한 자료가 아닙니다.
- 실제 기출 상세 풀이: 2022~2026학년도 수학 각 1·2번, 총 10문항. 정답표와 계산 대조 메타데이터를 포함합니다.
- 개념 정리 148개, 자체 구성 기본 연습 130문항. 수학·국어·영어의 18개 유형은 수치 또는 지문을 변형합니다. 탐구·외국어 등 고정 문제 은행은 실제 3~4문항 범위에서 중복 없이 출제하며, 한 유형에 1문항만 있으면 같은 개념 재연습으로 표시합니다.
- 과목별 전체 교육과정 완성, 최근 10년 전 문항 해설 완성, 실제 출제 가능성이나 난도 통계 분석을 의미하지 않습니다. 과거 교육과정의 동일 과목명도 현행 범위와 자동으로 동일시하지 않습니다.

## 데이터와 검증

`content/csat/*.json`이 자체 구성 문항·개념의 편집 원본입니다. `node scripts/build-csat-content.mjs`로 `dist/gichul/content.mjs`와 `data/coverage.json`을 다시 생성합니다. 공식 원문은 평가원 원문으로 연결하며 제3자 유료 해설을 복제하지 않습니다.

`node scripts/check.mjs`는 기존 공부방 검사와 `check-csat.mjs`를 실행합니다. 변형 22,400건의 정답을 별도 공식으로 계산하고 수식 렌더링, 전 과목 문제 수·정답 구조, 백업 중복 병합, 화면 렌더링, 보호자 읽기 전용, 기존 학습 저장소 보존을 확인합니다.

## 기존 공부방과의 연결

같은 출처의 PIN·역할을 재사용합니다. 기출 학습은 `gichul-lab-study-v1`에만 저장하며 기존 시간표·메모 저장소를 변경하지 않습니다. 보호자 역할에서는 채점·오답·메모·자료 저장·복원을 쓰지 않습니다. 새 기출 기록은 기기별로 저장되고 JSON으로 옮길 수 있으며 기존 가족 자동 동기화 목록에는 추가하지 않았습니다.

새로운 키나 서버는 필요하지 않습니다. 정적 파일과 로컬 문제 구성 엔진을 배포합니다. 기존 서비스워커 캐시 버전을 올려 공부방 진입 메뉴를 갱신합니다. 원문·새 학습 화면 전체에 오프라인 사용을 보장하지 않습니다.
