# 승준 공부관리 방 — 디자인 점검표 (2026-10-20)

> 측정: 폰 화면(390×844), 예시 데이터, 승준 화면 10개. 화면 안 보이는 요소는 제외하고 계산함.
> 이 문서는 Codex·Claude 작업 지시서로 같이 씀. 항목마다 **근거 → 고칠 방법 → 완료 기준 → 담당**.

## 진행 상황 (2026-10-20)

P1-1(글자·모서리)·P1-2·P1-3(체크박스 제외)·P1-4·P1-5·P2-7(과목 색)·P2-10 완료. 나머지는 `docs/codex-handoff.md` 의 C1~C7 순서로 Codex가 진행.

## 한 줄 결론

기능은 충분하고, 디자인은 **규칙이 없어서 화면마다 제각각**인 상태야. 새 그림보다 먼저 ① 글자·색·모서리·버튼을 몇 단계로 통일하고 ② 작은 글자와 작은 터치를 없애고 ③ 긴 화면(설정·학교)을 줄이면 확 달라져.

## P1 — 먼저 (모든 화면에 영향)

### 1. 디자인 규칙(토큰) 하나로 통일
- **근거**: 오늘 화면만 글자 크기 18종(11.5·12·13·13.5·13.6·14·16·17px…), 글자색 21종, 모서리 12종, 그림자 7종. 13.5와 13.6처럼 구분 안 되는 값이 섞여 있음.
- **고칠 방법**: `dist/ui-system.css` 맨 위에 토큰 정의 → 각 화면 CSS가 토큰만 쓰게.
  - 글자: `--fs-xs 12.5 / --fs-s 14 / --fs-m 16 / --fs-l 18 / --fs-xl 22 / --fs-2xl 28`
  - 모서리: `--r-s 10px / --r-m 16px / --r-pill 999px`
  - 그림자: `--sh-1`(카드) `--sh-2`(떠 있는 시트) 2개만
  - 색: 글자 3단(`--ink`, `--ink-2`, `--ink-3`), 배경 3단, 강조 1색(보라 #5b3fd6), 상태 3색(완료 초록·주의 주황·시험 빨강)
- **완료 기준**: 화면별 글자 크기 ≤ 7종, 모서리 ≤ 3종, 그림자 ≤ 2종 (같은 측정 스크립트로 다시 재기).
- **담당**: Codex(대량 치환) → Claude 검토.

### 2. 작은 글자 없애기
- **근거**: 오늘 30곳(진행 링 "할 일 0" 11.5px), 기록 22곳(요일 11px), 기말 플랜 26곳("1회독" 12px), 학교 소식 23곳("이번 달" 12px).
- **고칠 방법**: 최소 12.5px, 정보 글자는 13.5px 이상. 진행 링 숫자는 크게, 라벨은 링 밖으로.
- **완료 기준**: 12.5px 미만 0곳. 큰 글씨 모드(설정)에서 줄바꿈 깨짐 없음.
- **담당**: Codex.

### 3. 터치 영역 44px
- **근거**: 설정 33곳(전화번호 링크 98×17), 오늘 29곳(컨디션 이모지 40×40, 💌 42×44), 학교 소식 25곳(필터 칩 157×42), 체크박스 24×24(복습·시험).
- **고칠 방법**: 버튼·링크·칩 최소 44×44(보이는 크기는 작아도 누르는 영역은 패딩으로 확보). 체크박스는 줄 전체를 누를 수 있게.
- **완료 기준**: 44px 미만 터치 0곳.
- **담당**: Codex.

### 4. 긴 화면 줄이기
- **근거**: 설정 7,904px(약 9.4화면, 카드 18개), 학교 소식 2,842px(카드 33개), 기말 플랜 2,463px.
- **고칠 방법**
  - 설정: 위쪽 바로가기 + 섹션을 접기(`details`)로. 자주 쓰는 3개(화면·알림·흰둥이)만 펼침.
  - 학교 소식: "지금 챙길 것" 요약 카드 1장 + 과목별 탭.
  - 기말 플랜: 날짜별 계획은 "이번 주"만 펼치고 나머지 접기.
- **완료 기준**: 설정 ≤ 3화면, 학교 소식 ≤ 2화면(펼치기 전 기준).
- **담당**: Claude(구조 변경이라 기능 영향 큼).

### 5. 오늘 화면 정리
- **근거**: 카드 20개, 제목 14개 중 9개에 이모지. 위쪽 첫 화면에 배너·3시간·할 일·시험 타일이 겹쳐 보임.
- **고칠 방법**: 첫 화면 = 배너 + 지금부터 3시간 + 오늘 할 일 3개까지만. 나머지는 "더 보기" 묶음. 제목 이모지는 아이콘 1세트로 통일(또는 제목에서 빼고 왼쪽 작은 아이콘).
- **완료 기준**: 첫 화면(844px) 안에 "지금 할 것"이 다 보임, 카드 ≤ 10개.
- **담당**: Claude 설계 → Codex 적용.

## P2 — 다음

### 6. 버튼 3종으로
- **근거**: 보라 꽉 찬 버튼, 테두리 버튼, 점선 버튼(📋 붙여넣기), 초록 버튼(길찾기), 알약 버튼이 화면마다 섞임.
- **고칠 방법**: `primary`(보라 꽉 참, 화면당 1개) · `secondary`(테두리) · `ghost`(글자만). 길찾기는 네이버 초록 유지(외부 서비스 표시).
- **완료 기준**: 모든 버튼이 3종 + 예외(길찾기) 안에 들어감.
- **담당**: Codex.

### 7. 과목 색 통일
- **근거**: 학교 소식 과목 라벨, 시간표, 주간 일정, 기말 플랜에서 같은 과목이 다른 색.
- **고칠 방법**: 과목 8개 색 토큰(`--sub-kor`, `--sub-math` …)을 한 곳에 두고 모든 화면이 같이 씀. 색만으로 구분하지 않고 과목명 글자 유지.
- **완료 기준**: 같은 과목은 어디서나 같은 색.
- **담당**: Codex.

### 8. 떠 있는 것 겹침
- **근거**: 화면 캡처에서 흰둥이 버튼·"궁금한 건 물어봐" 말풍선·화이팅 토스트·가운데 집중 버튼이 아래 내용과 겹침(주간·오늘).
- **고칠 방법**: 아래 메뉴 위로 안전 여백, 흰둥이 버튼은 스크롤 중 숨김(이미 있음) + 토스트는 위쪽으로.
- **완료 기준**: 어떤 화면에서도 버튼·글자 위에 떠 있는 것이 겹치지 않음(캡처 확인).
- **담당**: Claude.

### 9. 빈 화면 통일
- **근거**: "할 일 0", "아직 넣은 교과서가 없어", "일정 없음 · 🌿" 등 빈 상태 문구·모양이 제각각.
- **고칠 방법**: 빈 상태 = 작은 그림 1개 + 한 줄 + 버튼 1개 공통 컴포넌트.
- **완료 기준**: 빈 상태 모양 1종.
- **담당**: Codex + 그림은 아래 12번.

### 10. 글꼴 하나로
- **근거**: 오늘 화면에 Pretendard와 system-ui가 섞여 있음.
- **고칠 방법**: 폰은 Pretendard만. 태블릿 다이어리 제목만 Gowun Batang/Gaegu 유지.
- **완료 기준**: 폰 화면 글꼴 1종.
- **담당**: Codex.

### 11. 어두운 화면 다시 보기
- **근거**: 지난 감수에서 남색 팔레트·대비는 고쳤지만(axe 기준), 이번 점검표의 토큰을 바꾸면 다시 확인이 필요해.
- **완료 기준**: 1번 토큰 적용 후 밝게/어둡게 두 번 캡처, 대비 문제 0.
- **담당**: Claude 검증.

| 과목 아이콘 8개 | 96×96 투명 PNG 또는 SVG, 한 세트 같은 그림체 | 시간표·학교 소식·기말 플랜 | 제목 이모지 대체 |

| 계절 배너 배경 | 1080×480 JPG | 오늘 배너 | 지금 배너 그림과 톤 맞추기 |

- **규칙**: 앱 색(보라 #5b3fd6, 남색 #0f1229, 크림 배경)과 같은 톤, 글자 없는 그림, 투명 배경.

- **담당**: ChatGPT 이미지 생성(엄마) → 파일 전달 → Claude가 `dist/img/`에 넣고 연결.
