# 공부방 → ChatGPT → Drive 검증 기록

## 변경

- 1분 말하기/사진 노트에서 로컬 저장 후 녹음·사진·작성 글을 24시간 전달 자료로 준비한다.
- 채팅의 기존 Drive MCP로 원본과 새 복습 정리를 저장하고 결과를 공부방에 반환한다. Google Cloud 설정은 이 기본 경로에 필요하지 않다.
- 결과를 받기 전에는 저장 완료로 표시하지 않는다. 원문·복습 날짜는 보존하고, 그사이 바꾼 노트는 확인 후 정리를 반영한다.
- 설정/복습에서 학습 기록 JSON을 별도로 전달한다. 녹음·사진 원본 및 계정·연락처·위치 설정은 해당 백업에 포함하지 않는다.

## 검증

| 범위 | 방법 | 확인 |
|---|---|---|
| 정적/기존 동작 | check.mjs와 모든 check-*.cjs/mjs | 구문·132개 SW 자산·기존 가족/복습/백업 기능 |
| 전달 서버 | check-study-handoff.mjs, 메모리 저장소 | 역할별 키 분리, 원본 크기/SHA-256, 한국시간 이름, 응답 유실 재시도, 결과 형식·해시 검증, 다른 결과 덮어쓰기 거절, 만료 및 고아 결과 정리 |
| 통합 | audit-study-chat-drive.mjs | 실제 앱/HTTP 처리기/MediaRecorder → 원본 다운로드 → 결과 POST → 재접속 후 노트·복습·녹음 링크 반영 |
| 변경 충돌 | 전달 뒤 저장한 정리를 수정 | 수정 내용 보존, 확인 버튼으로만 교체 |
| 실패/권한 | 응답 유실, 공유 미허용 엄마 화면, PIN 잠금 | 중복 전달 없음, 비공개 노트 접근/결과 반영 차단, 열린 결과창 즉시 닫기 |
| 모바일·테마 | 360/390/820/1180px × 밝게/어둡게 | 가로 넘침 없음, 44px 조작 영역, 본문 명암비 ≥4.5:1, 복사 실패 시 전체 요청 선택 |
| 기존 녹음 | audit-audio-vault.cjs | 실제 WebM, 60초 중지, IDB 복구, 직접 Drive 재시도, 권한 오류 |
| 기존 직접 붙여넣기 | audit-talk-note.cjs | 글만 보내기, 긴 요청·클립보드 오류, 받아쓰기, 일정·복습 질문, 16개 화면 조합 |

통합 테스트의 Drive 쓰기는 로컬 fixture다. 배포된 Netlify Blobs와 실계정 Drive MCP 검증은 PR의 운영 확인 결과로 별도 기록한다. 테스트 자료에는 가족 실제 기록을 사용하지 않는다.

## 운영 경계

- 기존 외부 Netlify 사이트를 ChatGPT Sites로 바꾸지 않는다. 현재 도구 목록에 Sites plugin eligibility 조회가 없어 해당 경로는 사용하지 않았다.
- 일반 Chat 링크가 ChatGPT 모드를 강제로 바꾼다는 보장은 없다. 실제 모드는 사용자가 확인한다.
- ChatGPT에 원본 다운로드/결과 POST 도구 및 Drive 쓰기 권한이 있어야 이 전달을 끝낼 수 있다. 실패한 단계는 완료로 안내하지 않도록 요청에 명시한다.
- 사이트는 반환 결과를 검증하지만 Google에 독립적인 재인증 조회를 하지는 않는다. Drive 실제 저장 확인은 채팅의 MCP 조회가 담당하며, 파일 링크를 함께 제공한다.
- 비밀 전달 링크는 24시간 동안 그 자료만 읽을 수 있다. 만료 접근은 즉시 거절하며 예약 정리가 시간당 최대 500건을 정리한다.
- 기존 저장 키와 원본 보관 방식을 유지한다. 전달 작업 키는 가족 공유/백업 목록에 넣지 않는다.
