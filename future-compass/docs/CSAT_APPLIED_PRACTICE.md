## 학습 흐름

`#practice/<현재 과목 ID>`로 해당 과목의 응용 연습을 바로 열 수 있습니다. 연습 구성·영역·과목·유형·문항 수를 고르고, 등록된 문제 안에서 중복 없이 묶습니다. 응용 모드는 과목별 2문항이므로 1·2문항만 선택할 수 있습니다. 다시 시작해도 보기 순서만 바꾸어 신규 문항을 생성한 것으로 세지 않습니다. 기존 수치·제한된 독해 틀 변형 및 기초 문항은 `기본 연습·유형 변형`에서 계속 이용합니다.

응용문제에는 조건 적용·자료 비교·역추론·상황 판단을 사용했습니다. 문항마다 힌트, 3단계 이상의 풀이, 두 가지 이상의 오개념, 다섯 선택지 각각의 해석을 제공합니다. 영어·제2외국어·한문에는 한국어 전체 해석과 어휘를 제공하고 아랍어 지문은 RTL(오른쪽에서 왼쪽)로 표시합니다. 학습 단계와 배점은 자체 연습용이며 실제 수능 난도·변별도 검증 결과가 아닙니다.

화면의 `기출에서 확인한 학습 근거`는 같은 대표 개념으로 분류한 실제 기출 위치의 수·학년도·최신 문항을 표시합니다. `유형 분석 보기`는 해당 과목·유형을 선택하며, 원문 버튼은 기존 전체 시험지 뷰어의 쪽·문항 좌표로 이동합니다. 한 유형에 기초 주제가 여러 개 연결되어도 동일 기출 문항을 합계에서 중복하지 않습니다. 자체 응용문제가 특정 기출을 직접 변형하거나 공식 해설을 사용했다는 뜻이 아닙니다. 규칙 보조 분류를 포함하며 과거 문항 수를 미래 출제 확률로 표현하지 않습니다.

## 데이터와 기록

`applied-content.mjs`의 82개 문항을 기존 `content.mjs`의 130개 뒤에 추가합니다. 과거 문항 ID·답 인덱스·저장 키는 유지합니다. `practiceSet: "type-linked"`로 응용 문항을 구분합니다. 기존 두 인자 `practiceInfo`와 기존 생성 옵션은 기본 모드로 호환되며, 새 옵션은 `practiceMode: "applied"`입니다. 동일 seed에서는 같은 구성·순서를 반환합니다.

응용 묶음은 `originId`를 유지합니다. 백업·복원은 기존 스키마를 사용하고 개인 분석에서는 동일 자체 문항의 반복 풀이를 최신 1회로 묶습니다. 해설을 먼저 본 채점은 정답률에서 제외합니다. 보호자는 문제와 해설을 미리 볼 수 있으나 채점·메모·북마크를 저장하지 않습니다. 오늘·복습 화면에는 수능 카드를 넣지 않습니다. 기존 StudyLab·PromptLab 메뉴와 서비스워커 캐시 목록을 보존합니다.

## 검증과 한계

- 8개 신규 검사는 과목별 2문항, 단일 정답 인덱스, 문항별 해설, 실제 유형 연결, 보유 수 한도, 중복 방지, 결정적 생성, 유형 합계 중복 제거, 안전한 빈 화면과 HTML 이스케이프, 모드 변경, 반복 origin의 개인 분석 및 백업 멱등성을 확인합니다.
- 수치 문항 33개는 문항 내 가정에서 독립 식·열거·부분합·좌표 등으로 재계산하여 정답 선택지와 비교합니다. RNA는 역상보 서열을 계산하며 수식은 KaTeX로 검증합니다.
- 실제 앱 실행 검사에서 41개 과목·212개 문항 화면, 새 과목별 경로와 응용 묶음, 풀이·오답·번역 및 유형 분석 연결을 확인합니다. 기존 유형 검사 31개와 생성기 22,400사례 및 가족·기록·백업 회귀 검사를 함께 실행합니다.
- Chrome에서 수학의 직접 풀이·보호자 채점·선택지 해석·유형 선택 이동, 모바일 아랍어 RTL·전체 번역·어휘를 점검합니다. 모바일 해설 탭의 가로 넘침은 그리드 최소 너비와 내부 스크롤을 조정해 보정합니다.
- 원전·정부·공식 교육 자료는 개념 확인용입니다. 실제 사례 수치·대화·지문은 자체 구성입니다. 외부 전문가나 원어민의 전수 감수, 실제 학습자에 의한 난도·변별도 보정은 시행하지 않았습니다.
