## 2. Codex에 넘기는 것 (순서대로)

공통 조건(모든 지시문 끝에 붙이기):
```
- 저장소 Mespital/ApuDa, 폴더 future-compass. 정적 앱(dist/), 빌드 없음.
- 기능·문구·데이터 저장 키(localStorage 키 이름)는 바꾸지 마.
- 색·크기는 dist/ui-system.css 의 토큰(--fs-*, --r-*, --sh-*, --ink*, --accent, --ok, --warn, --exam, --tap)을 써.
- 밤 화면은 dark-mode.js 가 색을 자동 변환해. 새 색은 :root 토큰으로만 추가해.
- 파일을 새로 만들면 dist/sw.js 의 ASSETS 에 넣고, CACHE 이름 버전을 올려.
- node future-compass/scripts/check.mjs 와 future-compass/scripts/check-*.cjs/.mjs(저장소 루트에서 실행)가 모두 통과해야 해.
- PR 설명에 바꾼 파일, 전후 차이, 확인 방법을 적어줘.
```

### C1. 색 토큰 정리 (P1-1 남은 것)
- 현재: 오늘 화면 글자색 18종, 배경 16종, 그림자 7종.
- 지시: "dist/*.css 와 dist/*.js 인라인 스타일의 글자색·배경색을 ui-system.css 토큰(--ink, --ink-2, --ink-3, --accent, --ok, --warn, --exam, --u-soft, --u-line)으로 바꿔줘. 비슷한 색(예: #6b6880·#667085·#57546a)은 하나로. 그림자는 --sh-1(카드)·--sh-2(시트·떠 있는 것) 두 개만."
- 완료 기준: 화면별 글자색 ≤ 8종, 그림자 ≤ 2종.

### C2. 체크박스 44px (P1-3 남은 것)
- 현재: 할 일·시험·복습 체크박스가 24×22로 작음(라벨에 안 싸인 것).
- 지시: "체크박스를 줄 전체를 누를 수 있는 공통 컴포넌트로 바꿔줘. 체크박스 자체는 22px 원형 유지, 누르는 영역은 44px 이상. 키보드(스페이스)·스크린리더 동작은 그대로."
- 완료 기준: 44px 미만 터치 0곳.

### C3. 버튼 3종 (P2-6)
- 지시: "버튼을 primary(보라 꽉 참, 화면당 1개), secondary(테두리), ghost(글자만) 세 클래스로 정리하고 ui-system.css 에 정의해줘. 기존 button.primary 는 primary 로, 점선 버튼(.dt-more, [data-tn-paste])은 secondary 로. 네이버 길찾기(.nx-map) 초록은 예외로 유지."
- 완료 기준: 모든 버튼이 3종 + 길찾기 예외.

### C4. 과목 색 통일 (P2-7) — ✅ 대부분 끝남. 남은 것: 주간 일정 수업 줄에 `window.FC_SUBJECT_KEY` 적용
- 지시: "과목 색 토큰 8개(--sub-kor 국어, --sub-math 수학, --sub-eng 영어, --sub-soc 사회, --sub-sci 과학, --sub-his 한국사, --sub-art 예체능, --sub-etc 기타)를 ui-system.css 에 만들고 school-live.js(과목 라벨), exam-plan.js, study-week.js(시간표), app-ui.js(주간 일정)가 같은 함수로 색을 고르게 해줘. 과목명 글자는 그대로 보이게(색만으로 구분하지 않기)."
- 완료 기준: 같은 과목은 어느 화면에서나 같은 색.

### C5. 빈 화면 공통 모양 (P2-9)
- 지시: "할 일 없음·교과서 없음·일정 없음·기록 없음 빈 상태를 공통 함수 emptyState(icon, text, buttonLabel, action)로 통일해줘. 그림 자리는 dist/img/empty-*.png 를 쓰고, 파일이 없으면 이모지로 대신."
- 완료 기준: 빈 상태 모양 1종.

### C6. 제목 이모지 → 아이콘 (P1-5·P3)
- 현재: 오늘 화면 제목 14개 중 10개, 설정 28개 중 12개에 이모지.
- 지시: "카드 제목 앞 이모지를 dist/img/icons/*.svg 한 세트(선 두께 1.75, 20px, currentColor)로 바꿔줘. 아이콘 파일이 없는 제목은 이모지 유지."
- 의존: 아이콘 세트(아래 3번) 먼저.

### C7. 떠 있는 버튼 겹침 (P2-8)
