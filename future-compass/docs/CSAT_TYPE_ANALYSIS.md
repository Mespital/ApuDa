# 수능 전 과목 유형 분석 · 2026-11-21

수능 학습 메뉴에서 공식 기출의 구성과 개인 풀이 기록을 살펴봅니다. 오늘·복습 화면에는 수능 카드를 추가하지 않습니다. 기존 가족 PIN·동기화·저장 기록·백업·보호자 읽기 전용을 유지합니다.

## 원문 수록 범위

최근 10개 학년도인 2018~2027의 원문 위치 색인은 총 9,302건입니다. 현행 41개 학습 항목과 과거 국어·수학 3개, 과거 직업탐구 5개의 분석 전용 범위를 구분합니다.

이 수는 과목·시험 체계·문항 번호별 출제 위치입니다. 국어·영어·수학·한국사는 홀수형 한 회를 집계하고 합본의 짝수형을 제외합니다. 탐구·제2외국어·한문은 단일형의 실제 문항을 한 회씩 셉니다. 서로 다른 과목·선택과목의 전체 합계를 한 수험생의 문항 수로 해석하지 않습니다.

국어는 2018~2021 단일 시험 180건, 2022~2027 공통 204건·화법과 작문 66건·언어와 매체 66건입니다. 수학은 2018~2021 가형 120건·나형 120건, 2022~2027 공통 132건·선택과목별 48건입니다. 현행 공통 문항은 선택과목마다 중복하지 않습니다. 과거 가·나형에 같은 내용이 실렸으면 각 형의 출제 위치에서 한 번씩 셉니다.

직업탐구는 현행 선택 5과목의 10개 학년도 1,000건, 성공적인 직업생활의 2022~2027 120건, 과거 5과목의 2018~2021 400건입니다. 성공적인 직업생활이 없던 2018~2021에 문항을 만들지 않습니다. 농업 이해·기초 제도·회계 원리·해양의 이해·생활 서비스 산업의 이해는 현행 과목과 섞지 않습니다. 과거 항목은 분석과 원문 열람에 사용하며 연습문제 생성 과목을 늘리지 않습니다.

## 분류 상태와 분모

기존 국어·수학·영어·한국사·사회·문화·생활과 윤리의 2,082건에 더해 7,220건의 원문 위치를 추가합니다. 새 과목은 발문·자료의 규칙 보조 분류와 개별 원문 대조를 함께 사용합니다. 전체를 전문가가 수동 검토한 것으로 표시하지 않습니다.

문항별 상태는 `reviewed`(개별 원문 대조), `rule-assisted`(발문·자료 규칙 보조), `needs-review`(추가 대조 필요)입니다. 미확정 문항은 typeId와 unit을 null로 보존하며, 원문 연결은 제공하되 구성 비중의 분자·분모에서 제외합니다. 화면에 전체 원문 색인 수와 유형이 분류된 수를 구분하고 선택 과목·학년도의 추가 검토 목록을 표시합니다. 실제 분류·미확정 건수는 생성 JSON의 scope.classifiedCount·pendingCount 및 화면에서 확인합니다.

유형별 비중은 과목·학년도·단원 필터에서 분류한 문항 수를 분모로 계산합니다. 유형 선택은 근거 문항 목록을 좁히며 구성표의 분모를 바꾸지 않습니다. —는 해당 연도에 집계된 문항이 없다는 뜻입니다. 전체 과목에서는 상위 40개 유형의 구성표와 연도 비교를 표시해 모바일 DOM 크기를 제한합니다. 과목을 선택하면 해당 과목의 전체 유형을 봅니다.

학습 단원은 서로 다른 교육과정의 문제를 탐색하기 위한 묶음입니다. 공식 교육과정의 동일 단원 코드로 간주하지 않습니다. 복합 문항에는 대표 주제 하나를 부여하고 발문 형식을 별도 표시합니다. 사상가·문항 번호만으로 같은 유형을 부여하지 않습니다. 실제 PDF 파일명과 학년도를 유지해 물리Ⅰ/물리학Ⅰ, 법과 정치/정치와 법 등의 변경을 확인할 수 있습니다.

분류는 평가원의 공식 유형 통계가 아닙니다. 원문 배점은 추정 난도·정답률이 아니며 과거 비중은 다음 시험 출제 확률이 아닙니다. 이번 확장으로 공식 기출의 앱 내 정답·풀이·해설 수를 증가시킨 것으로 표시하지 않습니다.

## 기존 분석과 개인 기록

국어는 발문·지문 묶음·선택지를 대조한 29개 대표 평가 유형을 과목별 52개 유형으로 나눕니다. 매체 속 문법과 매체의 언어 표현을 구분합니다. 수학은 28개 대표 개념을 과목별 67개 유형으로 나누고, 영어는 듣기·독해 발문과 공통 발문에 따른 31개 유형입니다. 한국사는 7개 학습 시대와 11개 대표 주제를 조합한 23개 유형 및 별도 발문 형식입니다. 사회·문화는 5단원·27유형, 생활과 윤리는 6단원·21유형입니다.

기존 수학의 공식 문제·정답·풀이 대조 10건은 같은 출제 위치에 풀이 링크만 연결해 다시 더하지 않습니다. 기초 연습은 의미가 맞는 공식 유형에 연결합니다. 같은 유형에 기초 연습 주제가 여러 개면 연결된 한 주제로 연습할 수 있으며, 모든 기출 쟁점을 다루는 연습으로 간주하지 않습니다.

개인 분석은 해설을 먼저 본 풀이를 제외하고 동일 원문 문제의 최신 채점만 집계합니다. 자체 문제의 반복 출현은 originId로 한 번만 계산합니다. 정오는 실제 답 인덱스로 재계산하며 3문항 미만 유형은 비율 대신 오답 횟수를 표시합니다. 남은 오답이 많은 순서로 제안하되 능력 점수나 공식 정답률을 추정하지 않습니다. 분석은 저장 기록을 쓰지 않으며 보호자 화면도 읽기 전용입니다.

## 원문과 재생성

공식 원문은 평가원의 등록 자료 ID와 PDF 파일 ID로 연결합니다. PDF·지문·선택지·추출 텍스트·OCR 전문을 저장소 결과물에 복제하지 않습니다. 각 문항에 학년도·과목·번호·쪽·좌표·배점·유형·검토 상태를 저장하고, 각 PDF에 실제 파일명·SHA-256·쪽 크기를 저장합니다. 그림 속 글은 필요한 경우 로컬 OCR로 보완한 후 일부 사례의 렌더링을 대조했습니다. OCR 결과는 임시 검토 자료입니다.

추가 과목의 검토 원장은 `scripts/data/csat-extended-social-review.json`, `csat-science-type-review.json`, `csat-vocation-type-review.json`, `csat-language-type-review.json`입니다. 각 파일에 단원·유형·기초 연습 연결, 실제 문항별 분류 상태·근거와 검토 한계, 원문 SHA-256을 기록합니다. 생성 결과는 각각 `extended-social-type-analysis.json`, `science-type-analysis.json`, `vocation-type-analysis.json`, `language-type-analysis.json`입니다. 기존 다섯 데이터 파일과 합쳐 사용하며, 한 영역의 로딩 실패가 다른 영역의 분석을 지우지 않습니다.

PyMuPDF(fitz)가 설치된 환경에서 실행합니다.

```sh
python scripts/build-csat-analysis-data.py --cache-dir /tmp/csat-type-analysis
python scripts/build-csat-math-analysis-data.py --cache-dir /tmp/csat-math-analysis
python scripts/build-csat-korean-analysis-data.py --cache-dir /tmp/csat-korean-analysis
python scripts/build-csat-history-analysis-data.py --cache-dir /tmp/csat-history-analysis
python scripts/build-csat-social-analysis-data.py --cache-dir /tmp/csat-social-analysis
python scripts/build-csat-extended-analysis-data.py --cache-dir /tmp/csat-extended-analysis
node scripts/check-csat-analysis.mjs
node scripts/check.mjs
```

추가 과목 빌더는 `--group social|science|vocation|languages`로 한 영역만 갱신할 수 있습니다. 원문 해시 변경, 누락·중복 번호, 학년도·과목 범위 위반, 50점 합계 불일치, 잘못된 유형·검토 상태가 있으면 중단합니다. 제2외국어·한문은 표시된 1점과 기본 2점을, 탐구는 표시된 3점과 기본 2점을 구분합니다. 2027 농업 기초 기술 11번의 2.28pt 들여쓰기와 2018의 다른 페이지 크기를 허용하되 두 열과 문항 번호 글꼴을 함께 검증합니다. 공통 지문의 머리말을 기준으로 문항 영역을 나누어 이웃 문항 배점의 혼입을 막습니다.

ZIP의 CP949 파일명을 복원하고 이름·CRC·파일 크기에서 기존 PDF 파일 ID를 계산합니다. 같은 ZIP은 한 번 내려받고 개별 과목으로 분리합니다. 개별 PDF는 fileId가 모두 paper일 수 있으므로 캐시 이름에 과목 ID를 포함합니다. 캐시·OCR 모델·원문 이미지는 git에 넣지 않습니다. Netlify는 생성된 JSON을 읽으며 Python이나 외부 생성 API 키가 필요하지 않습니다.

## 검증

31개 유형 분석 검사는 기존 분류 회귀 검사와 전 과목 원문 9,302건·현행 41개·역사적 8개 범위, 새 PDF 316개의 번호·쪽·좌표·배점·SHA 형식, 미확정 문항의 분모 제외, 파일별 로딩 실패, 기초 연습 연결과 저장 기록 보존을 포함합니다. 실제 앱 경로 검사에서는 모든 현행 과목의 분석 바로가기, 과학·직업·제2외국어/한문 원문 페이지와 강조 위치 전달, 보호자 읽기 전용을 확인합니다. 별도의 표본 원문 검토는 확인한 범위와 한계를 기록하며 전수 의미 검토로 표시하지 않습니다.
