# 수능 유형 분석 · 2026-11-21

수능 학습 메뉴의 ‘유형 분석’에서 기출 문항 구성과 이 기기의 채점 기록을 확인합니다. 오늘·복습 화면에는 수능 카드를 추가하지 않습니다. `gichul/index.html#analysis/korean-common`과 `#analysis/math-common`은 해당 공통 과목의 분석을 바로 엽니다.

총 1,482건(국어 516·영어 450·수학 516)은 형·과목별 출제 위치 기준입니다. 홀수형 한 회만 집계하며 합본의 짝수형을 제외합니다. 가·나형에 같은 내용이 출제되었으면 각 형에서 한 번씩 계산합니다. 현행 공통 문항(국어 34·수학 22)은 선택과목마다 중복하지 않습니다. 따라서 국어의 현행 한 학년도 전체 합계 56건, 수학의 합계 60건(2018~2021) 또는 46건(2022~2027)은 한 수험생의 시험 문항 수를 뜻하지 않습니다. 국어는 공통 34문항과 선택 11문항을 합해 수험생당 45문항입니다. 서로 다른 시험 체계와 과목을 동일 교육과정으로 간주하지 않습니다.

국어는 발문·지문 묶음·선택지를 대조한 29개 대표 평가 유형을 과목별 52개 유형으로 나눕니다. 독서·문학 각 162, 화법 30, 화법·작문 통합 46, 작문 30, 문법 50, 매체 36문항입니다. 2018~2021 국어 전체와 현행 세 과목을 별도로 집계합니다. 현행 언어와 매체 35~39번은 문법, 40~45번은 매체이며, 매체 속 조사·어미 등을 묻는 문항은 ‘매체의 언어 표현’으로 구분합니다. 예를 들어 언어와 매체 35번은 2022학년도 단어·형태소, 2026학년도 음운, 2027학년도 문장 구조를 평가하므로 번호를 기준으로 분류하지 않습니다.

영어는 발문과 공통 발문을 대조한 31개 유형입니다. 수학은 발문·조건·수식을 대조한 28개 대표 개념을 과목별로 나눈 67개 유형입니다. 복합 문항에는 대표 개념 하나를 부여합니다. 평가원이 공표한 공식 유형 통계가 아니며, 배점은 원문 배점이지 추정 난도가 아닙니다. 예를 들어 수학 공통 2번은 2023학년도에 함수의 극한, 2027학년도에 미분계수입니다. 16번도 2025학년도와 2026학년도에서 유형이 달라집니다. 번호만으로 매년 같은 유형이라고 가정하지 않습니다.

기존 수학 문제·정답·풀이를 대조한 10문항은 동일한 출제 위치에 풀이 링크만 연결합니다. 전체 분류에 다시 더하지 않으며, 새 분류의 유형·출처·쪽·좌표를 유지합니다. 국어의 기존 기초 연습 12개 주제도 해당 공식 기출 유형에 연결합니다. 41개 현행 학습 항목을 유지하고 한국사·탐구 등 공식 기출 유형 분류가 없는 범위를 표시합니다. 과거 국어 전체·수학 가형·나형의 세 항목은 분석에만 추가하며 연습문제 생성 과목을 늘리지 않습니다.

## 집계와 학습 기록

기출 비중은 과목·학년도·단원 필터에서 분류한 문항 수를 분모로 씁니다. 유형을 선택하면 근거 문항만 좁혀 보여 주며 구성표의 분모를 바꾸지 않습니다. 학년도 비교의 —는 해당 범위에 집계 문항이 없다는 뜻입니다. 비중은 소수점 첫째 자리까지 표시하며, 다음 시험의 출제 확률이 아닙니다. 수학 자료 로딩에 실패하면 기존 10문항 표본만 표시합니다. 국어 자료 로딩에 실패하면 국어 공식 유형 집계를 표시하지 않고 오류를 알립니다. 어느 경우에도 전체 516건을 불러온 것처럼 표시하지 않습니다.

개인 분석은 해설을 먼저 본 풀이를 제외하고 동일 원문 문제의 최신 채점만 집계합니다. 여러 자체 연습 묶음에 나온 같은 원문은 originId로 한 번만 계산합니다. 정오는 선택한 답과 실제 정답 인덱스로 재계산합니다. 유형별 3문항 미만 기록은 비율 대신 오답 횟수를 표시합니다. 남은 오답이 많은 순서로 복습을 제안하며, 능력 점수·공식 정답률을 추정하지 않습니다. 연결된 기초 연습은 해당 유형의 일부 개념을 연습하는 자료입니다.

기존 저장소·백업 형식·가족 동기화·PIN을 유지합니다. 분석 과정은 학습 기록을 쓰지 않으며 보호자 화면에서도 읽기 전용입니다.

## 출처와 재생성

`dist/gichul/data/type-analysis.json`은 영어 450건, `math-type-analysis.json`과 `korean-type-analysis.json`은 각각 516건입니다. 등록 자료 ID·선택 PDF 파일 ID·SHA-256·쪽·발문 좌표·유형 메타데이터를 저장합니다. 국어 원문 PDF 10개와 수학 14개를 대조했으며 PDF 본문·지문·선택지는 저장소 결과물에 복제하지 않습니다. ‘시험지에서 보기’는 등록된 원문의 해당 쪽과 문항 위치를 엽니다. 국어 과거 시험은 국어 자료실로 연결합니다.

PyMuPDF(fitz)가 설치된 환경에서 다음을 실행합니다.

```
python scripts/build-csat-analysis-data.py --cache-dir /tmp/csat-type-analysis
python scripts/build-csat-math-analysis-data.py --cache-dir /tmp/csat-math-analysis
python scripts/build-csat-korean-analysis-data.py --cache-dir /tmp/csat-korean-analysis
node scripts/check-csat-analysis.mjs
node scripts/check.mjs
```

수학·국어 재생성은 `scripts/data/csat-math-type-review.json`과 `csat-korean-type-review.json`의 문항별 분류와 원문 SHA-256을 사용합니다. 원문이 달라지거나 번호·범위가 일치하지 않으면 새 검토를 요구하며 중단합니다. 국어 선택과목은 PDF 텍스트 추출 순서가 아닌 머리말의 실제 좌표에서 판별하고, 매체 지문 안의 번호 목록을 문항으로 세지 않습니다. 원문 임시 캐시는 git에 넣지 않습니다. Netlify는 생성된 JSON을 읽으므로 Python 패키지·외부 생성 API 키가 필요하지 않습니다.

검사는 영어 450건·수학 516건·국어 516건의 번호 범위·홀수형·출처·좌표를 확인합니다. 배점 합계는 수학 가·나형 각 100점 및 공통 74점·선택 26점, 국어 과거 단일 시험 100점 및 공통 76점·선택 24점입니다. 시험 체계·과목·연도 필터의 분모, 풀이 10건 중복 배제, 개인 기록의 최신 결과·해설 열람·원문 중복 처리, 현행 41개 과목과 과거 세 범위의 화면도 검사합니다. 실제 앱 경로 검사에서는 국어·수학 바로가기와 선택과목·과거 시험지의 파일·쪽 연결 및 보호자 기록 보존을 확인합니다.
