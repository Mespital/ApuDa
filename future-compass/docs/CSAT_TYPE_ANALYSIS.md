# 수능 유형 분석 · 2026-11-20

수능 학습 메뉴 안의 ‘유형 분석’에서 기출 문항 구성과 이 기기의 학습 기록을 나누어 확인합니다. 오늘·복습 화면에는 수능 카드를 추가하지 않습니다.

## 기출 분류 범위

- 영어: 2018~2027학년도, 각 45문항, 총 450문항. 듣기 170문항과 독해 280문항입니다. 홀수형 한 회씩만 집계하여 합본·짝수형의 같은 문항이 중복되지 않게 했습니다.
- 수학 공통: 기존에 공식 문제·정답을 대조한 2022~2026학년도 1·2번 10문항 표본입니다. 기초 문항이므로 전체 수학 출제 분포로 일반화하지 않습니다.
- 다른 과목: 41개 학습 항목에 공통 분석 틀과 자체 연습 유형을 연결하고, 공식 기출 문항 분류가 없는 범위를 명시합니다. 원문 PDF 408개 열람과 문항 유형 분류의 완료량을 혼동하지 않습니다.

영어는 실제 발문과 공통 발문 구간을 읽어 유형을 분류했습니다. 문항 번호만 보고 매년 같은 유형이라고 가정하지 않습니다. 예를 들어 2018학년도 21번·42번과 후속 학년도의 같은 번호는 서로 다른 유형일 수 있습니다. 2019학년도 도표의 ‘표’ 표현, 2023학년도 안내문의 영문 Notice 표현도 대조했습니다. 유형 명칭은 학습을 위해 구성한 분류이며 평가원이 공표한 유형 통계가 아닙니다.

`dist/gichul/data/type-analysis.json`에는 원문 자료 ID·선택 파일 ID·PDF SHA-256·쪽 번호·발문 위치와 유형 메타데이터를 저장합니다. PDF 본문·지문·선택지를 결과물에 복제하지 않습니다. ‘시험지에서 보기’는 원문의 해당 쪽과 문항 위치를 표시합니다.

## 통계의 계산

기출 비중은 과목·학년도·단원 필터에서 분류한 문항 수를 분모로 사용합니다. 유형을 선택하면 근거 문항을 좁혀 보여 주며 전체 구성의 분모를 1개 유형으로 바꾸지 않습니다. 비중은 소수점 첫째 자리에서 표시하며 다음 시험의 출제 확률을 뜻하지 않습니다. 학년도 비교의 —는 집계 문항이 없는 범위입니다.

내 학습 분석은 해설을 먼저 본 풀이를 제외하고, 각 문제의 최신 채점 결과를 사용합니다. 같은 자체 개념 문제를 여러 묶음에서 다시 풀어도 원문 ID로 한 번만 집계합니다. 정오 여부는 저장된 correct 플래그가 아니라 선택한 답과 실제 정답 인덱스로 계산합니다. 유형별 3문항 미만 기록은 비율 대신 오답 횟수를 표시합니다. 학습 우선순위는 남은 오답이 많은 순서이며 능력 점수나 공식 난도 추정이 아닙니다.

기존 학습 저장소와 백업 형식을 재사용하며 분석 과정은 기록을 쓰지 않습니다. 보호자 화면에서도 읽기 전용입니다. 학습 기록의 기기 간 이동은 기존 JSON 백업·복원을 사용합니다.

## 재생성과 검사

PyMuPDF(fitz)가 설치된 Python 환경에서 `python scripts/build-csat-analysis-data.py --cache-dir /tmp/csat-type-analysis`를 실행합니다. 공개 원문을 임시 캐시에 내려받아 분류 메타데이터를 다시 만들고 학년도마다 1~45번 누락 여부·홀수형 여부를 검사합니다. 원문 캐시는 git에 넣지 않습니다. Netlify 빌드는 이미 생성된 JSON을 읽으며 새 Python 의존성이나 API 키가 필요하지 않습니다.

`node scripts/check-csat-analysis.mjs`는 분류 450건의 원문 위치, 유형 변화, 필터 분모·연도별 합계, 기출 중복 배제, 내 풀이의 최신 결과·해설 열람·원문 중복 처리, 41개 과목 메타데이터와 빈 화면·실패 상태를 검사합니다. 기존 `check-csat.mjs`는 실제 화면 경로·문항 위치 연결과 보호자 읽기 전용을 함께 검사합니다.
