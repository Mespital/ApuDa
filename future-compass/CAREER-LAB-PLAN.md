# 승준 진로탐색기 기획·검토 기록
검토일: 2026-10-04 KST

## 목표와 경계
관심 → 실제 업무 → 교육과정·학교 과목 → 작은 체험 → 재탐색을 연결한다.
실제 전문가 24명이나 고등학생 10명이 자문·사용한 결과가 아니다. 가상 전문 관점 24개와 고등학생 페르소나 10개를 이용한 설계 검토이며, 동작은 자동화 입력 시나리오로 별도 확인한다. 심리측정·입시·취업 예측 도구가 아니다.

## 기능
1. 미래 관심 주제: 10개 분야 복수선택, 미결정 학생은 선택 없이 진행.
2. 과목·활동: 성적과 흥미를 분리. 기술·문과·예술·사람 지원 포함.
3. 업무 환경: 문서·데이터 / 대화 / 제작·실험 / 현장·장비. 이 선택은 순위에 넣지 않고 확인 질문으로 안내.
4. 후보·비교·체험: 10개 분야, 직업 예시 30개. 두 분야 비교, 업무·학과·과목·공부·체험·장기 리스크 확인. 600자 체험 메모와 브라우저 저장, 내 기록 삭제.

## 정렬 규칙
직접 주제 선택 3 + 일치 활동마다 2 + 일치 과목마다 1. 동점은 분야 기본 순서. 임의의 설계 가중치이며 검증된 적성 점수·성공 확률 아님. 모든 분야를 계속 표시한다. 잘하는 정도·성적·가족 배경·개인 신상은 입력받지 않는다.

## 24개 전문 검토 관점
진로상담 / 고교 진학상담 / 교육심리 / 청소년 상담 / 학습코칭 / 교육과정 / AI 연구 / 미래학 / 노동경제 / 채용·인사 / 컴퓨터공학 / 전자·로봇공학 / 기계·제조 / 보안 / 바이오·보건 / 환경·에너지 / 디자인·UX / 경영·제품 / 교육·복지 / 도시·물류 / 직업교육 / 접근성 / 추천시스템 / 정보윤리.
각 관점의 요구사항은 앱의 ‘기획·감수 기준’에 명시한다. 특정 인물의 이름·소속·자문 실적을 만들지 않는다.

## 고등학생 10유형 검토
기기 관심 고1: 휴대폰에서 공학·디자인·제품으로 확장.
문과 성향 고1: 수학 선택 없이도 국어·사회·설명 활동으로 진행.
미결정 고1: 빈 선택에서도 모든 분야 표시.
과학 탐구 고2: 연구·실제 업무·전공·체험 연결.
미술·콘텐츠 고1: 비공학 경로 유지.
사람 돕기 고2: 교육·보건·복지 역할 및 자격 구분.
현장 실습 고2: 전문대·직업교육 경로를 제외하지 않음.
진학 고민 고3: 탐색 결과를 합격 확률로 표시하지 않음.
다중 관심 고1: 최대 두 분야 비교와 재선택.
모바일 사용자: 네 단계, 큰 터치 버튼, 단일열 결과와 선택 복귀.

## 검증 및 남은 검증
자동화: 10종 입력 조합·빈 선택·4단계 렌더·두 후보 비교·메모 문자 escaping·기기 저장·기존 8화면 회귀 확인.
설계 검토: 미결정 상태, 비공학 경로, 선택 근거 설명, 제한된 현장 업무 선호 안내, 자격·면허 구분.
실제 학생 관찰·인터뷰·키보드/스크린리더 실사용·휴대폰 기종별 QA는 별도 모집과 수행이 필요하다. 만족도·과제 성공률·실제 사용자 수를 만들어 보고하지 않는다.

## 후속 실사용 평가안
고1 6명·고2 3명·고3 1명(위 유형 다양성 확보), 연구 참여·기록 동의 후 15분 세션. 개인정보·성적·실명 수집 없이 관찰.
과제: 관심 세 가지 선택 → 결과 이유 설명 → 후보 두 개 비교 → 체험 계획과 메모 작성 → 다시 선택 → 기록 삭제.
측정: 도움 없이 과제 완료 여부, 추천 이유 이해 여부, 막힌 위치·걸린 시간, 불편한 표현. 결과 수집 전에는 수치 목표를 성과로 보고하지 않는다.
