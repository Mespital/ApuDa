# 출처 표기 정책 — 국가암지식정보센터 · NCCN · 기타 자료

- 작성일: 2026-10-04 · 적용: 「암 진단 첫 30일」 완전판(유료)·MINI(무료) 12종
- 이 문서는 각 기관이 공개한 저작권 정책을 요약하고, ApuDa가 어떻게 지키는지 정리한 편집 기준입니다. 법률 자문이 아니며, 판매용 출간 전에는 출판사 법무 검토와 각 기관 확인을 받아야 합니다.

## 1. 국가암지식정보센터(www.cancer.go.kr)

### 1-1. 기관 정보
- 2025년 6월 **국가암정보센터 → 「국가암지식정보센터」**로 확대 개편되었습니다(국립암센터 운영, 보건복지부 국민건강증진기금 후원). 원고에는 새 이름을 쓰고, 필요한 곳에 "구 국가암정보센터"를 함께 적습니다.
- 암정보 상담: ☎ 1577-8899(평일 9~18시, 상담료 없음). 암생존자통합지지센터: ☎ 1577-9740.

### 1-2. 센터의 저작권 정책(저작권 안내 페이지 직접 확인, 최종수정 2026.08.07)
| 항목 | 내용 |
|---|---|
| 저작권 | 센터 제공 자료는 저작권법으로 보호되는 저작물. 별도 표시가 없으면 센터에 저작권. 무단 복제·배포는 저작재산권 침해 |
| 이용조건 | ① 비영리 목적만 허락 ② 저작권 표기 필수(2차적 저작물에도 적용) ③ 내용·일러스트 변경 금지(협의 후 가능할 수 있음) ④ 배포 가능/불가 자료 구분 ⑤ 영리 목적은 저자와 협의 필요 |
| 수익 목적 | 센터 자료로 수익을 얻으려면 **사전 협의 또는 허락**이 필요하고, 그 경우에도 출처를 아래 형식으로 명시 |
| 이용 절차 | 정보사용신청서 접수 → 내부심사 → 이용 가능 여부 통보 → 자료 제공 |
| 이행 확인 | 센터 자료를 이용한 **출판물 1부를 센터에 제공**(웹 출판은 주소 제공) |
| 인쇄물 출처 형식 | "이 글은 보건복지부 국민건강증진기금의 후원으로 구축된 보건복지부ㆍ국립암센터ㆍ국가암지식정보센터<www.cancer.go.kr>에서 발췌한 것입니다." 또는 "출처 : 보건복지부ㆍ국립암센터 국가암지식정보센터<www.cancer.go.kr>" |
| 인터넷 출처 형식 | 『www.cancer.go.kr』 |
| 링크 | **첫 화면으로만** 링크 허용, 세부 화면 링크 불가. 첫 화면 링크도 **센터에 통지** |
| 게재 시 | 적법 절차로 게재해도 단순 오류 정정 외 내용 변경 금지 |
| 문의 | 홈페이지 운영자 canceradmin@ncc.re.kr · 031-920-2023 |

> 검색 결과에는 센터 자료가 "공공누리 제4유형(출처표시·비상업·변경금지)"이라는 설명도 보이지만, 저작권 안내 페이지에는 공공누리 표기가 없습니다. 이 책은 위 저작권 안내의 조건을 기준으로 삼습니다(두 기준 모두 비영리·출처표시·변경금지로 같은 방향).

**하지 말 것**
- 센터 문장을 그대로 옮기거나, 어순만 바꿔 고쳐 쓰기(변경금지 위반 소지)
- 센터의 그림·도표·사진·영상 캡처 사용
- "국가암지식정보센터 감수", "국립암센터 인증"처럼 보증받은 것으로 오해할 표현
- 광고·홍보물에 센터 이름 사용

**해도 되는 것**
- 의학적 사실·수치·제도 내용을 센터 자료와 대조해 확인하고, ApuDa 표현으로 새로 쓰기(사실·아이디어는 저작권 보호 대상이 아님)
- 참고문헌 목록에 기관명·사이트·확인일 적기
- 독자에게 공식 정보원과 상담 전화로 안내하기
