# 출처 표기 정책 — 국가암지식정보센터 · NCCN · 기타 자료

- 작성일: 2026-10-04 · 적용: 「암 진단 첫 30일」 완전판(유료)·MINI(무료) 12종
- 이 문서는 각 기관이 공개한 저작권 정책을 요약하고, ApuDa가 어떻게 지키는지 정리한 편집 기준입니다. 법률 자문이 아니며, 판매용 출간 전에는 출판사 법무 검토와 각 기관 확인을 받아야 합니다.

## 1. 국가암지식정보센터(www.cancer.go.kr)

### 1-1. 기관 정보
- 2025년 6월 **국가암정보센터 → 「국가암지식정보센터」**로 확대 개편되었습니다(국립암센터 운영, 보건복지부 국민건강증진기금 후원). 원고에는 새 이름을 쓰고, 필요한 곳에 "구 국가암정보센터"를 함께 적습니다.
- 암정보 상담: ☎ 1577-8899(평일 9~18시, 상담료 없음). 암생존자통합지지센터: ☎ 1577-9740.

### 1-2. 센터의 저작권 정책(공개 안내 요약)
| 항목 | 내용 |
|---|---|
| 저작권 | 센터가 제공하는 모든 자료는 저작권법으로 보호되는 저작물 |
| 공공누리 | **제4유형: 출처표시 + 비상업적 이용만 가능 + 변경 금지**(2차적 저작물 작성 금지) |
| 비영리 이용 | 비영리 목적일 때만 이용 허락. 저작권 표기 필수 |
| 내용 변경 | 원칙적으로 금지. 협의 후 가능할 수 있음 |
| 영리 목적 | 원저작자와 저작권 **협의 필요**(정보사용신청: 신청 → 내부 검토 → 이용 가능 여부 통보 → 자료 제공) |
| 인쇄물 출처 문구(센터 예시) | "이 글은 보건복지부 국민건강증진기금의 후원으로 구축된 보건복지부ㆍ국립암센터ㆍ국가암(지식)정보센터(www.cancer.go.kr)에서 발췌한 것입니다." 또는 "출처: 보건복지부ㆍ국립암센터ㆍ국가암(지식)정보센터(www.cancer.go.kr)" |

> 센터 안내문에 옛 이름이 남아 있을 수 있습니다. 출간 시점에 저작권 안내 페이지의 최신 문구를 다시 확인하세요.

### 1-3. ApuDa 적용 원칙
| | MINI(무료) | 완전판(유료) |
|---|---|---|
| 성격 | 비상업 배포(Instagram 구독자) | **상업적 이용** |
| 센터 글·표·그림 수록 | 하지 않음(변경금지 조건 때문에 고쳐 쓰기도 불가) | **하지 않음** |
| 사실 확인용 참고 | 가능: 문장은 ApuDa가 새로 씀 | 가능: 사실·수치 대조에만 쓰고 표현은 새로 씀 |
| 책 안 표기 | "출처: 보건복지부ㆍ국립암센터ㆍ국가암지식정보센터(www.cancer.go.kr) — 참고·대조 자료" | "참고문헌: … (확인일)" + "센터 저작물을 수록하지 않았음" 명시 |
| 독자 안내 | 사이트·1577-8899 소개(정보 안내이며 저작물 사용 아님) | 같음 |
| 출간 전 | — | **정보사용신청으로 참고문헌 표기·안내 문구가 괜찮은지 확인**(권장). 센터 문장·그림을 꼭 실어야 한다면 반드시 사전 협의 |

**하지 말 것**
- 센터 문장을 그대로 옮기거나, 어순만 바꿔 고쳐 쓰기(변경금지 위반 소지)
- 센터의 그림·도표·사진·영상 캡처 사용
- "국가암지식정보센터 감수", "국립암센터 인증"처럼 보증받은 것으로 오해할 표현
- 광고·홍보물에 센터 이름 사용

**해도 되는 것**
- 의학적 사실·수치·제도 내용을 센터 자료와 대조해 확인하고, ApuDa 표현으로 새로 쓰기(사실·아이디어는 저작권 보호 대상이 아님)
- 참고문헌 목록에 기관명·사이트·확인일 적기
- 독자에게 공식 정보원과 상담 전화로 안내하기

## 2. NCCN

- 적용: 표·알고리즘·문장·삽화를 옮기지 않음. "NCCN 기반", "NCCN 환자용 가이드라인 요약" 같은 표현 금지.
- 허용 표기: "참고 지침: NCCN Clinical Practice Guidelines in Oncology (NCCN Guidelines®) ○○, Version X.2026." + "이 책은 NCCN이 검토·승인한 자료가 아니며, NCCN과 무관한 ApuDa의 독자적 환자교육 저작물입니다."
