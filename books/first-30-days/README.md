## 유료판과 무료판을 나누는 원칙

**안전과 방향은 무료판에서 잠그지 않고, 깊이와 실행 도구를 유료판에 둡니다.**

| 무료판(MINI)에 남기는 것 | 완전판(유료)에만 있는 것 |
|---|---|
| 먼저 구분할 개념(전암 vs 암, 아형 등) | 30일 일자별 실행 로드맵 |
| 응급 상자 + 본문 응급 목록 | 가상 병리보고서 한 줄씩 해설, 판독지 단어장 |
| 진단 뒤 72시간 체크리스트 | 병기·아형별 시나리오(가상 사례) |
| 병리·병기·바이오마커 핵심 표 | 치료별 준비·회복 타임라인, 주차별 부작용 달력 |
| 치료 경로 지도와 장별 질문 3개 | 한국 제도·보험·회사 서류 상세 |
| 마음 돌보기 30초 요약(☎109) | 마음 돌보기·보호자·직장·식사운동 상세 |
| 산정특례 30일 등 제도 30초 요약 | 증상별 자가관리 표, 진료실 대화법, 검사 준비 카드 |
| 진료실 10가지 질문, 한 장 요약 | 자주 묻는 질문 12, 세 사람의 30일, 용어사전, 워크북 |

무료판에서는 빠진 자리마다 `📘 완전판에서 이어집니다 — (내용)` 안내가 들어가고, 책 끝에 완전판 목록이 자동으로 붙습니다.

```markdown
<!-- PAID:END -->
<!-- FREE:START --> … <!-- FREE:END -->            무료판에만 들어갈 블록
```

## 빌드

```bash
python3 tools/build.py        # 12종 전체
python3 tools/build.py 12     # 12권만
python3 tools/report_round1.py
```

빌드는 PAID 마커 짝과 치환 안 된 변수를 검사하고, 문제가 있으면 중단합니다.
