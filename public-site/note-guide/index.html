APUDA NOTE · 무료 기록 도구

치료 중 나의 기록,
진료 전에 한 장으로 정리하세요.

ApuDa 암환자 노트는 체온·증상·복약·치료 일정과 진료 질문을 기록하는 도구입니다. 말하듯 입력한 메모를 분류하고 진료에 가져갈 요약을 준비할 수 있습니다. 시작하기 전에 저장·백업 방법을 먼저 확인하세요.

암환자 노트 열기기록 저장·백업 안내

어떤 내용을 기록할 수 있나요?

01 · 증상과 검사

체온·증상·혈액검사 수치

그날의 몸 상태와 검사 수치를 기록하고 진료 때 변화 내용을 설명하는 데 활용합니다.

02 · 치료 일정

복약·항암 일정 메모

복용 약과 치료 일정을 정리합니다. 실제 약 복용 및 치료 일정은 의료진의 지시를 따르세요.

03 · 진료 준비

질문 목록과 진료요약

궁금한 내용을 모아 진료실에서 보여줄 수 있는 요약 자료를 준비합니다.

04 · 노트봇

말하듯 기록하는 메모

짧은 문장으로 내용을 입력하고 규칙 기반 분류를 도움받을 수 있습니다. 질병을 진단하는 AI는 아닙니다.

시작하는 방법

  1. 노트를 엽니다

    별도 가입 없이 앱을 열고 필요한 항목부터 기록할 수 있습니다.

  2. 오늘의 상태를 기록합니다

    체온, 증상, 약, 일정, 의료진에게 물어볼 질문을 자신의 말로 입력합니다.

  3. 진료요약과 백업을 확인합니다

    진료 전 요약을 확인하고, 기기를 바꾸거나 기록을 보존하려면 백업 파일을 따로 준비합니다.

기록 저장과 개인정보: 꼭 읽어주세요

  • 기본 기록은 현재 기기의 브라우저 저장소(localStorage)에 보관됩니다. 브라우저 데이터를 지우거나 기기를 바꾸면 기록을 잃을 수 있습니다.
  • Google 계정 로그인은 필수가 아닙니다. 사용자가 별도로 연결하면 본인 Google Drive의 앱 전용 저장 영역에 백업할 수 있습니다. 로그인만으로 다른 기기에 자동 동기화되지 않습니다.
  • 내보낸 JSON 백업 파일은 암호화되지 않습니다. 이름·암종·증상·약 정보가 들어갈 수 있으므로 공개 링크, 공용 기기, 공유 폴더에 두지 마세요.
  • 진료요약 PDF는 읽고 보여주는 자료이며, 기록 복구를 위한 백업 파일과 다릅니다. 백업 파일을 안전하게 보관하고 필요한 경우 실제 복원 여부를 확인하세요.
  • 이 안내 페이지는 개인정보를 입력받지 않습니다. 실제 기록은 별도 노트 앱에서만 입력합니다.

자주 묻는 질문

회원가입이나 Google 로그인이 꼭 필요한가요?

아니요. 기본 기록 기능은 로그인 없이 이용할 수 있습니다. Google Drive 앱 데이터 백업은 사용자가 연결을 선택했을 때 이용합니다.

휴대전화를 바꾸면 기록도 자동으로 옮겨지나요?

아니요. 기기 안에 저장한 내용은 자동 이전되지 않습니다. 기존 기기에서 별도 백업을 만들고 새 기기에서 복원해야 합니다.

노트봇이 치료나 약 용량을 결정해 주나요?

아니요. 노트봇은 기록을 정리하는 규칙 기반 도구입니다. 검사 결과 해석, 진단, 처방 및 약 용량 변경은 담당 의료진과 상의하세요.

의료 안전 안내

암환자 노트는 의료진의 진료·진단·처방을 대신하지 않습니다. 새로운 심각한 증상이나 응급 상황이 의심되면 노트의 안내를 기다리지 말고 즉시 의료기관 또는 119에 연락하세요.
