V3 저장·복원·삭제 동시성 시험실

IndexedDB(브라우저 내부 데이터베이스)의 원자적 트랜잭션과 revision(수정번호) 검사를 실제 브라우저에서 검증합니다.

실제 환자 수첩과 연결되지 않습니다. 매 실행마다 새 가상 DB를 만들고 종료 시 삭제합니다. 기존 환자 기록, 논술 기록, 계정, localStorage 또는 서버 API에는 접근하지 않습니다. 검증 통과는 운영 배포 승인과 무관합니다.

시험 전 · 실행 버튼을 눌러 주세요.

동일 브라우저에서 별도 IndexedDB 연결 두 개를 사용합니다. 구형 V3의 직접 localStorage 쓰기, 다른 기기의 데이터 동기화, 전원 차단·저장소 부족·실제 모바일 다중 창은 이 시험에 포함되지 않습니다.
