# ApuDa 5F 제약·헬스케어 뉴스 비밀번호 설정

5층의 **제약·헬스케어 뉴스** 페이지 `/news/` 및 `/news/index.html`은 Netlify Edge Function에서 비밀번호를 확인합니다. 기존 `/news/oncology/` 항암제·암 뉴스는 공개 상태를 유지합니다.

## 운영 반영 전 필수 설정

Netlify 대시보드에서 **해당 apuda.app 사이트**의 Site configuration → Environment variables에 다음 두 변수를 설정합니다. 설정 범위(scope)에는 **Functions**를 포함하고, 배포 환경은 최소 Production에 적용합니다.

- `APUDA_NEWS_PIN`: 사이트 운영자가 지정한 **4자리 숫자**. 코드 저장소에는 기록하지 않습니다.
- `APUDA_NEWS_SESSION_SECRET`: **32자 이상의 암호학적 난수**. 예: 관리자의 터미널에서 `openssl rand -hex 32`로 생성한 값. PIN과는 다른 값이어야 합니다.

**환경변수 설정 전에는 병합/운영 배포하지 않습니다.** 미설정 상태에서는 `/news/`에 HTTP 503 안내가 표시되는 fail-closed 동작입니다. Netlify 환경변수 설정 후 재배포가 필요할 수 있습니다.

## 접근 동작

1. 5F 메뉴의 잠금 표시가 있는 제약·헬스케어 뉴스를 클릭합니다.
2. 비밀번호 입력 페이지에서 4자리 번호를 입력합니다.
3. 서버 인증에 성공하면 HTTPS, HttpOnly, SameSite=Lax, 8시간 만료의 서명된 쿠키가 발급됩니다.
4. 페이지 주소 직접 접근, 날짜별 브리핑 및 뉴스 다운로드도 인증이 요구됩니다.
5. 환자 대상 `/news/oncology/`, 사이트 첫 화면의 항암 뉴스 카드, 공유 데이터 폴더 `/news/data/`와 `/news/status/`는 기존 서비스를 위해 **공개 유지**합니다.

## 보안 경계 및 검증

- 서버에서 PIN을 확인하므로 브라우저 JavaScript만 조작해 뉴스 페이지를 열 수 없습니다.
- **공유 JSON 데이터 `/news/data/`는 여전히 공개**입니다. 환자 대상 공개 페이지와 홈페이지에서 공용으로 사용하기 때문입니다. 이 변경은 **뉴스 페이지 접근 제한**이지 뉴스 원천 자료 전체의 비공개화가 아닙니다.
- 4자리 PIN은 최대 10,000가지 조합으로 추측 가능한 **간편 접근 제한**입니다. 민감정보나 유료 독점 데이터에 대한 강한 인증으로 사용해서는 안 됩니다. 필요 시 계정인증, IP 기반 요청 제한 및 별도 비공개 데이터 저장소를 추가해야 합니다.
- 검증 항목: 미인증 접근 제한; PIN 오류; 올바른 PIN 로그인; 8시간 쿠키 유지; 날짜별 URL; 다운로드 경로; 환자 대상 항암 뉴스 공개; Netlify 환경변수 부재 시 503.
