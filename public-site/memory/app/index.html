현재 기기에서 암호화된 보관함 파일을 내려받아 별도로 보관할 수 있습니다. 파일 안의 돌봄 기록은 암호화되어 있으며, 파일을 열려면 보관함 비밀번호가 필요합니다.

먼저 보관함 잠금을 해제해 주세요.

파일 저장은 브라우저 다운로드 목록에서 직접 확인해 주세요. 보관함 자동 동기화·새 기기 복원은 현재 제공되지 않습니다.

데이터 보호 원칙

  • 새 앱 기록은 AES-256-GCM 암호화 후 이 브라우저의 IndexedDB에 저장합니다.
  • 기록·비밀번호를 앱 서버로 자동 전송하지 않습니다.
  • 기기 분실·브라우저 데이터 삭제·암호 분실 시 복구할 수 없을 수 있습니다.
  • 보관함을 열어 놓은 동안 화면·클립보드·인쇄물은 별도로 보호해야 합니다.
  • 동시 탭에서 충돌이 발견되면 덮어쓰지 않고 저장을 중단합니다.

기존 돌봄 기록은 종전 기록함에 그대로 남아 있으며 자동으로 이 보관함에 이전하지 않습니다. 공개 배포 전 모바일 실기기·보안 검증이 필요합니다.
