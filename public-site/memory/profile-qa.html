실제 환자정보를 입력하지 마세요. 이 화면은 대상자별 기록 분리의 시험용 미리보기입니다. 기록을 저장하거나 기존 JSON을 읽지 않으며, ApuDa 서버로 건강정보를 전송하지 않습니다. 실서비스의 기존 돌봄 기록과는 연결되지 않습니다.

실제 ApuDa Memory는 아직 대상자별 분리를 제공하지 않습니다. 여기서 생성한 진료 메모는 의료진에게 제출할 자료가 아닙니다.

QA 화면 사용 가능 여부를 확인하고 있습니다.

미분류 기존 기록 예시: 0건 — 대상 A·B에 자동 배정하거나 요약에 포함하지 않습니다.
