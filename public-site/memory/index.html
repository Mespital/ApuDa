03 · CARE DIARY

오늘의 돌봄 메모

복약 문의, 진료에서 물어볼 내용, 생활 중 관찰한 사항을 간단히 기록해 보세요.

선택적 기기 내 저장
개인정보 보호: 저장에 동의하면 기록은 현재 기기의 브라우저 저장소(localStorage)에만 남습니다. ApuDa 서버에 전송·동기화되지 않으며 비밀번호 보호·암호화 기능도 없습니다. 공용 기기를 피하고 주민등록번호·실명 등 민감한 개인정보 입력은 삼가세요. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.

기록 백업·복원 (선택)

기기를 바꾸거나 브라우저 데이터를 정리하기 전, 먼저 JSON 백업을 받으세요. JSON은 이 화면에서 다시 복원할 수 있습니다. TXT는 읽기용으로만 사용합니다.

복원은 새 기록만 추가하며 기존 기록은 덮어쓰거나 삭제하지 않습니다. 같은 기록 ID는 건너뛰고 전체 20건을 초과하면 복원하지 않습니다.

보안 유의: JSON·TXT 파일은 암호화되지 않습니다. 다른 사람이 볼 수 있는 공유 폴더·메신저에 저장하지 마세요. 파일 내용은 이 브라우저에서 처리하며 ApuDa 서버로 전송되지 않습니다.

내 기기에 저장된 기록 0건

최대 20건까지 저장하며 기존 기록을 자동 삭제하지 않습니다. 한도에 도달하면 JSON 백업을 받은 후 불필요한 기록을 직접 정리하세요. 시크릿 모드나 다른 기기로 기록이 자동 공유되지 않습니다.
