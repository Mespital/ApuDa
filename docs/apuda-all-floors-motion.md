# ApuDa 기존 인물·모니터 모션

적용 범위: 기존 건물에 있던 인물 9명의 작은 움직임과 층별 모니터, 옥상 간판, 점등, 카메라 진입 및 자료 창을 유지한다. 별도로 덧붙였던 보행 인물 5명과 의자 5개는 제거한다.

## 기존 인물

- `public-site/assets/video/building-life-91eb77cdc84a.mp4`를 유지한다. 기존 건물 사진 속 인물의 고개·팔·상체가 조금 움직이는 6초 반복 영상이다.
- 이 영상에는 기존 인물이 일어나 걷거나 다시 앉는 동작이 없다. 그런 동작을 구현했다고 설명하지 않는다.
- 걷기·착석까지 자연스럽게 만들려면 기존 인물의 외형과 건물 구도를 유지한 새 동작 영상, 그리고 인물이 가렸던 의자·바닥·벽의 복원이 필요하다.
- 별도 보행·착석 인물과 추가 의자를 생성하는 코드 및 CSS를 제거한다. `apuda-walk-cycle-v1.png`와 `apuda-sit-cycle-v1.png`는 더 이상 요청하지 않는다.
- 상세 창과 숨겨진 탭에서는 기존 인물 영상을 정지한다. 모션 줄이기와 데이터 절약 설정에서는 영상 요청을 생략한다.

## 모니터

- `public-site/assets/video/apuda-monitor-atlas-98ff1ff3beaa.mp4`: 24초, H.264, 1600×180, 12fps, 음성 없음, 728768 bytes.
- 기존 암종별 책자 표지 12종으로 제작한 안내 몽타주다. 유튜브 원본에서 추출한 영상은 아니다.
- 재생기 1개가 320×180 타일 5개를 각 층의 캔버스로 전송한다. 화면은 4초씩 시차를 두어 서로 다른 암종을 보여준다.
- 모니터 앞의 기존 인물이 가려지지 않도록 실루엣 마스크를 적용한다.
- 모니터를 누르면 당시 표시 중인 암종의 기존 ApuDa 유튜브 영상이 새 창에서 열린다. 담도암 표지는 기존에 제공된 담관암 영상으로 연결한다.
- 자동재생 실패 시 원래 모니터 이미지를 유지한다. 상세 창과 숨겨진 탭에서는 디코딩·그리기 콜백을 정지한다. 모션 줄이기와 데이터 절약 설정은 영상 요청을 생략한다.

## 검증

- 추가 인물·의자 노드와 보행·착석 이미지 요청이 없는지 확인한다.
- 간판의 ApuDa 5글자와 한글 문구, 초기 1층→5층 점등을 확인한다.
- 모니터 캔버스 5개/재생기 1개, 암종 링크 매핑을 확인한다.
- 탭 숨김/재개, 상세 창 정지/재개, 오래된 재생 약속과 프레임 콜백 취소, 자동재생 거절, RAF 대체 경로를 확인한다.
- 기존 상세 자료 내용과 층 카메라 전환 코드를 유지한다.

테스트: `node tools/tests/apuda-building-life.cjs`, `node tools/tests/apuda-building-monitors.cjs`.
