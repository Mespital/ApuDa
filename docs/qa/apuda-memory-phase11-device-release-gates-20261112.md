## C. 보호자 5분 최소 시나리오 (개인정보 없는 시험)

1. 비공개/시크릿 창에서 [ApuDa Memory 미리보기](https://deploy-preview-293--apuda-total.netlify.app/memory/#care-diary) 열기. 첫 화면에서 기존 기록이 나타나면 **시험 중지**하고 다른 격리 환경에서 시작.
2. 날짜는 오늘로, 수면은 “약간 달라짐”, 식사는 “평소와 비슷함”, 돌봄 메모에는 **“가상 시험 기록입니다. 실제 환자 정보가 아닙니다.”**, 진료 질문에는 **“가상 질문: 기록을 어떻게 보여주나요?”** 입력.
3. 기기 내 저장 동의 후 저장. 목록의 기록 건수와 메모 내용을 확인. 목록에서 **수정**을 눌러 “가상 시험 기록 수정”으로 바꾼 다음 **수정 되돌리기**.
4. “진료 메모 준비”로 이동해 7일/30일 요약, 질문 표시, 복사 실패 안내·PDF 미리보기 확인. 외부 앱이나 실제 의료진에게 전송하지 않음.
5. 테스트 기록의 삭제/되돌리기는 격리된 테스트 브라우저에서만 실시. 테스트 파일을 내려받았다면 기기 다운로드 폴더에서 삭제. 비공개 창 종료 후 개인 프로필의 원래 기록을 건드리지 않음.

**문제 보고 형식:** 시험 ID, 기기 모델, OS·브라우저 버전, 글꼴/확대 비율, 재현 단계, 기대 결과, 실제 결과, 민감정보가 없는 스크린샷, PASS/FAIL/NT, 시험 시각.

## D. 배포 전 하드 게이트 (Hard Release Gates)

**P0 — 발견 즉시 NO_GO:** 기록 유실·중복 덮어쓰기, 다른 사용자 기록 노출, 명시적 동의 없는 서버 전송·마이그레이션, 응급/의료 판단을 잘못 안내, 운영 데이터 자동 초기화, 승인 없는 운영 배포.

**P1 — 해결 및 재검증 전 NO_GO:** 기록 수정·삭제 Undo 실패, 필터 때문에 신규 기록 확인 불가, 200% 확대·TalkBack/VoiceOver 이용 불가, 복사·PDF 개인정보 고지 누락, 중대한 인증·암호화·키 보관 오류.

**출시 승인 필요 조건:** \`apuda-memory-release-gates.json\`의 blocking 항목 전부 PASS(15/15) 및 구체 증거 첨부, P0/P1 미해결 이슈 0개, GitHub PR 정식 리뷰, 위험/개인정보 정책 검토, 명시적 **사용자 운영 배포 승인**. *사용자가 복원 시험을 추후로 미뤘으므로 그 조건은 현재 DEFERRED이며 출시 합격 판정을 내릴 수 없다.* 범위에서 복원을 제외하려면 별도 사양·승인 변경이 필요하며, 채팅의 단순 “다음”은 운영 배포 승인이 아니다.
