## 1. 검토 모드와 승인 상태

이 문서는 **AI 사전점검** 기록이다. 코드 정적 검토와 Node.js VM에서 실제 자바스크립트 핸들러를 실행한 합성 데이터 시험 결과이며, 실제 전문의 30명의 참여·승인 기록이나 환자/보호자 사용성 시험이 아니다.

- S01–S12 암종별 책임전문의의 임상 감수: 이번 백업·복원 코드 범위 밖. 각 암종 자료 승인 상태 변경 없음.
- P01–P06 환자와 C01–C02 보호자의 실제 참여: 0명, 사용성 결과 없음.
- 전체 ApuDa 100점 평가: 실시하지 않음. 필수 모바일·실사용 검증 항목이 NT이므로 합격 점수 산정 보류.

## 3. 반영된 개선점

1. 새 기록 저장 시 정규식 형태 검사뿐 아니라 실제 달력상의 존재 여부를 검사한다.
2. JSON 및 TXT 다운로드 시작 과정에서 브라우저 예외가 발생하면 성공을 잘못 표시하지 않는다.
3. 실패 안내에도 기존 기록이 유지된다는 점을 환자·보호자에게 명시한다.
4. 테스트 스크립트를 저장소의 `tests/memory/`에 보관해 다음 수정 때 재실행 가능하게 한다.

## 5. 개인정보 및 사용자 안내

- 기록은 해당 브라우저의 로컬 저장소(`localStorage`)에 **암호화 없이** 저장된다. 계정 동기화가 아니며 다른 기기에서 자동으로 나타나지 않는다.
- 생성된 JSON/TXT 백업 파일 역시 **암호화되지 않는다**. 공유 메신저·공용 기기·클라우드 폴더로 전송하거나 저장할 때 민감 건강정보 노출에 주의가 필요하다.
- JSON은 동일 ID를 덮어쓰지 않는 **추가 복원**에 사용한다. TXT는 읽기용이며 복원할 수 없다.
- 사용자 데이터 대신 합성 메모로 시험했다. 사용자 논술 기록, ApuDa 다른 암종 자료, 운영 사이트는 변경하지 않았다.
