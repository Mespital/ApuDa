## 무엇이 바뀌었는가

1. **7일·30일 날짜별 관찰표**: 기간에 해당하는 달력 날짜를 최신순으로 표시한다. 수면·식사·처방 확인의 선택값을 한 줄에서 대조할 수 있다. 30일 모드에서는 최신 7일을 먼저 표시하고 나머지 23일을 사용자가 펼칠 수 있다. 숫자는 저장 기록 건수일 뿐 건강 점수가 아니다.
2. **모르는 상태 구분**: 그 날짜에 저장 기록이 하나도 없으면 `날짜 기록 없음`, 메모는 있으나 특정 항목을 입력하지 않았으면 `항목 미기록`이라고 구별한다. 둘 중 어느 것도 정상 또는 무증상을 의미하지 않는다.
3. **같은 날 여러 기록 보존**: 동일 날짜에 수면 등의 값이 다르면 모두 열거하고 `복수 관찰`이라고 표시한다. 일부 항목이 누락된 기록이 섞여 있으면 `n건 항목 미기록`으로 표시한다. 입력 순서에 근거한 임의의 최신값, 평균 또는 위험도 추정은 하지 않는다.
4. **네 번째 기록 지표**: 저장된 날짜 수와 별도로 `기록이 없는 날짜`를 표시한다. 예: 30일 중 기록된 날짜가 2일이면 날짜 기록 없음 28일. 실제 증상 여부를 뜻하지 않는다.
5. **보호자용 짧은 진료 메모**: 선택 기간·기록 현황·의료진 질문·관찰 항목별 건수만 간단히 정리해 복사할 수 있다. 세부 메모가 필요한 상황에는 기존 `전체 상세 요약 복사` 및 인쇄/PDF 기능을 유지한다. 짧은 메모에도 부분 기록/비진단 경고를 넣었다.
6. **비파괴적 설계**: 새 화면은 기존 저장 키 `apuda-memory-care-diary-v1`을 **읽기 전용으로 집계**한다. 20건 보관 상한, V1/V2 JSON 백업·추가 복원, 기존 검색 필터의 비파괴적 동작을 유지한다. 신규 서버 API·동기화·추적·암호화 기능은 없다.
