# ApuDa Memory — 치매 돌봄 전체 서비스 통합판 (2026-11-12)

**앱 열기:** https://deploy-preview-293--apuda-total.netlify.app/memory/app/

**상태:** 모바일 친화 웹앱의 전체 서비스 통합 및 가상 DOM·정적 자동검사 완료. 실제 모바일 실기기 검증, 보안 검토, 운영 배포는 미완료. 기존 \`apuda.app\` 운영 페이지는 변경하지 않음.

## 1. 사용자 화면의 정보 구조

보호자가 매일 쓰는 **핵심 메뉴 3개**는 다음과 같이 유지:
1. **오늘 기록:** 잠/식사/처방 관련 확인·메모·진료 질문, 암호화 저장.
2. **지난 기록:** 돌봄 대상별 기록 조회·수정·삭제.
3. **진료 메모:** 선택한 대상에 한정한 7일/30일 요약, 복사, 인쇄/PDF 요청.

**네 번째 '전체 서비스'는 독립적으로 접었다 펼 수 있는 보조 서비스 허브**이며, 첫 화면이 길어지지 않도록 메인 기록 메뉴 밖에 배치했다. 비밀번호를 입력하지 않아도 돌봄 정보는 볼 수 있다.

## 2. 데이터 보호와 기존 기록 보존

- 현재 앱의 별도 암호화 저장 형식 \`apuda-memory-secure-v3\` 및 \`public-site/memory/app/vault.mjs\` **코드는 변경하지 않음**.
- PBKDF2-SHA256 600,000회 키 유도·AES-256-GCM, 변경 버전 검사(Compare-and-swap)는 기존 설계 유지.
- 기존 앱의 \`localStorage['apuda-memory-care-diary-v1']\`와 논술·FAQ/다른 기능에 접근하지 않음.
- 체크리스트는 페이지 메모리 상태로만 유지한다. **일지에 옮기기만으로 기록을 저장하지 않음**. 사용자가 '기록 저장하기'를 누르면 선택한 돌봄 대상에게만 들어감.
- 일지 수정 중 내용을 옮기려면 별도 확인을 요구하며, 메모 1,500자 초과는 거부해 기존 작성 중인 내용을 조용히 잘라내지 않음.
- 다른 대상의 기록을 현재 대상에 자동 배정하지 않음.
- 비밀번호 분실·브라우저 삭제 시 복원 불가 위험은 남아 있으며, 암호화 JSON 백업은 지원하지만 기기 간 복원은 아직 미지원.

## 3. 실제 구현 파일과 자동 검증

1. \`public-site/memory/app/index.html\`: 전체 서비스 허브 6개 영역, 반응형 4번째 내비게이션, 공식기관 링크 및 접근성 상태문구.
2. \`public-site/memory/app/app.mjs\`: 기억/생활/안전 체크, 인지 활동 설명, 기록으로 옮기기 기능. 민감정보 자동 저장·서버 전송 없음.
3. \`tests/memory/test_complete_app_static.cjs\`: 기능 영역/메뉴/공식 링크/서비스 이벤트 코드/기존 저장소 미변경 검증.
4. \`tests/memory/test_simple_caregiver_ui.cjs\`: 가상 DOM과 실제 대상별 기록 모델을 이용해 다음을 검사.
   - 비밀번호를 만들기 전 전체 서비스 안내를 열 수 있음.
   - 기록함이 잠긴 상태에서 체크리스트가 자동 저장되지 않음.
   - 보관함 시작, 첫 돌봄 대상 자동 생성, 일지 등록·수정·삭제, 요약 복사·인쇄, 잠금·잠금 해제.
   - 기억 변화 안내·일지 옮기기, 생활·안전 점검의 일지 옮기기, 음악 활동 선택·일지 옮기기.
   - 명시적 저장을 누르기 전까지 보관함 기록 건수가 변하지 않음.
   - A/B 가족 기록이 서로 섞이지 않음.

**검증 성격:** 소스 정적검사 및 가상 DOM/합성 데이터 JS 시험 PASS. Netlify 배포 미리보기 상태 2개 성공 확인. 실제 Android Chrome/iPhone Safari, 보조기술, 의료진 감수 및 독립 보안 검토는 **수행하지 않음**.

## 4. 출시·서비스 정확성

- 기존 \`docs/qa/apuda-memory-release-gates.json\`은 **NO_GO**. 운영 PR 병합과 실제 사용자 기록 이전·삭제는 하지 않는다.
- 치매 변화 체크리스트는 **비표준 자기 관찰 도구**로 치매 위험 점수·진단·치료 결정에 사용할 수 없음.
- 정부 지원 제도는 지역, 소득, 대상·등급 요건에 따라 달라진다. 앱은 **공식 지원기관으로 연결하는 안내**를 제공하며 지원 자격을 자동 판정하거나 신청을 대행하지 않는다.
- 실종 112 / 응급 119. 질환이나 약물 치료는 담당 의료진과 상의.
- 앱은 설치형 네이티브 Android/iOS 앱이 아니라 **브라우저에서 실행하는 모바일 웹앱(Deploy Preview)**이다.

**최종 결과:** 기존의 간단한 일상 기록을 유지하면서 치매 돌봄의 주요 안내·관찰·생활·실종 예방·지원 서비스를 한 앱에 통합했다. 정식 운영 사용을 위해서는 보안 및 실기기 검증이 아직 필요하다.
