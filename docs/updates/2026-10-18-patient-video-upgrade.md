# ApuDa 환자 영상·자료 연결 개선 (2026-10-18)

건물의 각 층 모니터와 기존 암종별 영상 카드를 누르면 사이트 안의 팝업에서 YouTube 영상을 재생한다. 12개 암종, 사용자가 제공한 13개 영상 ID를 유지한다. 기본 플레이어는 세로형이며 확대 버튼과 YouTube 전체화면 기능을 제공한다. 영상 아래에는 같은 암종의 MINI 책자, 기존 FAQ 답변 3개, 진료실 질문, 치료지도·항암제·바이오마커·요법 링크를 배치한다. 책자 다운로드 코드 정책은 유지한다.

팝업을 닫으면 iframe을 제거해 소리를 중지하고 원래 초점과 배경 상태를 복원한다. 뒤로 가기는 팝업을 닫는다. 영상 변경 시 한 개의 플레이어만 유지하며, 늦게 도착한 응답이 이전 암종의 자료를 덮어쓰지 않는다. 임베드가 제한된 경우 이유와 재시도, 사용자가 따로 선택하는 외부 재생 링크를 표시한다. YouTube 앱 이동은 기본 동작이 아니다.

기존 건물 이미지, 건물 안 원래 인물 영상, 간판, 층 진입 효과는 유지한다. 모니터와 인물 영상은 팝업·층 진입·화면 비활성 상태에서 일시 정지한다. `보기 설정`에 움직임 끄기, 큰 글씨, 상황별 바로가기를 추가한다. 움직임 끄기와 운영체제의 움직임 줄이기 설정에서도 모니터 링크는 이용할 수 있다.

## 이전 코드 감수에 따른 기록 안전성 수정

- 검사·질문·치료 기록 분기에서 먼저 반환하더라도 발열과 급한 증상 검사를 별도로 수행한다. 빨간 안내는 저장 확인보다 먼저 표시한다. 부정·과거·조건형 문맥에 대한 회귀 사례를 추가했다.
- 검사 단위가 없으면 숫자를 임의로 1,000배 하지 않는다. 원문과 단위를 함께 저장한다. 단위가 명확한 경우만 `/µL`로 환산하고 수치 기준 안내에 사용한다. 기존 단위 없는 데이터는 삭제·재환산하지 않고 확인 필요로 표시한다.
- 같은 날짜의 체온을 배열로 보존한다. 최근값·최고값·측정 이력을 구분하고 그래프는 일별 최고값, 진료요약은 전체 측정값을 반영한다. 기존 단일값도 첫 기록으로 보존한다.
- 트리플루리딘·티피라실 참고 달력은 28일 주기의 1–5일, 8–12일을 표시한다. 일반 참고 달력의 휴약 추정만으로 사용자의 등록 약을 숨기지 않는다. 실제 처방은 의료진의 안내를 따른다.
- 길잡이에서 노트로 옮기는 건강 문장을 URL에 넣지 않는다. 같은 출처에서는 10분 유효한 일회용 sessionStorage 항목으로 전달해 입력창에 채운다. 기록 전 사용자가 확인한다. 다른 출처 또는 저장 실패 시 복사·붙여넣기를 안내한다.
- 지원사업의 단정적인 가능성 표현을 상담 권장으로, 검진 결과 제목을 상담 준비안으로 바꾼다.

## 검증

아래 테스트는 합성 데이터로 실행한다. 실제 환자 정보는 사용하지 않는다.

```sh
node tools/tests/apuda-note-safety.cjs
node tools/tests/apuda-video-dialog.cjs
node tools/tests/apuda-building-life.cjs
node tools/tests/apuda-building-monitors.cjs
```

검증 범위는 복합 입력, 단위 명시·미명시, 직접 입력 폼, 같은 날 반복 체온·이전 값 보존, 요법 복용일, 안내 표시 순서, URL 없는 전달, 영상·암종 변경, 확대, 자료 조회 실패, 플레이어 정리, 뒤로/앞으로 가기, 초점 복원, 원래 인물 유지와 움직임 설정이다. JavaScript 파일과 HTML 인라인 스크립트의 구문도 검사한다.

의학 콘텐츠는 기존 ApuDa 공개 책자와 FAQ를 연결한다. 실제 전문의·환자 참여 감수나 임상 인증을 완료했다는 의미가 아니다. 브라우저별 자동 재생 정책과 영상 게시자의 임베드 허용 설정은 외부 조건이다.
