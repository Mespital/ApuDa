## 변경 및 확인

- `public-site/library/first30/index.html`: 3개 이미지 src·alt·원본 크기 및 새 WebP 전용 contain CSS만 변경. 30개 안내서 href, 모든 카드 텍스트, 스크립트, 의료 이용 안내 유지.
- `public-site/assets/books/first30/`: stomach.webp, colorectal.webp, all.webp만 추가. 기존 SVG 및 안내서 books/01.html–30.html 미변경.
- 배포 전 30권 운영 페이지 HTTP 200, 각 H1 암종 일치. 배포 후 30권 응답·본문 해시와 전체 표지 로딩을 다시 확인한다.
- 부분 범위 점검이므로 서비스 전체 점수·의료 승인·실제 환자 검증 완료를 선언하지 않는다. 실제 암종 책임전문의는 기존 승인 대기 상태를 유지한다.
- Netlify 대시보드는 별도 로그인 화면이며 이 문서는 내부 빌드 결과를 확인했다고 주장하지 않는다. main 갱신 후 Git 연동 배포 및 운영 응답으로 반영 여부를 확인한다.
