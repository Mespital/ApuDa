## 개발 브랜치 수정 사항

1. `automation/news-bot/editorial_quality.py` — 외부 의존성 없는 **TOP 전용** 좁은 제외 조건: 부고, 명확한 친선 스포츠대회, 홍보인 모임. 제목만 판정하며 학술대회 임상 결과·치료 정책 기사는 포괄 제외하지 않음.
2. `score_article` — 짧은 `약가`·`수가`의 한글 단어 경계를 검사해 `식의약가족` 같은 부분 문자열의 과다 점수를 방지. 본문에 우연히 언급된 키워드는 제목의 기사 범주로 오인하지 않음.
3. `make_report` — TOP만 큐레이션하고 원본 `outlet_status` 목록은 그대로 보존. 미래의 7/30일 기간 집계에도 과거 리포트의 명백한 행사·부고가 다시 끼어들지 않도록 `build_period_highlights`에서 제외. 과거 일별 JSON은 수정하지 않음.
4. `public-site/news/freshness.js` — 브리핑 보고일 09:00 KST 완료를 기준으로 **25시간 초과** 시 낡은 자료로 판정(09:03 KST 자동 작업 + 1시간 여유). 날짜 오류는 안전하게 낡은 자료로 표시.
5. `public-site/news/index.html`, `styles.css` — 오래된 일별 데이터가 표시될 때 ‘오늘’ 표현을 ‘마지막 공개 뉴스 브리핑’으로 교체, 기준일을 포함한 눈에 띄는 갱신 지연 안내 추가. 기간별 데이터도 `as_of`를 개별 확인해 오래된 7/30일 목록에 기준일 표시. 기록 열람과 정상적인 최신 브리핑은 별도 처리.
6. `install-vps.sh`, `deploy-news-vps.yml` — 향후 별도 승인된 배포 시 새 모듈의 복사·컴파일이 누락되지 않도록 파일 목록만 변경. **설치 스크립트 실행·워크플로 실행 없음**.
