# 신규 18암종 핵심 FAQ 360문항 및 30암종 FAQ 연결

기준일: 2026-11-02 (Asia/Seoul) · 콘텐츠 버전: `20261102-corefaq-v1`

## 결과와 검토 모드

신규 18암종에 진단 후 첫 30일 핵심 FAQ를 20문항씩 작성했다. 기존 12암종의 FAQ 100문항씩은 본문을 유지했다. 제공 범위는 총 30암종 1,560문항(기존 1,200 + 신규 360)이다. 신규 자료는 진단·검사 / 치료 선택 / 치료 중 관리 / 생활·추적의 네 분류별 5문항과 진료실 질문 5개를 제공한다.

작성은 3개 AI 작업으로 분담했고, 작성과 분리된 1개 AI 작업이 신규 360문항 전체를 독립 사전점검했다. 통합·기술 검증은 별도로 수행했다. 이는 30명이나 실제 전문의가 참여했다는 뜻이 아니다. **실제 의료진 검토 자료는 없으며 전문의 배정·검토·승인은 대기 중이다. 실제 환자·보호자 참여시험도 미실시다.**

## 의료 근거·독립 점검

- 최종 출처: 중복 제외 98개 URL. NCI PDQ, NHS·의료기관, 관련 전문학회 지침·원문 및 공식 환자교육 자료를 포함한다. 출처 확인일과 원문의 개정일을 구별한다.
- 문항별 `sourceRefs`가 해당 암종의 `sources`로 연결되는지 360/360 확인했다. 암종마다 같은 참조 ID가 다른 URL을 가리킬 수 있어 근거 사전을 암종별로 보관한다.
- 독립 AI 점검 범위에서 확인된 미해결 P0·P1 문제는 없으며, P2 보완 7건은 수정 후 재확인했다. 이는 임상 안전성 보증이나 실제 전문의 승인이 아니다.
- 보완: 후두전절제 후 발성, 자궁내막암 외부방사선 표현, 식도암 완화의료의 직접 근거, ALL의 공식 HTML·종양용해증후군 근거, M단백 설명, CML 정의, MGMT 예측 표지의 적용 범위.
- 원본 원고 SHA-256을 독립 검토 기록과 대조한 뒤 `aiCheck`·`aiReview` 메타데이터만 완료로 전환했다. `clinicalApproval`은 모두 `pending`이다. 검토한 질문·답변·출처의 지문은 자동 검사로 재확인한다.
- 국제 근거를 한국의 약제 허가·급여로 간주하지 않았고, 개인별 약제 용량·치료 변경 지시·개인 생존기간 예측을 제공하지 않았다. 오래된 환자교육 페이지의 범위·직접성·추가 검토 필요성은 각 근거 기록에 남겼다.

독립 검토 세부 기록: [보고서](2026-11-02-faq18-independent-review.md), [원고 지문·수정 기록](2026-11-02-faq18-independent-ledger.json). 분담별 근거: [A](2026-11-02-faq18-evidence-a.md), [B](2026-11-02-faq18-evidence-b.md), [C](2026-11-02-faq18-evidence-c.md).

공통 관점에서는 증상·연락(M03), 약물 상호작용·임의 변경 금지(M04), 불안·생활 표현(M05), 국내 제도 확정 주장 회피(M06)를 확인했다. 기술 관점 D01–D06은 암종 이동·레이블·읽기·키보드·근거 링크·정적 자료 접근을 중심으로 점검했다. P01–P06/C01–C02의 이해도·피로·정보 탐색은 **사용성 가설**이며 실제 참가자의 성공률·만족도·인용문을 만들지 않았다.

## 기술 반영과 검증

- 홈페이지 2F의 신규 18종 FAQ 버튼을 활성화하고 'FAQ 준비 중' 안내를 수정했다. MINI·영상은 기존 12종의 실제 제공 범위를 유지한다.
- FAQ 화면은 30종 선택, 실제 문항 수(20/100), 새 4분류/기존 5개 구간, 검색·초기화·질문 앵커·문항별 근거를 지원한다. 알 수 없는 암종 주소는 명시적 선택을 요청하며 다른 암종을 기본값으로 표시하지 않는다.
- 검토정보도 30종으로 연결하고, 각 암종의 확인일·출처·제공 자료·실제 임상 승인 대기를 구분했다.
- `node tools/tests/faq-catalog.test.cjs`: 30종 identity, 1,560문항, 신규 360문항의 검토 지문·출처·메타데이터, 20/100문항 구분, 검토정보 일치 검사 통과.
- `node tools/tests/first30-catalog.test.cjs`: 표지 30종의 권수·암종·이미지 지문·안내서 경로와 MINI 12종/FAQ 30종 제공 상태 검사 통과.
- 변경 JavaScript와 HTML 인라인 스크립트 구문 검사 통과.
- 로컬 브라우저: 난소암 20문항, 치료 분류 Q6–10, CA-125 검색 Q2·Q16와 자동 펼치기, 특수문자 검색·초기화, 문항별 출처 펼치기, 유방암 100문항 및 Q81–100 구간, 30종 선택과 PCNSL 검토정보 연결 확인.
- 320/375 CSS px 모의 뷰포트의 FAQ 표시·가로 넘침·질문 앵커를 확인했다. 실제 휴대전화·화면낭독기·실제 환자 시험은 미실시이며 WCAG·PEMAT 인증 또는 전체 서비스 합격 점수를 산출하지 않는다.
- 최신 GitHub 변경 중 논술 앱 진입점·병원 정보·다른 배포 구성을 유지하고 FAQ 관련 파일만 반영한다. 기존 12종 FAQ 본문, 30개 표지·무료 안내서 본문, MINI PDF는 변경하지 않는다.
