## 자료·기술 점검과 한계

- 신규 18파일의 연속 번호 1–20, 질문 중복, pending 승인 상태, 비어 있지 않은 출처 연결, HTTPS 형식은 통과했다. 이는 의료 사실의 자동 인증을 뜻하지 않는다.
- `nci-mouth`가 파일별로 다른 NCI 페이지를 가리키는 경우를 통합 담당에게 전달했다. 각 FAQ는 자신의 `sources`를 사용하며, 통합 registry도 암종별 사전을 사용하도록 설계되었다. 실제 UI/링크 표시 검증은 통합 담당의 별도 범위다.
- 독립 재열람 중 LLS 성인 ALL PDF는 timeout, 일부 Blood Cancer United HTML 및 PMC 페이지의 재요청은 접근 제한 응답이 있었다. 이를 영구적인 링크 불통이나 의학적 오류로 간주하지 않았다. 공식 검색 본문·이미 열람한 NCI 자료로 주장 범위를 대조하고, 접근 가능한 직접 근거를 추가했다. 해당 PDF의 원문 전체를 독립 검토에서 다시 열어 확인했다고 주장하지 않는다.
- 국내 약별 허가·보험급여, 모든 개별 요법/용량·예후 수치의 최신 전면 검증을 수행한 자료가 아니다. 이 초안은 이러한 개인별 치료 지시나 통계 일반화를 피하도록 작성되었다.
- 실제 의료인에게 검토·승인을 받거나 환자·보호자가 읽고 행동하는 시험은 실시하지 않았다. 추가 암종에 필요한 실제 책임전문의는 배정 대기이며, 기존 필수 12개 전문의 자리를 대체하거나 실제 인원으로 계산하지 않는다.
- 본 독립 점검은 의료 원고·근거 연결을 대상으로 한다. 배포 성공·모바일·화면낭독기·실제 기기 동작을 이 보고서로 통과 처리하지 않는다.

## 최종 원고 고정

작성자 A/B/C가 최종 수정본의 고정을 보고했고, 수정된 답변과 근거를 다시 읽었다. 검토 시점의 원본 파일 SHA-256과, 메타데이터와 분리한 질문·답변 본문의 SHA-256은 `faq-independent-review-ledger.json`에 남겼다. 통합 단계에서 `aiCheck`/`aiReview` 등 AI 검토 메타데이터를 갱신하더라도 실제 의료 승인 상태는 `pending`으로 유지해야 한다. 질문·답변이나 근거의 의미가 바뀌면 해당 항목을 다시 검토해야 한다.
