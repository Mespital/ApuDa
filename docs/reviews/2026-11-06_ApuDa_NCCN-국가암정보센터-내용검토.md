## 6. C1 패치안 (적용 전 승인 필요)

```js
// deBrand(): 상품명 → 성분명 치환 시 뒤 조사도 받침에 맞게 교정
function _bat(w){var c=w.charCodeAt(w.length-1)-0xAC00;return c>=0&&c<11172&&c%28!==0}
var _J={'은':['은','는'],'는':['은','는'],'이':['이','가'],'가':['이','가'],'을':['을','를'],'를':['을','를'],'과':['과','와'],'와':['과','와']};
BRAND.forEach(function(b){
  o=o.replace(new RegExp(b[0]+'(은|는|이|가|을|를|과|와)?(?![가-힣])','g'),function(_,j){
    return b[1]+(j?_J[j][_bat(b[1])?0:1]:'');
  });
});
```

검증(2026-11-06, 사본에 적용):
- 조사 오류 7건 → 0건.
- `node public-site/tools/test-regimens.js` 95/95 통과.
- 원본은 되돌려 둠.

`tchp`의 "피하주사 복합 피하주사로"는 원문 `how`를 직접 고쳐야 해.
