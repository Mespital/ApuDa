## GitHub Actions 방식

워크플로 .github/workflows/apuda-mobile-render.yml은 main 대상 PR에서 지정된 공개 사이트/검사 파일이 수정되었을 때만 실행. push/운영 배포/VPS 연결 트리거 없음. 최소 권한 contents: read, 체크아웃 인증 비보존, secrets 사용 없음.

1. PR 체크아웃의 공개 HTML/CSS를 Chromium에서 **오프라인 렌더링**합니다. 이 결과만 CI 실패 조건입니다. 1px 초과 넘침, FAQ 수/펼침 실패, 주요 SEO 메타데이터 누락을 오류로 기록하고 종료 코드 1을 반환.
2. 공개 운영 사이트 https://apuda.app 를 **읽기 전용으로 표본 조회**합니다. 외부 네트워크 문제나 배포 전 상태로 실패하더라도 continue-on-error 설정으로 CI 통과 판정과 구분합니다. 이 비교가 실패한 경우 운영 모바일 합격이라고 표현하지 않습니다.
3. 성공/실패와 상관없이 7일간 GitHub Actions Artifact에 결과 JSON, 보고서 MD, 스크린샷 PNG를 저장합니다.

## 안전과 한계

- 환자 노트 /note/, 논술 기록, 계정 로그인, API, 비공개 파일은 접근하지 않습니다. 공개 정적 3개 경로로만 접속하고, 허용된 호스트 이외의 네트워크 요청은 차단합니다.
- 오프라인 소스 검사는 서버 응답 헤더/리디렉션, 원격 글꼴/이미지를 완전히 재현하지 못합니다. 가로 넘침 0px이 실제 글자 겹침/잘림 부재 인증은 아닙니다.
- 44px는 ApuDa 내부 터치 영역 목표이며, 모든 WCAG 2.2 터치 크기 기준과 동일하지 않습니다. CI에서 경고로만 기록.
- Android/iPhone 실기기, TalkBack/VoiceOver, 네이티브 200% 확대, 환자·보호자 이용성은 별도 미검증.
- 실제 임상 감수, 개인정보 보존/복구 시험, 운영 배포 승인으로 해석하지 않습니다.
- **main 병합, Netlify 운영 배포, VPS 접속/변경, branch protection 변경은 하지 않습니다.** 기존 환자·논술 기록과 무료 요금제 유지.
