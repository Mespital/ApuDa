## 1. 결론과 근거

**개발 단계에서 확인된 P2 접근성 3건을 소스 수정했다.** 치명적(P0)·핵심 사용 차단(P1) 결함은 이번 공개 안내 화면의 확인 범위에서 발견되지 않았으나, 미시험 영역이 있어 *없다고 확정하지 않는다*. `https://deploy-preview-291--apuda-total.netlify.app/note-guide/`에서 1363 CSS px 데스크톱 화면의 구조·링크·FAQ 확장을 실제 확인했다. **320 CSS px 재배치, 200% 텍스트 확대, 실제 휴대전화 터치, 스크린리더/음성 낭독은 NT(미시험)**이다.

## 3. 점수·승인·추가 검증

- 감수 프레임 배점(100점): 의료 30 / 동선 20 / 접근성 15 / 쉬운 글 15 / 개인정보 10 / 성능 10.
- **전체 점수·합격 판정: 보류(NT 포함).** 필수 모바일 재배치(320 CSS px), 200% 확대, 키보드 초점 이동·읽기순서, VoiceOver/TalkBack, 실제 환자·보호자 이해시험, 백업·복원 실동작, 임상 승인 미실시.
- 백업 안전의 잔여 위험: 기존 앱이 내보내는 JSON은 비암호화 파일이며, 안내는 이를 명시한다. 안내 문구 점검만으로 저장소·Drive 권한·복원 데이터 안전성 검증을 대체하지 않는다. 관련 구현 또는 환자 데이터는 이번 작업에서 건드리지 않았다.
- 임상적 주의: 노트봇은 규칙 기반 기록 보조라고 안내하며 진단·처방·약 용량 변경을 하지 않는다고 표기한다. 실제 종양간호·약료/의사 승인은 여전히 대기다.
- 다음 검증: 실제 **320px·200% 확대** 화면 횡스크롤/잘림, Android TalkBack 및 iOS VoiceOver 초점·FAQ 열기, 44px 터치, 보호자에게 JSON과 PDF 백업 차이를 설명하도록 하는 가상 시나리오. 환자 기록을 쓰지 않는다.
