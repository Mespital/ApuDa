## 적용 근거 및 계산 방법

- W3C WCAG 2.2 [SC 1.4.3 Contrast (Minimum)](https://www.w3.org/TR/WCAG22/#contrast-minimum): 일반 텍스트 **4.5:1**, 큰 텍스트 **3:1** 이상. 이 검토에서는 작은 12px 배지와 글자까지 모두 보수적으로 **4.5:1**로 판정.
- W3C [SC 1.4.11 Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast): 작성자가 만든 키보드 초점 표시를 포함한 필수 비텍스트 상태 표시는 주변색과 **3:1** 이상.
- sRGB 색을 선형 광량으로 변환해 상대 휘도 `L = 0.2126 R + 0.7152 G + 0.0722 B`를 계산한 뒤 `(L밝음 + 0.05) / (L어두움 + 0.05)`를 이용. 소수 둘째 자리 반올림.
- 라이브 개발 미리보기의 CSS computed color/font-size/font-weight를 확인했으며, `.hero`의 `linear-gradient(130deg,#fff 4%,#e5f1ff)`는 양 끝 색을 보수적으로 별도 계산. 실제 픽셀 전수 검사나 보조공학 사용자 시험은 아님.
