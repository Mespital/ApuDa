# ApuDa 감수 개선 반영 · 2026-10-19

대상: 기존 apuda.app Netlify 배포본과 Mespital/ApuDa의 public-site. 최초 기준 소스 d627d70e433cf10d07d14ff82afd58a4dd12c38f. 배포 표식 audit-20261019.1.

사용자 요청에 따라 기존 건물·간판·기존 인물 애니메이션을 보존하고 감수 지적을 수정했다. 무료 MINI 12종은 코드·로그인·SNS 참여 없이 다운로드한다. 기존 APD1 자산은 공개 호환 키로 읽으며, 접근 제한이나 사용자 비밀키가 아니다. PDF 원문은 v3.2이고 웹의 보완 안내는 별도로 표시한다.

## 자동 검사

- apuda-note-storage.cjs: 실제 지원 구조, 복원 직전 사본, 용량·경합·손상 로컬 기록 보호, 마지막 기록 취소
- apuda-drive-restore.cjs: 모의 네트워크에서 안전 업로드 실패 시 중단과 복원 직전 보관
- apuda-note-safety.cjs: 열·심한 오한·단위·과거/부정/가정 문장·측정 이력·알림 우선순위
- apuda-floor-transition.cjs: 5층의 일반·끄기·감소 모드, 데스크톱/모바일 분기
- apuda-building-life.cjs 및 apuda-building-monitors.cjs: 기존 인물·한 디코더·일시정지·실패·경합
- apuda-video-dialog.cjs: 12암종 13영상 매핑, 하나의 플레이어, 자료·확대·오류·초점·이력·시간 제한
- apuda-free-books.cjs: 실제 12개 PDF를 브라우저 Web Crypto로 복호화해 원본 SHA-256과 대조, 쪽수 257쪽과 안내 일치, 코드·SNS 게이트 없음
- 모든 JavaScript 및 HTML 인라인 스크립트 구문 검사, git diff --check

PDF 검사는 파일 열림·원본 바이트·쪽수에 관한 기술 검사다. 257쪽 전체의 임상 검토가 아니다.

## 의료 근거와 실제 검토 상태

이번에 대조한 1차 출처는 public-site/library/review/registry.json에 URL·확인일·적용 범위와 함께 기록했다. 담도암 FAQ15의 확인되지 않은 국내 급여 시행월 단정은 삭제하고 국제 병용 근거와 국내 조건 확인을 구별했다. 다른 약별 국내 허가·급여 전체를 이번에 검증했다고 주장하지 않는다.

필수 책임전문의는 S01 유방, S02 폐, S03 위, S04 대장, S05 갑상선, S06 신장, S07 전립선, S08 췌장, S09 담도, S10 간, S11 림프종, S12 자궁경부이다. 12자리 모두 실제 위원 배정·검토·승인 대기다. 공통 의료·돌봄 4, 디자인·기술 6, 환자 6, 보호자 2를 합친 30자리는 책임·평가 관점이며 실제 30명이 참여했다는 뜻이 아니다. 실제 환자·보호자 8인 평가도 미실시다.

실기기 iPhone/Android, 화면낭독기, 13개 영상 전체의 실제 재생·자막·임상 내용, PDF 원문 전체, 약별 국내 허가·급여의 최신 대조는 별도 검토가 필요하다. 단위 검사 통과를 전체 서비스 합격 점수나 WCAG 인증·임상 승인으로 바꾸어 표시하지 않는다.
