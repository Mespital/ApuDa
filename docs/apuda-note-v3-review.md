## 4. 의견이 갈린 부분과 결정

- **노트봇에 AI(외부 API) 연결?** — 환자 다수 찬성, 전문의 다수 반대(오답·개인정보). → **기기 안 규칙 기반**으로 결정. 오프라인 동작, 서버 전송 없음. 이해 못 하면 "메모로 저장/질문으로 저장" 선택지 제공.
- **약 용량 자동 확인?** — 약제 전문가 반대(처방 변경 위험). → 이름·복용 시간만 기록, "처방전 그대로인지 확인, 조절은 의료진과" 문구.
- **37.5℃ 기준** — 병원마다 37.8/38.0 상이. → 37.5℃는 "재측정 권고"만, 즉시 연락은 38.0℃. "병원이 알려준 기준이 우선" 명시.
- **1339** — 2012년 119로 통합. 응급 화면에서 제거, 응급의료포털(E-gen) 응급실 찾기로 대체.

## 5. 유지한 것 (v2 감수본 계승)

응급 판단 체크리스트(빨강 7·노랑 5), 위기 대응 문구, 증상별 안내 20개 주제(발열·통증·구역·설사·구강·감염·피로·저림·탈모·식사·운동·마음·가족·진료질문·재발·2차소견·비용·직장·백업·개인정보), 구글드라이브 백업, 기존 데이터 키(`apuda_cancer_care_v1`) — **기존 사용자 기록 그대로 이어짐**.

## 6. 실제 감수 때 확인할 것

1. 노트봇이 저장하는 표현 범위(사투리·약 이름 오타) — 환자 5명 실사용 테스트
2. 37.5℃ 재측정 안내 문구가 병원 지침과 충돌하지 않는지
3. 진료요약 표의 항목 순서가 실제 외래에서 쓰기 편한지 (종양내과·전문간호사)
4. 구글드라이브 백업: apuda.app 도메인을 Google Cloud OAuth 승인된 출처에 추가
