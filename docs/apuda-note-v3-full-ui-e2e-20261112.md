# V3 실제 화면 2개 탭 회귀 시험 (합성 데이터 전용)

- 날짜: 2026-11-12 KST
- 대상: Draft PR #294의 현재 V3 전체 `index.html` 및 연관 JS/CSS.
- 실행: GitHub Actions PR 트리거 `.github/workflows/apuda-note-v3-full-ui.yml`.
- 독립 Chrome 프로필에서 임시 `http://127.0.0.1` 서버만 이용하고, 외부 Google OAuth / Drive / 지도 / 기타 네트워크 요청은 브라우저 Route에서 차단한다. Service Worker는 차단한다.
- 가상 건강기록과 가상 채팅을 로컬 브라우저 컨텍스트에 시드한다. 실제 `apuda.app`이나 사용자의 기존 브라우저 저장소에 **접근하지 않는다**.
- 동일 Origin의 V3 화면 **최소 2개 탭**을 열어 첫 번째 설정 폼에서 기록한 뒤 두 번째 탭의 오래된 수정이 차단되는지 테스트한다.
- 실제 앱의 경고 표시, 메모리 보존, 내보내기 JSON 다운로드 및 내용, 다운로드 후 메모리 유지, 전체 삭제 차단, 대화 저장 경합, 저장 용량 오류 시 원본 보존을 확인한다.
- 새 workflow는 코드 변경 검증만 수행하며 운영 `main` 병합/Netlify 운영 배포/Google Drive API를 실행하지 않는다.

## 증거 등급 및 배포 게이트

**GitHub Actions 실행이 완료되기 전에는 E2E PASS를 주장하지 않는다.** 각 실행의 실제 성공/실패 여부를 최신 PR SHA 기준으로 검증한다.

이 시험은 같은 버전의 V3 탭 2개만 대상으로 한다. 오프라인으로 남은 **이전 버전의 구형 V3 탭**은 새 보호 함수에 참여하지 않으며, `localStorage`에서의 TOCTOU(원문 확인 후 쓰기 경쟁 상태)도 여전히 P0이다. 구형 탭과 신형 IndexedDB 버전 혼재, Android/iPhone의 저장소 비정상 종료, 실제 Drive 보관 7개 `prune()` 경로는 별도 가상 시험이 필요하다.

검토 성격은 D04/D05/D06 관점의 AI 기술 사전점검이고 실제 전문가·환자·보호자 검증은 미실시. 운영 배포 승인은 없음.
