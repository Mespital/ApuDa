# ApuDa NCCN 콘텐츠 이용정책

적용일: 2026-10-04

## 운영 원칙

ApuDa는 NCCN 관련 자료를 환자·보호자가 공식 출처로 이동할 수 있도록 연결하되, NCCN 콘텐츠 자체를 복제·저장·변형·요약·재배포하지 않는다.

현재 운영 모드는 **link-only / patient-first** 이다.

- 기본 링크: NCCN 환자용 공식 가이드 페이지
- 보조 링크: NCCN 전문가용 공식 가이드 페이지
- NCCN 가이드라인 PDF, 알고리즘, 표, 그림, Evidence Blocks, 변경내용 전문을 ApuDa 서버나 Git 저장소에 저장하지 않음
- NCCN 가이드라인 본문을 AI 입력으로 사용하거나 자동 요약하지 않음
- NCCN 버전 자동 스크래핑 및 자동 변경 비교를 중단함
- ApuDa가 NCCN의 공식 파트너·후원 서비스로 오인되지 않도록 제휴/후원 관계가 없음을 명시함
- NCCN 권고와 국내 MFDS 허가 및 HIRA 급여기준을 별도 정보로 표시함

## 재개 조건

NCCN 버전/변경사항 자동 모니터링, 콘텐츠 요약, 표/알고리즘 표시 등은 아래 중 하나가 확인된 경우에만 재개한다.

1. NCCN의 명시적인 서면 사용 허가
2. NCCN이 제공하는 적법한 API/라이선스 피드
3. 별도 이용계약상 ApuDa의 사용 범위가 명확히 허용된 경우

허가를 받은 경우에도 허용 범위와 표시 의무를 코드 및 UI에 반영한 뒤 배포한다.

## 공식 링크

- 환자용: https://www.nccn.org/patientguidelines
- 전문가용: https://www.nccn.org/guidelines/category_1
- 업데이트 안내: https://www.nccn.org/updates
- 권한이 필요한 재사용은 NCCN Permissions 절차를 통해 확인
