## Netlify 무료 요금제 배포 장애

기존 `public-site/netlify/database/migrations/` 아래 파일은 Netlify Database의 자동 초기화를 유발했고, 해당 계정은 데이터베이스 기능 사용 권한이 없어 `createSiteDatabase 403 Forbidden` 및 빌드 종료 코드 4가 발생함. 이 디렉터리 밖으로 스키마 파일을 보존하여 **자동 DB 프로비저닝(automatic database provisioning)** 단계만 회피함.

이번 변경은 데이터베이스 삭제(DROP), 계정 삭제, 논술 기록 변경 또는 요금제 전환을 실행하지 않음. 기존에 별도 외부 데이터베이스가 존재한다면 그 데이터 역시 이 코드 변경으로 삭제되지 않음.

## 논술 기록 보호 운영 지침

1. 이전에 논술을 작성한 동일 브라우저에서 기존 앱의 **나의 기록 → 기록 내보내기**로 JSON 백업 파일을 먼저 다운로드할 것.
2. 백업 확인 전 해당 브라우저의 사이트 데이터/쿠키/로컬 저장소를 지우거나 다른 기기에서 원본을 덮어쓰지 말 것.
3. 필요하면 **백업 불러오기** 기능으로 복원 가능 여부를 확인할 것. 사용자가 확인하지 않은 기존 기록을 삭제하지 말 것.
4. `@netlify/database`를 사용하는 `nonsul-state` 클라우드 동기화 API는 해당 무료 계정에서 503/403이 발생할 수 있음. **클라우드 동기화 성공을 가정하지 말고** 기기 기록과 JSON 백업을 유지할 것.
5. 추후 데이터베이스 연결이 승인된 환경으로 이전한다면 이 SQL 스키마를 다시 적용하되, 기존 사용자 데이터를 먼저 백업하고 별도 마이그레이션 계획을 검증할 것.
